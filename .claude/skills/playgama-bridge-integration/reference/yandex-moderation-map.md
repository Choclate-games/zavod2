# Требования Яндекс Игр → чем закрываются в игре на Playgama Bridge

Таблица нужна, чтобы разбирать вывод `yandex-games-debug-checker` осмысленно.
Чекер написан под прямой Yandex SDK; игра на мосту вызывает его внутри
бандла. Колонка «кто закрывает» разделяет: что делает мост сам, что игра
обязана сделать своими руками, и что чекер физически не увидит статикой.

Источники требований (на момент аудита чекера, 11.08.2026):
`yandex.ru/dev/games/doc/ru/concepts/requirements`, `.../moderation`.

| Пункт | Требование | Кто закрывает | Как проверяется |
|---|---|---|---|
| 1.1 | Подключён `/sdk.js` | Мост, динамически | runtime: `bridge.platform.id === 'yandex'` |
| 1.19.1 | `YaGames.init()` | Мост, внутри `initialize()` | runtime: `bridge.isInitialized` |
| 1.19.2 | `LoadingAPI.ready()` после полной загрузки | **Игра**: `sendMessage(GAME_READY)` ровно один раз | runtime: перехват `sendMessage`, порядок и счётчик |
| 1.19 | Ввод закрыт до `ready()` | **Игра**: кнопки `disabled` до `game_ready` | runtime: клик по меню до ready не меняет состояние |
| 1.9 | Сохранение прогресса | **Игра**: `bridge.storage`, зеркало в `localStorage` | runtime: запись → перезагрузка → чтение |
| 1.3 | Звук глушится на скрытой вкладке | **Игра**: `AUDIO_STATE_CHANGED` + `visibilitychange` | runtime: подписка существует и вызвана |
| 4.7 | Звук и геймплей встают на время рекламы | **Игра**: `PAUSE_STATE_CHANGED` + состояния рекламы | runtime: `interstitial opened` → игра на паузе |
| 4.4 | Расположение рекламы | **Игра**: баннер только вне игрового поля | вручную (`docs/manual-checklist.md` чекера) |
| 2.14 | Язык из SDK, не хардкод | **Игра**: `bridge.platform.language` до интерактивности | runtime: чтение `platform.language` до `game_ready` |
| 2.14 | Фолбэк `be/kk/uk/uz → ru` | **Игра** | статически, через `YGDebugCheckerConfig.resolveLanguage` |
| 1.6.2.7 | Нет контекстного меню и выделения текста | **Игра** (мост дублирует, но поздно и внутри бандла) | статически по CSS/HTML игры |
| 1.10.2 | Нет прокрутки страницы и swipe-to-refresh | **Игра**: `overflow:hidden` + `overscroll-behavior:none` | статически по CSS игры |
| 1.6.1.1 | Полный экран на мобильном | **Игра**: `viewport-fit=cover`, корень на `100%` | статически + runtime-замер |
| 1.6.2.2 | На десктопе поле не длиннее 2:1 | **Игра** | runtime-замер канваса |
| 1.13.2 | Цены покупок из каталога SDK | **Игра**: `payments.getCatalog()` | статически: нет хардкода `₽/$/€` рядом с числами |
| 1.7 | Только относительные пути, без S3-ссылок | **Игра**: `base: './'` в vite | статически |
| 1.15 | Игра выглядит законченной, без debug-панелей | **Игра** | статически + глазами |
| 1.16 | Нет имитации рекламных блоков | **Игра** | статически |
| 1.18 | Нет привязки к домену | **Игра** | статически |
| 1.6.1.6 / 1.6.2.5 | Музыка через Web Audio, не `<audio>`/`new Audio()` | **Игра** | статически |
| 1.6.1.7 | Нет сообщения «включите WebGL» | **Игра** | статически |
| 1.6.2.6 | Нет обработчиков Ctrl/Alt/Meta+клавиша | **Игра** | статически |
| — | Управление по `e.code`, не `e.key` (русская раскладка) | **Игра** | статически |

## Пункты, которые чекер помечает `NOT VERIFIED` у игры на мосту

Это не дефекты. Мост вызывает Yandex SDK динамически, поэтому статический
grep по исходникам игры не находит `YaGames.init` / `LoadingAPI.ready`.
`verify-playgama.mjs` закрывает их своим runtime-наблюдением и печатает их
отдельным блоком `bridge-mediated`.

Категорически нельзя «чинить» это, добавляя в исходники мёртвые строки
вроде `// YaGames.init()` ради grep-а чекера. Это подгонка под инструмент,
а не под требование.

## Что чекер не проверит никогда

`docs/limitations.md` чекера: содержательная корректность геймплея,
промоматериалы, фактический round-trip сохранений, бизнес-правила покупок.
Перед отправкой игры проходится `docs/manual-checklist.md`.
