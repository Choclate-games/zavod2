# Уроки фабрики: на чём игры спотыкаются на самом деле

Документ собирается автоматически из отчётов приёмки всех игр (`.factory/gate.json`). Это не теория и не советы вообще — это список того, что уже ломалось в выпущенных проектах, с указанием, у скольких игр именно эта проверка была красной.

Обновлено: 25.08.2026. Игр с приёмкой: 0, из них зелёных: 0.

## Пока учиться не на чем

Ни одна игра ещё не прошла приёмку фабрики, либо все прогоны были зелёными. Список наполнится сам, как только появятся красные.

## Чек-лист

- [ ] `npm run build` проходит начисто — до того, как работа считается сделанной
- [ ] Консоль игры пуста при запуске: ни одного исключения в первые секунды
- [ ] Игровой цикл не встаёт после ввода — кадры идут и через минуту игры
- [ ] В кадре что-то есть: сцена, свет и камера сведены, отрисовка не нулевая
- [ ] Игра переживает клавиши, мышь и палец, а не только показ первого кадра
- [ ] На экране 390×844 ничего не вылезает за ширину и не требует горизонтальной прокрутки
- [ ] Интерфейс виден: корни экранов вставлены в документ, а не только созданы
- [ ] Каждый импорт объявлен: `.css` и ассеты не роняют строгую сборку
- [ ] Раздел 0 приёмки закрыт: игра про то, что заказал пользователь
