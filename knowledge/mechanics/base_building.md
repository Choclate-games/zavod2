# Mechanic: Grid & Freeform Base Building

Name: Grid & Freeform Base Building
Category: Strategy & Building
Description: Placing defense structures (walls, automated ballistas, flame traps, healing shrines, crystal pylons) on a grid or radial boundary during preparation phases or on-the-fly.

Player interaction:
Radial build wheel or quick hotbar. Tap/drag to place, repair, or upgrade structures with collected scrap/gold.

Feedback:
- Holographic placement projection with green (valid) / red (blocked) shader.
- Thumping construction animation with dust puffs.
- Structure health bars visible on damaged buildings.

Strengths:
- Long-term tactical investment.
- Massive player agency and creative defense layouts.

Weaknesses:
- UI complexity on small mobile screens.

Good combinations:
- Wave survival.
- Resource mining.

Technical complexity:
Moderate. Spatial occupancy grid + navigation mesh dynamic recalculation / obstacle tagging.

Three.js suitability:
High (8.5/10).

PixiJS suitability:
Very High (9.5/10).

Retention potential:
High.
