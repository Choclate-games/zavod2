# Pattern: Builder Defense Loop

Pattern Name: Builder Defense Loop
Primary Genre: Base Defense / Tower Defense Hybrid

Starting State:
Central core/base with finite power and starter defensive perimeter.

Player Action:
- Phase A (Mining / Building): Gather resources, place turrets, upgrade power grid, fortify walls.
- Phase B (Defense Wave): Pilot unit / trigger defenses to repel incoming alien or enemy swarm.

Challenge:
- Swarms target core structures; multi-directional assault paths; flying / tunneling enemy variants.

Reward:
- Rare mineral veins discovered, tech blueprints unlocked.

Progression:
- Tech tree research (automated repair drones, laser grids, plasma artillery).

Escalation:
- Colossal siege behemoths that can bypass basic walls.

Session Ending:
- Evacuation rocket launch victory or base core collapse.

Replay Trigger:
- Different planetary maps, endless wave survival mode.
