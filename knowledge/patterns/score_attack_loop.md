# Pattern: Score Attack Loop

Pattern Name: Score Attack Loop
Primary Genre: Arcade / Endless Runner / Combo Chaser

Starting State:
Clean score multiplier (1.0x), basic speed, full lives.

Player Action:
- Execute high-risk actions (near-miss dodges, continuous kills, perfect parries) to sustain combo multiplier timer.

Challenge:
- Speed accelerates continuously; margin for error shrinks to milliseconds.

Reward:
- Exponential score escalation, fever mode activation (temporary invincibility and point explosion).

Progression:
- High score milestones unlock cosmetic trails and arena themes.

Escalation:
- Screen-speed increases, hazard frequency peaks.

Session Ending:
- Instant game over on collision, immediate Playgama leaderboard submission.

Replay Trigger:
- Instant restart button with zero load time ("Just one more run").
