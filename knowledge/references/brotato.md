# Reference Game: Brotato

Game: Brotato
Genre: Top-Down Arena Shooter Roguelite
Core loop: 60-second arena wave -> Shop phase (buy items, reroll, lock) -> Next wave -> Boss wave 20.
Core mechanic: 6-weapon loadout, stat synergy trades (+Attack Speed but -Damage), tight boundary maneuvering.
Progression: Character unlock matrix with radically different rules (e.g. Pacifist, One-Armed, Bull).
Retention: High build variety and instant restart loop.
Monetization: Premium base or ad-supported mobile version with rewarded rerolls.
Visual identity: Expressive potato character vector sprites on clean grid arena.
Why it works: Crisp 60-second wave intervals provide constant micro-milestones.
What can be learned: Trade-off mechanics make every shop choice interesting and risky.
What should NOT be copied: Flat visual arenas without interactive cover or physical props.
