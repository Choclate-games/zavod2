# Reference Game: Dome Keeper

Game: Dome Keeper
Genre: Mining Roguelite & Base Defense
Core loop: Dig into planetary crust -> Mine iron, cobalt, water -> Carry resources to dome -> Purchase tech upgrades -> Sprint back to surface -> Man dome laser to repel wave.
Core mechanic: Split-phase tension loop: deep exploration vs urgent defensive defense.
Progression: Tech tree unlocking dome shields, teleporters, resource lift drones, super weapons.
Retention: High atmosphere, risk/reward mining decisions ("Can I dig one more block before the wave alarm?").
Monetization: Premium base / rewarded boosters in web port.
Visual identity: Atmospheric pixel art with high-contrast lighting and deep subterranean soundscape.
Why it works: Perfectly tuned audio warning cue and time budget creating genuine urgency.
What can be learned: Combining two contrasting loops (peaceful mining + high-stakes shooter defense) multiplies player engagement.
What should NOT be copied: Slow dragging physics without carrying capacity upgrades early in the run.
