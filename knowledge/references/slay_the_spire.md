# Reference Game: Slay the Spire

Game: Slay the Spire
Genre: Roguelike Deckbuilder
Core loop: Draw hand -> Spend energy on attacks/blocks/powers -> Defeat enemy -> Add 1 card to deck -> Navigate spire path -> Boss relic.
Core mechanic: Intent system (showing enemy next turn move), energy management, relic synergy cascades.
Progression: Deck refinement, removal of basic strikes, ascension climbing.
Retention: Immense tactical depth, endless permutations of relic and card combos.
Monetization: Premium / web trial.
Visual identity: Hand-drawn 2D fantasy illustrations with clean card layout and status buff badges.
Why it works: Complete transparency of enemy intent transforms combat into a satisfying puzzle.
What can be learned: Clear telegraphing of enemy moves allows players to make informed tactical decisions.
What should NOT be copied: Cluttered text descriptions that require zooming on mobile screens.
