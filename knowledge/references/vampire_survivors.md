# Reference Game: Vampire Survivors

Game: Vampire Survivors
Genre: Horde Survival Roguelite
Core loop: Move -> Avoid horde -> Auto-attack -> Collect XP -> Pick 1 of 3 upgrades -> Evolve weapons -> Survive 30 min.
Core mechanic: Auto-firing weapons with radial coverage, XP magnet gem collection, exponential upgrade scaling.
Progression: Mid-run weapon level 8 evolution pairs; meta gold shop with persistent stat tiers.
Retention: "Power fantasy escalation" - going from struggling against 3 bats to annihilating 5,000 monsters per second.
Monetization: Free-to-play with rewarded revive and optional character DLCs.
Visual identity: Retro 2D pixel sprites, dense swarm rendering, golden treasure chest animations.
Why it works: Zero friction entry combined with slot-machine sensory reward loops.
What can be learned: Clear evolution formulas and immediate audio-visual reward on level up create intense flow state.
What should NOT be copied: Static repetitive background tiles; lack of active dodging mechanics in late game.
