# QA & Testing Plan: Биослизь: Королевская Охота 3D

## 1. Functional Test Matrix
- [ ] Проверка корректности поглощения: только объекты меньше игрока исчезают и увеличивают массу
- [ ] Проверка работы таймера и появления боссов строго на 3:00, 6:00, 9:00 и 10:00
- [ ] Проверка выбора всех доступных мутаций и корректности применения их модификаторов
- [ ] Проверка работы паузы при открытии рекламного окна и переключении вкладки
- [ ] Проверка сохранения и загрузки очков ДНК и купленных генов через Playgama Cloud

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS на десктопных браузерах Chrome/Firefox/Safari
- [ ] Не менее 50-60 FPS на мобильных устройствах среднего уровня (iPhone 11 / Snapdragon 720G)
- [ ] Потребление оперативной памяти вкладки не более 180 МБ
- [ ] Время первичной загрузки ассетов не более 2.5 секунд при 4G соединении

## 3. Target Browser Matrix
- Google Chrome (Desktop / Android)
- Safari (iOS 15+ / macOS)
- Яндекс.Браузер (Desktop / Android)
- Mozilla Firefox
- Samsung Internet
