# Skill: Процедурный шейдер деформации слизи на Three.js

## Purpose
Обеспечение физически правдоподобного эффекта колыхания, сквоша и подповерхностного свечения слизи на базе кастомного ShaderMaterial.

## When to Use
При создании меша главного персонажа, миньонов-слизней и эффекта поглощения.

## Core Rules & Constraints
- Вычислять смещение вершин в вертексном шейдере на основе 3D Simplex Noise и вектора скорости.
- Использовать нормали для создания эффекта полупрозрачного френелевского свечения на гранях.

## System Architecture
Custom ShaderMaterial с uniform-переменными: uTime, uVelocity, uSquashFactor, uColorPrimary, uColorCore.

## Implementation Guidance
Передавать вектор ускорения из физического контроллера в материал каждый кадр с плавной экспоненциальной интерполяцией (lerp).

## Common Mistakes to Avoid
- ❌ **Mistake**: Пересчет нормалей на CPU вместо GPU (убивает производительность)
- ❌ **Mistake**: Отсутствие ограничения амплитуды шума, приводящее к самопересечению полигонов

## Validation Checklist
- [ ] Проверить работу на мобильном WebGL 1.0/2.0
- [ ] Убедиться в отсутствии лагов при быстром изменении масштаба меша
