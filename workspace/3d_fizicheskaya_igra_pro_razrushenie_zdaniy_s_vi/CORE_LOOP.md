# Core Loop Design: Сейсмо-Домино: Точечный Снос

## 1. Чем эта петля отличается
- **Фирменный момент**: Момент, когда на 14-м уровне «Нео-Сибуя» игрок рассекает диагональным клином 45° опору центрального 70-этажного небоскрёба: время замедляется на 0.25x, камера даёт кинематографичный наезд на трескающийся бетон, верхушка башни с громоподобным металлическим стоном сносит стеклянный купол торгового центра, тот падает на две жилые башни-близнецы, и весь квартал из 5 зданий за 7.2 секунды аккуратно схлопывается внутрь защитного периметра под перезвон идеального комбо «100% SECTOR COLLAPSE».
- **Отличие от жанрового шаблона**: В отличие от традиционных физических разрушалок с отстрелом блоков, здесь игрок манипулирует векторной плоскостью среза и смещением 3D-центра масс (Center-of-Mass). Здания обладают реалистичным тензором инерции и монолитностью, не рассыпаясь в кашу сразу, а падая как гигантские жесткие рычаги-домино, которые передают сотни тысяч тонн кинетической энергии соседним конструкциям, требуя расчета угла падения, высоты среза и времени детонации сейсмических микрозадержек.
- **Сознательно НЕ берём**: Отвергаем шаблон «беспорядочный кликер взрывов» (размещение десятков динамитных шашек по всему фасаду, как в Demolition Company / спам бомбами) и «аркадную рогатку» (выстрел шаром-тараном по постройке). В нашей игре разрушение — это не хаотичный спам снарядов, а детерминированная тактическая геометрия одного точного кинетического надреза (1–2 клина на уровень), где гравитация и масса самих зданий выступают главным оружием каскада.

## 2. Схема петли
```text
+-----------------------------------------------------------------------------------+
|                        СЕЙСМО-ДОМИНО: СИСТЕМА ТОЧЕЧНОГО СНОСА                     |
+-----------------------------------------------------------------------------------+
                                        |
  [ MACRO ]                             v
  +-------------------------------------------------------------------------------+
  |  Глобальная карта мегаполиса -> Выбор квартала-контракта -> Звездный ранг    |
  +-------------------------------------------------------------------------------+
         |                                                               ^
         v                                                               |
  [ MESO ]                                                               |
  +--------------------------------------------------------------------+ |
  | 1. Анализ топологии квартала и границ охранного периметра          | |
  | 2. Распределение лимита зарядов (1-2 клина / сейсмо-задержки)      | |
  | 3. Оценка результата: % обрушения (>=95%) и чистота периметра      |-+
  +--------------------------------------------------------------------+
         |                                                               ^
         v                                                               |
  [ MICRO ]                                                              |
  +--------------------------------------------------------------------+ |
  | [Осмотр опоры] ---> [Drag-to-Cut срез] ---> [Прогноз дуги масс]   | |
  |       ^                      |                        |            | |
  |       |                      v                        v            | |
  |   (Коррекция)        [Пуск клина Rapier3D] -> [Кинетический удар]  | |
  |       |                      |                        |            | |
  |       +--- (Рестарт [R]) <---+                        v            | |
  |                                            [Каскадный снос домино] | |
  |                                                       |            | |
  |                                                       v            | |
  |                                              [100% зачистка сектора]-+
  +--------------------------------------------------------------------+
```

## 6. Кривая напряжения
Напряжение строится по принципу взведенной пружины: Фаза 1 (Штиль и расчет, 0–5 с) — тихий эмбиент, игрок вдумчиво крутит камеру и целится лазерным срезом; Фаза 2 (Спуск курка, 5–6 с) — резкий щелчок клина, взрыв пиропатрона, замирание звука на 0.2 с (pre-impact silence); Фаза 3 (Пик кинетической кульминации, 6–11 с) — оглушительный низкочастотный гул, замедленный крен гиганта, лавинообразное крушение соседних башен, экранотряска и нарастание торжественного аккорда; Фаза 4 (Катарсис и разрядка, 11–13 с) — оседание пылевого облака, глухой финальный стук последнего обломка, чистый звон победных звезд и счетчика 100%.

## 7. Формулы ядра
- `F_shear = M_building * g * sin(theta_cut) + F_wedge_impulse — Сила начального соскальзывания срезанного блока по наклонной плоскости (Н), где M_building — масса блока (кг), g = 9.81 м/с², theta_cut — угол среза (градусы), F_wedge_impulse = 850 кН.`
- `tau_torque = M_building * g * (H_com * sin(alpha_tilt)) — Опрокидывающий гравитационный момент здания (Н·м), где H_com — высота центра масс (м), alpha_tilt — текущий угол отклонения оси башни от вертикали (градусы).`
- `E_impact = 0.5 * I_rot * omega^2 + 0.5 * M_building * v_com^2 — Кинетическая энергия удара падающей башни в соседнее сооружение (Дж), где I_rot — момент инерции башни относительно точки вращения (кг·м²), omega — угловая скорость (рад/с), v_com — линейная скорость центра масс (м/с).`
- `Damage_received = E_impact / R_structural_integrity — Расчет повреждения несущего каркаса принимающего здания; при Damage_received >= 1.0 (порог 15.0 МДж) здание теряет устойчивость и переходит в динамическое падение.`
- `Score_contract = (Collapse_ratio * 1000) + (Unused_charges * 500) - (Debris_perimeter_breach * 250) + (Chain_combo_multiplier * 300) — Итоговый расчет очков за контракт демонтажа квартала.`
