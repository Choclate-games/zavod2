# DESIGN.md — Сейсмо-Домино: Точечный Снос

Дизайн-документ игры. Написан до первой строчки кода. Числа геймплея живут в
`balance.yaml`, здесь — только замысел.

---

## 1. Как игра выглядит (одна фраза)

Закатный финансовый квартал из зеркальных высоток, нарисованный тёплым янтарным
солнцем и холодной бирюзовой инженерной разметкой: игрок видит тёмно-графитовый
HUD чертёжного стиля поверх живого 3D-города, и одна светящаяся лазерная линия
среза — бирюзовая или тревожно-красная — это главный цветовой акцент кадра.

## 2. Палитра

Пять цветов с ролями; они же становятся токенами `src/ui/theme.css`:

| Роль | HEX | Где видна |
|---|---|---|
| Фон / подложка панелей | `#1A202C` | Панели HUD, модалки, подложки текста |
| Поверхность выше фона | `#232B3A` | Кнопки, строки списка уровней, диски задержки |
| Текст основной | `#E8EDF4` | Заголовки, числа телеметрии |
| Интерактивный акцент | `#00E5FF` | Лазер среза, кнопки действий, сетка напряжения |
| Опасность | `#FF1744` | Выход за периметр, критический наклон, удаление |
| Успех / звёзды | `#FFC107` | Звёзды зачистки, счётчик 100%, победный аккорд |
| Закатный свет | `#FFA726` | DirectionalLight сцены, тёплые блики фасадов |

Один цвет = один смысл: бирюзовый — «можно трогать», красный — «ошибка/опасность»,
янтарный — «награда». Вторых акцентов на экране одновременно не бывает.

## 3. Камера и свет

- **Камера**: перспективная, FOV 45°, орбитальная тактическая: смотрит на центр
  квартала сверху-сбоку под углом ~35–45°, радиус 60–140 м по размеру сектора.
  Орбиту вращает игрок (ПКМ / два пальца); после пуска клина камера плавно
  доезжает до эпицентра столкновения. В портрете вертикальный FOV пересчитывается,
  чтобы горизонтальный охват не схлопывался.
- **Свет**: один направленный источник — низкое закатное солнце (#FFA726) с картой
  теней 1024; заполняет HemisphereLight (#4DD0E1 небо / #263238 земля). Неоновые
  акценты (#00E5FF) — эмиссивные материалы сетки напряжения и лазера, не источники
  света.
- **Читаемость на телефоне**: pixelRatio ≤ 1.5, тени только от солнца, здания —
  боксы с одной канвас-текстурой окон, обломки — InstancedMesh. Силуэт башни
  читается на расстоянии формой (шаг высот, шпиль), а не цветом.

## 4. Экраны

Переходы: `SplashScreen → LevelSelectScreen → GameplayHUD ⇄ (VictoryModal |
DefeatModal) → LevelSelectScreen`. Один экран виден за раз, скрытый —
`display:none`. Каждый экран имеет три зоны и состояния загрузка/пусто/ошибка.

- **SplashScreen** (overlay): название игры + прогресс реальных вех загрузки.
  Главное действие не требуется — экран уходит сам на 100%. Подложка только под
  логотипом; за ним видна живая сцена.
- **LevelSelectScreen** (screen): заголовок «Сектора»; сетка карточек 25 уровней
  со звёздами (главная зона); главное действие — кнопка следующего непройденного
  уровня (крупная, бирюзовая); второстепенный ряд — кнопка паузы звука. За сеткой
  виден город.
- **GameplayHUD** (hud): TopLeft — заряды клиньев и номер сектора; TopRight —
  шкала % зачистки и пауза; BottomRight — рестарт (R) и переключение ракурса;
  Center — диегетическая лазерная линия среза. HUD никогда не кликается.
- **VictoryModal** (modal): заголовок «Сектор снесён», анимация звёзд, очки по
  формуле контракта; главное действие — «Следующий сектор»; второстепенное —
  «В меню» и «Повторить».
- **DefeatModal** (modal): причина провала (мало разрушения / обломки за
  периметром); главное действие — «Повторить»; второстепенное — «В меню», и —
  только если площадка поддерживает rewarded и зачистка ≥85% — кнопка
  «+1 клин за рекламу».

## 5. Сцена за меню

Живая игровая сцена на пониженной нагрузке: камера медленно облетает
полуразрушенный закатный небоскрёб, сквозь стеклянный фасад пробиваются лучи
солнца, мягко оседают частицы пыли (тот же InstancedMesh-пул, что в игре).
Никакой непрозрачной заливки поверх канваса: подложка допускается только под
текстовым блоком и кнопками. Игровой цикл крутится, свет живёт, пыль падает.

## 6. Управление: таблица глаголов

Каждому глаголу — клавиша/жест мыши И тач-эквивалент, плюс видимый отклик.
Активную схему выбирает `bridge.device.type`; `?input=touch|desktop` принудительно.

| Глагол | Клавиатура + мышь | Тач | Отклик |
|---|---|---|---|
| Векторный Срез Опорного Пилона | ЛКМ на пилоне, протянуть вектор, отпустить | Свайп поперёк колонны | Лазерная линия среза следует пальцу, тон гидронасоса растёт, вспышка плазмы на отпускании |
| Прогноз дуги центров масс | Пассивно при удержании ЛКМ | Пассивно при удержании свайпа | Бирюзовая пунктирная дуга из 32 точек; красная при выходе за периметр |
| Орбитальная камера | ПКМ / Пробел + движение мыши | Два пальца | Плавный орбитальный доворот вокруг центра сектора |
| Сейсмический клин задержки | ПКМ (или кнопка клина) по колонне чужого здания | Двойной тап по колонне | Голограмма заряда + диск таймера; −/+ меняют задержку 0.5–3.0 с |
| Рестарт уровня | R | Кнопка рестарта (BottomRight) | Мгновенный телепорт тел в начальное состояние |
| Пауза | Esc / P | Кнопка паузы (TopRight) | Модалка паузы поверх живой сцены |
| Переключение ракурса | C | Кнопка ракурса (BottomRight) | Камера между общим планом и ближним |

Вертикальных глаголов (прыжок, присед) в игре нет и уровень их не обещает:
игрок — инженер-оператор, а не персонаж на арене; единственная вертикаль —
гравитация самих зданий.

## 7. Правила интерфейса

- Все значения — токены `src/ui/theme.css`; литералы цвета/z-index вне темы запрещены.
- Слои над канвасом прозрачны для ввода (`pointer-events:none`), интерактивны только листья.
- Кнопки ≥64 px, главная ≥96 px, зазор ≥12 px; safe-area + измеренная высота баннера.
- Меняющиеся числа — `tabular-nums` в слоте фиксированной ширины; полосы — `scaleX`.
- Иконки — инлайновый SVG c `currentColor`; эмодзи, alert/confirm/prompt запрещены.
- Возможность, которой нет на площадке, не рисуется вовсе.
