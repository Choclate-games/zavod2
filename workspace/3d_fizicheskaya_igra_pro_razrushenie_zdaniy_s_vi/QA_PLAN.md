# QA & Testing Plan: Сейсмо-Домино: Точечный Снос

## 1. Functional Test Matrix
- [ ] Тест точности вектора среза: соответствие угла жеста углу физического импульса в Rapier3D
- [ ] Тест каскадного обрушения: проверка передачи кинетической энергии при столкновении мешей
- [ ] Тест условий победы/поражения: начисление 3 звезд при 100% сносе за 1 заряд
- [ ] Тест лимита зарядов: блокировка среза при исчерпании клиньев
- [ ] Тест облачного сохранения: корректная запись и чтение массива звезд уровней через Playgama Bridge

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS на средних мобильных устройствах (iOS Safari / Android Chrome) при симуляции 50 физических тел
- [ ] Лимит триангуляции сцены: не более 45 000 полигонов на уровень
- [ ] Лимит Draw Calls: не более 80 за счет батчинга и InstancedMesh
- [ ] Время первоначальной загрузки бандла: менее 2.5 секунд на 4G-соединении

## 3. Target Browser Matrix
- Google Chrome 120+ (Desktop & Mobile, Windows, macOS, Android)
- Apple Safari 17+ (iOS 16+, iPadOS, macOS)
- Mozilla Firefox 120+ (Desktop)
- Yandex Browser (Desktop & Mobile, WebGL 2.0 / WASM)
