# UI/UX Specification: Сейсмо-Домино: Точечный Снос

## 1. Материал интерфейса
Интерфейс живёт в том же мире, что и сцена. Проверка: если закрыть игровое поле,
меню обязано выдавать именно эту игру, а не любую другую.

- **Тема от арт-директора**: Минималистичный высокотехнологичный инженерный HUD (Dark Sci-Fi Blueprint / Industrial Clean)
- **Визуальный язык**: Инженерный брутализм с четкой контрастной типографикой, темно-графитовой подложкой и яркими бирюзово-янтарными акцентами.
- **Типографика**: Primary: 'Inter', sans-serif для числовых индикаторов и текста; Secondary: 'JetBrains Mono' для инженерных телеметрий, градусов и процентов.

## 2. Акценты: один цвет — один смысл
Разный цвет у каждой кнопки «чтобы отличались» — главная ошибка игрового
интерфейса. На одном экране одновременно видно не больше двух акцентов.

| Токен | Единственный смысл |
|---|---|
| `Background` | #1A202C (Темно-серые подложки панелей) |
| `Danger/Destruction` | #FF1744 (Критические зоны напряжения и разрушения) |
| `Interactive` | #00E5FF (Интерактивные узлы среза и лазерные направляющие) |
| `Success/Stars` | #FFC107 (Звезды победы и процент зачистки 100%) |

Все значения — токенами в `src/ui/theme.css`: цвета, гарнитуры, шкала отступов,
радиусы, длительности, порядок слоёв `--z-*`. Литерал цвета внутри экрана — баг.

## 3. Композиция экрана
Меню и экраны между сессиями лежат ПОВЕРХ живой игровой сцены — той же, что в
игре, только с медленной камерой. Непрозрачная заливка на весь экран запрещена:
подложка только под текстом и кнопками.

- **Сцена за меню**: Камера медленно облетает полуразрушенный залитый закатом небоскреб, сквозь стеклянный фасад которого пробиваются лучи солнца и мягко оседают пылевые частицы

Экран — не колонка кнопок по центру. Три зоны, и каждый элемент лежит ровно в одной:

1. **Идентичность** — что это за экран: заголовок, режим, состояние игрока.
2. **Главное действие** — ровно одно на экран, самое крупное и единственное с
   основным акцентом.
3. **Второстепенный ряд** — всё остальное, одним рядом или сеткой, одним весом.

Зоны нажатия: основная ≥ 96 px, остальные ≥ 64 px, зазор ≥ 12 px, отступы через
`env(safe-area-inset-*)` плюс измеренная высота липкого баннера. Ни один экран не
скроллит страницу: длинный список скроллится во внутреннем контейнере.

## 4. Набор компонентов (закрытый)
Всё на экране — один из этих компонентов. Одноразовый `<div>` с инлайновыми
стилями — это то, из-за чего второй экран перестаёт совпадать с первым.

- ChargeIndicator
- DestructionMeter
- CuttingGizmo
- RestartButton
- RatingStarsBadge

Каждый интерактивный компонент несёт пять состояний: покой, наведение, нажатие,
недоступность, `:focus-visible`; асинхронное действие — ещё и `loading`.

## 5. HUD
Не больше пяти постоянных элементов на телефоне. Пять якорей, посередине экрана
не висит ничего, кроме временной обратной связи.

| Якорь | Что там |
|---|---|
| `BottomRight` | Кнопка мгновенного рестарта (R) и переключения ракурса |
| `Center` | Диегетический вектор среза на выбранной колонне |
| `TopLeft` | Индикатор зарядов клиньев и номер сектора/контракта |
| `TopRight` | Шкала процента зачистки (0–100%) и кнопка паузы |

Элементы:
- Индикатор оставшихся зарядов клиньев (иконки заряженных гидравлических поршней)
- Круговой прогресс-бар процента зачистки сектора (0% -> 100%)
- Диегетический вектор среза с отображением угла наклона в градусах
- Кнопка быстрого рестарта уровня (Instant Reset)
- Кнопка переключения ракурса камеры / свободного вращения

Меняющиеся числа — `tabular-nums` в слоте фиксированной ширины, полосы —
`transform: scaleX()`, а не `width`. Текст поверх геймплея всегда с подложкой или
обводкой: белое число исчезает на светлой сцене.

## 6. Состояние, показанное миром, а не оверлеем
- Голографическая бирюзовая сетка напряжения прямо на теле колонн
- Лазерная линия среза, проецируемая на геометрию здания
- Цифровые индикаторы градусов наклона, парящие рядом с точкой среза

## 7. Каталог экранов
### Экран: SplashScreen
- **Что на экране**: Экран мгновенной загрузки с логотипом и инициализацией Playgama Bridge.; type: overlay
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: LevelSelectScreen
- **Что на экране**: Изометрическая карта мегаполиса с разделением на сектора и отображением 3-звездочного прогресса.; type: screen
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: GameplayHUD
- **Что на экране**: Минималистичный игровой интерфейс с индикатором зарядов, шкалой разрушения и подсказкой жеста.; type: hud
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: VictoryModal
- **Что на экране**: Победный экран с анимацией звезд зачистки, подсчетом очков за комбо и кнопкой перехода к следующему уровню.; type: modal
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: DefeatModal
- **Что на экране**: Экран недостаточного разрушения с кнопкой мгновенного повтора или взятия дополнительного клина за Rewarded Video.; type: modal
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

**Переходы**: SplashScreen -> LevelSelectScreen -> GameplayHUD <-> (VictoryModal | DefeatModal) -> LevelSelectScreen

## 8. Состояния экрана
- AimingState: активен гизмо среза, время идет со скоростью 1.0 (без таймера спешки)
- CuttingState: моментальный импульс, отключение ввода прицеливания
- PhysicsSimulationState: активна честная физика Rapier3D, камера плавно следит за каскадом
- EvaluationState: фиксация покоя тел, показ победного/повторного экрана

## 9. Отклик и движение
- Зажатие пальца на узле -> тактильная микро-вибрация и вспышка голографической сетки напряжения
- Протяжка вектора -> плавное изменение звукового тона гидронасоса и перекрашивание лазера
- Отрыв пальца -> вспышка плазменной резки, мощный кинетический глухой удар и тряска экрана
- Столкновение башен -> слоу-мо хит-стоп на 80мс, звук сминаемого металла и разлёт стекла
- Достижение 100% зачистки -> триумфальный звуковой аккорд и каскад золотых искр

Переход один на всю игру и укладывается в 300 мс; анимируются только `transform`
и `opacity`; `prefers-reduced-motion: reduce` убирает трансформации.

## 11. Чек-лист приёмки интерфейса
- [ ] Ни одного литерала цвета, шрифта, радиуса или длительности вне `theme.css`.
- [ ] Слои над канвасом не перехватывают игровой ввод: контейнеры `pointer-events: none`.
- [ ] Каждый экран помещается в измеренный вьюпорт, страница не скроллится.
- [ ] Одно главное действие на экран, не больше двух акцентов одновременно.
- [ ] Меняющиеся числа не дёргают строку HUD.
- [ ] У каждого экрана описаны загрузка, пустота и ошибка.
- [ ] Возможность, которой нет на площадке, не нарисована вовсе.
- [ ] Ни `alert`/`confirm`, ни эмодзи вместо иконок, ни `z-index` мимо токенов.
- [ ] Самая длинная переведённая строка помещается в кнопку.
- [ ] За меню видна живая сцена игры, а не заливка цветом.
- [ ] Ни одного эмодзи в подписи кнопки: иконка — инлайновый SVG с `currentColor`.
- [ ] У каждого экрана расписаны три зоны, а не «карточка по центру».
- [ ] С закрытым игровым полем меню всё ещё узнаётся как «Сейсмо-Домино: Точечный Снос».
