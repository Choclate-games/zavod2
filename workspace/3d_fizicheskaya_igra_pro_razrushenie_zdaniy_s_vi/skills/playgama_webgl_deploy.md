# Skill: Интеграция Playgama Bridge и Оптимизация WebGL

## Purpose
Стандарт развертывания веб-билда с поддержкой рекламы, облачных сохранений и стабильного фреймрейта.

## When to Use
При интеграции SDK платформ и подготовке релизного бандла.

## Core Rules & Constraints
- Размер бандла до 4.5 МБ
- Корректная пауза физики и звука при показе рекламы
- Изолированное хранение сейвов

## System Architecture
Событийно-ориентированный адаптер платформы с фоллбэком на LocalStorage

## Implementation Guidance
Инициализировать Playgama SDK до загрузки тяжелых 3D-ассетов

## Common Mistakes to Avoid
- ❌ **Mistake**: Неотжатые звуки во время интерстишела
- ❌ **Mistake**: Блокировка UI при медленном ответе сети

## Validation Checklist
- [ ] Проверено ли восстановление WebGL-контекста?
- [ ] Работают ли сохранения прогресса?
- [ ] Соблюден ли кулдаун рекламы 90с?
