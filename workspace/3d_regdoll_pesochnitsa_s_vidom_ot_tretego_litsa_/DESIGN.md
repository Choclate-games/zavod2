# DESIGN — Банкетный Краш: Свадебный Саботаж

Дизайн игры, написанный до первой строчки кода (секция 7 мастер-промпта).

## 1. Как игра выглядит одной фразой

В первую секунду игрок видит тёплый золотой банкетный зал в стиле рококо:
хрустальные люстры над пятиъярусным свадебным тортом, пирамида бокалов
шампанского, столы под бордовыми скатертями и каскадёр в смокинге,
натянутый в ложе катапульты — всё залито шампанским светом витражных окон.

## 2. Палитра

Цвета взяты из `ART_DIRECTION.md` и становятся токенами `src/ui/theme.css`.

| Роль | Токен | HEX |
|---|---|---|
| Фон сцены / глубокая тень | `--color-bg` | `#1C1C24` (Tuxedo Charcoal) |
| Поверхность панелей (бархат) | `--color-surface` | `#7B1113` (Royal Crimson) |
| Текст и золотые рамки | `--color-primary` | `#D4AF37` (Gold Luxury) |
| Светлый текст на тёмном | `--color-text` | `#F7E7CE` (Champagne Cream) |
| Акцент хрусталя/успеха | `--color-accent` | `#A4D8E8` (Crystal Cyan Spark) |
| Опасность / предупреждение | `alert_danger` | `#E53935` |
| Комбо-плашка (кремовый неон) | `combo_popup` | `#FF4081` |
| Счётчик ущерба | `damage_counter` | `#FFD700` |
| Кнопка быстрого рестарта | `retry_button` | `#4CAF50` |

Шрифты: заголовки — «Cinzel Decorative» (золотой неоклассический гротеск),
числа и комбо — «Montserrat ExtraBold», `font-variant-numeric: tabular-nums`
для меняющихся цифр. Иконки — инлайновый SVG-спрайт, цвет через `currentColor`,
эмодзи запрещены.

## 3. Камера и свет

- Камера: перспективная, FOV 55° (пересчитывается под аспект, чтобы портрет
  не превращался в трубу), наклон ~25° вниз. В меню — медленный облёт зала;
  при выстреле — динамическое преследование каскадёра (FOV 60→80); в Slow-Mo —
  наезд на точку разрыва троса.
- Свет: Directional Light от витражных окон (тёплый жёлтый), Ambient цвета
  шампанского (`#F7E7CE`, низкая интенсивность), Point Lights внутри люстр.
  Металл держит `metalness ≤ 0.4` + `scene.environment` (RoomEnvironment PMREM),
  чтобы хрусталь не превратился в чёрные дыры без окружения.
- Сцена читается на телефоне: pixel ratio ≤ 1.5, тени только от направленного
  света, частицы — один InstancedMesh на тип эффекта.

## 4. Экраны

Каждый экран — три зоны: чем называется, главное действие, второстепенный ряд.
Все экраны лежат ПОВЕРХ живой сцены; непрозрачных полноэкранных заливок нет.

### main_menu — Главное Меню
- Название: логотип «Банкетный Краш» сверху слева.
- Главное действие: крупная кнопка «В БОЙ!» (золотой арт-деко).
- Второстепенный ряд одним весом: «Гардероб», «Катапульты», «Лидерборд»
  (рисуется только если площадка поддерживает таблицы).
- За меню камера медленно облетает живой зал.

### gameplay_hud — Игровой HUD
- top_center: DamageScoreCounter (золотые tabular-nums).
- top_left: StarProgressWidget (пороги $50k/$120k/$250k полосой scaleX).
- top_right: SettingsButton (пауза).
- bottom_right: InstantRetryButton (зелёная).
- Посередине экрана — только временная обратная связь: комбо-плашки,
  'CRASH!', 'WEDDING RUINED!', индикатор LOW VELOCITY / TOO SLOW.

### victory_screen — Экран Итогов Саботажа
- Название: «Чек саботажа», штамп APPROVED VANDALISM.
- Главное действие: «СЛЕДУЮЩИЙ ЗАЛ».
- Второстепенный ряд: «Удвоить награду» (rewarded, рисуется только при
  поддержке площадки), мгновенный рестарт, выход в меню.

## 5. Сцена за меню

Живой 3D-фон: тот же рендерер, тот же банкетный зал; катапульта стоит на
стартовой позиции, гости суетятся у столов, люстры покачиваются. Камера
медленно облетает зал по эллипсу. Игровой цикл крутится на сниженной нагрузке
(меньше частиц, шаг физики тот же). Меню, пауза и итоги рисуются поверх этой
сцены прозрачными для ввода слоями; подложка допускается только под текстовым
блоком и кнопками.

## 6. Управление: глагол → клавиша → тач → отклик

| Глагол | Клавиатура/мышь | Тач | Экран + звук |
|---|---|---|---|
| Натянуть катапульту | Зажать ЛКМ, тянуть назад; Пробел (зажать) + Стрелки вверх/вниз — угол | Касание в любой точке и оттягивание назад | Дуга траектории (30% пути), манометр давления, нарастающий скрип тросов |
| Выстрелить | Отпустить ЛКМ / Пробел | Отпустить палец | Хлопок пробки, конфетти, рывок камеры FOV 60→80, haptic-щелчок |
| Планировать (тангаж) | W/S или мышь (движение курсора) в полёте | Удержание пальца, свайп вверх/вниз | Свист воздуха меняется, ленты ветра за руками |
| Виражить (крен) | A/D | Свайп влево/вправо | Крен корпуса, ленты ветра |
| Доворот в Slow-Mo | Движение мыши / клик | Тап/драг в окне Slow-Mo | Доворот корпуса, звон цепи |
| Stunt Kick (однократно при контакте со столом) | Пробел | Тап | Импульс столу, хрустальный перезвон |
| Мгновенный рестарт | R или зелёная кнопка | Зелёная кнопка (≥96 px) | Мгновенный сброс зала без загрузки |
| Пауза | Esc/P | SettingsButton (top_right) | Модал паузы поверх живой сцены |

Вертикаль (прыжок/присед) осознанно не сделана: игрок — снаряд, вертикаль
даёт гравитация и баллистика; уровень не обещает уступов, на которые нужно
забираться. Отмена действия — рестарт в один клик.

Активная схема выбирается по `bridge.device.type` (планшет = тач), на dev-сервере
— по запасному признаку (`ontouchstart`/`maxTouchPoints`). Переключение на лету:
клавиша/настоящий `mousemove` → десктоп, `pointerdown` c `pointerType === 'touch'`
→ тач. Неактивная схема снимает слушателей и удаляет слой из DOM.
`?input=touch` / `?input=desktop` и `?touch=1`/`?touch=0` — для проверки обеих
раскладок на одной машине. Pointer lock не используется вовсе (управление —
drag, а не mouse look).

## 7. Звук

Web Audio API, процедурный синтез (без mp3): скрип натяжения (нарастающий),
хлопок пробки, свист ветра (фильтрованный шум, питч от скорости), лязг разрыва
троса, хрустальный звон (стаккан синусов), шлепок крема, праздничный аккорд
звезды. Всё через один мастер GainNode с рампой; mute игрока и mute площадки —
раздельные входы; AudioContext стартует suspended и оживляется первым жестом.
