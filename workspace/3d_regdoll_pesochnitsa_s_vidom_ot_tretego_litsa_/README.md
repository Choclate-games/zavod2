# Банкетный Краш: Свадебный Саботаж

> Запустите каскадёра из катапульты в роскошный свадебный зал, подруливайте
> телом в воздухе, перебейте трос хрустальной люстры — и наблюдайте в slow-mo,
> как она обрушивается в пятиъярусный торт, осыпая пирамиды бокалов и разгоняя
> нарядных гостей.

## Запуск

```bash
npm install
npm run dev        # Vite dev-сервер, открыть адрес из консоли
```

Сборка и предпросмотр релиза:

```bash
npm run build      # tsc --noEmit + vite build -> dist/
npm run preview    # локальный сервер поверх dist/
```

Проверки приёмки:

```bash
node scripts/check-spec.mjs   # статическая часть приёмки
node scripts/smoke.mjs        # сборка + запуск в браузере + ввод + телефон
```

## Управление

### Клавиатура и мышь (десктоп)
| Действие | Управление |
|---|---|
| Натянуть катапульту | Зажать **ЛКМ** (или **Пробел**) и оттянуть назад |
| Угол возвышения | Стрелки **Вверх/Вниз** при натянутой рогатке |
| Выстрелить | Отпустить ЛКМ / Пробел |
| Планирование (тангаж) | **W/S** в полёте |
| Вираж (крен) | **A/D** в полёте |
| Stunt Kick / доворот в Slow-Mo | **Пробел** при контакте |
| Мгновенный рестарт | **R** или зелёная кнопка внизу справа |
| Пауза | Кнопка настроек справа сверху |

### Телефон (тач)
| Действие | Жест |
|---|---|
| Прицел | Касание в любой точке и оттягивание назад, отпустить — выстрел |
| Манёвр в полёте | Удержание пальца и свайп в сторону манёвра |
| Stunt Kick | Короткий тап в полёте |
| Рестарт | Зелёная кнопка внизу справа |

`?input=touch` / `?input=desktop` принудительно включают схему; `?touch=1`
показывает мобильную раскладку на десктопе. Схема также переключается на лету:
клавиша — десктоп, палец — тач.

## Как играть

Натяжение задаёт скорость (`V = 32 * pull^1.35`), угол — дугу. Попадание телом
в трос люстры на скорости от 15 м/с рвёт подвес: slow-mo, искры, люстра падает.
Люстра в торте — взрыв крема, крем и ударная волна опрокидывают бокалы, столы
и сшибают гостей — каждый предмет добавляет доллары ущерба с комбо-множителем.
1 звезда — $50,000, 2 — $120,000, 3 — $250,000; меньше $20,000 — попытка провалена.

## Структура каталогов

```text
index.html                  # входная страница Vite
src/
├── main.ts                 # bootstrap: мост площадки -> Game.boot()
├── Game.ts                 # координатор фаз попытки и событий шины
├── vite-env.d.ts           # объявление импортов не-кода (?raw, css)
├── config/balance.ts       # числа игры: читает balance.yaml (?raw + js-yaml)
├── core/
│   ├── EventBus.ts         # типизированная шина pub/sub
│   ├── GameLoop.ts         # фиксированный шаг 60 Гц + time scale для slow-mo
│   └── InputRouter.ts      # единственный роутер ввода двух схем
├── platform/
│   ├── PlaygamaService.ts  # Playgama Bridge: init, game_ready, реклама, лидерборды
│   └── StorageService.ts   # облако + зеркало localStorage, нормализация
├── physics/PhysicsWorld.ts # мир Rapier3D, группы столкновений
├── entities/
│   ├── Stuntman.ts         # рэгдолл каскадёра: 11 тел, суставы, CCD
│   └── BanquetHall.ts      # зал: люстры на разрывных подвесах, торт, бокалы, гости
├── systems/
│   ├── RagdollAerodynamicsSystem.ts   # подъёмная сила и сопротивление
│   ├── StructuralDestructionSystem.ts # напряжение тросов, разрыв подвеса
│   ├── CascadeChainSystem.ts          # взрыв торта, ударная волна
│   ├── NpcCrowdPanicSystem.ts         # паника и разбегание массовки
│   └── DamageComboScoringSystem.ts    # ущерб $ и комбо
├── rendering/
│   ├── SceneManager.ts     # камера, свет, окружение, FOV по аспекту
│   ├── ProceduralModels.ts # процедурные модели зала и каскадёра
│   ├── ParticleSystem.ts   # инстанс-партиклы: искры, крем, осколки, конфетти
│   └── TrajectoryArc.ts    # пунктирная дуга траектории
├── audio/AudioManager.ts   # процедурный Web Audio синтез, мастер-гейн
└── ui/
    ├── theme.css           # все значения интерфейса: токены, слои, брейкпоинты
    ├── UiRoot.ts           # измеренный вьюпорт, слои, экраны, тач-слой
    ├── ScreenRouter.ts     # автомат экранов
    ├── Hud.ts              # счётчик ущерба, звёзды, рестарт, попапы
    ├── TouchControls.ts    # мобильная раскладка на Pointer Events
    ├── screens.ts          # главное меню и экран итогов
    ├── pauseScreen.ts      # пауза
    ├── components.ts       # кнопка, панель, полоса прогресса
    └── icons.ts            # инлайновый SVG-спрайт
public/playgama-bridge-config.json   # конфиг моста площадки
balance.yaml               # источник чисел баланса
scripts/check-spec.mjs     # статическая приёмка
scripts/smoke.mjs          # дымовой запуск: сборка, кадры, ввод, телефон
```

Пакет документации проекта (`AI_DEVELOPER_PROMPT.md`, `ACCEPTANCE.md`,
