# Changelog — Лавинный снайпер: Эхо Каньона

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [SemVer](https://semver.org/lang/ru/).

## [Unreleased]

### Added
- Игра целиком: снайперский контракт на заснеженном перевале — один выстрел раскалывает ледник и хоронит титана под лавиной.
- Честная баллистика: боковой ветер с порывами, гравитационное провисание пули, поправки по сетке Mil-Dot и дальномерная шкала.
- Задержка дыхания с фокус-зумом: сетка замирает, слышно сердцебиение; передержал — спазм и двойной тремор.
- Шаг по карнизу (A/D или слайдер) и упор на сошки (C), снижающий колебания.
- Кинематографичная рапид-камера пули (×0.15) от выстрела до попадания в стрессовое ядро.
- Физический раскол ледника на 48 глыб на Rapier3D и сход лавины, погребающей титана.
- Ледяной титан с ритмом поступи 4.2 с и ложным эхо-выстрелом (E), замораживающим его на 3 секунды.
- Пятнадцать перевалов с разным ветром и геометрией ледника; звёзды, счёт контракта и разблокировка перевалов сохраняются между сессиями.
- Две полные схемы управления: клавиатура+мышь с pointer lock и экранная для телефонов (мультитач, щипок-зум, крупные кнопки).
- Живое меню поверх игровой сцены, сводка перевала, экраны победы и поражения с причинами срыва контракта.
- Процедурный звук на Web Audio: выстрел с эхом, вой метели по силе ветра, треск льда и грохот лавины — без единого аудиофайла.
- Интеграция Playgama Bridge: game_ready по вехам загрузки, облачные сохранения, rewarded-награды («Золотой Калибр», метео-сканирование, удвоение знаков) с ограничением интерстишлов 90 секундами.
- Адаптивное качество рендера, сходящееся к стабильному фреймрейту.

### Changed
- Меню, пауза и экраны итогов рисуются поверх живой сцены каньона, а не глухой заливки.
