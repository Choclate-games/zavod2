# Core Loop Design: Лавинный снайпер: Эхо Каньона

## 1. Чем эта петля отличается
- **Фирменный момент**: Снайпер на 47-й секунде перевала замечает, как 30-метровый ледяной титан вступает в зону ущелья 'Зев Мороза'. Ветер пульсирует с порывами 7.5 м/с влево. Дозорный смещается на 6 метров по карнизу, огибая ледяной сталагмит, ложится на упор, задерживает дыхание на 3.2 секунде (пульс 72 уд/мин, идеальная стабилизация сетки). Выстрел! Камера в рапиде (0.15x) следует за 12.7-мм бронебойной пулей, преодолевающей 620 метров сквозь снежный вихрь. Пуля вонзается точно в ультрамариновое кристаллическое ядро напряжения (Stress Core) нависающего глетчера. Беззвучная микропауза 0.2 с — затем ядро взрывается сапфировой ударной волной, сеть трещин рассекает ледник, и 1.2 миллиона тонн физического снега и 40-тонных монолитов с громоподобным инфразвуковым ревом обрушиваются прямо на замахнувшегося титана, погребая его в бездне ущелья в 15 метрах от рубежа заставы.
- **Отличие от жанрового шаблона**: В отличие от традиционных снайперских игр (Sniper Elite, Hitman Sniper), где цель — живая мишень, здесь мишень — статико-динамическая геологическая система напряжения льда. Победа достигается не попаданием в движущуюся голову врага, а сложным двойным расчетом: баллистическим вычислением траектории пули с поправкой на штормовой ветер на 600+ м и кинематическим расчетом тайминга схода лавины под шаг и инерцию титана. Окружающая среда — это единственный инструмент уничтожения, где каждый ледник просчитывается как физическая система разрушаемых тел на Rapier3D.
- **Сознательно НЕ берём**: Отвергается шаблон классического мобильного снайперского тира с полоской здоровья босса (Boss HP Bar) и отстрелом уязвимых 'красных зон' на теле врага, а также шаблон случайных карточек улучшений (Rogue-lite Card Pick).
Почему отвергаем:
1. Стрельба по телу титана обесценивает масштаб угрозы — винтовочная пуля физически не может нанести урон 30-метровой ходячей ледниковой массе. Вместо ковыряния HP игрок использует стихию и окружающую среду (Environmental Hazard As Weapon).
2. Карточки случайных баффов разрушают атмосферу сурового снайперского симулятора-головоломки, где исход зависит от расчета баллистики, чтения ветра и понимания механики хрупкости льда, а не от выпавшего случайного '+15% к урону огнем'.

## 2. Схема петли
```text
+-------------------------------------------------------------------------------+
|                       МАКРО-ПЕТЛЯ (АРКТИЧЕСКИЙ ДОЗОР)                         |
|  [Карта Хребта] -> [Выбор снаряжения] -> [15 Перевалов] -> [Арсенал / Моды]   |
+---------------------------------------+---------------------------------------+
                                        |
                                        v
+-------------------------------------------------------------------------------+
|                        МЕЗО-ПЕТЛЯ (СНАЙПЕРСКИЙ ПЕРЕВАЛ)                       |
|  [Рекогносцировка] -> [Занятие позиции] -> [Выстрел по клину] -> [Коллапс]    |
+---------------------------------------+---------------------------------------+
                                        |
                                        v
+-------------------------------------------------------------------------------+
|                      МИКРО-ПЕТЛЯ (ВЫСТРЕЛ И ОБРУШЕНИЕ)                        |
|                                                                               |
|   +-----------------------+      Смещение      +--------------------------+   |
|   | 1. Оценка ветра       | -----------------> | 2. Позиция на карнизе    |   |
|   |    и дистанции        |                    |    (обход слепых зон)    |   |
|   +-----------------------+                    +--------------------------+   |
|               ^                                             |                 |
|     Промах    |                                             | Вход в оптику   |
|   (перезарядка)|                                            v                 |
|   +-----------------------+                    +--------------------------+   |
|   | 5. Оценка обвала      |                    | 3. Задержка дыхания      |   |
|   |    и массы лавины     |                    |    (окно стабилизации)   |   |
|   +-----------------------+                    +--------------------------+   |
|               ^                                             |                 |
|               |         Bullet-Cam / Рапид                  | Спуск курка     |
|               +---------------------------------------------+                 |
|                                                                               |
+-------------------------------------------------------------------------------+
```

| Шаг | Действие игрока | Ответ игры | Решение игрока | Длительность |
| :--- | :--- | :--- | :--- | :--- |
| Чтение флюгеров и расчет ветра | Осмотр анемометрических флажков на скалах и вихрей снега в ущелье через бинокль/оптику | Флажки отклоняются на угол 28 градусов, частицы бурана сносятся влево со скоростью 6.2 м/с | Рассчитать горизонтальную поправку по сетке Mil-Dot (3.5 деления вправо) или подождать спада порыва ветра | 4–8 с |
| Позиционирование на карнизе | Перемещение влево/вправо по обледенелому карнизу клавишами A/D или свайпом | Смещение угла обзора открывает скрытый за скалой кристаллический штифт ледника, звук хруста наста под кошками | Выбрать точку упора с максимальным обзором двух связанных ледников ценой сужения сектора отхода | 3–5 с |
| Вход в оптику и контроль дыхания | Зажатие кнопки задержки дыхания (Shift / виртуальная кнопка легких) | Оптический зум увеличивается до 16x, прицельная сетка замирает, звук глухого сердцебиения нарастает, виньетка сужается | Произвести спуск в идеальном окне 1.5–3.5 с до наступления кислородного голодания и критического тремора | 2–4 с |
| Спуск курка и полет пули | Клик ЛКМ / тап по спусковому крючку | Глухой винтовочный выстрел с эхом по каньону, активация кинематографичной рапид-камеры (Bullet-Cam), пуля преодолевает дистанцию с аэродинамическим сносом | Оценить попадание: детонация Stress Core либо рикошет/промах, требующий экстренной перезарядки | 1.5–3 с |
| Физический каскад и оценка эффекта | Наблюдение за распространением трещины и сходом лавинной массы | Сапфировое свечение раскола, обрушение 40-тонных глыб на Rapier3D, деформация траектории титана или его погребение | Если массы лавины недостаточно (<80%), немедленно готовить второй выстрел по нижнему ледяному клину | 4–6 с |

## 6. Кривая напряжения
Кривая пилообразного напряжения с экспоненциальным финалом (Sawtooth with Exponential Climax):
0:00–0:15 (Напряжение 20%): Спокойная аналитическая фаза. Величественный эмбиент ледяного ущелья, далекий низкий гул шагов титана. Стрелок замеряет ветер и планирует геометрию обвала.
0:15–0:40 (Напряжение 45% -> 60%): Титан приближается к опасной зоне. Ветер начинает пульсировать рывками (3->8 м/с). Стрелок перемещается по карнизу, ища угол, секунды тают.
0:40–0:65 (Напряжение 80%): Титан входит в зону поражения под ледником. Сердцебиение стрелка учащается, титан заносит лапу для разрушения первой опоры. Окно для выстрела сжимается до 5 секунд.
0:65–0:72 (Напряжение 100% -> Пик): Задержка дыхания. Звуки ветра затихают, остается только биение пульса и звон кристаллов. Выстрел! Камера летит в рапиде (0.15x) — время почти замерло.
0:72–0:80 (Катарсис и спад до 10%): Ослепительный ультрамариновый раскол, грохот обрушения 1.2 млн тонн льда, титан сметен в пропасть. Напряжение сменяется торжествующей тишиной и звоном оседающей ледяной пыли.
0:80–0:90: Окно отчета, начисление очков, подготовка к следующему перевалу.

## 7. Формулы ядра
- `Горизонтальное смещение пули от ветра: Deflection_X = K_wind * Wind_Speed * (Distance / 100)^1.35 * sin(Wind_Angle), где K_wind = 0.042 м/(м/с) (коэффициент парусности 12.7-мм пули), Wind_Speed в м/с (от 0.0 до 15.0 м/с), Distance в метрах (300–850 м), Wind_Angle — угол направления ветра к линии огня в радианах.`
- `Гравитационное провисание пули: Drop_Y = 0.5 * G_bullet * (Distance / V_muzzle)^2, где G_bullet = 9.81 м/с², V_muzzle = 880 м/с (начальная скорость тяжелой пули), дистанция Distance от 300 до 850 м. На 600 м провисание составляет ровно 2.28 метра (3.8 деления Mil-Dot).`
- `Радиус тремора при дыхании: Tremor_Radius = Base_Tremor * (1.0 - Breath_Hold_Factor) * (1.0 + Heart_Rate_Penalty), где Base_Tremor = 0.035 рад, Breath_Hold_Factor = 1.0 (при удержании дыхания в окне 0–4.0 с), после 4.0 с нарастает штраф Heart_Rate_Penalty = ((Time_Hold - 4.0) / 1.5)^2 * 3.5.`
- `Объем обрушенной массы лавины: Avalanche_Mass = Base_Glacier_Mass * (1.0 - Hit_Offset / Core_Radius)^2 * Structural_Integrity_Multiplier, где Base_Glacier_Mass = 1 200 000 тонн, Core_Radius = 0.45 м (радиус ядра напряжения), Hit_Offset — расстояние от центра ядра до точки попадания в метрах. При Hit_Offset > Core_Radius обвал не происходит (рикошет).`
- `Кинетический урон лавины титану: Impact_Force = Avalanche_Mass * Avalanche_Velocity * cos(Slope_Angle), где Avalanche_Velocity = 35 м/с (скорость фронта лавины), Slope_Angle = 52 градуса. Если Impact_Force >= Titan_Stability_Threshold (28 000 кН), титан сбивается с ног и уносится в пропасть.`
- `Итоговый счет чистоты контракта: Contract_Score = (Base_Pass_Score * Star_Multiplier) + (Unspent_Ammo * 2500) + max(0, (Time_Limit - Elapsed_Time) * 120) + (Mass_Percentage >= 95 ? 5000 : 0) - (Tremor_Shots_Count * 1000).`
