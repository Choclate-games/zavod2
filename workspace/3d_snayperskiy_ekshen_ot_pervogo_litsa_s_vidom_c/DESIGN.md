# Дизайн: Лавинный снайпер: Эхо Каньона

Документ написан до первой строчки кода. Здесь: как игра выглядит, палитра,
камера и свет, экраны, управление и сцена за меню.

## 1. Как игра выглядит (одна фраза)

Кадр из глаз стрелка на ледяном карнизе: слепяще-белый заснеженный каньон в
холодных сине-стальных тенях, по дну ущелья шагает исполинский ледяной титан,
а на противоположной стене светится ультрамарином трещина стрессового ядра
нависающего ледника — всё это сквозь круг оптики с сеткой Mil-Dot и метель.

## 2. Палитра

Роли цветов совпадают с токенами `src/ui/theme.css` один в один.

| Роль | Токен | HEX |
|---|---|---|
| Фон (глубина каньона, тени) | `--color-bg` | `#0B1626` |
| Поверхность панелей (матовое арктическое стекло) | `--color-surface` | `rgba(13,24,40,0.66)` |
| Текст основной | `--color-text` | `#EAF2FA` |
| Акцент фокуса/прицела (единственный акцент действия) | `--color-accent` (`--color-focus`) | `#00F0FF` |
| Опасность (рубеж, провал, тремор) | `--color-danger` | `#FF3B30` |
| Успех (лавина погребла титана) | `--color-success` | `#30D158` |
| Стресс-ядро / разлом | `--color-stress` | `#3A86FF` |
| Ветер / телеметрия | `--color-wind` | `#E0E1DD` |
| Тёплый закатный свет | `--color-sun` | `#FFAA55` |

Один цвет = один смысл: бирюзовый — только действие/фокус, красный — только
опасность, зелёный — только успех, синий разлома — только ледник.

## 3. Камера и свет

- **Камера**: вид строго от первого лица (FPS). Глаза стрелка на карнизе,
  высота 42 м над дном ущелья, базовый FOV 65° (в портрете пересчитывается под
  аспект, чтобы горизонтальный обзор не схлопывался). Вход в оптику — плавный
  переход к FOV 65/zoom (кратность 8x–16x–24x, фокус-зум ×1.25 при задержке
  дыхания). Bullet-Cam — отдельная кинематографичная камера слежения за пулей
  со стороны, рапид ×0.25.
- **Свет**: низкое закатное солнце DirectionalLight `#FFAA55` с запада с
  длинными тенями; заполняющий HemisphereLight небо `#88CCFF`, земля `#223344`;
  туман ущелья Exp2 `#99BBDD`. Сцена читается на телефоне: контраст белого
  снега и синих теней держится даже без постобработки, металл нигде не темнее
  `metalness ≤ 0.4`.
- **Меню-камера**: та же сцена, медленный дрейф вдоль карниза — меню живёт
  поверх игры.

## 4. Экраны (у каждого три зоны: имя, главное действие, второстепенный ряд)

| Экран | Имя себя | Главное действие | Второстепенный ряд |
|---|---|---|---|
| MainMenu | Заголовок игры + номер перевала | Кнопка «Вперёд» ≥ 96 px (продолжить/начать) | Звук вкл/выкл, краткая справка управления |
| BriefingModal | «Перевал N: сводка» | «Принять контракт» ≥ 96 px | Дистанция, роза ветров, патроны, лимит времени; кнопка метео-сканирования (только если площадка поддерживает rewarded) |
| GameplayHUD | Не называет себя — телеметрия | Спуск курка (ЛКМ / кнопка огня) | Анемометр сверху, дистанция титана справа, дыхание слева, патроны справа внизу |
| BulletCamOverlay | Метка рапида «×0.25» | Нет (неинтерактивен) | Виньетка, индикатор замедления |
| VictorySummaryScreen | «Контракт выполнен» | «Следующий перевал» ≥ 96 px | Разбор очков (масса, время, патроны), удвоение знаков через rewarded (если поддержано), выход в меню |
| DefeatRetryScreen | «Контракт сорван: причина» | «Повторить» ≥ 96 px | Выход в меню; «Золотой Калибр» +1 патрон через rewarded (если поддержано и причина — боезапас) |

Скрытый экран — `display: none`. Переход один на всю игру, ≤ 240 мс,
анимируются только `opacity`/`transform`; при `prefers-reduced-motion` — только
`opacity`. За каждым экраном видна живая сцена, непрозрачных заливок нет.

## 5. Сцена за меню

Живой кадр той же сцены: рассветный каньон с карниза, винтовка на сошках на
переднем плане, поземка у дула, метель, вдали шагает титан. Камера медленно
плывёт; игровой цикл крутится на сниженной нагрузке. Меню рисуется поверх
канваса прозрачным слоем; подложка допускается только под текстом и кнопками.

## 6. Управление: глагол → клавиша → тач → отклик

Активная схема выбирается по `bridge.device.type` (`mobile`/`tablet` → тач),
`?input=touch` / `?input=desktop` / `?touch=1|0` — принудительно для отладки.

| Глагол | Клавиатура/мышь | Тач | Отклик на экране и в звуке |
|---|---|---|---|
| Наведение прицела | Мышь (pointer lock из обработчика нажатия) | Перетаскивание правой половины экрана | Плавное ведение сетки; шелест ветра меняет высоту |
| Кратность оптики 8x–16x–24x | Колесо мыши | Щипок двумя пальцами или кнопка оптики | Плавный зум, щелчок оптики |
| Дальномерная шкала | Пробел | Кнопка шкалы у кластера огня | Метки поправок (MIL) у сетки, тихий клик |
| Задержка дыхания | Shift или ПКМ (удержание) | Круглая кнопка с иконкой лёгких | Сетка замирает, глухое сердцебиение, виньетка сужается; после 4.5 с — спазм и двойной тремор |
| Шаг по карнизу | A / D | Горизонтальный слайдер в левой нижней зоне | Параллакс скалы, хруст наста |
| Упор на сошки | C (переключение) | Кнопка сошек у кластера огня | Колебания −60 % после развёртывания 0.8 с, глухой лязг |
| Ложное эхо-выстрел (стоп титана, 1 заряд) | E | Кнопка эха над спуском | Свист, титан замирает на 3.0 с |
| Спуск курка | ЛКМ | Крупная круглая кнопка ≥ 96 px справа внизу | Хлопок калибра, отдача, вибрация, эхо; рапид-камера пули |
| Пауза / выход в меню | Esc / P | Кнопка паузы в углу HUD | Меню поверх живой сцены |

**Вертикаль осознанно не реализована** (ни прыжка, ни приседаний-движений):
стрелок стоит на карнизе, единственное позиционирование — шаг по карнизу и упор
на сошки. Уровень этого и не обещает: нет уступов, ящиков и мест, куда тянет
забраться. Отмены действий тоже нет: выстрел необратим — это ядро напряжения
игры («цена одного решения»), а не недоделка.

**Pointer lock** запрашивается только в десктопной схеме, из обработчика
нажатия; на таче его нет. При смене схемы все зажатые оси и кнопки сбрасываются.

## 7. Состояние, показанное миром, а не оверлеем

- Флажки-ветроуказатели на скалах отклоняются по реальному ветру.
- Снежные вихри бурана летят по ветру (частицы).
- Морозное дыхание стрелка паром перед стволом при задержке дыхания.
- Треск раскалывающегося льда и ультрамариновая вспышка разлома.

## 8. Победа/поражение и счёт

Победа: попадание в стрессовое ядро (радиус 0.45 м) с массой обвала ≥ 80 %
до пересечения титаном рубежа заставы. Поражение: 90 секунд истекли, титан
пересёк рубеж, либо 3 патрона исчерпаны без критического обвала.
Счёт контракта: база за перевал × звёзды + 2500 за неиспользованный патрон +
120 × остаток секунд + 5000 за массу ≥ 95 % − 1000 × выстрелы в треморе.
