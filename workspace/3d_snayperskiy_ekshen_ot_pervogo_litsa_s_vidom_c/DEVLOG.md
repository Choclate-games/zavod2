  - Рендер: процедурный каньон без GLTF (стены, дно, карниз, ледник со стрессовым ядром и трещинами, флажки, застава, монолиты), титан из переиспользуемой геометрии с анимацией группами, винтовка-вьюмодель на камере, пул частиц (метель + ледяная пыль), трассер вдоль +Z под lookAt, RoomEnvironment PMREM, metalness ≤ 0.4 везде.

  - Механики: баллистика по формулам ТЗ (снос K=0.042·V·(D/100)^1.35, провисание 0.5g(D/880)²), задержка дыхания 4.5 с с фокус-зумом ×1.25 и тремором после спазма, шаг по карнизу 2.8 м/с и сошки (−60 % колебаний), титан с шагом 4.2 с к рубежу, ложное эхо 3.0 с (1 заряд), рапид ×0.15 с камерой слежения за пулей, победа при массе ≥ 80 % и погребении, поражения: таймаут 90 с / рубеж / боекомплект.
  - Управление: InputRouter выбирает схему по `bridge.device.type` (запасной онтауч-флаг только для dev), живое переключение без перезагрузки со сбросом осей, pointer lock только в десктопной ветке из обработчика нажатия, `?input=touch|desktop` и `?touch=1|0`; TouchControls на Pointer Events с setPointerCapture и pointerId-учётом (слайдер карниза, зона наведения, щипок-зум, кнопки дыхания/огня/эха/оптики/шкалы), слой монтируется в DOM только в тач-режиме.
  - Аудио: Web Audio синтез (выстрел+эхо, ветер по силе, сердцебиение, треск льда, гул лавины, поступь титана, свист), один мастер-GainNode, отдельные мьюты игрока и площадки, контекст оживает по первому жесту.
  - Площадка: PlaygamaService поверх @playgama/bridge v2 c локальным mock-режимом — initialize с таймаутом 10 с, сторожевой таймер 15 с, game_ready ровно один раз после интерактивного меню, тихая VK/OK-авторизация до сейва, StorageService (ключ `unlocked_passes`, normalize, зеркало localStorage ≤4 обращений, debounce 1.5 с, flush на pagehide/visibilitychange), rewarded строго по `state === 'rewarded'` со снятием слушателя и защитой от повторного клика, интерстишл только из клика по выходу с экранов итогов и с полом 90 с, restorePurchases (grant→consume), capability gating (кнопки рекламы/лидерборда не рисуются без поддержки), пауза/звук из PAUSE_STATE_CHANGED/AUDIO_STATE_CHANGED со сбросом накопителя dt, конфиг `public/playgama-bridge-config.json`.
