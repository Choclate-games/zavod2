# Лавинный снайпер: Эхо Каньона

> Кинематографичный 3D FPS-снайперский экшен: один точный выстрел с учётом
> ветра и задержки дыхания раскалывает вековой ледник и хоронит исполинского
> ледяного титана под сокрушительной лавиной физических обломков.

---

## Запуск

```bash
npm install
npm run dev        # dev-сервер Vite, открыть адрес из консоли
```

Сборка и проверка:

```bash
npm run build      # tsc --noEmit + vite build → dist/
npm run preview    # локальный просмотр собранной версии
npm run check:spec # статическая приёмка (scripts/check-spec.mjs)
npm run smoke      # сборка + запуск в Chromium + ввод (scripts/smoke.mjs)
```

## Управление

Активная схема выбирается автоматически (`bridge.device.type`); для отладки:
`?input=touch`, `?input=desktop`, `?touch=1|0`.

### Клавиатура и мышь

| Действие | Управление |
|---|---|
| Наведение прицела | мышь (клик по сцене захватывает курсор) |
| Кратность оптики 8x–16x–24x | колесо мыши |
| Дальномерная шкала (поправки MIL) | Пробел |
| Задержка дыхания | Shift или ПКМ (удержание) |
| Шаг по карнизу влево/вправо | A / D |
| Упор на сошки | C |
| Ложное эхо — стоп титана (1 заряд) | E |
| Спуск курка | ЛКМ |
| Пауза / меню | Esc или P |

### Телефон

| Действие | Управление |
|---|---|
| Наведение | перетаскивание правой половины экрана; щипок — зум |
| Шаг по карнизу | горизонтальный слайдер в левой нижней зоне |
| Задержка дыхания | кнопка с иконкой лёгких слева |
| Спуск курка | большая круглая кнопка справа внизу |
| Эхо / оптика / шкала | кнопки над кластером огня |

## Как играть

1. Изучите ветер по флажкам и анемометру: порывы до 14.5 м/с сносят пулю.
2. Займите позицию на карнизе с открытым углом на стрессовое ядро ледника.
3. Войдя в оптику, задержите дыхание и совместите марку сетки с ядром,
   взяв поправку на провисание и снос (дальномерная шкала покажет MIL).
4. Выстрел запускает рапид-камеру пули: попадание в ядро раскалывает ледник.
5. Лавина ≥ 80 % массы погребает титана до рубежа заставы — контракт выполнен.

Три патрона, 90 секунд. Титан неуязвим к пулям — его хоронит только стихия.

## Структура каталогов

```text
├── index.html               # канвас + корень интерфейса
├── public/
│   └── playgama-bridge-config.json
├── scripts/                 # приёмка фабрики (check-spec, smoke, fetch-knowledge)
├── src/
│   ├── main.ts              # загрузка по вехам, мост, сторожевой таймер
│   ├── core/                # Game (координатор), GameLoop 60 Гц, EventBus, balance.yaml-числа, i18n ru/en
│   ├── platform/            # PlaygamaService (@playgama/bridge v2 + mock), StorageService
│   ├── physics/             # мир Rapier3D, пул глыб обвала
│   ├── rendering/           # SceneManager, процедурный каньон/титан/винтовка, частицы
│   ├── systems/             # InputRouter (две схемы), ветер, баллистика, титан, лавина, адаптивное качество
│   ├── audio/               # процедурный звук на Web Audio
│   └── ui/                  # theme.css (все токены), экраны, HUD, тач-слой, SVG-иконки
├── balance.yaml             # числа игры (код читает значения отсюда)
├── DESIGN.md                # дизайн: палитра, камера, экраны, управление
├── ACCEPTANCE.md            # приёмка с проставленными чек-листами
└── DEVLOG.md / CHANGELOG.md
```
