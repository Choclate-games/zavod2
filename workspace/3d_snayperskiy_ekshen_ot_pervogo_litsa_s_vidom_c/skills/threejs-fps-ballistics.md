# Skill: Снайперская баллистика и оптический прицел в Three.js

## Purpose
Реализация честной параболической баллистики с учетом ветрового сноса, оптического зума с шейдером линзы и механики задержки дыхания

## When to Use
При разработке систем прицеливания и стрельбы в FPS проектах

## Core Rules & Constraints
- Использовать Raycast в сочетании с пошаговой симуляцией траектории для дальних дистанций
- Шейдер оптического прицела рендерить через отдельный RenderTarget или полноэкранный пост-процесс с маской
- Частоту физического шага пули синхронизировать с FixedUpdate

## System Architecture
Модуль WindBallisticsSystem рассчитывает вектор смещения (WindForce * Time.deltaTime), FPSCameraController управляет углами обзора и дрожанием (Perlin Noise Sway), ScopeShader накладывает виньетку и хроматическую аберрацию.

## Implementation Guidance
Привязать дрожание рук к синусоиде с наложением шума Перлина; при зажатии клавиши задержки дыхания плавно интерполировать амплитуду колебаний к нулю за 0.3 секунды.

## Common Mistakes to Avoid
- ❌ **Mistake**: Мгновенный хитскан без учета времени полета пули на дистанциях >300 м
- ❌ **Mistake**: Линейный ветровой снос без учета угла атаки ветра относительно траектории
- ❌ **Mistake**: Резкое обрывание зума камеры без плавной интерполяции FOV

## Validation Checklist
- [ ] Баллистическая траектория пули учитывает силу и вектор ветра
- [ ] Сетка прицела точно соответствует делениям Mil-Dot
- [ ] Задержка дыхания расходует энергию и стабилизирует прицел
- [ ] Зум плавно меняет угол обзора камеры
