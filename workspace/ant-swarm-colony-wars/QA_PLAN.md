# QA & Testing Plan: Муравьиный Рой: Война Колоний

## 1. Functional Test Matrix
- [ ] Проверка корректной генерации потока феромонов при непрерывном и прерывистом рисовании
- [ ] Тестирование сборки живого моста над пропастью и успешного перехода муравьев на другую сторону
- [ ] Проверка захвата нейтрального и вражеского муравейников при достижении нулевого гарнизона
- [ ] Валидация сохранения прогресса биомассы и открытых улучшений в LocalStorage и Cloud Save
- [ ] Тест работы рекламы Rewarded и Interstitial при наличии и отсутствии интернет-соединения

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS при 600 активных муравьях на экране на устройствах уровня iPhone 8 / Snapdragon 665
- [ ] Время начальной загрузки игры менее 2.5 секунд при 4G соединении
- [ ] Потребление оперативной памяти вкладки браузера не более 120 МБ

## 3. Target Browser Matrix
- Chrome Mobile (Android 11+)
- Safari Mobile (iOS 14+)
- Yandex Browser Desktop / Mobile
- Firefox Desktop
- VK App WebView (Android/iOS)
