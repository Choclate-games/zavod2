# Муравьиный Рой: Война Колоний 🐜⚡

> Тактический симулятор роя муравьев с векторным управлением феромонами и физикой живых био-структур на WebGL (PixiJS v8) и Playgama Bridge v2.

---

## 🎮 Игровой процесс и Особенности
- **Векторные Феромонные Тропы (Flow Fields)**: Рисуйте траектории пальцем или мышью — рой мгновенно устремляется по феромонному следу.
- **Живые Био-Структуры (Verlet Physics)**: Рабочие муравьи сцепляются в живые висячие мосты для преодоления пропастей и рек.
- **Таранная Защитная Сфера**: Сбор сотен муравьев в единый бронированный катящийся шар для сокрушения укреплений.
- **Специализация Каст**:
  - 🟢 **Рабочие (Workers)**: Высокая скорость, сбор биомассы, возведение мостов.
  - 🔴 **Солдаты (Soldiers)**: Высокий урон, прочный хитиновый панцирь, защита колонии.
  - 🟡 **Бомбардиры (Bombers)**: Кислотные взрывы по площади, пробивание стен и штурм цитаделей.
- **Захват Муравейников**: Окружайте вражеские и нейтральные гнезда для конвертации их в спавнеры своей колонии.
- **Древо Мутаций ДНК**: Прокачивайте скорость, урон, панцири, емкость феромонов и инкубаторы матки за собранную биомассу.
- **Полная интеграция с Playgama Bridge v2**: Облачные и локальные сохранения, реклама Rewarded & Interstitial, мультиязычность (RU / EN), адаптивность под мобильные устройства и десктоп.

## 🕹️ Управление

### 📱 Сенсорные экраны (Смартфоны и Планшеты)
- **1 палец (свайп / удержание)**: Рисование феромонных троп движения роя
- **2 пальца (щипок / pinch)**: Плавное масштабирование камеры (Zoom in / out)
- **Нижняя панель**: Быстрое переключение каст (Рабочие / Солдаты / Бомбардиры)
- **Кнопка [Рассеять]**: Мгновенный сброс всех активных феромонов
- **Кнопка [Сфера]**: Активация/деактивация таранной сферы роя

### 💻 Клавиатура и Мышь (Десктоп)
- **ЛКМ (зажатие и ведение)**: Рисование феромонного следа
- **ПКМ / СКМ (перетаскивание)**: Панорамирование камеры
- **Колесико мыши**: Зум камеры
- **Клавиши 1, 2, 3** или **Q, W, E**: Выбор активной касты (Рабочие / Солдаты / Бомбардиры)
- **Space (Пробел)**: Таранная защитная сфера
- **R**: Рассеять феромонные следы
- **Esc / P**: Пауза / Меню

## 🛠️ Запуск и Разработка

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки (Vite)
npm run dev

# Продакшн-сборка (TypeScript TypeCheck + Vite Build)
npm run build

# Предпросмотр сборки
npm run preview
```

## 📁 Структура проекта

```text
src/
├── main.ts                    # Инициализация платформы Playgama и запуск игры
├── core/
│   ├── Game.ts                # Главный координатор и машина состояний (Finite State Machine)
│   ├── GameLoop.ts            # Фиксированный игровой цикл 60 Гц с защитой от лагов и hitstop
│   ├── EventBus.ts            # Строго типизированная шина событий
│   ├── SwarmEngine.ts         # Высокопроизводительный движок симуляции роя 1000+ муравьев (SOA Float32Array)
│   ├── FlowFieldGrid.ts       # Сетка векторных полей феромонов и затухание следа
│   └── LivingStructureManager.ts # Физика живых мостов (Verlet) и таранных сфер
├── entities/
│   ├── AntTypes.ts            # Касты, характеристики и перечисления состояний
│   ├── Nest.ts                # Муравейники (спавн, гарнизон, захват)
│   ├── Obstacle.ts            # Пропасти, реки, разрушаемые укрепления
│   ├── BiomassNode.ts         # Кристаллы биомассы для сбора и эволюции
│   └── EnemySwarmAI.ts        # ИИ вражеской колонии и тактические атаки
├── level/
│   ├── LevelData.ts           # Набор сюжетных кампаний (1-6)
│   └── LevelGenerator.ts      # Процедурный генератор бесконечных уровней (7+)
├── physics/
│   └── SpatialHashGrid.ts     # Пространственное хеширование 64x64 для коллизий роя без аллокаций
├── platform/
│   ├── BridgeManager.ts       # Полная обертка над @playgama/bridge v2 (Ads, Cloud Save, Leaderboards)
│   ├── StorageService.ts      # Синхронизация данных с дебаунсингом и fallback
│   └── I18n.ts                # Система локализации (RU / EN)
├── rendering/
│   ├── SceneManager.ts        # PixiJS v8 граф сцены, слои рендеринга и камера
│   ├── TextureFactory.ts      # Процедурная генерация WebGL текстур юнитов и эффектов
│   └── VFXSystem.ts           # Взрывы, брызги кислоты, искры, тряска камеры
├── systems/
│   └── EvolutionManager.ts    # Древо эволюции мутаций и учет биомассы
└── ui/
    ├── TouchController.ts     # Обработка тач-жестов и мультитача
    └── UIManager.ts           # DOM HUD оверлей, модальные окна и экраны
```
