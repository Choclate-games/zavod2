# UI/UX Specification: Муравьиный Рой: Война Колоний

## 1. HUD Overlay Elements
- Счетчик популяции роя (текущие / лимит)
- Панель выбора активной касты муравьев (Рабочие / Солдаты / Бомбардиры)
- Индикатор запаса феромонной энергии
- Прогресс-бар захвата вражеских баз
- Кнопка экстренного рассеивания роя (Disperse)
- Кнопка паузы и настроек

## 3. Screen Catalog
### Screen: Mainmenu
- Панорама цветущего макро-леса, живой фоновый рой муравьев, кнопки 'В бой', 'Эволюция', 'Лидерборд'
### Screen: Evolutiontree
- Интерактивная карта ДНК муравейника для прокачки скорости, урона, защиты и емкости феромонов за биомассу
### Screen: Gameplayhud
- Минималистичный интерфейс, не закрывающий поле боя, с поддержкой жестов мультитача
### Screen: Victorydefeatmodal
- Всплывающее окно с анимацией подсчета захваченных муравейников, собранной биомассы и кнопкой удвоения за рекламу
