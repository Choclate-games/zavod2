# Core Loop Design: Аркадный fps упором пинки

## 1. Чем эта петля отличается
- **Фирменный момент**: Выбивание с разбега ногой тяжелой двери, которая сносит двух автоматчиков вглубь комнаты, подхват в воздухе выпавшего из их рук дробовика, выстрел в летящую бочку и добивающий пинок горящего огнетушителя прямо в лоб бронированному боссу-пулемётчику.
- **Отличие от жанрового шаблона**: Враги, двери и объекты окружения — это основной расходуемый боекомплект игрока. Огнестрельное оружие служит детонатором и катализатором инерции, а кинетический пинок запускает цепные физические коллизии (Ragdoll Bowling) с мгновенным сплэш-уроном о стены.
- **Сознательно НЕ берём**: Отказ от позиционной стрельбы из статичных укрытий и врагов-губок с полосками здоровья (Hitscan Bullet-Sponge & Cover-Shooter). В игре нет пассивного отсиживания за ящиками и унылого зажима гашетки: патроны строго ограничены, любое укрытие уничтожается пинком, а каждое тело врага и предмет мебели являются летающим физическим оружием массового поражения.

## 2. Схема петли
```text
+-------------------------------------------------------------------------+
|                        ХАБ МЕТА-ПРОКАЧКИ                                |
|  [Улучшение ботинок] <---> [Покупка оружия] <---> [Выбор модификатора]  |
+-------------------------------------------------------------------------+
                                     |
                                     v [Старт забега]
+-------------------------------------------------------------------------+
|                        СЕКТОР ЭТАПА (MESO LOOP)                         |
|                                                                         |
|   +-----------------------------------------------------------------+   |
|   |                    КОМНАТНЫЙ ТАКТ (MICRO LOOP)                  |   |
|   |                                                                 |   |
|   |  [СПРИНТ / СЛАЙД] ---> [ПИНОК ДВЕРИ / ТАРАН]                    |   |
|   |         ^                             |                         |   |
|   |         |                             v                         |   |
|   |  [СБОР ПАТРОНОВ]            [ПОЛЕТ ТЕЛА ВО ВРАГОВ]              |   |
|   |         ^                             |                         |   |
|   |         |                             v                         |   |
|   |  [ПЕРЕХВАТ ОРУЖИЯ] <--- [СПЛЭТ О СТЕНУ / ВЗРЫВ БОЧКИ]           |   |
|   +-----------------------------------------------------------------+   |
|                                    |                                    |
|                                    v [Комната зачищена]                 |
|                     [ТАКТИЧЕСКИЙ ВЫБОР 1 ИЗ 3 КАРТ]                     |
+-------------------------------------------------------------------------+
                                     |
                                     v [Завершение 5 секторов]
+-------------------------------------------------------------------------+
|                    ФИНАЛЬНЫЙ БОСС / ЭКРАН ИТОГОВ                        |
|        [Победа / Поражение] ---> [Конвертация очков в Мета-Валюту]      |
+-------------------------------------------------------------------------+
```

## 3. Микро-петля (посекундно)
| Шаг | Действие игрока | Ответ игры | Решение игрока | Длительность |
| :--- | :--- | :--- | :--- | :--- |
| Сближение и оценка угла | Игрок делает спринт-слайд к дверному проему или группе стрелков, выравнивая вектор атаки под углом к стене. | Увеличивается FOV камеры, звук шагов ускоряется, враги поднимают оружие с задержкой реакции 0.35 с. | Ворваться через дверь с ноги для мгновенного стана или расстрелять бочку через окно снаружи. | 0.8 с |
| Кинетический удар / Выстрел | Нажатие клавиши пинка (или выстрела из дробовика с близкой дистанции). | Мгновенный хитстоп на 0.05 с, цель переходит в режим ragdoll и с ускорением 22 м/с отлетает назад, сбивая стоящих позади противников. | Пнуть тело в стену для краш-урона или направить во взрывоопасный баллон. | 0.3 с |
| Цепная коллизия и перехват лута | Игрок ловит в воздухе выбитый из рук врага автомат и нажимает спуск. | Тело врага сминается о стену с ударной волной, подхваченное оружие делает критический залп без траты собственного боезапаса. | Сбросить пустое оружие броском во врага или сохранить для прицельного выстрела. | 1.2 с |
| Зачистка и перезарядка импульса | Добивание оглушенных выживших подкатом и переход к следующей двери. | Камера выравнивается, замедление времени прекращается, начисляются комбо-очки и восстанавливается выносливость. | Собрать выпавшие аптечки или немедленно вломиться в следующую комнату для удержания комбо-таймера. | 1.5 с |

## 4. Мезо-петля (этап за этапом)
| Шаг | Действие игрока | Ответ игры | Решение игрока | Длительность |
| :--- | :--- | :--- | :--- | :--- |
| Вход в боевой сектор этапа | Игрок выбирает один из 2–3 доступных маршрутов (коридор с турелями, склад бочек или казарма). | Генерация геометрии комнат, расстановка интерактивных преград (двери, шкафы, подвесные балки). | Выбрать маршрут с максимальным количеством физических объектов или короткий путь с плотным огнем. | 2.0 с |
| Штурм и зачистка сектора | Последовательное преодоление 3–5 связанных комнат через выбивание дверей, комбо-пинки и стрельбу. | Спавн подкреплений, нарастание темпа музыки, появление элитных врагов со щитами. | Экономить редкие патроны гранатомёта для элиты или расчистить толпу на входе. | 45–90 с |
| Выбор тактического модуля | Взаимодействие с терминалом снабжения в конце сектора (выбор 1 из 3 синергетических карт). | Экран выбора с демонстрацией эффектов на манекене и пересчетом характеристик. | Усилить кинетику пинка (+ударная волна о стены) или модифицировать дробовик (огненный шквал). | 8.0 с |

## 5. Макро-петля (забег за забегом)
| Шаг | Действие игрока | Ответ игры | Решение игрока | Длительность |
| :--- | :--- | :--- | :--- | :--- |
| Подготовка в хабе (Гараж контрабандистов) | Трата мета-валюты (Титановые пластины и Гильзы) на постоянные перки и разблокировку новых типов обуви/оружия. | Визуальное обновление экипировки героя, активация пассивных узлов дерева технологий. | Инвестировать в базовую прочность и скорость слайда или открыть экспериментальный ботинок с пьезо-детонатором. | 30–60 с |
| Прохождение забега (5 этажей комплекса) | Серия из 5 биомов с нарастающей сложностью, мини-боссами и финальным боссом этажа. | Динамическая кривая спавна врагов, возрастающий урон окружения, дроп редких чертежей. | Идти на опциональные комнаты испытаний ради удвоенной награды или двигаться напрямую к боссу. | 5–8 мин |
| Кульминация забега (Победа / Смерть) | Финальная дуэль с меха-боссом либо гибель от перекрестного огня при исчерпании HP. | Экран итоговой статистики: число сплэт-убийств, средняя скорость прохождения, начисление валюты. | Анализ эффективности собранного билда и выбор фокуса прокачки на следующий забег. | 15 с |

## 6. Кривая напряжения
Фаза 1: Взрывной пик адреналина (0–2 с) при пробитии двери и внезапном входе в комнату. Фаза 2: Высокое напряжение и тактическое жонглирование объектами (2–8 с) при уклонении от пуль и расчете траекторий пинков. Фаза 3: Разрядка и катарсис (8–12 с) при детонации последних бочек и физическом уничтожении врагов. Фаза 4: Полный покой и дофаминовый выбор награды (12–20 с) перед следующим прорывом.

## 7. Формулы ядра
- `impact_wall_damage = base_kick_dmg(45) + (ragdoll_velocity_mps^1.45 * enemy_mass_kg(75) * 0.08) * (is_wall_splat ? 2.5 : 1.0)`
- `chain_collision_force = initial_kick_impulse(350 Ns) * (0.75 ^ chain_target_index)`
- `door_breach_cone_damage = 120 * (1 - (distance_m / 4.0))`
- `ammo_scavenge_chance = clamp(0.20 + (current_combo_streak * 0.08), 0.20, 0.85)`
- `room_threat_budget = 100 + (run_stage_index * 45) + (player_perk_count * 15)`
