# Mechanics Catalog: Аркадный fps упором пинки

> Каждая механика описана до уровня, на котором её можно реализовать без
> додумывания: решение игрока, числа, состояния, режим отказа и сопротивление игры.

## Механика: Кинетический пинок со сплэтом о препятствия (Kinetic Wall-Splat Kick) (CORE)
- **Категория**: Главный двигатель темпа, основной инструмент контроля пространства и ключевой источник физического урона.
- **Описание**: Вместо стандартного рукопашного удара с фиксированным уроном пинок является физическим транслятором кинетической энергии: урон рассчитывается исключительно из конечной скорости соударения тела с препятствием.
- **Взаимодействие игрока**: Клавиатура/Мышь: Нажатие [F] или [Mouse4] / Мобильный тач: Кнопка-иконка тяжелого ботинка в правой нижней зоне экрана (радиус 48px).
- **Отклик**: Визуал/VFX: Радиальное искажение экрана (Radial Screen Warp) вокруг точки удара, декали треснувшей штукатурки и разлетающиеся 3D-обломки кирпичей при ударе тела о стену.; Звук (Web Audio API): Саб-басовый панч (Sub-bass Drop 55 Гц) при ударе ноги + сочный хрустящий щелчок сминания брони/костей (комбинация синтеза шума и сэмпла разрушения дерева на 1.8 кГц).; Камера: Мгновенный импульсный зум FOV (90° -> 83° -> 90° за 0.14 с) с резким вертикальным киком вверх на 2.2° и плавным затуханием.; UI/Тактильность: Haptic-импульс 45 мс (Heavy Impact), динамический всплывающий маркер 'WALL CRUSH x2.5' ярко-оранжевого цвета над точкой сплэта.
- **Техническая сложность**: Medium
- **Сильные стороны**: Высокая вовлеченность, Глубокая кривая мастерства
- **На что смотреть**: Требует точной калибровки таймингов

### Глубина механики
- **Роль в петле**: Главный двигатель темпа, основной инструмент контроля пространства и ключевой источник физического урона.
- **Решение игрока**: Пнуть ближнего врага прямо в стену для мгновенного гарантированного убийства (х2.5 урон) или пнуть его в скопление стрелков позади для массового сбивания с ног ценой меньшего урона.
- **Управление**: Клавиатура/Мышь: Нажатие [F] или [Mouse4] / Мобильный тач: Кнопка-иконка тяжелого ботинка в правой нижней зоне экрана (радиус 48px).
- **Состояния**: `READY (готов к удару)`, `WINDUP (замах ноги 0.06 с)`, `ACTIVE_HITBOX (активное окно контакта 0.12 с)`, `RECOVERY (возврат ноги 0.18 с)`, `COOLDOWN (восстановление заряда 0.35 с)`
- **Параметры и настройка**:
  - **kick_launch_velocity**: `22.5 м/с` — Если опустить ниже 16 м/с — враги вяло падают под ноги, пропадает ощущение нечеловеческой мощи; если поднять выше 30 м/с — рэгдолл пролетает сквозь коллизии стен.
  - **wall_splat_multiplier**: `2.5 x` — Если сделать меньше 1.8х — игроки перестают целиться в углы и стены, скатываясь в банальный спам удара в пустоту.
  - **kick_hitbox_cone_angle**: `52.0 градуса` — Если сузить меньше 35° — на мобильных устройствах и при быстром вращении камеры начинаются частые раздражающие промахи в упор.
  - **kick_recovery_duration**: `0.18 с` — Если увеличить более 0.30 с — персонаж ощущается неповоротливым бревном и получает гарантированный урон от соседних стрелков.
- **Слои отклика**:
  - Визуал/VFX: Радиальное искажение экрана (Radial Screen Warp) вокруг точки удара, декали треснувшей штукатурки и разлетающиеся 3D-обломки кирпичей при ударе тела о стену.
  - Звук (Web Audio API): Саб-басовый панч (Sub-bass Drop 55 Гц) при ударе ноги + сочный хрустящий щелчок сминания брони/костей (комбинация синтеза шума и сэмпла разрушения дерева на 1.8 кГц).
  - Камера: Мгновенный импульсный зум FOV (90° -> 83° -> 90° за 0.14 с) с резким вертикальным киком вверх на 2.2° и плавным затуханием.
  - UI/Тактильность: Haptic-импульс 45 мс (Heavy Impact), динамический всплывающий маркер 'WALL CRUSH x2.5' ярко-оранжевого цвета над точкой сплэта.
- **Режим отказа**: Промах пинком мимо цели (Whiff): нога рассекает воздух, игрок входит в фазу удлиненного восстановления (0.28 с) с потерей скорости бега на 40%, сопровождаясь глухим свистом рассекаемого воздуха.
- **Кривая мастерства**: Новичок на 30-й секунде пинает одиночных врагов в упор, стоя на месте. Эксперт на 10-м забеге в слайде на скорости 14 м/с рассчитывает рикошет одного тела сразу в двух автоматчиков с одновременным впечатыванием третьего в стенную турель.
- **Сопротивление игры**: Тяжелые щитоносцы и стационарные роботы: пинок без предварительного ослабления выстрелом не сдвигает их с места, а отбрасывает самого игрока назад на 2.5 м с микро-станом на 0.2 с.
- **Синергии**:
  - Тактический прорыв дверей (выбитая дверь удваивает импульс пинка)
  - Перехват оружия в воздухе (пинок по врагу гарантированно выбивает его ствол по дуге вверх)
  - Сверхзвуковой слайд (скорость подката суммируется со стартовой скоростью полета рэгдолла)
- **Почему это не жанровый шаблон**: Вместо стандартного рукопашного удара с фиксированным уроном пинок является физическим транслятором кинетической энергии: урон рассчитывается исключительно из конечной скорости соударения тела с препятствием.
- **Псевдокод тика**:
```text
function updateKickTick(dt, player, enemies, walls, input) {
  if (player.kickCooldown > 0) { player.kickCooldown -= dt; return; }
  if (!input.kickPressed) return;
  player.kickCooldown = 0.35;
  let target = findBestConeTarget(player.cameraPos, player.forward, 2.4, 52.0, enemies);
  if (target) {
    let finalVelocity = player.forward.clone().multiplyScalar(22.5 + player.currentSpeed * 0.4);
    target.activateRagdollPhysics(finalVelocity);
    applyHitstop(0.05);
    emitScreenWarp(player.cameraPos, 0.14);
    playSynthPunchAudio(55, 1.8);
  } else {
    player.applySlowdown(0.4, 0.28);
    playAudioWhiff();
  }
}
```

## Механика: Штурмовой вылом дверей и баррикад (Tactical Breach-Ram) (SECONDARY)
- **Категория**: Источник инициативы, инструмент безопасного вскрытия слепых зон и генератор массового контроля на старте комнаты.
- **Описание**: Двери в игре — это не статические порталы между комнатами, а тяжелые физические метательные снаряды с механикой пробития геометрии и встроенным триггером тактического микро-слоумо.
- **Взаимодействие игрока**: Клавиатура/Мышь: Нажатие [F] / [Space] в движении в упор к двери / Мобильный тач: Свайп вперед в сторону дверного проема при активном спринте.
- **Отклик**: Визуал/VFX: Срыв петель с яркими искрами, густое объемное облако древесной пыли (threejs particle system), разлет 8–12 физических щепок с собственной коллизией.; Звук (Web Audio API): Резкий металлический скрежет срывающихся петель (Metal Tear 3.2 кГц) + мощный низкочастотный взрывной удар выбиваемого бруса (120 Гц).; Камера: Резкий толчок вперед с кратковременным размытием движения (Motion Blur) и расширением угла обзора FOV до 102° на 0.35 с.; UI/Тактильность: Двойной виброотклик (25 мс легкий пред-удар + 60 мс жесткий пролом), появление крупного стилизованного бейджа 'DOOR BREACH!'.
- **Техническая сложность**: Medium
- **Сильные стороны**: Высокая вовлеченность, Глубокая кривая мастерства
- **На что смотреть**: Требует точной калибровки таймингов

### Глубина механики
- **Роль в петле**: Источник инициативы, инструмент безопасного вскрытия слепых зон и генератор массового контроля на старте комнаты.
- **Решение игрока**: Открыть дверь выстрелом издалека для безопасного обзора или выбить дверь ногой на полном ходу, превратив створку в летающий таран ценой телепортации в центр толпы.
- **Управление**: Клавиатура/Мышь: Нажатие [F] / [Space] в движении в упор к двери / Мобильный тач: Свайп вперед в сторону дверного проема при активном спринте.
- **Состояния**: `DOOR_LOCKED (дверь заперта/готова к вылому)`, `IMPACT_FRAME (точка контакта ноги 0.04 с)`, `PROJECTILE_FLIGHT (полет сорванного полотна 0.45 с)`, `SPLINTER_EXPLOSION (разрушение створки на щепки при контакте со стеной/врагом)`
- **Параметры и настройка**:
  - **door_flight_speed**: `26.0 м/с` — Если сделать ниже 19 м/с — враги в комнате успевают вскинуть стволы и нанести игроку урон еще до прилета створки.
  - **breach_slowdown_scale**: `0.3 x` — Если отключить слоумо — игрок не успевает сориентироваться в новой комнате при резкой смене ракурса и врезается в мины.
  - **breach_slowdown_duration**: `0.35 с` — Если сделать длиннее 0.6 с — ломается аркадный флоу и игра начинает казаться затянутой и вязкой.
  - **splinter_damage_radius**: `3.8 м` — Если уменьшить до 2 м — дверь превращается в одиночный снаряд и теряет функцию зачистки дверного фойе.
- **Слои отклика**:
  - Визуал/VFX: Срыв петель с яркими искрами, густое объемное облако древесной пыли (threejs particle system), разлет 8–12 физических щепок с собственной коллизией.
  - Звук (Web Audio API): Резкий металлический скрежет срывающихся петель (Metal Tear 3.2 кГц) + мощный низкочастотный взрывной удар выбиваемого бруса (120 Гц).
  - Камера: Резкий толчок вперед с кратковременным размытием движения (Motion Blur) и расширением угла обзора FOV до 102° на 0.35 с.
  - UI/Тактильность: Двойной виброотклик (25 мс легкий пред-удар + 60 мс жесткий пролом), появление крупного стилизованного бейджа 'DOOR BREACH!'.
- **Режим отказа**: Попытка выбить бронированную гермодверь с кодовым замком без специального перка: дверь вибрирует, игрок отскакивает назад с оглушением на 0.45 с и потерей 15 HP от отдачи.
- **Кривая мастерства**: Новичок выбивает дверь стоя на пороге и медленно заходит следом. Эксперт пинает дверь в падении под углом 40°, направляя полотно точно в дальнего элитного снайпера на втором ярусе комнаты.
- **Сопротивление игры**: Враги могут устанавливать растяжки и лазерные мины на обратной стороне двери: вылом двери детонирует мину прямо в летящее полотно, требуя от игрока своевременного слайда назад.
- **Синергии**:
  - Кинетический пинок (створка двери усиливает базовый импульс пинка на +30%)
  - Жонглирование арсеналом (враги, убитые дверью, выбрасывают оружие прямо в траекторию движения игрока)
- **Почему это не жанровый шаблон**: Двери в игре — это не статические порталы между комнатами, а тяжелые физические метательные снаряды с механикой пробития геометрии и встроенным триггером тактического микро-слоумо.
- **Псевдокод тика**:
```text
function updateDoorBreach(dt, player, door, kickAction) {
  if (!door.isClosed || !kickAction) return;
  if (getDistance(player.pos, door.pos) <= 1.9 && isFacing(player, door.pos, 40.0)) {
    door.isClosed = false;
    let breachVector = player.forward.clone().multiplyScalar(26.0);
    door.launchAsProjectile(breachVector, 120.0, 3.8);
    triggerBreachSlowmo(0.3, 0.35);
    spawnSplintersAndDust(door.pos, player.forward);
    playBreachAudioLayer();
  }
}
```

## Механика: Акробатический перехват оружия в воздухе (Airborne Disarm & Catch) (SECONDARY)
- **Категория**: Главный регулятор расхода боеприпасов, источник тактической награды за агрессивный стиль и драйвер непрерывной смены пушек.
- **Описание**: Механика полностью устраняет скучную паузу на классическую перезарядку за укрытием, превращая смену оружия в непрерывный трюковой комбо-элемент прямо в гуще боя.
- **Взаимодействие игрока**: Клавиатура/Мышь: Нажатие [E] или [Mouse1] в момент наведения на силуэт летящего оружия / Мобильный тач: Тап по появившемуся золотому кольцу захвата вокруг летящего ствола.
- **Отклик**: Визуал/VFX: Вращающийся золотой шлейф (Motion Trail) за летящей пушкой, яркая контурная подсветка (Outline Glow) и эффект вспышки при успешном захвате в руку.; Звук (Web Audio API): Звонкий металлический щелчок досылания патрона в патронник (Gun Cocking 2.4 кГц) + высокий гармонический резонанс (Sine Chord 880 Гц).; Камера: Микро-доводка прицела (Magnetic Aim Snap на 5 градусов) в сторону летящего оружия в момент нажатия кнопки подхвата.; UI/Тактильность: Короткий щелкающий тактильный импульс (Haptic Tick 15 мс), появление всплывающей плашки 'TRICKSHOT READY x2.2' рядом с прицелом.
- **Техническая сложность**: Medium
- **Сильные стороны**: Высокая вовлеченность, Глубокая кривая мастерства
- **На что смотреть**: Требует точной калибровки таймингов

### Глубина механики
- **Роль в петле**: Главный регулятор расхода боеприпасов, источник тактической награды за агрессивный стиль и драйвер непрерывной смены пушек.
- **Решение игрока**: Тратить время на перезарядку своего пустого дробовика (1.8 с) или пнуть автоматчика, чтобы в воздухе поймать его заряженный ствол и сделать мгновенный критический выстрел.
- **Управление**: Клавиатура/Мышь: Нажатие [E] или [Mouse1] в момент наведения на силуэт летящего оружия / Мобильный тач: Тап по появившемуся золотому кольцу захвата вокруг летящего ствола.
- **Состояния**: `HOLSTERED_ON_ENEMY (оружие в руках врага)`, `DISARMED_AIRBORNE (оружие летит по параболе в воздухе)`, `MAGNET_SNAPPED (оружие захвачено в радиус перехвата)`, `EQUIPPED_TRICKSHOT (оружие в руках игрока с бонусом первого выстрела)`
- **Параметры и настройка**:
  - **disarm_pop_height**: `2.8 м` — Если сделать ниже 1.8 м — оружие слишком быстро падает на пол, игрок не успевает визуально зафиксировать траекторию.
  - **air_catch_window_duration**: `0.95 с` — Если сделать дольше 1.5 с — оружие зависает как в невесомости, разрушая ощущение жесткого приземленного экшена.
  - **trickshot_crit_multiplier**: `2.2 x` — Если опустить ниже 1.5х — игроки перестают рисковать ради трюка и предпочитают стрелять из базового пистолета.
  - **catch_magnet_radius**: `1.75 м` — Если сузить меньше 1.0 м — на сенсорных экранах попадание в тайминг становится почти невыполнимым.
- **Слои отклика**:
  - Визуал/VFX: Вращающийся золотой шлейф (Motion Trail) за летящей пушкой, яркая контурная подсветка (Outline Glow) и эффект вспышки при успешном захвате в руку.
  - Звук (Web Audio API): Звонкий металлический щелчок досылания патрона в патронник (Gun Cocking 2.4 кГц) + высокий гармонический резонанс (Sine Chord 880 Гц).
  - Камера: Микро-доводка прицела (Magnetic Aim Snap на 5 градусов) в сторону летящего оружия в момент нажатия кнопки подхвата.
  - UI/Тактильность: Короткий щелкающий тактильный импульс (Haptic Tick 15 мс), появление всплывающей плашки 'TRICKSHOT READY x2.2' рядом с прицелом.
- **Режим отказа**: Пропуск тайминга перехвата: оружие падает на бетон, магазин выпадает и разряжается, а поднятое с пола оружие имеет штраф -50% к точности на первые 2 секунды.
- **Кривая мастерства**: Новичок поднимает оружие с пола после боя. Эксперт выбивает пинком дробовик у первого врага, в прыжке ловит его над головой, делает выстрел x2.2 в воздухе и кидает пустой корпус во второго врага.
- **Сопротивление игры**: Камикадзе и гренадеры: при выбивании их оружия они роняют активированную гранату с таймером детонации 0.7 с прямо под ноги игроку.
- **Синергии**:
  - Кинетический пинок (основной триггер выбивания оружия из рук)
  - Векторное отражение снарядов (бросок пустого оружия блокирует летящие пули)
- **Почему это не жанровый шаблон**: Механика полностью устраняет скучную паузу на классическую перезарядку за укрытием, превращая смену оружия в непрерывный трюковой комбо-элемент прямо в гуще боя.
- **Псевдокод тика**:
```text
function updateAirCatch(dt, player, flyingWeapons, input) {
  for (let weapon of flyingWeapons) {
    if (!weapon.isAirborne) continue;
    let dist = getDistance(player.cameraPos, weapon.pos);
    if (dist <= 1.75 && isLookAtTarget(player, weapon.pos, 35.0)) {
      weapon.showHighlight(true);
      if (input.interactPressed || input.firePressed) {
        player.equipTransientWeapon(weapon.type, weapon.loadedAmmo, 2.2);
        weapon.destroy();
        playAudioCockingTrill();
        triggerHapticTick();
        break;
      }
    }
  }
}
```

## Механика: Векторный редирект взрывных объектов (Hazard Redirection Kick) (SECONDARY)
- **Категория**: Источник высокого риска и высокой награды, инструмент борьбы с дальнобойными скоплениями и боссами.
- **Описание**: Превращает вражеские снаряды и смертоносные ловушки уровня из источника опасности в самый мощный разрушительный инструмент игрока при наличии чувства ритма.
- **Взаимодействие игрока**: Клавиатура/Мышь: Нажатие [F] в окне 0.18 с до соприкосновения со снарядом / Мобильный тач: Тап по центральной зоне экрана при приближении красного индикатора опасности.
- **Отклик**: Визуал/VFX: Вспышка белого пламени в точке контакта, огненный след (Fire Ribbon Trail) за отраженным объектом и эффект радиальной ударной волны при детонации.; Звук (Web Audio API): Звонкий металлический удар наковальни (Anvil Clang 1.6 кГц) с последующим низким гулом турбины ускорения (Pitch Slide 200 -> 800 Гц).; Камера: Полная заморозка кадра (Hitstop Frame) на 0.06 с с последующей радиальной тряской камеры (Trauma Shake 0.7).; UI/Тактильность: Двойной мощный виброудар (Impact Heavy 70 мс), крупная надпись 'REFLECTED! x3.0' с эффектом вспышки интерфейса.
- **Техническая сложность**: Medium
- **Сильные стороны**: Высокая вовлеченность, Глубокая кривая мастерства
- **На что смотреть**: Требует точной калибровки таймингов

### Глубина механики
- **Роль в петле**: Источник высокого риска и высокой награды, инструмент борьбы с дальнобойными скоплениями и боссами.
- **Решение игрока**: Убегать от летящей ракеты/катящейся бочки или пойти на смертельный риск, подбежать навстречу и в идеальный тайминг пнуть угрозу обратно во врагов.
- **Управление**: Клавиатура/Мышь: Нажатие [F] в окне 0.18 с до соприкосновения со снарядом / Мобильный тач: Тап по центральной зоне экрана при приближении красного индикатора опасности.
- **Состояния**: `INCOMING_HAZARD (снаряд/бочка движется к игроку)`, `PARRY_TIMING_WINDOW (активное окно отражения 0.18 с)`, `DEFLECTED_SUPERCHARGED (снаряд ускорен и заряжен критическим уроном)`, `DETONATION_CASCADE (финальный взрыв с цепной реакцией)`
- **Параметры и настройка**:
  - **parry_window_duration**: `0.18 с` — Если сузить до 0.10 с — механика становится непроходимой при пинге в браузере и 60fps; если расширить до 0.30 с — исчезает напряжение и цена риска.
  - **deflected_speed_multiplier**: `2.4 x` — Если сделать ниже 1.8х — отраженная бочка летит слишком медленно и враги успевают разбежаться из зоны поражения.
  - **deflected_blast_radius**: `4.6 м` — Если уменьшить до 2.5 м — отражение одиночных ракет не окупает риск получения прямого урона.
  - **hazard_kick_self_damage_immunity**: `0.45 с` — Если убрать иммунитет — игрок гарантированно взрывает сам себя при пинке близко расположенной бочки.
- **Слои отклика**:
  - Визуал/VFX: Вспышка белого пламени в точке контакта, огненный след (Fire Ribbon Trail) за отраженным объектом и эффект радиальной ударной волны при детонации.
  - Звук (Web Audio API): Звонкий металлический удар наковальни (Anvil Clang 1.6 кГц) с последующим низким гулом турбины ускорения (Pitch Slide 200 -> 800 Гц).
  - Камера: Полная заморозка кадра (Hitstop Frame) на 0.06 с с последующей радиальной тряской камеры (Trauma Shake 0.7).
  - UI/Тактильность: Двойной мощный виброудар (Impact Heavy 70 мс), крупная надпись 'REFLECTED! x3.0' с эффектом вспышки интерфейса.
- **Режим отказа**: Опоздание с нажатием пинка на 0.05 с: ракета/бочка детонирует в момент замаха ноги, нанося игроку полный урон (50 HP) и отбрасывая его в угол комнаты.
- **Кривая мастерства**: Новичок обходит взрывоопасные бочки стороной, боясь задеть их. Эксперт специально провоцирует ракетчиков на залп, бежит наперерез и пинком запускает ракету точно в скопление турелей.
- **Сопротивление игры**: Лазерные снайперы и огнеметчики: их атаки не имеют дискретного физического тела и не могут быть отражены кинетическим пинком, вынуждая использовать слайды.
- **Синергии**:
  - Кинетический пинок (использует общий тайминг и позиционирование ноги)
  - Штурмовой вылом дверей (пнутая сквозь огонь дверь превращается в горящий таран)
- **Почему это не жанровый шаблон**: Превращает вражеские снаряды и смертоносные ловушки уровня из источника опасности в самый мощный разрушительный инструмент игрока при наличии чувства ритма.
- **Псевдокод тика**:
```text
function updateHazardRedirect(dt, player, hazards, kickAction) {
  for (let item of hazards) {
    let dist = getDistance(player.pos, item.pos);
    if (dist <= 2.1 && isObjectInFront(player, item.pos, 45.0)) {
      if (kickAction && item.isReflectable) {
        item.velocity = player.forward.clone().multiplyScalar(item.baseSpeed * 2.4);
        item.damageMultiplier = 3.0;
        item.team = 'PLAYER';
        applyHitstop(0.06);
        player.grantInvulnerability(0.45);
        playAudioAnvilReflect();
        triggerCameraTrauma(0.7);
        return;
      }
    }
  }
}
```
