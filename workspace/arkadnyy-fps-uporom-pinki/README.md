# Аркадный FPS: Упором Пинки 🎮👢

> **Выбивай двери с ноги, запускай врагов в стены и лови оружие на лету в динамичном аркадном экшен-рогалике от первого лица!**

---

## 🌟 Об игре
- **Жанр**: 3D Аркадный FPS / Экшен-рогалик с физикой кинетических ударов
- **Движок & Рендерер**: Three.js + 3D Physics Simulation (60 Гц фиксированный шаг)
- **Звук**: Процедурный Web Audio API синтезатор эффектов и динамический бит
- **Платформа**: Playgama Bridge (Яндекс Игры, VK, CrazyGames, Web)
- **Ориентация**: Landscape (горизонтальная)

---

## 🚀 Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки (Vite)
npm run dev

# Проверка TypeScript и сборка продакшен-бандла
npm run build

# Предпросмотр продакшен-сборки
npm run preview
```

## 🎮 Управление

### На компьютере (Клавиатура и Мышь)
- **WASD / Стрелки** — Перемещение и стрейф
- **Мышь** — Обзор камеры (кликните по экрану для захвата курсора)
- **ПКМ или F** — Мощный кинетический пинок ногой
- **ЛКМ** — Стрельба из экипированного оружия
- **Space / Shift / C** — Спринт и скоростной подкат (слайд)
- **E** — Перехват летящего в воздухе оружия / Взаимодействие
- **P / Esc** — Пауза игры

### На мобильных устройствах (Сенсорный экран)
- **Левая половина экрана** — Плавающий виртуальный джойстик (появляется под пальцем)
- **Правая половина экрана** — Зона свайпа для вращения обзора
- **Кнопка 👢 (ПИНОК)** — Основная крупная кнопка удара ногой
- **Кнопка 🎯 (ОГОНЬ)** — Выстрел из оружия
- **Кнопка 💨 (СЛАЙД)** — Скоростной рывок / подкат
- **Кнопка 🧲 (ПЕРЕХВАТ)** — Захват оружия в воздухе (подсвечивается золотом при приближении ствола)

> 💡 **Совет для отладки**: Добавьте параметр `?touch=1` к URL в браузере на ПК, чтобы протестировать мобильную раскладку управления мышью.

## 🏗️ Структура проекта (`src/`)

```text
src/
├── main.ts                    # Точка входа, инициализация Playgama Bridge и запуск Game
├── types/
│   └── index.ts               # Типы стейт-машины, оружия, врагов, перков и событий
├── core/
│   ├── Game.ts                # Главный координатор состояний и игрового цикла
│   ├── GameLoop.ts            # Фиксированный 60Гц цикл с аккумулятором и хит-стопом
│   └── EventBus.ts            # Типизированная шина сообщений (pub/sub)
├── platform/
│   ├── PlaygamaService.ts     # Адаптер @playgama/bridge (Реклама, Облако, Лидерборды)
│   └── StorageService.ts      # Синхронизация сохранений с дебаунсингом
├── audio/
│   └── AudioManager.ts        # Процедурный синтезатор звуков и аудио-эффектов
├── physics/
│   └── PhysicsWorld.ts        # 3D физический мир, AABB-коллизии, лучевые запросы
├── rendering/
│   ├── SceneManager.ts        # Three.js сцена, камера с динамическим FOV и тряской
│   ├── ProceduralModels.ts    # 3D модели ботинка, оружия, врагов, дверей и бочек
│   └── ParticleSystem.ts      # Инстансированная система частиц (искры, щепки, обломки)
├── entities/
│   ├── Player.ts              # FPS контроллер игрока, механика пинка и стрельбы
│   ├── Enemy.ts               # Враги, логика преследования, рэгдолл и сплэт о стены
│   ├── Door.ts                # Выбиваемые двери-снаряды
│   ├── Barrel.ts              # Взрывоопасные пинаемые бочки
│   ├── Projectile.ts          # Снаряды и отражаемые ракеты
│   ├── WeaponPickup.ts        # Летящее оружие для трюкового перехвата
│   └── EntityManager.ts       # Управление жизненным циклом сущностей
├── systems/
│   ├── CombatSystem.ts        # Расчет урона, хит-стопа, комбо-серий и сплэша
│   ├── LevelGenerator.ts      # Процедурная генерация секторов комнат
│   └── UpgradeSystem.ts       # Рогалик-драфт 3 карт улучшений
└── ui/
    ├── TouchControls.ts       # Мобильный тач-слой на Pointer Events
    └── UIManager.ts           # HUD, меню, мастерская, пауза и экраны результатов
```
