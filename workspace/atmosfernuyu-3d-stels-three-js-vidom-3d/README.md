# Атмосферный 3D-Стелс (Three.js) 🎮⚡

> **Исследуйте лабиринты библиотек, управляйте развитием колонии кротов, собирайте древние свитки и защищайтесь от стражей!**

---

## 🌟 Обзор проекта
- **Жанр**: 3D Стелс / Рогалик-арена / Менеджмент колонии
- **Движок рендера**: **Three.js** (WebGL2) с процедурными шейдерами
- **Физика**: 3D симуляция твердых тел с коллизиями, импульсами и рэгдоллом
- **Аудио**: Web Audio API процедурный синтезатор и эмбиентная музыка
- **Платформа**: Playgama Bridge v2 (Yandex Games, VK, OK, CrazyGames, Web)
- **Ориентация**: Альбомная (Landscape)

## 🕹️ Управление

### На клавиатуре и мыши (ПК):
- `WASD` / `Стрелки` — Передвижение крота-исследователя
- `J` / `Пробел` / `ЛКМ` — Основная атака вращающимся буром
- `K` / `Shift` / `ПКМ` — Подземный турбо-рывок (неуязвимость 0.35 с)
- `E` / `Q` — Эхолокационный сонарный импульс (раскрывает врагов и оглушает на 1.4 с)
- `Escape` / `P` — Пауза

### На сенсорном экране (Мобильные):
- **Левая половина экрана** — Плавающий виртуальный джойстик (появляется под пальцем, мертвая зона 8%)
- **Кнопка ⚔️ УДАР** — Атака буром
- **Кнопка 💨 РЫВОК** — Ускоренный рывок
- **Кнопка 📡 СОНАР** — Сонарный импульс
- **Тестирование на десктопе**: Добавьте `?touch=1` в адресную строку для принудительного включения мобильной раскладки.
