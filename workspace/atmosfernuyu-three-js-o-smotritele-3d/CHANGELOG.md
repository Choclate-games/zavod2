# Changelog — Атмосферную three.js о смотрителе 3D

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [SemVer](https://semver.org/lang/ru/).

## [Unreleased]

### Added
- Полноценная игра: погружение в жёлоб, сбор светящихся образцов, бои с существами и возврат к поверхности.
- Три счётчика-ядро: свет/энергия, воздух и прочность корпуса делят один ресурс — прожектор тускнеет, когда кончается энергия.
- Управление на клавиатуре (WASD/ Space/ Shift/ J/ K/ P) и полноценный тач (плавающий стик + кнопки Pulse/Ascend/Descend/Heavy на Pointer Events).
- Волны врагов и экран выбора из 3 карт улучшений между волнами.
- Интеграция Playgama Bridge: наградные и межстраничные ролики, облачное сохранение, таблица лидеров, авторизация.
- Синтезированное аудио через Web Audio API с единым master-усилением и плавным мьютом.
- Авто-тюнер качества графики, который сходится к максимальной детализации под 60 FPS.
- Телеметрия первого действия и первой награды, сохранение рекорда глубины и шестерен.

### Changed
- Заголовок страницы и все внутриигровые названия сделаны байт-идентичными.
- Управление скрывается в меню/паузе/результатах и сбрасывается при сворачивании вкладки.
