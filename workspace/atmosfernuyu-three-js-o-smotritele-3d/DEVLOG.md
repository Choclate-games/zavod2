## 2026-08-20 12:40 — Полная игровая структура и ядро геймплея
- **Задача**: создать рабочую HTML5-игру целиком: рендерер, физику, управление, аудио и Playgama Bridge, без заглушек и TODO.
- **Сделано**:
  - Каркас: `package.json`, `vite.config.ts`, `tsconfig.json`, `index.html` (page-lock, viewport-fit=cover, байт-идентичный заголовок), `src/style.css`.
  - Ядро геймплея реализовано как **три счётчика — свет/энергия, воздух, прочность корпуса** — прожектор, двигатели и сонар делят один запас энергии; яркость света падает по мере траты энергии (видимое обещание ядра). Возврат к поверхности восполняет воздух.
  - `core/`: `EventBus` (типизированная шина), `GameLoop` (фикс. 60 Гц + аккумулятор), `InputManager` (клавиатура + тач в параллель), `Game` (координатор/стейт-машина).
  - `platform/`: `PlaygamaService` (инит с таймаутом 10 с, `game_ready` ровно раз, rewarded/interstitial с capability-гейтингом и single-in-flight, лидерборд, авторизация), `StorageService` (один JSON-ключ, normalize, зеркало localStorage, flush на pagehide).
  - `physics/`: `PhysicsWorld` (Rapier3D, аккумулятор, shaft-арена из 6 статик-стен), `RagdollController` (трупы врагов с отскоком и затуханием).
  - `entities/`: `Player` (тело Rapier + меш + ресурсы + автояркость света), `Enemy`+`EnemyPool` (переиспользуемые тела, `setEnabled`), `Weapon` (гейтинг пульса по кулдауну/энергии).
  - `systems/`: `CombatSystem` (сонар-хитбоксы, отбрасывание, хит-стоп 40 мс, контактный урон), `WaveManager` (волны по мере погружения), `UpgradeManager` (3 карты, гарантия Rare/Epic), `CrowdFavorSystem` (favor → бонус-бёрст), `SampleField` (сбор образцов).
  - `rendering/`: `SceneManager` (тёмная сцена, туман, прожектор, follow-камера, авто-тюнер качества по каденции отрисованных кадров), `MeshPool` (InstancedMesh-пул частиц), `Shaders` (материалы).
  - `ui/`: `UIManager` (HUD, бары, меню, пауза, результаты, загрузка), `VirtualJoystick` (плавающий стик + кнопки на Pointer Events, deadzone 8%, сброс при скрытии/blur), `CardModal` (3 карты).
  - `audio/`: `AudioManager` (Web Audio API, единый master GainNode с рампом, suspended→resume по жесту, раздельный mute игрока/платформы, синтез без ассетов; Howler подключён как движок).
  - `telemetry/`: `Telemetry` (микротаски, `trackOnce` для first_action/first_reward).
  - `i18n/`: `I18n` (en/ru, `_touch`-варианты, translateDOM).
- **Затронутые файлы**: весь `src/` (≈30 модулей), `package.json`, `vite.config.ts`, `tsconfig.json`, `index.html`, `src/style.css`.
- **Проверено**: `npm install` (ok), `npx tsc --noEmit` — ошибок нет, `npm run build` — собирается (2.9 МБ / 989 КБ gzip, в бюджете <4.2 МБ), `npm run dev` — сервер поднимается, `index.html` и `/src/main.ts` отдаются (HTTP 200).
- **Известные проблемы / следующий шаг**: полноценный прогон в браузере (WebGL + Rapier wasm) в этой среде не выполнялся автоматически — рекомендуется проверка `npm run dev` в браузере и замер FPS/телеметрии; при необходимости докрутить баланс ресурсов и баллистику врагов.
