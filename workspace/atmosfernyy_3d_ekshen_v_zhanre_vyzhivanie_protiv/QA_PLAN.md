# QA & Testing Plan: Маяк: Ночная Вахта

## 1. Functional Test Matrix
- [ ] Тест вращения прожектора: проверка соответствия угла луча позиции курсора/тача на 360° без застреваний на границе 0°/360°.
- [ ] Тест термодинамики: зажатие фокуса ровно на 3.5 секунды вызывает Overheat; отпускание на 2.5 секунды полностью обнуляет шкалу.
- [ ] Тест таймера вахты: ровно через 180 секунд реального времени (при 60 FPS) запускается последовательность победного рассвета.
- [ ] Тест коллизий периметра: достижение монстром основания башни стабильно отнимает HP маяка с шагом урона.

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS на бюджетном мобильном устройстве (уровня Mali-G52 / Adreno 610) при 250 активных монстрах в кадре.
- [ ] Количество Draw Calls не превышает 65 при максимальной плотности орды.
- [ ] Время начальной загрузки и инициализации сцены Three.js не превышает 2.2 секунды на 4G-соединении.

## 3. Target Browser Matrix
- Chrome Mobile (Android 11+)
- Safari Mobile (iOS 15+)
- Desktop Chrome / Edge / Firefox (Windows 10/11, macOS)
- Yandex Browser (Desktop & Mobile WebGL)
