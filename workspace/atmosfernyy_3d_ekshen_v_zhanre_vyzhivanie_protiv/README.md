# Маяк: Ночная Вахта

Атмосферный 3D-экшен-выживание на 180 секунд: вы — смотритель маяка и держите
луч прожектора против орды глубоководных тварей до рассвета 06:00.

## Запуск

```bash
npm install
npm run dev        # dev-сервер Vite
npm run build      # проверка типов + сборка в dist/
npm run preview    # предпросмотр собранной версии
```

Проверки приёмки:

```bash
node scripts/check-spec.mjs   # статическая часть
node scripts/smoke.mjs        # сборка, запуск в браузере, ввод, телефон
```

## Управление

### Клавиатура и мышь
| Действие | Ввод |
|---|---|
| Поворот прожектора 360° | движение мыши, либо A/D и стрелки |
| Термо-фокус (прожигающий луч) | удерживать ПКМ / ЛКМ / Пробел |
| Паровой сброс (контрудар) | E или F |
| Пауза | Esc или P |
| Звук вкл/выкл | M |

### Телефон
- Драг пальцем по левой/центральной зоне экрана (70% ширины) — поворот прожектора.
- Круглая кнопка «ФОКУС» справа — удержание прожигающего луча.
- Кнопка «СБРОС» над ней — паровой сброс (активен при заряде от цепных убийств).
- Принудительная раскладка для отладки: `?input=touch` / `?input=desktop` (`?touch=1|0`).

## Как играть

1. Сканируйте периметр: широкий луч (60°) замедляет тварей на 65%, но не жжёт.
2. Удерживайте фокус (10°) на плотных скоплениях: урон растёт до +100% за 2 секунды,
   а термометр линзы идёт к 100 °C. Перегрев заклинивает прожектор на 3 секунды.
3. Био-мины взрываются после 0.8 с прогрева ядром луча: радиус 4.5 м, 250 урона,
   соседние мины детонируют каскадом. Цепные убийства копят заряд парового сброса.
4. Продержитесь 180 секунд (до 06:00), сохранив прочность маяка выше нуля.

## Структура каталогов

```text
├── index.html                  # точка входа Vite
├── balance.yaml                # числа игры; код читает их отсюда
├── public/playgama-bridge-config.json
├── src/
│   ├── main.ts                 # bootstrap: мост -> сейв -> движок -> UI -> game_ready
│   ├── core/                   # Game (координатор), GameLoop 60 Гц, EventBus
│   ├── config/Balance.ts       # разбор balance.yaml + резервные значения
│   ├── platform/               # PlaygamaService (реклама/сейв/лидерборд), StorageService
│   ├── physics/                # SpatialGrid + аркадная физика арены
│   ├── entities/EnemyManager.ts# пул орды на типизированных массивах
│   ├── systems/                # LensSystem (термодинамика), CombatSystem, WaveDirector
│   ├── rendering/              # SceneManager, процедурные модели, луч, океан, небо, частицы
│   ├── input/InputRouter.ts    # две схемы управления, переключение на лету
│   ├── audio/AudioManager.ts   # процедурный Web Audio, один мастер-гейн
│   └── ui/                     # theme.css (токены), HUD, экраны, тач-слой, i18n
├── scripts/                    # check-spec.mjs, smoke.mjs, fetch-knowledge.mjs
└── docs/ref/                   # база знаний фабрики (если загружалась)
```
