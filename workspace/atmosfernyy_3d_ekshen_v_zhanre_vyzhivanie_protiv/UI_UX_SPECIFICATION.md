# UI/UX Specification: Маяк: Ночная Вахта

## 1. Материал интерфейса
Интерфейс живёт в том же мире, что и сцена. Проверка: если закрыть игровое поле,
меню обязано выдавать именно эту игру, а не любую другую.

- **Тема от арт-директора**: Латунный морской дизельпанк: темные металлические плашки с заклепками, аналоговые круглые циферблаты часов и термометра, янтарная подсветка шрифтов.
- **Визуальный язык**: Дизельпанк-готика: темный металл (#1B222E), теплая латунь (#D49B42), фосфорный бирюзовый акцент (#1CE8B5) для угроз и сигнальный рубиновый (#E63946) для перегрева.
- **Типографика**: Четкий геометрический гротеск с винтажными засечками для заголовков (Cinzel / Oswald) и моноширинный шрифт для таймеров и счетчиков (Share Tech Mono).

## 2. Акценты: один цвет — один смысл
Разный цвет у каждой кнопки «чтобы отличались» — главная ошибка игрового
интерфейса. На одном экране одновременно видно не больше двух акцентов.

| Токен | Единственный смысл |
|---|---|
| `base_brass` | #D49B42 (Латунные рамки приборов и циферблаты) |
| `biomass_glow` | #1CE8B5 (Биолюминесценция врагов и цепные взрывы) |
| `primary_focus` | #FFF6D6 (Ослепительно-янтарное ядро луча) |
| `warning_heat` | #E63946 (Перегрев линзы и критический урон) |

Все значения — токенами в `src/ui/theme.css`: цвета, гарнитуры, шкала отступов,
радиусы, длительности, порядок слоёв `--z-*`. Литерал цвета внутри экрана — баг.

## 3. Композиция экрана
Меню и экраны между сессиями лежат ПОВЕРХ живой игровой сцены — той же, что в
игре, только с медленной камерой. Непрозрачная заливка на весь экран запрещена:
подложка только под текстом и кнопками.

- **Сцена за меню**: Камера медленно облетает окутанный ночным туманом маяк, волны с грохотом бьются о скалы, лампа маяка мерно вращается, прорезая тьму.

Экран — не колонка кнопок по центру. Три зоны, и каждый элемент лежит ровно в одной:

1. **Идентичность** — что это за экран: заголовок, режим, состояние игрока.
2. **Главное действие** — ровно одно на экран, самое крупное и единственное с
   основным акцентом.
3. **Второстепенный ряд** — всё остальное, одним рядом или сеткой, одним весом.

Зоны нажатия: основная ≥ 96 px, остальные ≥ 64 px, зазор ≥ 12 px, отступы через
`env(safe-area-inset-*)` плюс измеренная высота липкого баннера. Ни один экран не
скроллит страницу: длинный список скроллится во внутреннем контейнере.

## 4. Набор компонентов (закрытый)
Всё на экране — один из этих компонентов. Одноразовый `<div>` с инлайновыми
стилями — это то, из-за чего второй экран перестаёт совпадать с первым.

- CircularThermometer (радиальный прогресс-бар с эффектом накала)
- AnalogWatchTimer (стилизованные круглые часы с движущейся стрелкой)
- ThreatEdgePointers (пульсирующие стрелки на краях экрана)
- ScoreComboPopup (всплывающий текст комбо с анимацией масштабирования)

Каждый интерактивный компонент несёт пять состояний: покой, наведение, нажатие,
недоступность, `:focus-visible`; асинхронное действие — ещё и `loading`.

## 5. HUD
Не больше пяти постоянных элементов на телефоне. Пять якорей, посередине экрана
не висит ничего, кроме временной обратной связи.

| Якорь | Что там |
|---|---|
| `bottomLeft` | Pause Button & Sound Toggle |
| `bottomRight` | Heat Gauge & Focus Button (Touch) |
| `topCenter` | Watch Clock (00:00 - 06:00) & Remaining Time |
| `topLeft` | Tower HP Bar & Armor Indicator |
| `topRight` | Score & Combo Multiplier |

Элементы:
- Круговой аналоговый термометр линзы (Heat Gauge) в правом нижнем углу
- Морские часы вахты (00:00 -> 06:00) по центру вверху с таймером (180с)
- Индикатор целостности фундамента маяка (HP Bar 100%) в левом верхнем углу
- Счетчик очков и комбо-детонаций в правом верхнем углу
- Индикаторы векторов угроз (мигающие бирюзовые стрелки по краям экрана)

Меняющиеся числа — `tabular-nums` в слоте фиксированной ширины, полосы —
`transform: scaleX()`, а не `width`. Текст поверх геймплея всегда с подложкой или
обводкой: белое число исчезает на светлой сцене.

## 6. Состояние, показанное миром, а не оверлеем
- Раскаливание латунного купола маяка в 3D сцене по мере роста шкалы тепла.
- Клубы пара, вырывающиеся из вентиляционных решеток башни при остывании.
- Физические трещины на гранитной кладке башни при падении HP.

## 7. Каталог экранов
### Экран: MainMenu
- **Что на экране**: Заглавный экран: Старт вахты, Таблица лидеров, Настройки, Выбор скина луча.
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: GameplayHUD
- **Что на экране**: Минималистичный игровой интерфейс с термометром, часами и компасом.
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: PauseModal
- **Что на экране**: Окно паузы с кнопками 'Продолжить', 'Звук', 'В меню'.
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: VictoryScreen
- **Что на экране**: Экран рассвета 06:00: Статистика ночи, рекорд комбо, кнопка удвоения очков за Ad.
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: DefeatScreen
- **Что на экране**: Экран разрушения маяка: Время выживания, кнопка спасения вахты (Revive Ad), возврат в меню.
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

**Переходы**: MainMenu -> (Начать вахту) -> GameplayHUD -> (HP=0 -> DefeatModal -> ReviveAd / Restart) -> (Time=180s -> VictoryModal -> NextNight / Menu)

## 8. Состояния экрана
- Normal State: янтарный луч, спокойный шум волн, термометр < 50%.
- High Heat State: пульсирующий красный термометр, свист пара, купол башни светится малиновым.
- Overheat State: аварийный звон, дым, тусклый луч 10%, надпись 'COOLING 3.0s'.
- Victory State: рассветные лучи, ликующий аккорд, испепеление всех врагов.

## 9. Отклик и движение
- При фокусе: экран слегка вибрирует, термометр быстро заполняется оранжевым.
- При Overheat: вспышка красного экрана, шипение пара и блокировка кнопки фокуса на 3с.
- При цепном взрыве: вспышка бирюзового света и эффектная надпись 'COMBO x5' по центру.
- При рассвете 06:00: экран заливается теплым золотым светом, мгновенно испепеляя всех оставшихся монстров.

Переход один на всю игру и укладывается в 300 мс; анимируются только `transform`
и `opacity`; `prefers-reduced-motion: reduce` убирает трансформации.

## 11. Чек-лист приёмки интерфейса
- [ ] Ни одного литерала цвета, шрифта, радиуса или длительности вне `theme.css`.
- [ ] Слои над канвасом не перехватывают игровой ввод: контейнеры `pointer-events: none`.
- [ ] Каждый экран помещается в измеренный вьюпорт, страница не скроллится.
- [ ] Одно главное действие на экран, не больше двух акцентов одновременно.
- [ ] Меняющиеся числа не дёргают строку HUD.
- [ ] У каждого экрана описаны загрузка, пустота и ошибка.
- [ ] Возможность, которой нет на площадке, не нарисована вовсе.
- [ ] Ни `alert`/`confirm`, ни эмодзи вместо иконок, ни `z-index` мимо токенов.
- [ ] Самая длинная переведённая строка помещается в кнопку.
- [ ] За меню видна живая сцена игры, а не заливка цветом.
- [ ] Ни одного эмодзи в подписи кнопки: иконка — инлайновый SVG с `currentColor`.
- [ ] У каждого экрана расписаны три зоны, а не «карточка по центру».
- [ ] С закрытым игровым полем меню всё ещё узнаётся как «Маяк: Ночная Вахта».
