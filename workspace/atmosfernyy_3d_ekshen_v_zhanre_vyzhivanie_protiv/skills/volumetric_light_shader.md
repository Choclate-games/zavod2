# Skill: Кастомный шейдер конуса объемного света и обнаружения

## Purpose
Создание кинематографичного светящегося луча прожектора маяка с процедурным затуханием и каплями дождя.

## When to Use
При визуализации луча линзы Френеля и расчете пересечений со скалой и монстрами.

## Core Rules & Constraints
- Использовать коническую геометрию с кастомным ShaderMaterial (AdditiveBlending, transparent: true).
- Мягкое затухание по краям конуса (Fresnel term) для избежания резких полигональных стыков.
- Процедурный шум в фрагментном шейдере для имитации лучей сквозь ливень.

## System Architecture
LighthouseRig -> ConeGeometry -> VolumetricShaderMaterial -> LightDetectionSystem.

## Implementation Guidance
Передавать в uniform-переменные угол раствора луча (fov), текущий уровень нагрева (для подмешивания раскаленного оттенка) и время для анимации дождевых полос.

## Common Mistakes to Avoid
- ❌ **Mistake**: Использование тяжелого пост-процессинга с объемным светом (Screen Space God Rays), роняющего производительность на смартфонах.
- ❌ **Mistake**: Отсутствие AdditiveBlending, из-за чего свет перекрывает геометрию черными артефактами.

## Validation Checklist
- [ ] Шейдер компилируется без предупреждений на WebGL 1.0 и WebGL 2.0.
- [ ] Плавная интерполяция угла конуса от 60° до 10° при включении фокуса.
- [ ] Шейдер корректно реагирует на шкалу перегрева (смена цвета на оранжево-красный).
