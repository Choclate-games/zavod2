# Changelog — Браузерную «почтальон улиток» three.js

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [SemVer](https://semver.org/lang/ru/).

## [Unreleased]

### Added
- Каркас проекта и спецификация игры.
- Играбельный сад с цветами, гнездом, улитками-курьерами, письмами и феромонными маршрутами.
- Управление мышью, клавиатурой и полноценным Pointer Events touch-слоем с плавающим стиком.
- Влажность сада, расход росы, автономные роли улиток и спавн птиц, ос и жуков.
- Сохранение прогресса через Playgama Bridge с безопасным локальным offline fallback.

### Changed
- Проект теперь запускается через Vite командами `npm run dev`, `npm run build` и `npm run preview`.

### Fixed
- Пауза теперь стабильно возвращается в игру кнопкой «Продолжить», `P` или `Esc`, не сбрасывая состояние из-за внешних событий платформы.
- Кнопка «Продолжить» больше не остаётся заблокированной после паузы, пришедшей от платформы.
- Даже если звуковой контекст браузера недоступен, нажатие «Продолжить» всё равно возобновляет игру.
