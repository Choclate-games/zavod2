# QA & Testing Plan: Куриный Побег 3D: Стелс на Ферме

## 1. Functional Test Matrix
- [ ] Проверка 100% невидимости неподвижной курицы под коробкой внутри конуса зрения собаки
- [ ] Проверка срабатывания тревоги, если курица двигается в коробке на глазах у собаки
- [ ] Корректное блокирование конуса зрения сплошными препятствиями (стены амбара, тюки сена)
- [ ] Открытие ворот выхода строго после сбора 100% необходимых зерен
- [ ] Работа кнопки Revive с корректным респавном курицы и очисткой статуса тревоги у всех собак

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS на iPhone 11 / Redmi Note 9 и выше
- [ ] Количество Draw Calls на сцене не превышает 45
- [ ] Потребление оперативной памяти WebGL Heap менее 120 МБ

## 3. Target Browser Matrix
- Chrome Desktop / Mobile (Windows, Android)
- Safari Mobile (iOS 15+)
- Yandex Browser (Desktop & Android)
- VK App WebView / In-App Browser
