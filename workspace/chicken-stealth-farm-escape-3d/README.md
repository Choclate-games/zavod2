# Куриный Побег 3D: Стелс на Ферме 🎮

> **Дерзкая курица планирует побег века! Прокрадитесь мимо патрулирующих фермерских псов, прячьтесь под картонную коробку при малейшей опасности, соберите все золотые зерна, чтобы взломать замок ворот, и вырвитесь на свободу!**

---

## 🌟 Обзор Проекта
- **Жанр**: 3D Стелс-головоломка / Аркадный Экшен (Изометрический стелс / Тактический лабиринт)
- **Рендерер**: **Three.js** (^0.170.0) + **Rapier3D** (@dimforge/rapier3d-compat 0.13.x)
- **Платформа**: Playgama Bridge v2 (Yandex Games / VK / WebGL)
- **Ориентация**: Landscape
- **Целевая аудитория**: Широкая казуальная и мидкорная аудитория 10-35 лет
- **Ключевой хук**: Механика маскировки картонной коробкой в стиле Metal Gear Solid, перенесенная в комедийный сеттинг фермы с динамическими конусами обзора сторожевых собак.

---

## 🎮 Управление

### На клавиатуре (ПК):
- **WASD** / **Стрелки**: Перемещение курицы в изометрии
- **Пробел (Space)** / **E**: Спрятаться / Снять коробку-маскировку
- **P** / **Escape**: Пауза и настройки звука

### На смартфоне / Сенсорных экранах:
- **Левая половина экрана**: Плавающий виртуальный джойстик (2 оси, мертвая зона 8%, Pointer Events)
- **Правая кнопка «КОРОБКА»**: Мгновенное надевание и снятие маскировочной коробки
- Для принудительного включения тач-управления на ПК используйте параметр `?touch=1`

## 🛠️ Запуск и Разработка

### Установка зависимостей:
```bash
npm install
```

### Запуск локального сервера разработки:
```bash
npm run dev
```

### Сборка релизной версии:
```bash
npm run build
```
