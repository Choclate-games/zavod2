# UI/UX Specification: Куриный Побег 3D: Стелс на Ферме

## 1. HUD Overlay Elements
- Счетчик собранных зерен (иконка колоска + '7 / 10')
- Круговой индикатор готовности ворот побега
- Кнопка 'Маскировка (Коробка)' в правом нижнем углу с индикатором статуса
- Плавающий виртуальный джойстик в левой части экрана
- Кнопка паузы / настроек в верхнем углу
- Мини-индикатор тревоги фермы (Safe / Suspicious / Alarm!)

## 3. Screen Catalog
### Screen: Main Menu
- 3D-диорама фермы с бродящей курицей, кнопки 'В БОЙ!', 'Гардероб Скинов', 'Настройки' и таблица лидеров.
### Screen: Gameplay Hud
- Минималистичный интерфейс, не закрывающий обзор изометрии: джойстик, счетчик зерен, большая кнопка коробки.
### Screen: Victory Modal
- Окно победы с 3 звездами за скорость, количеством собранных зерен, кнопкой 'Удвоить награду (Видео)' и переходом на след. уровень.
### Screen: Game Over Modal
- Комичная анимация лающей собаки, кнопка 'Спастись под коробкой (Revive Ad)' и кнопка 'Переиграть'.
### Screen: Skin Shop
- Выбор скинов курицы и коробок с предпросмотром 3D-моделей и покупкой за зерна.
