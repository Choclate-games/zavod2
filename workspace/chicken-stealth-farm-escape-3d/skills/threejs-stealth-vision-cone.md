# Skill: Генератор Процедурных Конусов Зрения Three.js

## Purpose
Обеспечение высокопроизводительного рендеринга динамических секторов видимости с мягким шейдером затухания и raycast-окклюзией.

## When to Use
При создании стелс-игр с охранниками, прожекторами и камерами наблюдения на Three.js.

## Core Rules & Constraints
- Использовать единую переиспользуемую BufferGeometry для конуса с динамическим обновлением атрибута position.
- Применять MeshBasicMaterial с additive blending и альфа-градиентом для экономии GPU.
- Ограничивать количество лучей трассировки в зависимости от профиля мобильного устройства.

## System Architecture
DogVisionSystem -> RaycastOcclusionManager -> DynamicConeGeometryBuffer -> ToonShaderMaterial

## Implementation Guidance
Генерировать веер треугольников из центральной точки глаз собаки к точкам пересечения лучей с препятствиями.

## Common Mistakes to Avoid
- ❌ **Mistake**: Пересоздание new THREE.BufferGeometry() каждый кадр вместо мутации существующих буферов вершин
- ❌ **Mistake**: Игнорирование высоты препятствий при проверке видимости

## Validation Checklist
- [ ] Буферы вершин переиспользуются через .needsUpdate = true
- [ ] Материал конуса корректно меняет цвет с зеленого на красный при тревоге
- [ ] Конус не просвечивает сквозь сплошные стены амбаров
