# Game Design Document (GDD): Бурильщик Бездны: Рикошет Руды

## 1. Executive Summary & Vision
- **Title**: Бурильщик Бездны: Рикошет Руды
- **Vision Statement**: Создать главный веб-хит в жанре экшен-майнеров с плавной адаптацией под мобильные экраны, сочным тактильным откликом разрушений и глубокой вариативностью синергий билдов.
- **Elevator Pitch**: Вертикальный 2D рогалик-майнер, где вы управляете боевым буром, уничтожаете процедурную пиксельную породу и запускаете рикошетящие лазеры, испепеляющие орды подземных тварей. Каждые 50 метров — выбор перка, каждые 200 метров — колоссальный босс!
- **Genre**: 2D Экшен-рогалик / Майнер (Вертикальный шахтёр / Bullet Heaven)
- **Target Audience**: Любители Dome Keeper, Noita, Vampire Survivors и Mr. Mine; казуальные и мидкорные игроки мобильного веба 16-35 лет, ценящие сочную физику разрушений и быстрые сессии.

## 3. Player Fantasy & Core Hook
- **Player Fantasy**: Пилот тяжелобронированного высокотехнологичного бурового меха, пробивающегося сквозь недра враждебной планеты, расщепляющего скалы и плавящего титанических боссов лучами рикошета.
- **Core Hook**: Гипер-удовлетворяющее пиксельное разрушение породы в комбинации с лазерным авто-рикошетом, превращающим каждый узкий туннель в смертоносную световую ловушку для подземных чудовищ.
- **Unique Value Proposition**: Уникальный симбиоз физического майнинга в разрушаемом пиксельном мире и рикошетной баллистики Vampire Survivors: чем уже прорытый туннель, тем выше плотность лазерных отражений и сокрушительнее урон.

## 4. Session Model & Game Loop
- **Session Duration**: Быстрые вертикальные спуски по 4-8 минут с постоянным мета-прогрессом и открытием новых буров и лазерных модулей.
- **Core Gameplay Loop**:
```text
Бурение породы вниз -> Автострельба с рикошетом по монстрам -> Сбор выпадающей руды -> Выбор перка каждые 50 метров -> Битва с боссом на рубеже биома -> Эвакуация / Гибель -> Мета-улучшение бура и лазеров в ангаре.
```
- **Win Conditions**: Пройти 5 глубинных биомов (1000 метров), победить Древнее Ядро Бездны и успешно эвакуировать ультра-редкое Реликтовое Ядро.
- **Lose Conditions**: Полное истощение очков прочности (HP) бурового меха или перегрев реактора при критическом давлении.

## 5. Player Actions & Controls
- **Movement**: Smooth 360-degree locomotion with responsive controls.
- **Offense**: Dynamic attack abilities, stance modifiers, and combo chains.
- **Defense**: Evasion, shielding, and tactical positioning.
- **Progression Interaction**: 3-Choice card draft upon wave clear or level-up.

## 6. Progression & Retention Drivers
- **In-Run Escalation**: Upgrades synergize via keyword tags.
- **Meta-Progression**: Currency earned in run spent permanently to unlock new traits.
- **Leaderboards**: Highest wave reached and total score submitted to Playgama Leaderboards.
