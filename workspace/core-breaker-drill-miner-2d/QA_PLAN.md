# QA & Testing Plan: Бурильщик Бездны: Рикошет Руды

## 1. Functional Test Matrix
- [ ] Проверка корректности очистки пикселей воксельной сетки при любом угле входа бура
- [ ] Проверка сохранения импульса и количества отскоков рикошета лазера от наклонных поверхностей
- [ ] Проверка гарантированного срабатывания окна перков на отметках 50, 100, 150... метров
- [ ] Проверка разблокировки достижений и синхронизации лидербордов через Playgama Bridge

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS на средних устройствах (iPhone 11 / Xiaomi Redmi Note 10)
- [ ] Время первого старта игры из кеша < 2.0 секунд
- [ ] Потребление RAM в браузере не более 120 МБ после 20 минут непрерывного бурения

## 3. Target Browser Matrix
- Chrome Mobile (Android 10+)
- Safari iOS (iOS 15+)
- Yandex Browser Desktop & Mobile
- VK App WebView (Android & iOS)
