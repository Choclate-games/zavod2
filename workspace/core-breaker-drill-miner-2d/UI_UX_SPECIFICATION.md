# UI/UX Specification: Бурильщик Бездны: Рикошет Руды

## 1. HUD Overlay Elements
- Шкала глубины (Vertical Depth Meter слева с отметками боссов и перков)
- Индикатор прочности корпуса (HP Bar сверху слева)
- Счетчики собранной руды (Иконки кристаллов и цифры сверху справа)
- Мини-радар плотности породы и приближения босса
- Кнопка паузы / настроек в верхнем углу
