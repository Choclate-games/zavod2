# CYBER SLICE: BULLET PROTOCOL (Кибер Срез: Протокол Времени) 🎮⚡

> **«Ghostrunner встречает Fruit Ninja в неоновом киберпанке»: замедляй время одним касанием, рассекай киборгов и летящие ракеты на светящиеся полигональные части, выстраивай безумные комбо и сокрушай мега-боссов с уникальными roguelite-талантами прямо в браузере!**

---

## 🌟 Об игре
- **Жанр**: 3D Roguelite свайп-слэшер с замедлением времени и процедурным разрушением геометрии
- **Движок**: Three.js (^0.170.0) + WebGL 3D
- **Платформа**: Playgama Bridge v2 (Yandex Games / VK Play / Web / Android)
- **Ориентация**: Landscape (Альбомная)
- **Звук**: Web Audio API (динамический синтивейв, Bullet Time фильтры, синтез звуков)

---

## 🕹️ Управление

### Десктоп (Клавиатура и мышь):
- `WASD` / `Стрелки` — Перемещение кибер-ниндзя по неоновой арене
- `Зажать ЛКМ + Свайп мыши` / `Тач-свайп` — Замедление времени (Bullet Time) и процедурный срез врагов/снарядов
- `Space` / `Shift` — Тактический рывок / уклонение с неуязвимостью
- `E` / `Q` — Активация режима Overdrive при полном заполнении шкалы Heat
- `P` / `Escape` — Пауза

### Мобильные устройства (Тачскрин):
- **Левая половина экрана**: Плавающий виртуальный джойстик для перемещения
- **Правая половина / весь экран**: Свайп-срез врагов и снарядов в замедлении времени
- **Кнопка `DASH` (⚡)**: Рывок / уклонение
- **Кнопка `TIME` (⌛)**: Принудительный вход в Bullet Time
- **Кнопка `OVER` (🔥)**: Активация режима Overdrive
- **Флаг отладки**: `?touch=1` принудительно включает тач-контроллер на ПК

```bash

# Запуск локального сервера разработки (Vite)
npm run dev

# Продакшн-сборка (TypeScript проверка + Vite build)
npm run build

# Просмотр собранного бандла
npm run preview
```

## ⚡ Особенности Реализации
1. **True Procedural 3D Slicing**: Любой меш врага или снаряда разрезается секущей плоскостью под произвольным углом с построением внутренних срезов с неоновым свечением расплавленного ядра.
2. **Kinematic Bullet Time**: При прицеливании время плавно замедляется до 10% с динамическим низкочастотным аудиофильтром и расходом Chrono-энергии.
3. **Multi-Phase Boss "Apex Chronos"**: Босс с уязвимыми голографическими плоскостями среза (Weak Planes).
4. **14+ Roguelite Cyber-Chips**: Плазменный рикошет, Квантовое расщепление, Цепные молнии, Хроно-вампиризм и др.
5. **Playgama Bridge Compliance**: Rewarded Ad для Кибер-Реанимации и Удвоения очков, облачные сохранения и лидерборды.
