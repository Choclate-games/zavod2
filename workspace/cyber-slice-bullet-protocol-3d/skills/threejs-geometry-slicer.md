# Skill: Процедурный 3D Слайсер Геометрии для Three.js

## Purpose
Обеспечить высокопроизводительное рассечение BufferGeometry плоскостью с генерацией неонового среза без утечек памяти.

## When to Use
При создании боевой системы свайп-слэшеров и разрушаемых трехмерных объектов.

## Core Rules & Constraints
- Всегда утилизировать старые BufferGeometry через .dispose() при удалении объектов.
- Использовать единый шейдерный материал для всех внутренних срезов для минимизации Draw Calls.
- Ограничивать глубину повторного разрезания одного и того же осколка до 2 раз.

## System Architecture
Plane Math Intersection -> Vertex Interpolation -> Triangulation Subroutine -> Multi-Mesh Spawn with Rapier3D Impulses.

## Implementation Guidance
Используйте алгоритм классификации вершин по знаку скалярного произведения с нормалью секущей плоскости. Ребра, пересекающие плоскость, делятся в точке интерполяции t = (d - dot(n, v1)) / dot(n, v2 - v1).

## Common Mistakes to Avoid
- ❌ **Mistake**: Создание новых материалов в цикле рендера вместо использования общего пула материалов.
- ❌ **Mistake**: Забывание обновления индексного буфера geometry.setIndex().

## Validation Checklist
- [ ] Проверен расчет нормалей и UV-координат на срезе
- [ ] Включен пулинг геометрии
- [ ] Настроены коллайдеры для половинок в Rapier3D
