# Mechanics Catalog: Ледяной Экспресс: Жидкий Баланс

> Каждая механика описана до уровня, на котором её можно реализовать без

## Механика: Гидродинамический Маятник и Гидроудар Цистерны (CORE)
- **Категория**: Источник риска и главный физический рычаг управления траекторией
- **Описание**: В стандартных автосимуляторах центр тяжести статичен. Здесь 8 тонн жидкости обладают собственной физической инерцией и фазовым сдвигом, превращая управление молоковозом в непрерывную работу с живой динамической массой.
- **Взаимодействие игрока**: Клавиатура: A/D или Стрелки Влево/Вправо (руление); Тачскрин: горизонтальный виртуальный слайдер руля / гироскоп наклона устройства.
- **Отклик**: Визуал/VFX: Хромированная цистерна глубоко кренится на рессорах; сквозь смотровой иллюминатор виден бушующий накат белой массы молока; при опасном крене из сапунов вырываются струи молочной пены; из-под перегруженных колес бьют снопы ледяных искр.; Звук (Web Audio): Глухой низкочастотный рокот перекатывающейся жидкости (bandpass фильтр 80-200 Гц); звонкий металлический удар 'БОММ' о стенку цистерны при гидроударе; шипение сброса воздуха из пневморессор.; Камера: Динамический наклон камеры вслед за креном цистерны (до 14°); импульсный рывок камеры наружу виража в момент удара волны; шейкер камеры (амплитуда 0.35, частота 22 Гц) при вывешивании колес.; UI/Тактильность: Круговой гироскопический инклинометр крена по центру капота с красной опасной зоной (>30°); тактильный вибро-импульс Haptic Feedback (80 мс) при ударе волны о стенку цистерны.
- **Техническая сложность**: Medium
- **Сильные стороны**: Высокая вовлеченность, Глубокая кривая мастерства
- **На что смотреть**: Требует точной калибровки таймингов

### Глубина механики
- **Роль в петле**: Источник риска и главный физический рычаг управления траекторией
- **Решение игрока**: Использовать ли инерционный удар волны молока для заброса тяжелой кормы тягача в поворот или заранее погасить раскачку контрсмещением ради безопасного прохождения шпильки.
- **Управление**: Клавиатура: A/D или Стрелки Влево/Вправо (руление); Тачскрин: горизонтальный виртуальный слайдер руля / гироскоп наклона устройства.
- **Состояния**: `state_quiescent: Жидкость в покое (угол отклонения < 3°, опрокидывающий момент минимален)`, `state_slosh_building: Нарастание волны (жидкость смещается к внешнему борту под действием центробежной силы, крен 5°–20°)`, `state_hydro_impact: Гидроудар о борт (волна бьет в стенку цистерны, отрыв колес внутреннего борта на 10°–30°)`, `state_critical_roll: Критический крен (>32°, срыв сапунов, потеря молока со скоростью 350 л/с, угроза переворота)`, `state_counter_slosh: Противоволна (обратный откат жидкости при перекладке руля, требующий компенсации тягой)`
- **Параметры и настройка**:
  - **Масса перевозимого молока**: `8000 кг` — При массе выше 9000 кг тягач становится неуправляемым и мгновенно опрокидывается; при снижении ниже 6000 кг пропадает ощущение тяжести жидкого маятника.
  - **Фазовое запаздывание волны молока**: `0.35 с` — Меньше 0.15 с — жидкость ощущается приклеенным твердым грузом; больше 0.6 с — игрок теряет причинно-следственную связь между рулением и ударом волны.
  - **Критический угол опрокидывания шасси**: `32.0 градуса` — Ниже 25° — грузовик переворачивается слишком внезапно; выше 38° — игрок перестает бояться переворота и ездит на двух колесах.
  - **Интенсивность выплеска молока при разгерметизации**: `350 л/с` — Меньше 150 л/с — потеря молока не создает угрозы поражения; больше 600 л/с — малейший крен моментально аннулирует победу.
- **Слои отклика**:
  - Визуал/VFX: Хромированная цистерна глубоко кренится на рессорах; сквозь смотровой иллюминатор виден бушующий накат белой массы молока; при опасном крене из сапунов вырываются струи молочной пены; из-под перегруженных колес бьют снопы ледяных искр.
  - Звук (Web Audio): Глухой низкочастотный рокот перекатывающейся жидкости (bandpass фильтр 80-200 Гц); звонкий металлический удар 'БОММ' о стенку цистерны при гидроударе; шипение сброса воздуха из пневморессор.
  - Камера: Динамический наклон камеры вслед за креном цистерны (до 14°); импульсный рывок камеры наружу виража в момент удара волны; шейкер камеры (амплитуда 0.35, частота 22 Гц) при вывешивании колес.
  - UI/Тактильность: Круговой гироскопический инклинометр крена по центру капота с красной опасной зоной (>30°); тактильный вибро-импульс Haptic Feedback (80 мс) при ударе волны о стенку цистерны.
- **Режим отказа**: Игрок затягивает руление в повороте и не успевает компенсировать фазу волны: гидроудар накладывается на центробежную силу, крен превышает 32°, молоко выбивает сапуны люков и тягач валится на бок.
- **Кривая мастерства**: Новичок на 30-й секунде пугается первого крена, бросает газ и опрокидывается от запоздалого гидроудара. Эксперт на 10-м забеге использует гидроудар как пружину: раскачивает молоко перед входом, срывая заднюю ось точно в фазу удара волны для молниеносного закручивания в шпильку.
- **Сопротивление игры**: Трасса предлагает череду связок поворотов с переменным радиусом и обратным поперечным уклоном полотна (-8° в сторону обрыва), что удваивает опрокидывающий момент.
- **Синергии**:
  - Связана с 'Ледяным Срывом и Контррулением': скольжение на синем льду снижает боковое трение, переводя опрокидывающий момент в управляемый дрифт.
  - Связана с 'Инерционным Хлыстом Ручником': блокировка задней тележки провоцирует мгновенный гидроудар для скоростного разворота.
  - Связана с 'Фактором Бездны': зависание накрененной цистерны над обрывом дает максимальный множитель очков.
- **Почему это не жанровый шаблон**: В стандартных автосимуляторах центр тяжести статичен. Здесь 8 тонн жидкости обладают собственной физической инерцией и фазовым сдвигом, превращая управление молоковозом в непрерывную работу с живой динамической массой.
- **Псевдокод тика**:
```text
function updateSloshDynamicBalance(dt, lateralAccel, steerInput, bodyRoll) {
  const targetSloshAngle = (lateralAccel / GRAVITY) * SLOSH_SENSITIVITY;
  sloshVelocity += (targetSloshAngle - sloshAngle) * SLOSH_SPRING_K * dt;
  sloshVelocity -= sloshVelocity * SLOSH_DAMPING * dt;
  sloshAngle += sloshVelocity * dt;
  const totalRollTorque = (LIQUID_MASS * SLOSH_ARM * Math.sin(sloshAngle)) + (TRUCK_MASS * CG_HEIGHT * lateralAccel);
  currentBodyRoll += (totalRollTorque - currentBodyRoll * SUSPENSION_STIFFNESS) * dt;
  if (currentBodyRoll > CRITICAL_ROLL_ANGLE_DEG * DEG_TO_RAD) {
    spilledMilkVolume += MILK_SPILL_RATE * dt;
    triggerFeedback('hydro_spill_warning', currentBodyRoll);
  }
}
```

## Механика: Ледяной Срыв Покрытия и Контрруление (SECONDARY)
- **Категория**: Двигатель динамического скольжения и инструмент траекторного контроля
- **Описание**: Вместо искусственного скриптового дрифта моделируется честное дифференциальное сцепление осей на разных типах северного покрытия с учетом смещения нормальной нагрузки колес.
- **Взаимодействие игрока**: Клавиатура: Стрелки Влево/Вправо (A/D) для быстрого контрруления; Тачскрин: виртуальный рулевой диск с центрирующей пружиной.
- **Отклик**: Визуал/VFX: Под колесами матовый снег сменяется зеркальным синим льдом с глубокими трещинами; из-под шипов вылетает густой веер ледяной стружки; передние колеса точно повернуты в сторону заноса.; Звук (Web Audio): Плотный шорох снежного наката мгновенно сменяется пронзительным визгом шипов по гладкому льду (resonant filter 3.2 кГц) и ревом мотора в отсечке.; Камера: Камера плавно смещается наружу поворота с демпфированием 0.25 с, ориентируя горизонт по вектору скольжения тягача.; UI/Тактильность: Аналоговая дуга угла заноса ('Slip Angle Gauge') с подсвеченной зеленой зоной баланса (28°–42°); серия мелких вибрационных щелчков при пересечении границы синего льда.
- **Техническая сложность**: Medium
- **Сильные стороны**: Высокая вовлеченность, Глубокая кривая мастерства
- **На что смотреть**: Требует точной калибровки таймингов

### Глубина механики
- **Роль в петле**: Двигатель динамического скольжения и инструмент траекторного контроля
- **Решение игрока**: Выбрать безопасную траекторию по снежному накату (стабильно, но медленно) или забросить колеса на синий лед ради глубокого скоростного дрифта над обрывом.
- **Управление**: Клавиатура: Стрелки Влево/Вправо (A/D) для быстрого контрруления; Тачскрин: виртуальный рулевой диск с центрирующей пружиной.
- **Состояния**: `state_snow_grip: Снежный зацеп (mu=0.65, стабильное прямолинейное движение, угол скольжения < 8°)`, `state_blue_ice_snap: Ледяной срыв (резкое падение mu до 0.18, потеря сцепления задней оси, начало заноса)`, `state_active_counter_steer: Активное контрруление (руль вывернут навстречу заносу, баланс угла 25°–40°)`, `state_spin_out: Неконтролируемое вращение (угол заноса > 60°, потеря тяги, вылет с трассы)`
- **Параметры и настройка**:
  - **Коэффициент сцепления синего льда**: `0.18 mu` — Ниже 0.10 — колеса превращаются в лыжи, теряя управление; выше 0.28 — пропадает контраст и физическое ощущение ледяного срыва.
  - **Окно реакции на парирование заноса**: `0.22 с` — Больше 0.4 с — занос становится казуальным и тривиальным; меньше 0.12 с — игроки на смартфонах физически не успевают парировать срыв.
  - **Оптимальный угол дрифта молоковоза**: `35.0 градусов` — Меньше 20° — нет ощущения скольжения тяжелой техники; больше 50° — тягач складывается в 'ножницы' с цистерной.
  - **Скорость перекладки рулевого механизма**: `130 град/с` — Быстрее 220 град/с — тяжелый тягач управляется как карт; медленнее 80 град/с — невозможно поймать ритм в S-образных связках.
- **Слои отклика**:
  - Визуал/VFX: Под колесами матовый снег сменяется зеркальным синим льдом с глубокими трещинами; из-под шипов вылетает густой веер ледяной стружки; передние колеса точно повернуты в сторону заноса.
  - Звук (Web Audio): Плотный шорох снежного наката мгновенно сменяется пронзительным визгом шипов по гладкому льду (resonant filter 3.2 кГц) и ревом мотора в отсечке.
  - Камера: Камера плавно смещается наружу поворота с демпфированием 0.25 с, ориентируя горизонт по вектору скольжения тягача.
  - UI/Тактильность: Аналоговая дуга угла заноса ('Slip Angle Gauge') с подсвеченной зеленой зоной баланса (28°–42°); серия мелких вибрационных щелчков при пересечении границы синего льда.
- **Режим отказа**: Запоздалое или чрезмерное контрруление: при опоздании тягач срывается в неконтролируемый спин-аут (разворот на 180°), при переруливании ловит резкий зацеп на снегу и выстреливает в скалу.
- **Кривая мастерства**: Новичок на 30-й секунде оттормаживается перед синим льдом до 25 км/ч или улетает в штопор. Эксперт на 10-м забеге намеренно целится колесами на полосы синего льда, проходя виражи на скорости 90 км/ч с ювелирным контррулением.
- **Сопротивление игры**: Чередование коротких островков синего льда с участками глубокого вязкого снега, сбивающего угол дрифта.
- **Синергии**:
  - Связана с 'Гидродинамическим Маятником': синий лед снимает сопротивление шин, позволяя перенаправить волну в угол заноса.
  - Связана с 'Фактором Бездны': идеальное контрруление на синем льду удерживает задние колеса в 20 см от обрыва.
  - Связана с 'Инерционным Хлыстом': продлевает скольжение после рывка ручника без падения оборотов мотора.
- **Почему это не жанровый шаблон**: Вместо искусственного скриптового дрифта моделируется честное дифференциальное сцепление осей на разных типах северного покрытия с учетом смещения нормальной нагрузки колес.
- **Псевдокод тика**:
```text
function updateIceSlipstream(dt, steerInput, isBlueIce, currentSpeed) {
  const currentFrictionCoeff = isBlueIce ? BLUE_ICE_MU : SNOW_MU;
  const rawSlipAngle = calculateSlipAngle(velocityVector, truckForwardVector);
  const targetCounterSteer = -Math.sign(rawSlipAngle) * Math.min(Math.abs(rawSlipAngle), MAX_STEER_ANGLE);
  const steerError = Math.abs(steerInput - targetCounterSteer);
  if (steerError < BALANCED_DRIFT_TOLERANCE && isBlueIce) {
    driftStabilityScore += dt * 1.5;
    applyLateralGripForce(currentFrictionCoeff * 1.25 * TRUCK_MASS);
  } else if (steerError > SPINOUT_THRESHOLD) {
    spinAngularVelocity += Math.sign(rawSlipAngle) * SPIN_ACCEL * dt;
    applyLateralGripForce(currentFrictionCoeff * 0.35 * TRUCK_MASS);
  }
}
```

## Механика: Инерционный Хлыст Ручным Тормозом (SECONDARY)
- **Категория**: Инструмент мгновенной инициации заноса и баллистического прохождения апекса
- **Описание**: Ручник работает не как кнопка аркадного поворота, а как механический спусковой крючок гидроудара, превращающий массу груза в катапульту для прохождения шпилек.
- **Взаимодействие игрока**: Клавиатура: Пробел (Space) / Клавиша S; Тачскрин: крупная кнопка ручника в правом нижнем углу / свайп вниз.
- **Отклик**: Визуал/VFX: Мгновенная блокировка 4 задних колес; шипы выбивают сноп оранжевых искр об ледяную корку; из-под рамы вырываются клубы морозного пара пневмотормозов.; Звук (Web Audio): Громкий металлический хлопок пневмоклапана 'ПШШ-КЛАЦ'; яростный скрежет заблокированного металла по льду; падение оборотов дизеля с последующим турбо-подхватом.; Камера: Резкий рывок камеры назад с кратковременным увеличением угла обзора FOV с 75° до 86° на 0.3 с.; UI/Тактильность: Вспышка красного значка стояночного тормоза; плотный одиночный тактильный удар Haptic Feedback (110 мс) в момент зажима колодок.
- **Техническая сложность**: Medium
- **Сильные стороны**: Высокая вовлеченность, Глубокая кривая мастерства
- **На что смотреть**: Требует точной калибровки таймингов

### Глубина механики
- **Роль в петле**: Инструмент мгновенной инициации заноса и баллистического прохождения апекса
- **Решение игрока**: В какой момент перед апексом дернуть ручник: рано — молоко погасит скорость; поздно — инерция груза утащит тягач прямо в пропасть.
- **Управление**: Клавиатура: Пробел (Space) / Клавиша S; Тачскрин: крупная кнопка ручника в правом нижнем углу / свайп вниз.
- **Состояния**: `state_ready: Ручник отпущен, колеса свободно передают крутящий момент`, `state_clamping: Зажим задних колодок (время срабатывания 0.08 с, мгновенная блокировка задней спарки)`, `state_whip_snap: Хлыстовой импульс (задняя тележка срывается по дуге, закручивая 8-тонную цистерну)`, `state_boost_release: Сброс ручника с подхватом газа (мгновенный выстрел тягача из шпильки)`
- **Параметры и настройка**:
  - **Окно идеального удержания ручника**: `0.28 с` — Больше 0.5 с — скорость падает более чем на 35 км/ч; меньше 0.12 с — 14-тонный автопоезд не успевает сорвать задние колеса.
  - **Множитель углового ускорения хлыста**: `2.4x` — Выше 3.5x — грузовик неестественно крутится волчком; ниже 1.5x — не хватает импульса для прохождения узких горных шпилек.
  - **Задержка пневматического привода колодок**: `0.08 с` — Создает осязаемую механическую задержку тяжелой техники; при 0.0 с управление кажется невесомым.
  - **Импульс турбо-подхвата при идеальном сбросе**: `22.0 км/ч` — Меньше 15 км/ч — выход из шпильки вялый; больше 40 км/ч — тягач вылетает с дороги на выходе из поворота.
- **Слои отклика**:
  - Визуал/VFX: Мгновенная блокировка 4 задних колес; шипы выбивают сноп оранжевых искр об ледяную корку; из-под рамы вырываются клубы морозного пара пневмотормозов.
  - Звук (Web Audio): Громкий металлический хлопок пневмоклапана 'ПШШ-КЛАЦ'; яростный скрежет заблокированного металла по льду; падение оборотов дизеля с последующим турбо-подхватом.
  - Камера: Резкий рывок камеры назад с кратковременным увеличением угла обзора FOV с 75° до 86° на 0.3 с.
  - UI/Тактильность: Вспышка красного значка стояночного тормоза; плотный одиночный тактильный удар Haptic Feedback (110 мс) в момент зажима колодок.
- **Режим отказа**: Передержка ручника дольше 0.55 с: тяжелый тягач теряет кинетическую энергию, волна молока бьет в переднюю стенку цистерны и полностью гасит скорость.

function updateCliffEdgeMultiplier(dt, rearWheelPosition, cliffEdgePolylines, isDrifting) {
  const distanceToEdge = computeDistanceToPolyline(rearWheelPosition, cliffEdgePolylines);
  if (distanceToEdge < 0.0) {
    triggerCatastrophicFallEvent();
    return;
  }
  if (distanceToEdge <= MAX_EDGE_DISTANCE && isDrifting) {
    const proximityNorm = 1.0 - (distanceToEdge / MAX_EDGE_DISTANCE);

  } else {
    currentEdgeMultiplier = 1.0;
  }
}
