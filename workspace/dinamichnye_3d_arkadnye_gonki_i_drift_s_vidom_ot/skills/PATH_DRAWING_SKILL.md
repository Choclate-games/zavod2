# Skill: Catmull-Rom Path Drawing & Movement

## Purpose
Рисование маршрутов пальцем/курсором, сглаживание сплайнами и перемещение юнитов по траектории.

## When to Use
При создании игр с рисованием линий, логистических головоломок и управления роем.

## Core Rules & Constraints
- Сглаживание точек алгоритмом Catmull-Rom Spline для исключения изломов.
- Юниты плавно поворачиваются по касательной к траектории движения.

## System Architecture
PathDrawer захватывает ввод и строит кривую, PathFollower перемещает объект.

## Implementation Guidance
Строй кривую через THREE.CatmullRomCurve3 (curveType 'centripetal'), шлейф линии — Line2/TubeGeometry по той же кривой.

## Common Mistakes to Avoid
- ❌ **Mistake**: Движение по сырым несоглаженным точкам приводит к дерганию спрайта.

## Validation Checklist
- [ ] Нарисованная линия плавно направляет юнита к цели.
