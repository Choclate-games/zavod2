# Skill: Интегратор Гидродинамического Смещения Массы Груза

## Purpose
Численный расчет динамики плещущейся жидкости в цистерне и передача сил на твердое тело грузовика в Rapier3D.

## When to Use
Использовать в каждом физическом тике при расчете центра масс и крутящих моментов подвески молоковоза.

## Core Rules & Constraints
- Частота физического тика строго фиксирована (60 Гц)
- Угол отклонения маятника ограничен диапазоном [-35°, +35°]
- При перевороте тягача расчет маятника плавно отключается во избежание физического взрыва

## System Architecture
Демпфированный маятниковый осциллятор 2-го порядка, связанный с RigidBody молоковоза через динамический смещаемый Center of Mass.

## Implementation Guidance
Использовать метод Верле для стабильной интеграции при переменных временных шагах браузера.

## Common Mistakes to Avoid
- ❌ **Mistake**: Расчет смещения жидкости в мировых координатах вместо локальной системы координат цистерны
- ❌ **Mistake**: Отсутствие ограничения максимального опрокидывающего момента

## Validation Checklist
- [ ] Проверена стабильность при резких разворотах на 180°
- [ ] Центр масс возвращается в нейтраль при остановке
- [ ] Корректно рассчитывается отрыв внутренних колес
