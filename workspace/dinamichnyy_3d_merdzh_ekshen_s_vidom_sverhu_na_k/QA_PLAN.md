# QA & Testing Plan: Био-Колизей: Ударный Синтез

## 1. Functional Test Matrix
- [ ] Корректность слияния: проверка объединения двух комьев уровня N в уровень N+1 с генерацией импульса
- [ ] Детекция ринг-аута: уничтожение мутантов и начисление очков при падении ниже Y = -2.0
- [ ] Сужение арены: удаление сегментов коллайдеров и падение плит по таймерам 20 с и 40 с
- [ ] Проверка жестового управления: корректность векторов броска при различных скоростях свайпа
- [ ] Переход между волнами: завершение волны 1 при выживании 60 с и спавн волны 2 с сохранением титана

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS при наличии 35 активных физических тел Rapier3D и 100 частиц на экране
- [ ] Время холодного старта игры до первого кадра геймплея < 2.5 секунд на 3G/4G соединении
- [ ] Потребление оперативной памяти WebGL контекстом < 120 МБ на мобильных вкладках браузера

## 3. Target Browser Matrix
- Mobile Safari (iOS 15+) — touch drag & drop без скролла страницы
- Chrome Mobile (Android 10+) — WebGL2, стабильный Rapier3D WASM
- Yandex Browser Desktop & Mobile — интеграция рекламы и лидербордов
- Desktop Chrome/Firefox/Edge — поддержка управления мышью и клавиатурных хоткеев
