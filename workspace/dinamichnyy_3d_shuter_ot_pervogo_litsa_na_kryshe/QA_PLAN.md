# QA & Testing Plan: Громовой Перехват: Штормовой Экспресс

## 1. Functional Test Matrix
- [ ] Проверка корректности расчета ветрового сноса прицела при различных углах и скоростях ветра (10-50 м/с)
- [ ] Тестирование детекции хитбоксов горящих обломков при стрейфе игрока на всех трех линиях вагона
- [ ] Проверка триггера цепной детонации: уничтожение лидера роя обязано разрушать всех привязанных ведомых дронов
- [ ] Тестирование тайминга прыжка через межвагонную сцепку: отсутствие проваливания сквозь геометрию вагона
- [ ] Проверка фаз босса «Громовержец» и регистрации урона от режима Тесла-Перегрузки

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS на десктопе (Chrome / Firefox / Safari / Edge) при 1080p
- [ ] Стабильные 55-60 FPS на мобильных устройствах среднего уровня (iPhone 11+, Redmi Note 10+, Samsung Galaxy A52)
- [ ] Количество Draw Calls не превышает 45 в пиковых сценах цепных взрывов
- [ ] Количество треугольников в кадре не более 35 000
- [ ] Время первоначальной загрузки бандла и ресурсов менее 3.0 секунд на 4G соединении

## 3. Target Browser Matrix
- Windows: Chrome 120+, Firefox 120+, Edge 120+, Yandex Browser 23+
- macOS: Safari 17+, Chrome 120+
- Android: Chrome Mobile, Yandex Browser Mobile, Samsung Internet
- iOS: Safari Mobile iOS 15.0+, Chrome iOS
