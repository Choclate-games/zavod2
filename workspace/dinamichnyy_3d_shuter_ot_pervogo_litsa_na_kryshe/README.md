# Громовой Перехват: Штормовой Экспресс

3D-шутер от первого лица: рейд по крышам мчащегося бронепоезда сквозь ночной
грозовой шторм. Рассчитывай ветровое упреждение, детонируй звенья дронов
цепными реакциями, прыгай через межвагонные сцепки и добей босса «Громовержец»
за 85 секунд.

## Запуск

```bash
npm install        # один раз
npm run dev        # дев-сервер Vite, открывать выданный адрес в браузере
npm run build      # релизная сборка в dist/ (+ проверка типов)
npm run preview    # локальный просмотр собранной версии
```

Проверка качества:

```bash
npm run check:spec # статическая приёмка (исходники)
npm run smoke      # сборка + запуск в Chromium + кадры + ввод + телефон
```

Числа игры живут в `balance.yaml`; перед dev/build скрипт `gen-balance.mjs`
перегенерирует `src/config/balance.gen.ts`. Правьте баланс — не код.

## Управление

| Действие | Клавиатура и мышь | Телефон (тач) |
|---|---|---|
| Наведение прицела | мышь (после клика — захват курсора) | drag правой половиной экрана |
| Выстрел | ЛКМ (удержание — автоматный огонь) | автоспуск при наведении; тап правой зоной |
| Тесла-перегрузка | ПКМ или E | кнопка OVERLOAD справа внизу |
| Стрейф по полосам | A / D | свайп влево/вправо левой половиной |
| Скольжение/подкат | S или C | свайп вниз левой половиной |
| Прыжок через сцепку | Пробел | свайп вверх левой половиной |
| Пауза | Esc или P | кнопка паузы сверху |

Отладочные флаги адресной строки: `?input=touch`, `?input=desktop`, `?touch=1`.

## Как играть

85 секунд, 5 крыш вагонов, ≥24 сбитых дрона и энергоядро босса. Золотой маркер
рядом с прицелом показывает поправку на ветер: держите цель под маркером —
точное упреждение даёт x2.5 урона. Убийство золотого лидера звена детонирует
ведомых цепочкой и рождает горящий обломок, летящий прямо в вас: уходите
полосой или подкатом. Полная зарядка конденсатора позволяет разрядить луч
молнии через ПКМ/OVERLOAD.

## Структура каталогов

```text
├── index.html                  # входная страница Vite
├── public/playgama-bridge-config.json  # конфиг моста площадки
├── balance.yaml                # числа игры (источник баланса)
├── scripts/
│   ├── gen-balance.mjs         # balance.yaml -> src/config/balance.gen.ts
│   ├── check-spec.mjs          # статическая приёмка
│   └── smoke.mjs               # дымовой запуск в браузере
└── src/
    ├── main.ts                 # bootstrap: мост -> язык -> сейв -> игра
    ├── core/                   # Game, GameLoop (60 Гц fixed), EventBus, состояние
    ├── config/                 # правила и сгенерированный баланс
    ├── platform/               # PlaygamaService (Bridge SDK), StorageService
    ├── input/                  # InputRouter: клавиатура+мышь / тач, pointer lock
    ├── audio/                  # AudioManager: процедурный Web Audio без файлов
    ├── rendering/              # SceneManager, процедурные модели, частицы
    ├── systems/                # ветер, поезд, рой дронов, обломки, оружие, босс
    ├── entities/               # игрок: полосы, слайд, щит
    └── ui/                     # theme.css (токены), UiRoot, ScreenRouter,
                                # Hud, TouchControls, screens/, icons
```

Документация дизайна: `DESIGN.md` (палитра, камера, экраны), `ACCEPTANCE.md`
(приёмка). История разработки — `DEVLOG.md`, изменения глазами игрока —
`CHANGELOG.md`.
