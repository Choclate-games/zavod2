# Skill: Three.js Rail FPS Controller

## Purpose
Архитектура высокоскоростного FPS-контроллера с симуляцией поезда и ветра

## When to Use
При разработке механики движения, тряски камеры и баллистической стрельбы с упреждением

## Core Rules & Constraints
- Никакого прямого изменения camera.position без сглаживания инерции
- Все траектории пуль рассчитываются с учетом вектора ветра

## System Architecture
Модульный контроллер на базе Three.js Camera, Raycaster и физического решателя сноса

## Implementation Guidance
Использовать Quaternion slerp для наклона камеры при стрейфах

## Common Mistakes to Avoid
- ❌ **Mistake**: Слишком резкий возврат камеры после отдачи
- ❌ **Mistake**: Отсутствие учета относительной скорости поезда

## Validation Checklist
- [ ] Плавность 60 FPS
- [ ] Корректный угол наклона при стрейфе
- [ ] Четкая регистрация попаданий
