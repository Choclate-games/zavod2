# QA & Testing Plan: Бур Судного Дня: Шахтерский Рогалик

## 1. Functional Test Matrix
- [ ] Корректность генерации и разрушения блоков без дыр в сетке коллизий
- [ ] Безотказный драфт перков: применение эффектов модификаторов (лед, урон, радиус)
- [ ] Работа Revive за рекламу с сохранением текущей глубины и счета
- [ ] Корректность синхронизации рекорда глубины с лидербордом Playgama

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS на смартфонах уровня Redmi Note 8 / iPhone 8
- [ ] Время начальной загрузки игры менее 2.5 секунд при 3G соединении
- [ ] Потребление оперативной памяти вкладки браузера не более 95 МБ

## 3. Target Browser Matrix
- Chrome Mobile (Android 10+)
- Safari iOS (iOS 14+)
- Yandex Browser Desktop & Mobile
- VK In-App WebView (Android/iOS)
