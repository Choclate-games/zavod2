# Бур Судного Дня: Шахтерский Рогалик 🎮⚡

> **Вертикальный 2D экшен-рогалик на PixiJS v8 + Matter.js с поддержкой Playgama Bridge 2.x.**
> Управляйте гигантским буром, прогрызающим недра чужой планеты! Взрывайте динамитные пласты, замораживайте перегревающийся бур, устанавливайте турели против роя монстров и прокачивайте ядерный таран на лету.

---

## 🚀 Быстрый старт и запуск

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки (Vite)
npm run dev

# Проверка сборки и типов TypeScript
npm run build

# Предпросмотр production-сборки
npm run preview
```

Для принудительного включения мобильного тач-интерфейса на десктопе добавьте флаг `?touch=1`:
`http://localhost:3000/?touch=1`

---

## 🕹️ Управление

### Десктоп (Клавиатура):
- `A` / `D` или `←` / `→` — горизонтальное руление буром
- `S` / `↓` / `Space` / `Shift` — активация форсажа (Ядерный таран)
- `P` / `Escape` — пауза

### Мобильные устройства (Touch):
- **Левая половина экрана**: плавающий виртуальный джойстик (свободное руление с мёртвой зоной 8%)
- **Правая нижняя зона**: кнопка форсажа «ТАРАН / TURBO» (мультитач на Pointer Events)
- **Тап по карточке**: выбор перка при повышении уровня крафта

## 📁 Архитектура проекта

```text
src/
├── main.ts                       # Инициализация платформы, загрузка сохранений, запуск
├── core/
│   ├── Game.ts                   # Главный координатор игры и машина состояний
│   ├── GameLoop.ts               # Фиксированный цикл 60 Гц с delta clamping
│   ├── GameState.ts              # Реактивное состояние забега и мета-прогрессия
│   ├── EventBus.ts               # Типизированная шина событий
│   └── Localization.ts           # Полная двуязычная локализация (RU / EN)
├── platform/
│   ├── PlaygamaService.ts        # Обвязка @playgama/bridge (Реклама, Облако, Лидерборды)
│   └── StorageService.ts         # Синхронизация с облаком и LocalStorage с debounce
├── physics/
│   ├── PhysicsWorld.ts           # Физический мир Matter.js (60Hz timestep, взрывы)
│   └── CollisionCategories.ts    # Битовые маски коллизий
├── entities/
│   ├── PlayerDrill.ts            # Буровая меха: физика, фреза, перегрев, охлаждение
│   ├── Block.ts                  # Разрушаемые блоки пород, руды и динамит
│   ├── Enemy.ts                  # Подземные враги: пауки, жуки, споровики
│   ├── Boss.ts                   # Титаны недр (Голем 500м, Магматический Червь 1000м)
│   ├── DropItem.ts               # Кристаллы и руда с магнитной физикой
│   ├── Projectile.ts             # Плазменные лазеры и кислотные плевки
│   └── DroneTurret.ts            # Авто-турели, орбитальные пилы, цепная молния
├── systems/
│   ├── ChunkManager.ts           # Бесконечная вертикальная генерация 4 биомов
│   ├── CombatSystem.ts           # Расчет урона фрезы, выстрелов и взрывов
│   ├── WaveManager.ts            # Кривые спавна волн и спавн боссов
│   ├── UpgradeManager.ts         # 3-карточный драфт перков и синергии
│   └── JuiceSystem.ts            # Тряска экрана (trauma decay), hitstop и тактильность
├── rendering/
│   ├── SceneManager.ts           # PixiJS v8 Application, слои сцены и камера
│   ├── TextureGenerator.ts       # Процедурная генерация пиксель-арт текстур
│   ├── ParticleSystem.ts         # Предсозданный пул 600 частиц (0 GC в цикле)
│   └── LightingOverlay.ts        # 2D свет: конус передних фар и глубинная тьма
└── ui/
    ├── UIManager.ts              # Управление экранами и модальными окнами
    ├── TouchControls.ts          # Мобильный тач-слой на Pointer Events
    ├── InputManager.ts           # Агрегация ввода с клавиатуры и сенсора
    └── screens/
        ├── StartScreen.ts        # Стартовый экран / ангар
        ├── GameScreen.ts         # HUD: HP, температура, крафт, глубина, перки
        ├── HangarModal.ts        # Постоянная прокачка характеристик
        ├── DraftModal.ts         # Модалка выбора из 3 перков в slow-mo
        ├── GameOverModal.ts      # Итоги спуска, воскрешение и удвоение руды
        ├── LeaderboardModal.ts   # Таблица рекордов
        └── SettingsModal.ts      # Настройки звука, языка и чувствительности
```
