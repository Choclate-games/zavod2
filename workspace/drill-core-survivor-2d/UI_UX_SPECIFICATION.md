# UI/UX Specification: Бур Судного Дня: Шахтерский Рогалик

## 1. HUD Overlay Elements
- Вертикальная шкала глубины (справа с отметками рекорда)
- Индикатор прочности бура (HP Bar) и датчик температуры реактора (сверху слева)
- Шкала наполнения крафт-энергии (по центру сверху)
- Счетчик собранных за забег кристаллов (сверху справа)
- Индикаторы активных перков и уровней их прокачки (иконки под HP баром)

## 3. Screen Catalog
### Screen: Startscreen
- Ангар с кастомизацией бура, кнопка 'В забой!', магазин мета-прокачки, топ игроков и настройки.
### Screen: Gamescreen
- Активный экран бурения с чистым обзором, HUD элементами и зоной управления.
### Screen: Draftperkmodal
- Всплывающее окно выбора из 3 перков с замедлением времени, подробным описанием бонусов и кнопкой реролла.
### Screen: Gameovermodal
- Статистика спуска (глубина, убито врагов, добыто руды), кнопка воскрешения за рекламу и возврат в ангар.
