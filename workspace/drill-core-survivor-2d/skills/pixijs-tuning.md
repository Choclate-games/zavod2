# Skill: Оптимизация рендеринга и пулинга в PixiJS

## Purpose
Обеспечение стабильных 60 FPS при интенсивном разрушении блоков и потоке частиц.

## When to Use
При разработке систем частиц, тайловых карт и спавна врагов.

## Core Rules & Constraints
- Никогда не создавать объекты через new PIXI.Sprite() в update-цикле
- Использовать единый Texture Atlas для всех блоков и элементов HUD
- Отсекать невидимые чанки за пределами экрана (Frustum Culling)

## System Architecture
Статический ObjectPoolManager с предсозданными 200 частицами и 100 блоками породы.

## Implementation Guidance
Группировать разрушаемые тайлы в единый ParticleContainer или использовать кастомную сетку вершин Mesh.

## Common Mistakes to Avoid
- ❌ **Mistake**: Утечка текстур при динамической генерации
- ❌ **Mistake**: Использование тяжелых фильтров PIXI на мобильных устройствах

## Validation Checklist
- [ ] Draw calls не превышают 25
- [ ] GC не срабатывает во время активного бурения
- [ ] Текстурный атлас сжат в WebP
