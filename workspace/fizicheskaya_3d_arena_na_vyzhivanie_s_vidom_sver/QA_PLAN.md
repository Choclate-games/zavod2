# QA & Testing Plan: Ледовый Сумо-Батл: Последний Тюбинг

## 1. Functional Test Matrix
- [ ] Проверка отклика управления: время реакции физического тела тюбинга на стик/WASD < 16 мс
- [ ] Тестирование расчета импульса столкновения: передача импульса p=mv строго по закону сохранения импульса
- [ ] Проверка триггера затопления: сегмент льда гарантированно погружается и отключает коллайдер при наступлении фазы раскола
- [ ] Проверка Ring-Out: пересечение тюбингом отметки Y < -0.8 м мгновенно регистрирует выбывание и начисляет фраг атакующему
- [ ] Тест окна Revive: восстановление игрока в центре арены с временным щитом неуязвимости на 2 секунды
- [ ] Тест сохранения данных: корректная запись и чтение cloud_save_keys при перезагрузке страницы

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS на средних смартфонах (Snapdragon 680 / Helio G88 / Apple A12 Bionic)
- [ ] Количество Draw Calls во время пикового боя с 8 участниками <= 55
- [ ] Время первоначальной загрузки бандла на 3G соединении < 3.0 секунд
- [ ] Потребление оперативной памяти (JS Heap + GPU Memory) < 180 МБ

## 3. Target Browser Matrix
- Google Chrome Desktop (Windows / macOS / Linux)
- Safari Mobile (iOS 15+ iPhone & iPad)
- Chrome Mobile / Yandex Browser Mobile (Android 9+)
- Firefox Desktop & Edge Desktop
- Встроенные Webview клиентов VK и Яндекс Игры
