# UI/UX Specification: Ледовый Сумо-Батл: Последний Тюбинг

## 1. Материал интерфейса
Интерфейс живёт в том же мире, что и сцена. Проверка: если закрыть игровое поле,
меню обязано выдавать именно эту игру, а не любую другую.

- **Тема от арт-директора**: Чистый нео-спортивный арктический интерфейс с закругленными плашками, полупрозрачным стеклянным блюром (Frosted Glass), крупной жирной типографикой и яркими контрастными кнопками
- **Визуальный язык**: Сочные полярные контрасты: лазурный лед и темно-синий океан служат нейтральным контрастным фоном для неоново-оранжевых, лаймовых и фиолетовых тюбингов. Крупные плашки с мягкими градиентами и глянцевыми бликами.
- **Типографика**: Рубленый спортивный геометрический гротеск (Russo One / Montserrat Black) с жирным начертанием, небольшим наклоном курсива для передачи динамики скорости и тонким темным контуром для идеальной читаемости на любом фоне.

## 2. Акценты: один цвет — один смысл
Разный цвет у каждой кнопки «чтобы отличались» — главная ошибка игрового
интерфейса. На одном экране одновременно видно не больше двух акцентов.

| Токен | Единственный смысл |
|---|---|
| `currency_trophy` | #ffd166 (Золотисто-желтый — кубки, монеты, победный ранг №1) |
| `danger_warning` | #e63946 (Кораллово-красный — тонущие плиты, зоны обрушения, вражеский таран) |
| `primary_action` | #ff6b35 (Яркий оранжевый — кнопки 'В БОЙ!', 'ТУРБО', ключевые призывы) |
| `safe_status` | #00f5d4 (Неоновый бирюзовый — стабильный лед, шкала готовности, живые игроки) |

Все значения — токенами в `src/ui/theme.css`: цвета, гарнитуры, шкала отступов,
радиусы, длительности, порядок слоёв `--z-*`. Литерал цвета внутри экрана — баг.

## 3. Композиция экрана
Меню и экраны между сессиями лежат ПОВЕРХ живой игровой сцены — той же, что в
игре, только с медленной камерой. Непрозрачная заливка на весь экран запрещена:
подложка только под текстом и кнопками.

- **Сцена за меню**: Главное меню: тюбинг игрока плавно покачивается на устойчивом ледяном постаменте посреди северного сияния, отражаясь в зеркальном льду; вокруг кружатся редкие снежинки

Экран — не колонка кнопок по центру. Три зоны, и каждый элемент лежит ровно в одной:

1. **Идентичность** — что это за экран: заголовок, режим, состояние игрока.
2. **Главное действие** — ровно одно на экран, самое крупное и единственное с
   основным акцентом.
3. **Второстепенный ряд** — всё остальное, одним рядом или сеткой, одним весом.

Зоны нажатия: основная ≥ 96 px, остальные ≥ 64 px, зазор ≥ 12 px, отступы через
`env(safe-area-inset-*)` плюс измеренная высота липкого баннера. Ни один экран не
скроллит страницу: длинный список скроллится во внутреннем контейнере.

## 4. Набор компонентов (закрытый)
Всё на экране — один из этих компонентов. Одноразовый `<div>` с инлайновыми
стилями — это то, из-за чего второй экран перестаёт совпадать с первым.

- RadarMiniMap (круговой радар 16 сегментов льдины с цветовой индикацией целостности)
- NitroBoostButton (круглая кнопка с круговым радиальным индикатором перезарядки)
- KillFeedBanner (всплывающие короткие плашки: 'ИГРОК выбил БОТ-1 в воду!')
- TrophyCounterWidget (анимированный счетчик кубков с иконкой золотого кубка)
- TubingCardItem (карточка выбора ватрушки в магазине с 3D-превью и кнопкой 'ВЫБРАТЬ')

Каждый интерактивный компонент несёт пять состояний: покой, наведение, нажатие,
недоступность, `:focus-visible`; асинхронное действие — ещё и `loading`.

## 5. HUD
Не больше пяти постоянных элементов на телефоне. Пять якорей, посередине экрана
не висит ничего, кроме временной обратной связи.

| Якорь | Что там |
|---|---|
| `bottom_left` | Зона виртуального джойстика движения |
| `bottom_right` | Кнопка реактивного форсажа с круговым прогресс-баром |
| `top_center` | Количество выживших участников и таймер фазы раунда |
| `top_left` | Мини-радар целостности арены и счетчик массы игрока |
| `top_right` | Кнопка паузы / звука |

Элементы:
- Счетчик оставшихся выживших ('ЖИВЫ: 5 / 8' с мини-иконками тюбингов вверху по центру)
- Таймер до следующего раскола льдины / времени раунда ('ДО СЖАТИЯ: 00:15' в верхней панели)
- Круговой индикатор энергии форсажа (Nitro Gauge) вокруг кнопки 'ТУРБО' справа внизу
- Мини-радар арены с цветовой подсветкой статуса 16 сегментов льда в левом верхнем углу
- Счетчик набранной массы / фрагов ('+24% МАССА [x3]' под аватаром игрока)
- Плавающий виртуальный джойстик в левой нижней четверти экрана (на мобильных)

Меняющиеся числа — `tabular-nums` в слоте фиксированной ширины, полосы —
`transform: scaleX()`, а не `width`. Текст поверх геймплея всегда с подложкой или
обводкой: белое число исчезает на светлой сцене.

## 6. Состояние, показанное миром, а не оверлеем
- Светящийся неоновый обод по периметру ватрушки, мигающий при критическом сближении с краем льдины
- Струя дыма и искр из сопла на корме тюбинга, визуализирующая оставшийся запас закиси азота
- Постепенное визуальное увеличение диаметра надувного баллона ватрушки при росте массы за фраги

### Экран: RevivePromptModal

- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: LeaderboardScreen
- **Что на экране**: Турнирная таблица лучших игроков недели в Лиге Айсбергов
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

**Переходы**: Главное Меню [main_menu] -> клик 'В БОЙ НА ЛЕД' -> мгновенный старт матча в Игровом Экране [match_hud] -> ликвидация соперников или падение в воду -> показ Экрана Итогов [match_results] -> клик 'СЛЕДУЮЩИЙ РАУНД' перезапускает [match_hud] (клик 'В ГЛАВНОЕ МЕНЮ' возвращает в [main_menu]). Из [main_menu] доступны переходы в Ангар [customization_hangar] и Таблицу Рекордов [leaderboard_screen] с кнопкой 'НАЗАД'. Во время [match_hud] кнопка паузы открывает оверлей [pause_settings_modal] с возможностью продолжить матч или выйти.

## 8. Состояния экрана
- Загрузка ассетов: ледяной спиннер с прогресс-баром 'Заморозка океана...'
- Потеря фокуса / сворачивание вкладки: авто-пауза и приглушение звука
- Низкий FPS: автоматическое отключение второстепенных частиц брызг и снижение разрешения теней
- Отсутствие интернета: локальное сохранение прогресса в localStorage с последующей синхронизацией

## 9. Отклик и движение
- Старт матча: обратный отсчет 3-2-1-GO с пульсацией цифр в центре экрана и взревом турбин
- Удар по сопернику: микро-задержка кадра (hitstop 30 мс), веер осколков, басовый 'бум' и легкая вибрация
- Выбивание в воду: замедление времени на 0.3 с, фонтан брызг, всплывающий текст 'ВЫБИТ!' и звон монет
- Раскол плиты: экранная тряска, звук ломающегося монолита, подъем морской пены

Переход один на всю игру и укладывается в 300 мс; анимируются только `transform`
и `opacity`; `prefers-reduced-motion: reduce` убирает трансформации.

## 11. Чек-лист приёмки интерфейса
- [ ] Ни одного литерала цвета, шрифта, радиуса или длительности вне `theme.css`.
- [ ] Слои над канвасом не перехватывают игровой ввод: контейнеры `pointer-events: none`.
- [ ] Каждый экран помещается в измеренный вьюпорт, страница не скроллится.
- [ ] Одно главное действие на экран, не больше двух акцентов одновременно.
- [ ] Меняющиеся числа не дёргают строку HUD.
- [ ] У каждого экрана описаны загрузка, пустота и ошибка.
- [ ] Возможность, которой нет на площадке, не нарисована вовсе.
- [ ] Ни `alert`/`confirm`, ни эмодзи вместо иконок, ни `z-index` мимо токенов.
- [ ] Самая длинная переведённая строка помещается в кнопку.
- [ ] За меню видна живая сцена игры, а не заливка цветом.
- [ ] Ни одного эмодзи в подписи кнопки: иконка — инлайновый SVG с `currentColor`.
- [ ] У каждого экрана расписаны три зоны, а не «карточка по центру».
- [ ] С закрытым игровым полем меню всё ещё узнаётся как «Ледовый Сумо-Батл: Последний Тюбинг».
