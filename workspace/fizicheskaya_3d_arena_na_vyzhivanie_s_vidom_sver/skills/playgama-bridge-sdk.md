# Skill: Интеграция Playgama Bridge SDK

## Purpose
Обеспечение кроссплатформенной работы игры на Яндекс Играх, VK и Web с поддержкой облачных сохранений, рекламы и лидербордов.

## When to Use
При подключении монетизации, сохранений и публикации игры на игровых порталах.

## Core Rules & Constraints
- Инициализация bridge.initialize() до загрузки тяжелых 3D ассетов
- Обязательная пауза звука и игрового цикла при показе рекламы и сворачивании вкладки
- Локальный кэш сохранений в localStorage на случай сбоя сети

## System Architecture
Служба StorageService и AdsService инкапсулируют методы SDK и предоставляют реактивный интерфейс для UI и GameState.

## Implementation Guidance
Использовать bridge.advertisement.showRewardedVideo() с Promise-оберткой для надежной обработки успешного просмотра.

## Common Mistakes to Avoid
- ❌ **Mistake**: Показ межстраничной рекламы посреди активного раунда
- ❌ **Mistake**: Отсутствие блокировки повторного нажатия на кнопку рекламы

## Validation Checklist
- [ ] Облачные сохранения проверены на тестовом аккаунте
- [ ] Rewarded Video начисляет награду только после события 'rewarded'
- [ ] Звук корректно возобновляется после закрытия рекламы
