# Гладиаторский roguelike арена-экшен ragdoll 🎮

> **Сражайтесь в Колизее с физикой рэгдолла: рубите врагов, сбрасывайте их в ямы и прокачивайте оружие!**

---

## 🌟 Project Overview
- **Genre**: 3D Физический Арена-Экшен (Рэгдолл Рогалик)
- **Renderer**: **THREEJS** + Rapier3D (@dimforge/rapier3d-compat 0.13.x)
- **Platform**: Playgama Bridge (Yandex Games / VK / Web)
- **Orientation**: Landscape
- **Target Audience**: Любители экшен-слэшеров, рэгдолл-игр и средневековых сражений.
- **Core Hook**: Тактические бои на мечах с активной рэгдолл-физикой, отсечением элементов брони и ликованием трибун Колизея.

---

## 🚀 Запуск и Сборка
```bash
npm install     # Установка зависимостей
npm run dev     # Запуск локального сервера разработки (Vite)
npm run build   # Проверка типов TypeScript и продакшн сборка
```

## 🎮 Управление в Игре

### Десктоп (Клавиатура + Мышь):
- **WASD / Стрелки** — Перемещение гладиатора по арене
- **Мышь + ЛКМ / J** — Направление и круговой кинетический замах меча
- **ПКМ / K** — Тяжелый рубящий удар
- **Space / Shift / F** — Силовой таран / рывок
- **P / Esc** — Пауза

### Мобильные Устройства (Тач):
- **Левая половина экрана** — Плавающий виртуальный 2-осевой джойстик ходьбы (Pointer Events, deadzone 8%)
- **Кнопка ⚔️ РУБИТЬ** — Основной удар мечом по направлению взмаха
- **Кнопка ⚡ РЫВОК** — Скоростной уворот с кадрами неуязвимости
- **Кнопка 🛡️ ТАРАН** — Силовой толчок щитом для сбивания противников с ног
- **Отладочный флаг `?touch=1`** — Принудительно включает мобильную тач-раскладку на ПК в браузере

## 📁 Структура Исходного Кода (`src/`)
```text
src/
├── main.ts                    # Точка входа, preloader, инициализация SDK, single-shot game_ready
├── core/
│   ├── Game.ts                # Главный координатор и стейт-машина игры
│   ├── GameLoop.ts            # Фиксированный 60Гц цикл обновления (accumulator, hitstop 40ms)
│   └── EventBus.ts            # Строго типизированная шина событий
├── platform/
│   ├── PlaygamaService.ts     # Адаптер @playgama/bridge v2 (реклама, cloud save, лидерборды)
│   └── StorageService.ts      # Синхронизация прогресса (Cloud + LocalStorage mirror)
├── physics/
│   ├── PhysicsWorld.ts        # Коллизии арены Колизея, отскок от стен (0.62), препятствия
│   └── Ragdoll.ts             # Активный рэгдолл, шарнирный мотор (850 Н·м), отсечение брони
├── entities/
│   ├── Player.ts              # Персонаж игрока, кинетический замах, выносливость
│   ├── Enemy.ts               # Враги 4 типов (Ретиарий, Мурмиллон, Центурион, Титан)
│   └── Weapon.ts              # Физический клинок, расчет кинетической энергии E_k = 0.5*m*v^2
├── systems/
│   ├── CombatSystem.ts        # Коллизии клинка, окно парирования (0.22с), сбитие с ног
│   ├── WaveManager.ts         # Менеджер 10 волн арены, спавн боссов и элиты
│   ├── UpgradeManager.ts      # 3-Card драфт гладиаторских даров (Эдикты Цезаря)
│   └── CrowdFavorSystem.ts    # Ликование трибун, комбо-множитель, спавн наград
├── rendering/
│   ├── SceneManager.ts        # Three.js сцена, изометрическая камера, тени, screen shake
│   ├── ArenaEnvironment.ts    # 3D Колизей: песок, колонны, жаровни со светом, шипы
│   ├── ParticleSystem.ts      # Пулинг частиц (кровь, искры, пыль, монеты)
│   └── WeaponTrail.ts         # Динамический ленточный шлейф клинка с градиентом скорости
├── audio/
│   └── AudioManager.ts        # Процедурный синтезатор WebAudio/Howler SFX и ритм боя
├── ui/
│   ├── UIManager.ts           # HUD, модальные окна улучшений/кузницы, всплывающий урон
│   └── TouchControls.ts       # Мультитач виртуальный джойстик и кнопки
└── input/
    └── InputManager.ts        # Единый снимок клавиатурного и сенсорного ввода
```
