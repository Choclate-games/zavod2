# Reference Analysis & Market Research: Гладиаторский roguelike арена-экшен ragdoll

### Reference: Vampire Survivors / Brotato (Horde Survival / Arena Roguelite)
- **Mechanics Analyzed**: Выбор из 3 карт, Мета-прогрессия, Синергия способностей
- **Key Lessons**: Каждое повышение уровня должно давать мгновенный ощутимый прирост силы.
- **What NOT to Copy**: Не делать пустые статичные арены без физических объектов.

### Reference: Carmageddon / Drift Hunters (Physics Action Racing)
- **Mechanics Analyzed**: Физика заноса, Таранные удары, Деформация окружения
- **Key Lessons**: Физическая инерция и сочные столкновения создают высокий уровень вовлечения.
- **What NOT to Copy**: Не перегружать управление сложными комбинациями клавиш.
