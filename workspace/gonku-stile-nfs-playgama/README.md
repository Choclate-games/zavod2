# Гонку стиле нфс playgama 🎮⚡

> **3D Экшен-Дрифт в стиле Need for Speed: Ночной побег от полиции с разрушением города, нитро-яростью и битвами с боссами на арене!**

---

## 🌟 Об игре
- **Жанр**: 3D Экшен-Дрифт / Побег от полиции (Аркадный Авто-Рогалик)
- **Стек**: Three.js + Rapier3D (WebAssembly) + Vite + TypeScript + Web Audio API
- **Платформа**: Playgama Bridge v2 (Яндекс Игры, VK Play, Web)
- **Ориентация**: Landscape (Горизонтальная)
- **Управление**: Десктоп (Клавиатура) + Мобильные устройства (Мультитач Pointer Events)

---

## 🎮 Управление

### На компьютере (Клавиатура):
- `W` / `↑` — Газ / Ускорение
- `S` / `↓` — Тормоз / Задний ход
- `A` / `D` или `←` / `→` — Поворот руля
- `Space` / `E` — Впрыск Нитро (при 100% заряде)
- `Shift` / `F` — Ручной тормоз (срыв задней оси в занос)
- `P` / `Esc` — Пауза

### На телефоне / планшете (Сенсорный экран):
- **Слева**: Плавающий виртуальный джойстик руления (горизонтальная ось, центрируется под пальцем).
- **Справа**: 
  - Большая педаль **ГАЗ** (Drive)
  - Педаль **ТОРМОЗ** (Reverse)
  - Кнопка **НИТРО** (Nitro Burst)
  - Кнопка **ДРИФТ** (Ручник)
- **Мультитач**: Поддерживается одновременное зажатие газа, руления и нитро тремя пальцами.
- **Отладочный флаг**: добавьте `?touch=1` в адресную строку браузера для включения мобильного интерфейса на ПК.

## 🚀 Запуск и Сборка

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск локального сервера разработки (Vite)
npm run dev

# 3. Сборка продакшен-бандла
npm run build

# 4. Предпросмотр сборки
npm run preview
```

## 📁 Структура проекта (`src/`)

```text
src/
├── main.ts                    # Bootstrap, инициализация Playgama Bridge и запуск
├── core/
│   ├── Game.ts                # Главный координатор и стейт-машина игры
│   ├── GameLoop.ts            # Фиксированный цикл 60Гц с субстепами и таймскейлом
│   └── EventBus.ts            # Типизированная шина событий
├── platform/
│   └── PlaygamaService.ts     # Адаптер Playgama Bridge (реклама, cloud save, лидерборды)
├── physics/
│   └── PhysicsWorld.ts        # Rapier3D физический мир, коллайдеры, группы коллизий
├── audio/
│   └── SoundSynthesizer.ts    # Web Audio процедурный синтез (мотор, дрифт, нитро, взрывы, музыка)
├── rendering/
│   ├── SceneManager.ts        # Three.js сцена, свет, динамическая следящая камера, город
│   ├── ProceduralModels.ts    # Процедурные 3D модели машин, копов, вертолета, ловушек
│   ├── ParticleSystem.ts      # InstancedMesh частицы дыма, искр, пламени, шестеренок
│   └── TireTracksManager.ts   # Процедурные ленты следов шин на асфальте
├── entities/
│   ├── PlayerVehicle.ts       # Физический рэйкаст-контроллер броневика, дрифт, нитро
│   ├── PoliceVehicle.ts       # ИИ патрулей (Cruiser, Interceptor, Rhino, Roadblock)
│   ├── Helicopter.ts          # Полицейский вертолет с прожектором
│   ├── BossEntity.ts          # Битва с титаном-боссом и Bullet-Time финишер
│   ├── PursuitBreaker.ts      # Разрушаемые опоры (щиты, заправка, вышка)
│   └── EntityManager.ts       # Пул и спавн всех активных сущностей и столкновений
├── systems/
│   └── UpgradeSystem.ts       # Рогалик-прогрессия и выбор 3 карт модулей
└── ui/
    ├── TouchControls.ts       # Мобильное тач-управление на Pointer Events
    └── UIManager.ts           # HUD, гараж, модальные окна, баннеры, счетчики
```
