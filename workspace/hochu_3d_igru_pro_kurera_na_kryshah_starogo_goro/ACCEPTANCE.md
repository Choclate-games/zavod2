# Приёмка: Черепичный Спринт: Чистый Флоу

Готовность игры определяется этим файлом, а не ощущением. Каждый пункт — либо
команда с ожидаемым результатом, либо факт, который видно на экране. Пока хотя
бы один пункт раздела **A–C** красный, игра не готова: это не качество, это
работоспособность.

Автоматическая часть запускается одной командой:

```bash
node scripts/check-spec.mjs        # или npm run check:spec
```

Скрипт лежит в проекте и проверяет то, что проверяется статически. Остальное —
руками, по этому же списку. Результат прогона записывается в `DEVLOG.md`.

## C. Платформа Playgama

Без этого раздела игра не запускается на площадке — не «работает хуже», а не
стартует и снимается с модерации.

- [x] **C1** · `game_ready` отправляется РОВНО ОДИН РАЗ и только после загрузки, когда меню уже интерактивно.
- [x] **C2** · `bridge.initialize()` обёрнут таймаутом (~10 с), сторожевой таймер (~15 с) отправляет `game_ready` в любом случае.
- [x] **C3** · Прогресс загрузки идёт от реальных вех, заставка доходит до 100% до `game_ready`.
- [x] **C4** · Ни один шаг загрузки не ждёт решения игрока: `authorize()` в загрузке отсутствует.
- [x] **C5** · Сохранение — один ключ (`courier_rank`), один JSON, нормализация при чтении; битый сейв поднимается на умолчаниях.
- [x] **C6** · Награда за rewarded выдаётся только по `state === 'rewarded'` (Страховка Гильдии (Второе дыхание)), слушатель снимается через `off()`, повторный клик не платит дважды.
- [x] **C7** · Interstitial не показывается при старте, в середине геймплея и сразу после покупки; пауза между показами соблюдена.
- [x] **C8** · Пауза и звук приходят из событий моста (`PAUSE_STATE_CHANGED` / `AUDIO_STATE_CHANGED`), дельта времени сбрасывается при возврате.
- [x] **C9** · Возможность, которой на площадке нет, не нарисована вовсе — не серой кнопкой и не ошибкой по нажатию. Проверяется подменой флага (best_delivery_time_royal_district).
- [x] **C10** · Покупки: `getPurchases()` при каждом запуске, сначала выдача, потом `consumePurchase(productId)`.
- [x] **C11** · Игра проверена в фрейме площадки и гостем, и авторизованным.
