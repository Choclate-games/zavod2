# Changelog — Черепичный Спринт: Чистый Флоу

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [SemVer](https://semver.org/lang/ru/).

## [1.0.0] - 2026-08-23

### Added
- Полный Three.js 3D-раннер на викторианских крышах старого города.
- Процедурный риг курьера с анимациями бега, группировки, переката, подката и зацепа за карниз.
- Механика амортизационного переката (Cushion Roll) с ускорением +4.5 м/с.
- Катапультирующий зацеп за медные отливы (Ledge Grab) с импульсом +6.2 м/с.
- Скоростной подкат под дымовыми и паровыми трубами (Slate Slide).
- Физика гидродинамики и кавитации алхимической колбы (Parcel Integrity System).
- Система темпа и комбо флоу x1..x4 (Flow Combo System).
- Процедурный генератор модульных кварталов крыш с препятствиями и канатами.
- Процедурный Web Audio синтезатор звуков (звуки карабинов, ветра, бьющегося стекла, фанфар).
- Пул частиц на `InstancedMesh` (искры, пар, дым).
- Полная система интерфейса: Splash, Главное меню, HUD, Мастерская снаряжения, Экран победы, Экран поражения.
- Сенсорное управление One-Thumb Flow на Pointer Events с поддержкой мыши и мультитача.
- Интеграция с Playgama Bridge v2 (жизненный цикл, `game_ready`, Rewarded реклама, сохранение прогресса в `courier_rank`).
