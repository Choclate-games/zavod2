# QA & Testing Plan: Черепичный Спринт: Чистый Флоу

## 1. Functional Test Matrix
- [ ] Проверка корректности распознавания жестов свайпа вверх/вниз и удержания на сенсорных экранах
- [ ] Тест расчета урона посылке: нанесение ровно 25 HP урона при жестком падении и 30 HP при прямом ударе о трубу
- [ ] Тест множителя Флоу: корректный рост от x1.0 до x4.0 с шагом 0.25 и мгновенный сброс до x1.0 при столкновении
- [ ] Тест генератора крыш: отсутствие непроходимых разрывов (> 12м) на всех уровнях сложности
- [ ] Тест интеграции Playgama Bridge: корректное начисление награды за просмотр Rewarded Video и восстановление посылки

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS на устройствах уровня iPhone 11 / Redmi Note 10 / Samsung Galaxy A52
- [ ] Время первичной загрузки и инициализации сцены менее 2.5 секунд при 4G-соединении
- [ ] Потребление оперативной памяти вкладки браузера не более 160 МБ
- [ ] Количество Draw Calls в игровом цикле не превышает 65

## 3. Target Browser Matrix
- Mobile Safari (iOS 15+)
- Chrome Mobile (Android 10+)
- Samsung Internet (Android)
- Desktop Chrome / Edge (Windows / macOS)
- Yandex Browser Mobile & Desktop
