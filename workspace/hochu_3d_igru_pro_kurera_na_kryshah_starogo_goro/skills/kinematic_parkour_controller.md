# Skill: Кинематический паркур-контроллер с распознаванием жестов

## Purpose
Обеспечение отзывчивого физического движения курьера, обработки свайпов и тайминга амортизации

## When to Use
При программировании управления персонажем, анимаций и взаимодействия с поверхностями

## Core Rules & Constraints
- Использовать кинематический рейкастинг вместо тяжелой физики твердых тел
- Обрабатывать тач-события с буферизацией в 120 мс
- Плавная интерполяция высоты при скольжении по наклонным скатам

## System Architecture
Конечный автомат состояний (FSM: Run, Jump, Slide, CushionRoll, LedgeGrab, Fall) с событийным входом

## Implementation Guidance
Привязывать вертикальное смещение к нормалям полигонов черепицы для естественного бега по уклонам

## Common Mistakes to Avoid
- ❌ **Mistake**: Использование стандартного физического трения, приводящего к спотыканиям на стыках
- ❌ **Mistake**: Игнорирование потери фокуса окна (touchcancel)

## Validation Checklist
- [ ] Все состояния FSM корректно выходят в Run или Fall
- [ ] Управление одним пальцем работает без виртуальных джойстиков
- [ ] FPS стабилен при непрерывных жестах
