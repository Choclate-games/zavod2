# Skill: Генератор процедурных крыш на Three.js

## Purpose
Сборка бесшовной полосы крыш из модульных заготовок с InstancedMesh и гарантированной проходимостью

## When to Use
При разработке уровня, чанков зданий и системы пулинга геометрии

## Core Rules & Constraints
- Использовать единый буфер для черепицы каждого типа
- Поддерживать минимальную ширину крыши не менее 4 метров
- Ограничивать максимальный разрыв между зданиями 12 метрами

## System Architecture
Модульный менеджер чанков с пулом объектов (ChunkPool), фабрикой модулей (ModuleFactory) и генератором сидов

## Implementation Guidance
Создавать чанки с запасом на 3 шага вперед по движению камеры и удалять позади с дистанцией 30м

## Common Mistakes to Avoid
- ❌ **Mistake**: Создание новых инстансов Three.Geometry в цикле рендера
- ❌ **Mistake**: Отсутствие проверки досягаемости следующего карниза

## Validation Checklist
- [ ] Пул чанков не выделяет память в рантайме
- [ ] Коллизии через BVH генерируются асинхронно при спавне
- [ ] Draw calls не превышают 65
