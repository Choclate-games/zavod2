# Core Loop Design: Идея: kick & shoot

## 1. Чем эта петля отличается
- **Фирменный момент**: Игрок на полном ходу с ноги выбивает тяжелую бронедверь отсека: слетевшая с петель створка впечатывает пулеметчика в стену, выбивая у него в воздух раскаленный пулемет. Включается 0.8-секундный адреналиновый bullet-time: игрок на лету перехватывает пулемет, разряжает очередь в двух парящих штурмовиков, после чего пинком отправляет летящую навстречу взрывную бочку в толпу подкрепления, вызывая огненный цепной взрыв и звон комбо-ранга SSS.
- **Отличие от жанрового шаблона**: Вместо пассивного кайтинга врагов по кругу игра принуждает к агрессивному рашу вперед: дефицит патронов вынуждает регулярно сближаться для пинка, а любая туша врага, бочка или выбитая дверь становятся смертоносным метательным снарядом, экономящим боеприпасы.
- **Сознательно НЕ берём**: Отвергаем шаблон 'пассивного автошутера/рогалика с зачисткой открытых пустых арен и выбором скучных карточек +15% урона от пуль'. В нашем FPS урон и победа рождаются не из сухих DPS-статов, а из геометрии комнат, кинетических ragdoll-столкновений и агрессивного ближнего контакта, где пинок — главный инструмент контроля толпы, добычи ресурсов и запуска цепных реакций.

+---------------------------------------------------+
|                 ОЦЕНКА ДИСТАНЦИИ                  |
|    Патроны есть?                   Патронов мало? |

             |                              |

                           |

                           |

## 6. Кривая напряжения
Пилообразная кривая с 4 фазами на каждый отсек: 1. Фаза прорыва (Spike: 95%) — взрывной вынос двери ногой, всплеск адреналина в замедлении времени; 2. Фаза кинетического хаоса (Plateau: 80-90%) — непрерывный бег, серия пинков, жонглирование в воздухе и уклонение от снарядов; 3. Фаза добивания (Decrescendo: 40%) — ликвидация единичных оглушенных противников и сбор патронов; 4. Фаза передышки (Rest: 10%) — выбор перка на консоли, оценка билда и подготовка к следующей двери.

## 7. Формулы ядра
- `KickLaunchVelocity = BaseLaunchSpeed (17.5 m/s) * (1.0 + BootBoosterUpgrade * 0.12) * clamp(PlayerForwardSpeed / 6.0 m/s, 1.0, 1.6)`
- `WallImpactDamage = BaseWallDamage (45 HP) + (RagdollImpactVelocity ^ 1.4) * MassFactor (1.15) * (IsSpikeWall ? 2.5 : 1.0)`
- `AirSkeetMultiplier = BaseCrit (2.2x) + clamp(AirHangTime / 0.8 s, 0.0, 1.5) * WeaponPrecisionFactor (1.3x)`
- `DominoChainDamage = VictimVelocity * TargetBodyMass * 2.8 * (ChainDepth ^ 0.75)`
- `AmmoDropChance = BaseChance (0.15) + (KilledByWallOrBarrelKick ? 0.70 : 0.0) + (ComboLevel * 0.05)`
