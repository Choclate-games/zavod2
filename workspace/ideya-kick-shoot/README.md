# Идея: kick & shoot 🎮⚡

> **3D Аркадный кинетический экшен-рогалик с выносом дверей с ноги, воздушным жонглированием и рогалик-прокачкой!**

---

## 🌟 Об игре (Overview)
- **Жанр**: 3D Аркадный кинетический экшен-рогалик (короткие забеги по 12 отсекам)
- **Движок и рендер**: Three.js (^0.170.0) + WebGL + Web Audio API
- **Платформа**: Playgama Bridge v2 (Яндекс Игры, VK, Web)
- **Ориентация**: Landscape (Горизонтальная)
- **Фирменная механика**: Кинетический тактический пинок берцем (вынос бронедверей, slow-mo прорыв, воздушный Skeet-крит x2.5, боулинг телами во взрывные бочки).

---

## 🚀 Быстрый запуск (Quick Start)

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск локального сервера разработки (Vite)
npm run dev

# 3. Сборка для публикации (Production Build)
npm run build
```

## 🎮 Управление (Controls)

### 💻 Клавиатура и Мышь (Desktop):
- **WASD** / **Стрелки**: Перемещение персонажа
- **ЛКМ** / **J**: Стрельба из текущего оружия (Пистолет, Дробовик, Автомат, Ракетомет)
- **ПКМ** / **E** / **K**: Кинетический тактический пинок (Kinetic Spartan Kick)
- **Space** / **Shift**: Рывок / Спринт (Dash)
- **Q** / **F**: Тактическая способность (Энергетическая ударная волна EMP)
- **Флаг `?touch=1`**: Принудительно включает экранные мобильные кнопки для тестирования на десктопе

### 📱 Сенсорное управление (Mobile Touch):
- **Слева (вся левая половина экрана)**: Плавающий виртуальный джойстик перемещения (база под пальцем, мертвая зона 8%)
- **Справа (большая кнопка 96px)**: Кинетический пинок (Kick)
- **Справа (кнопка 76px)**: Огонь / Стрельба (Shoot)
- **Справа (кнопки 64px)**: Рывок (Dash) и Ударная волна (EMP Ability)
- Полная поддержка мультитач (одновременный бег, прицеливание и атака на Pointer Events)

## 📁 Структура исходного кода (`src/`)

```text
src/
├── main.ts                     # Точка входа, бутстрап платформы Playgama Bridge, guards
├── core/
│   ├── Types.ts                # TypeScript интерфейсы, энумы и структуры данных
│   ├── EventBus.ts             # Типизированная шина событий
│   ├── GameLoop.ts             # Фиксированный 60Гц цикл обновления с хит-стопом
│   └── Game.ts                 # Главный координатор и стейт-машина игры
├── platform/
│   ├── PlaygamaService.ts      # Интеграция @playgama/bridge (Rewarded, Interstitial, Leaderboards)
│   └── StorageService.ts       # Синхронизация сохранений (Cloud + LocalStorage mirror)
├── audio/
│   └── AudioManager.ts         # Процедурный синтезатор звуков Web Audio API + динамический BGM
├── physics/
│   ├── MathUtils.ts            # Геометрия, конус удара 55°, баллистика
│   └── PhysicsWorld.ts         # Кинематическая и динамическая физика 3D тел и соударений
├── entities/
│   ├── Player.ts               # Контроллер игрока со стейт-машиной Spartan Kick
│   ├── Enemy.ts                # ИИ врагов (Пехотинец, Щитовик, Берсерк, Снайпер, Босс-Колосс)
│   ├── EnemyPool.ts            # Пул сущностей без аллокаций в тике 60Гц
│   ├── Weapon.ts               # Арсенал (Пистолет, Дробовик, Штурмовик, Ракетомет, Овердрайв)
│   ├── ProjectilePool.ts       # Пул снарядов и ракет
│   └── Props.ts                # Взрывные бочки, штурмовые двери, выбитые стволы, плазма
├── systems/
│   ├── CombatSystem.ts         # Расчет урона, Skeet-криты (2.5x), урон о стены, комбо SSS
│   ├── WaveManager.ts          # 12 штурмовых отсеков и битва с финальным Боссом
│   ├── UpgradeManager.ts       # Выбор 1 из 3 тактических био-чипов и мастерская экзо-берцев
│   └── ParticleSystem.ts       # 3D частицы, искры, вспышки, ударные кольца
├── rendering/
│   ├── ModelFactory.ts         # Процедурные стилизованные 3D меши и материалы
│   └── SceneManager.ts         # Three.js сцена, изометрическая камера с FOV punch, тени
└── ui/
    ├── TouchControls.ts        # Pointer Events тач-контроллер со стиком и кнопками
    └── UIManager.ts            # HUD, 3-Card модалка, мастерская, экран результатов
```
