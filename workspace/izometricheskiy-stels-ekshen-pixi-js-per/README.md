# Изометрический стелс-экшен: персонаж 🎮🌲

> **Выживайте в священном ночном лесу: прячьтесь в кустах от блуждающих огоньков и древнего Лешего, зажигайте берестяные факелы, собирайте редкие травы и чертите защитные круги из соли!**

---

## 🌟 Обзор игры
- **Жанр**: 2D Изометрический стелс-экшен / Roguelite выживание
- **Графический движок**: **PixiJS v8** (Изометрическая 2.5D проекция, динамический свет, тени, частицы)
- **Физика**: **Matter.js** (Фиксированный 60Гц шаг, рэгдолл-отдача, коллизии с препятствиями и радиусы света)
- **Аудио**: Web Audio API с процедурным синтезатором звуков и фоновым эмбиентом
- **Платформа**: Playgama Bridge v2 (Яндекс Игры, VK, OK, CrazyGames, Web)
- **Ориентация**: Landscape (Горизонтальная)

---

## 🕹️ Управление

### 💻 Десктоп (Клавиатура и мышь):
- **WASD** / **Стрелки** — Перемещение персонажа в изометрии
- **Пробел** / **J** / **ЛКМ** — Атака клинком / Удар из тени ($3.0\times$ критический урон при атаке из кустов или со спины)
- **F** / **1** — Зажечь ближайший берестяной факел (отпугивает огоньки и волков)
- **E** / **2** — Начертить защитный круг из соли (блокирует проход нечисти и наносит ей урон)
- **Shift** / **3** / **K** — Бесшумный рывок / уклонение
- **P** / **Esc** — Пауза

### 📱 Мобильные устройства (Touch Controls на Pointer Events):
- **Левая половина экрана**: Плавающий виртуальный джойстик (появляется под пальцем, мёртвая зона 8%)
- **Правая кнопка «УДАР» (96px)**: Атака клинком
- **Кнопка «🔥 Факел»**: Зажечь факел
- **Кнопка «🧂 Соль»**: Начертить круг соли
- **Кнопка «💨 Рывок»**: Рывок / уклонение
- *Отладочный флаг*: добавьте `?touch=1` в адресную строку, чтобы включить сенсорную раскладку на ПК.

## 📁 Структура проекта (`src/`)
```text
src/
├── main.ts                    # Инициализация платформы, прелоадер и старт игры
├── core/
│   ├── Game.ts                # Главный координатор и стейт-машина игры
│   ├── GameLoop.ts            # Фиксированный 60Гц игровой цикл с защитой от скачков дельты
│   └── EventBus.ts            # Типизированная шина событий
├── platform/
│   ├── viewport.ts            # Блокировка страницы, Safe Area Insets и защита от скролла
│   ├── PlaygamaService.ts     # Интеграция @playgama/bridge v2 (Реклама, Сейвы, Лидерборды)
│   └── StorageService.ts      # Cloud & LocalStorage сохранение с нормализацией данных
├── physics/
│   ├── PhysicsWorld.ts        # 2D физический мир Matter.js и трассировка лучей видимости
│   └── RagdollController.ts    # Расчет импульсов отдачи и отскока
├── entities/
│   ├── Player.ts              # Персонаж: стелс-маскировка, перемещение, атака, факелы и соль
│   ├── Enemy.ts               # ИИ врагов (Блуждающие огоньки, Лесные волки, Босс Леший)
│   └── Weapon.ts              # Факелы, круги соли, кусты для укрытия, сбор трав и монет
├── systems/
│   ├── CombatSystem.ts        # Расчет урона, хит-стоп 40мс, удары из тени, искры
│   ├── WaveManager.ts         # Процедурная генерация леса, сменяемость ночей и волны духов
│   ├── UpgradeManager.ts      # Рогалик-система выбора 1 из 3 карт с синергиями
│   └── CrowdFavorSystem.ts    # Надежда колонии: бонусы за освещение леса и спасение духов
├── rendering/
│   ├── SceneManager.ts        # Сцена PixiJS v8, изометрическая проекция, Y-сортировка, свет
│   ├── MeshPool.ts            # Процедурный генератор текстур и пул частиц
│   └── Shaders.ts             # Палитра и параметры источников света
├── ui/
│   ├── UIManager.ts           # HUD, меню, прокачка лагеря, таблица лидеров, Game Over
│   ├── VirtualJoystick.ts     # Сенсорный плавающий мультитач джойстик
│   └── CardModal.ts           # Окно выбора 3 карт улучшений
├── audio/
│   └── AudioManager.ts        # Web Audio API синтезатор звуков и эмбиент
└── telemetry/
    └── Telemetry.ts           # Отслеживание метрик плотности впечатлений
```

## 🚀 Запуск и Сборка

### Установка зависимостей:
```bash
npm install
```

### Запуск dev-сервера:
```bash
npm run dev
```

### Продакшен сборка:
```bash
npm run build
```
Сборка будет сохранена в папке `dist/` и готова к загрузке в Яндекс Игры / VK / CrazyGames.
