# QA & Testing Plan: Тени Фестиваля: Клинок и Эшелон

## 1. Functional Test Matrix
- [ ] Проверка перехода между всеми 3 эшелонами шествия без падения сквозь геометрию
- [ ] Проверка правильности расчета конусов видимости стражи при нахождении в толпе и вне толпы
- [ ] Проверка срабатывания окна парирования (0.22 с) на ЛКМ/ПКМ и мобильных тапах
- [ ] Проверка взятия тотема и применения модификатора скорости перемещения
- [ ] Проверка условий победы при достижении переулка и поражения при 100% тревоге

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS в Chrome/Firefox/Safari на средних ПК при 120 инстансированных танцорах
- [ ] Стабильные 60 FPS (не ниже 50 FPS) на мобильных устройствах уровня iPhone 11 / Snapdragon 720G
- [ ] Количество Draw Calls не превышает 75 в любой момент геймплея
- [ ] Время первичной загрузки ассетов и старта сцены менее 2.5 секунд на 4G соединении

## 3. Target Browser Matrix
- Chrome 120+ (Desktop & Android)
- Safari 16+ (iOS & macOS)
- Firefox 120+ (Desktop)
- Yandex Browser (Desktop & Mobile)
