# UI/UX Specification: Тени Фестиваля: Клинок и Эшелон

## 1. Материал интерфейса
Интерфейс живёт в том же мире, что и сцена. Проверка: если закрыть игровое поле,
меню обязано выдавать именно эту игру, а не любую другую.

- **Тема от арт-директора**: Стимпанк-барокко с золотой филигранью, латунными рамками и контрастными индикаторами ритма
- **Визуальный язык**: Контрастный латунный и рубиновый интерфейс с четкими геометрическими маркерами опасности и мягкой золотой аурой скрытности.
- **Типографика**: Заголовки: стилизованный гротеск с засечками (Cinzel / Playfair Display); Игровой интерфейс и таймеры: четкий высокочитаемый численный шрифт (Roboto Bold / Montserrat)

## 2. Акценты: один цвет — один смысл
Разный цвет у каждой кнопки «чтобы отличались» — главная ошибка игрового
интерфейса. На одном экране одновременно видно не больше двух акцентов.

| Токен | Единственный смысл |
|---|---|
| `danger` | #e71d36 |
| `gold_collect` | #e6a135 |
| `rhythm_perfect` | #ffd166 |
| `stealth_safe` | #2ec4b6 |

Все значения — токенами в `src/ui/theme.css`: цвета, гарнитуры, шкала отступов,
радиусы, длительности, порядок слоёв `--z-*`. Литерал цвета внутри экрана — баг.

## 3. Композиция экрана
Меню и экраны между сессиями лежат ПОВЕРХ живой игровой сцены — той же, что в
игре, только с медленной камерой. Непрозрачная заливка на весь экран запрещена:
подложка только под текстом и кнопками.

- **Сцена за меню**: Вид на залитую праздничными огнями площадь с медленно движущейся карнавальной платформой на заднем плане и силуэтом вора на карнизе крыши

Экран — не колонка кнопок по центру. Три зоны, и каждый элемент лежит ровно в одной:

1. **Идентичность** — что это за экран: заголовок, режим, состояние игрока.
2. **Главное действие** — ровно одно на экран, самое крупное и единственное с
   основным акцентом.
3. **Второстепенный ряд** — всё остальное, одним рядом или сеткой, одним весом.

Зоны нажатия: основная ≥ 96 px, остальные ≥ 64 px, зазор ≥ 12 px, отступы через
`env(safe-area-inset-*)` плюс измеренная высота липкого баннера. Ни один экран не
скроллит страницу: длинный список скроллится во внутреннем контейнере.

## 4. Набор компонентов (закрытый)
Всё на экране — один из этих компонентов. Одноразовый `<div>` с инлайновыми
стилями — это то, из-за чего второй экран перестаёт совпадать с первым.

- RhythmBeatMetronome
- StealthDetectionDisc
- TotemWeightIndicator
- ParryFlashIndicator
- TouchButtonCluster

Каждый интерактивный компонент несёт пять состояний: покой, наведение, нажатие,
недоступность, `:focus-visible`; асинхронное действие — ещё и `loading`.

## 5. HUD
Не больше пяти постоянных элементов на телефоне. Пять якорей, посередине экрана
не висит ничего, кроме временной обратной связи.

| Якорь | Что там |
|---|---|
| `bottom_center` | Пульсирующий ритм-индикатор карнавальной музыки |
| `bottom_left` | Зона виртуального аналогового стика |
| `bottom_right` | Кнопки действия (Атака / Парирование) |
| `top_center` | Таймер шествия и статус эшелона |
| `top_left` | Кнопка паузы и настройки звука |
| `top_right` | Счетчик дукатов и индикатор реликвии |

Элементы:
- Индикатор Ритма шествия (пульсирующий метроном внизу по центру)
- Круговой датчик скрытности / тревоги над головой персонажа (Eye Icon / Stealth Disc)
- Счетчик похищенного золота и иконка захваченного тотема
- Таймер шествия платформы (обратный отсчет до 120 с)
- Мобильный виртуальный стик слева и контекстные латунные кнопки атаки/парирования справа

Меняющиеся числа — `tabular-nums` в слоте фиксированной ширины, полосы —
`transform: scaleX()`, а не `width`. Текст поверх геймплея всегда с подложкой или
обводкой: белое число исчезает на светлой сцене.

## 6. Состояние, показанное миром, а не оверлеем
- Конусы света от латунных фонарей в руках стражников вместо плоских 2D наложений
- Фонари на платформе, мигающие в такт сильным долям музыки
- Анимация вора, пригибающегося и натягивающего маску при входе в толпу танцоров

## 7. Каталог экранов
### Экран: MainMenu
- **Что на экране**: Главное меню: выбор маршрута шествия, гардероб масок, запуск ограбления
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: GameplayHUD
- **Что на экране**: Минималистичный игровой экран: ритм-метроном, статус скрытности, таймер
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: HeistResultScreen
- **Что на экране**: Экран итогов: украденное золото, ранг стиля (S/A/B), кнопка удвоения за Ad
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: WorkshopScreen
- **Что на экране**: Мастерская гильдии воров: покупка рапир, улучшение масок, просмотр лидерборда
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

**Переходы**: MainMenu -> RouteSelection -> InGameCutscene (2s) -> ActiveGameplayHeist -> EscapeSuccess / CaughtFail -> ResultScreen -> Workshop

## 8. Состояния экрана
- State: HiddenInCrowd -> HUD показывает закрытый глаз и зеленый ореол
- State: InCombat -> HUD переключает фокус на индикаторы атак врагов
- State: CarryingTotem -> HUD показывает шкалу выносливости и вес реликвии

## 9. Отклик и движение
- При попадании в ритм: золотая вспышка по контуру экрана и звонкий щелчок кастаньет
- При успешном парировании: замедление времени на 150мс, взрыв искр и разлет стражника в рэгдолл
- При входе в толпу: плавное затемнение вора и появление полупрозрачного силуэта маскировки
- При обнаружении: резкий свисток стражи и пульсация конуса алым цветом

Переход один на всю игру и укладывается в 300 мс; анимируются только `transform`
и `opacity`; `prefers-reduced-motion: reduce` убирает трансформации.

## 11. Чек-лист приёмки интерфейса
- [ ] Ни одного литерала цвета, шрифта, радиуса или длительности вне `theme.css`.
- [ ] Слои над канвасом не перехватывают игровой ввод: контейнеры `pointer-events: none`.
- [ ] Каждый экран помещается в измеренный вьюпорт, страница не скроллится.
- [ ] Одно главное действие на экран, не больше двух акцентов одновременно.
- [ ] Меняющиеся числа не дёргают строку HUD.
- [ ] У каждого экрана описаны загрузка, пустота и ошибка.
- [ ] Возможность, которой нет на площадке, не нарисована вовсе.
- [ ] Ни `alert`/`confirm`, ни эмодзи вместо иконок, ни `z-index` мимо токенов.
- [ ] Самая длинная переведённая строка помещается в кнопку.
- [ ] За меню видна живая сцена игры, а не заливка цветом.
- [ ] Ни одного эмодзи в подписи кнопки: иконка — инлайновый SVG с `currentColor`.
- [ ] У каждого экрана расписаны три зоны, а не «карточка по центру».
- [ ] С закрытым игровым полем меню всё ещё узнаётся как «Тени Фестиваля: Клинок и Эшелон».
