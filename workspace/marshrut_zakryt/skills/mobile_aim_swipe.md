# Skill: Мобильный прицел и выбор улицы

## Purpose
Сделать сенсорное управление точным без стандартной схемы с джойстиком и кнопками.

## When to Use
При подключении мобильного ввода, адаптивного HUD и тестировании коротких сессий.

## Core Rules & Constraints
- Перетаскивание управляет прицелом.
- Удержание цели управляет очередью.
- Свайп распознаётся только в контексте открытого перекрёстка.

## System Architecture
Единый слой Pointer Events преобразует жесты в команды прицела, очереди и выбора маршрута.

## Implementation Guidance
Разделять жест по длительности, расстоянию и текущему состоянию перекрёстка; не использовать двойное касание для атаки.

## Common Mistakes to Avoid
- ❌ **Mistake**: Создавать отдельную кнопку атаки.
- ❌ **Mistake**: Распознавать любой горизонтальный жест как поворот.
- ❌ **Mistake**: Размещать элементы под системными вырезами.

## Validation Checklist
- [ ] Ввод работает в Safari и мобильном Chrome.
- [ ] Свайп вне перекрёстка не меняет путь.
- [ ] Удержание цели не блокирует визуальные указатели.
