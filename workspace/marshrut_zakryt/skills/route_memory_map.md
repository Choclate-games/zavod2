# Skill: Память улиц и динамическое перекрытие

## Purpose
Реализовать измерение привычного маршрута и честное изменение графа улиц.

## When to Use
После создания графа уровня и перед балансировкой переходов между волнами.

## Core Rules & Constraints
- Перекрытие определяется поведением игрока, а не случайным выбором.
- Минимум два прохода всегда остаются доступными.
- Причина закрытия должна быть видна в сцене и интерфейсе.

## System Architecture
Счётчики сегментов обновляются во время волны, контроллер волны выбирает сегмент, а навигация получает новое состояние графа.

## Implementation Guidance
Использовать взвешенный журнал времени на сегментах, исключения для терминалов и проверку связности перед закрытием.

## Common Mistakes to Avoid
- ❌ **Mistake**: Закрывать единственный путь к терминалу.
- ❌ **Mistake**: Сбрасывать память между волнами.
- ❌ **Mistake**: Скрывать алгоритм от игрока.

## Validation Checklist
- [ ] Повторение пути повышает его вес.
- [ ] При равенстве используется детерминированное правило.
- [ ] После закрытия сохраняются два маршрута.
