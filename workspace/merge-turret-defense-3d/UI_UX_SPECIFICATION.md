# UI/UX Specification: Слияние Турелей 3D: Оборона Базы

## 1. HUD Overlay Elements
- Верхняя панель: Прогресс-бар текущей волны (Wave Progress) и HP базы
- Правый верхний угол: Баланс золотых монет и кристаллов
- Центральный разделитель: Кнопка режима «Безумие (2x)» и таймер дропа ящика
- Нижняя панель (Сетка 4x4): 16 ячеек с турелями и таймерами готовности
- Нижняя строка действий: Кнопка «Купить Турель» с динамической ценой, кнопка «Магазин Апгрейдов» и иконка «Корзина»

## 3. Screen Catalog
### Screen: Maingamescreen
- Основной сплит-экран: верх — 3D изометрическая битва, низ — сетка слияния 4х4.
### Screen: Upgradeshopmodal
- Всплывающая снизу шторка для покупки постоянных улучшений урона, крита и дохода.
### Screen: Newtierunlockedmodal
- Праздничный экран поздравления с 3D демонстрацией открытой новой турели и характеристиками.
### Screen: Offlineearningsmodal
- Окно подсчета заработанных за оффлайн монет с кнопкой удвоения за рекламу.
### Screen: Defeatrevivemodal
- Окно поражения с 5-секундным таймером для использования кнопки «Воскреснуть со щитом».
