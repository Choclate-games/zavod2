# Skill: Синхронизация Прогресса Playgama Bridge

## Purpose
Бесшовное сохранение состояния сетки слияния, баланса валюты и таймстампов в облако Яндекс Игр / Playgama.

## When to Use
При завершении волны, покупке улучшений, слиянии новых тиров и закрытии игры.

## Core Rules & Constraints
- Синхронизировать данные с задержкой (Debounce 2 секунды) во избежание превышения лимитов API платформы
- Дублировать каждое сохранение в localStorage как локальный фолбэк

## System Architecture
SaveManager сериализует состояние в JSON и передает в bridge.storage.set(). При старте выполняет bridge.storage.get() с миграцией версий схем.

## Implementation Guidance
Хранить состояние сетки в виде компактного массива идентификаторов уровней: [1, 1, 2, 0, 0, 3, ...].

## Common Mistakes to Avoid
- ❌ **Mistake**: Отправка запроса на сохранение после каждого одиночного выстрела или мелкого слияния
- ❌ **Mistake**: Отсутствие обработки оффлайн-режима при потере интернет-соединения

## Validation Checklist
- [ ] Прогресс сохраняется в облако
- [ ] Оффлайн доход корректно восстанавливается
- [ ] Ошибки сети перехватываются без краша игры
