# QA & Testing Plan: Ночной Спринт: Трафик и Закись

## 1. Functional Test Matrix
- [ ] Проверка инициализации и корректной калибровки Raycast-лучей всех 4 колес при старте сцены
- [ ] Проверка срабатывания детектора Near Miss на дистанции строго 0.1–1.2 метра от коллайдеров трафика
- [ ] Проверка расхода и пополнения шкалы нитро (не уходит в отрицательные значения, не превышает 1.0)
- [ ] Проверка добавления +25 секунд к таймеру при пересечении коллайдера-триггера Чекпоинта
- [ ] Проверка корректной отправки рекорда времени заезда в Playgama/Yandex Leaderboards после победы
- [ ] Проверка механики Revive после просмотра Rewarded Video (восстановление машины на трассе без застреваний)

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS на средних мобильных устройствах (Snapdragon 680 / Helio G88) на протяжении всего 90-секундного заезда
- [ ] Количество Draw Calls в кадре не превышает 75 при максимальной плотности трафика и эффектах нитро
- [ ] Количество полигонов в кадре не превышает 42,000 треугольников
- [ ] Общий размер стартового бандла (JS + Wasm + Audio + Textures) не превышает 4.2 МБ (Gzip < 1.8 МБ)

## 3. Target Browser Matrix
- Chrome / Chromium 115+ (Desktop & Android) — полная поддержка WebGL 2.0 и Web Audio
- Safari 15.4+ (iOS 15+) — корректная обработка аудио-разблокировки по первому тапу и Pointer Events
- Yandex Browser (Desktop & Mobile) — бесшовная интеграция Playgama Bridge SDK и полноэкранного режима
- Firefox 115+ (Desktop) — проверка сглаживания и шейдеров PBR отражений
