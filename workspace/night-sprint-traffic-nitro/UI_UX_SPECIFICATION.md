# UI/UX Specification: Ночной Спринт: Трафик и Закись

## 1. HUD Overlay Elements
- Центральный цифровой спидометр (0–300 км/ч) с индикатором текущей передачи (1-6)
- Дуговая светящаяся шкала баллона закиси азота (NITRO GAUGE) с индикатором готовности буста
- Таймер обратного отсчета до чекпоинта (крупные контрастные цифры с пульсацией при < 5 сек)
- Мини-индикатор прогресса по трассе (полоса с иконкой спорткара и отметками Чекпоинт 1, Чекпоинт 2, Финиш)
- Счетчик Комбо-Адреналина (x1 ... x8) со всплывающими плашками очков трюков ('NEAR MISS +250', 'ONCOMING x2', 'SLIPSTREAM')
- Кнопка паузы в верхнем правом углу экрана
