# Skill: Three.js + Rapier3D Raycast Vehicle Controller

## Purpose
Руководство по созданию высокопроизводительного Raycast-контроллера автомобиля с честной подвеской, сносом шин и кренами кузова в WebGL

## When to Use
При разработке 3D-гонок, требующих стабильных 60 FPS, ощущения массы автомобиля и точной физики сцепления без тяжелых составных Rigidbody.

## Core Rules & Constraints
- Использовать единый динамический RigidBody для корпуса шасси и 4 математических Raycast-луча для колес
- Рассчитывать силы подвески и сцепления шин в фиксированном физическом тике (FixedUpdate 60Hz)
- Интерполировать позицию и вращение меша Three.js между физическими тиками для идеальной плавности
- Исключать создание новых объектов Vector3/Quaternion внутри цикла обновления (zero-allocation)

## System Architecture
VehicleController -> Rapier3D World -> Raycast Query -> Tire Friction Solver -> Three.js Mesh Transform Sync

## Implementation Guidance
Связывай физический кузов машины с мешем с помощью прямого копирования матрицы трансформаций. Силы подвески вычисляй по закону Гука с демпфированием.

## Common Mistakes to Avoid
- ❌ **Mistake**: Использование тяжелых составных шарниров (HingeJoint) для колес
- ❌ **Mistake**: Аллокация временных векторов в Update
- ❌ **Mistake**: Отсутствие интерполяции графики

## Validation Checklist
- [ ] Raycast лучи направлены строго вниз
- [ ] Сила пружин сбалансирована с массой шасси
- [ ] Крены кузова визуализируются корректно
- [ ] FPS стабилен на 60
