# Один дубль: Разбор сцены

> **В «Один дубль: Разбор сцены» игрок проходит съёмочный павильон от первого лица и
> останавливает шестерых саботажников. Хедшот возвращает весь текущий магазин, промах
> навсегда уменьшает его предел, а точные попадания в декорации меняют маршрут и линии
> обзора прямо во время перестрелки.**

- **Жанр**: постановочный физический FPS с разрушаемыми декорациями
- **Стек**: TypeScript strict + Vite + Three.js + Rapier3D (`@dimforge/rapier3d-compat`) + Web Audio + Playgama Bridge
- **Платформа**: Playgama Bridge / Yandex Games / браузер / мобильные устройства

---

## Запуск

```bash
npm install        # один раз
npm run dev        # dev-сервер Vite, открыть адрес из консоли
npm run build      # проверка типов + сборка в dist/
npm run preview    # локальный просмотр собранной версии
```

Проверки приёмки:

```bash
npm run check:spec # статическая часть приёмки (читает исходники)
npm run smoke      # собирает, открывает игру в Chromium, трогает ввод
```

Игра работает и без площадки: мост Playgama деградирует в локальный режим.

## Управление

| Действие | Клавиатура и мышь | Телефон |
|---|---|---|
| Ходьба | WASD / стрелки | свайп в левой половине экрана |
| Обзор и прицел | мышь (захват по клику) | свайп в правой половине |
| Выстрел | ЛКМ или Пробел | круглая кнопка «Огонь» справа внизу |
| Приближение | ПКМ (удержание) | второй палец (удержание) |
| Пауза | Esc или P | кнопка паузы сверху справа |

Перезарядки в игре нет сознательно: магазин пополняется только хедшотом,
клавиша R не используется. Прыжков и приседаний нет: все решения — монтажные.

## Правила дубля

- За 120 секунд пройти 4 павильонные точки и 3 перехода, обезвредить
  6 саботажников и дойти до отметки режиссёра минимум с одним патроном.
- Хедшот (сфера радиусом 0.22 м над плечами) мгновенно обезвреживает цель
  и заполняет магазин до текущей вместимости; корпусное попадание тратит
  2 патрона на цель.
- Промах стоит патрона и навсегда уменьшает вместимость магазина (минимум 1).
  Пустой магазин = дубль забракован.
- Выстрел в янтарный узел обрушивает фасад перехода: соседние звенья падают
  с задержкой, открывая путь и новые линии обзора.
- Саботажник, дошедший до пиростанции, активирует заряд; три заряда или
  три ранения — брак дубля.

## Структура каталогов

```text
index.html                  # точка входа Vite
public/
└── playgama-bridge-config.json   # конфиг моста, обязателен в сборке
scripts/                    # check-spec.mjs, smoke.mjs — приёмка фабрики
src/
├── main.ts                 # порядок загрузки, watchdog, game_ready
├── config/balance.ts       # числа игры из balance.yaml
├── core/                   # Game (машина состояний), GameLoop (60 Гц), EventBus
├── platform/               # PlaygamaService, StorageService (ключ best_time_ms)
├── physics/PhysicsWorld.ts # мир Rapier, контроллер персонажа, рейкасты
├── rendering/              # PavilionScene (InstancedMesh), VfxSystem (пул частиц)
├── game/                   # PlayerController, WeaponSystem, SaboteurSystem,
│                           # GateSystem (цепи), DirectorSystem (блокинг), Viewmodel
├── input/InputRouter.ts    # единственный источник ввода, две схемы
├── audio/AudioManager.ts   # процедурный синтез, один мастер-гейн
├── i18n/strings.ts         # ключи ru/en, язык с площадки
└── ui/                     # theme.css (токены), UiRoot, ScreenRouter, Hud,
                            # TouchControls, screens.ts, icons.ts (SVG)
docs/ref/                   # база знаний фабрики (fetch-knowledge)
balance.yaml                # источник всех чисел игры
DESIGN.md                   # дизайн до кода: палитра, камера, экраны, управление
ACCEPTANCE.md               # приёмка: пронумерованные проверки готовности
DEVLOG.md / CHANGELOG.md    # журнал и changelog агента
skills/                     # правила фабрики по областям
preview/                    # концепт-арт
```
