# QA & Testing Plan: Судебный Пристав: Штурм Локдауна

## 1. Functional Test Matrix
- [ ] Проверка срыва гермодверей от пинка Space/кнопки мобильного управления с корректным импульсом 450 Нс
- [ ] Проверка перехода пораженных врагов в Dynamic RigidBody Rapier3D без проваливания сквозь пол
- [ ] Проверка рикошета пуль карабина от стальных коллайдеров с увеличением урона в 1.5 раза
- [ ] Проверка окна парирования щитом (0.18 с) и корректного наложения стана 1.2 с на врага
- [ ] Проверка таймера локдауна (120 с) и перехода в DefeatScreen при истечении времени
- [ ] Проверка интеграции Playgama Bridge: сохранение прогресса, показ Rewarded Video и удвоение награды

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS на десктопном Chrome/Firefox при 15 активных рэгдоллах и взрывах бочек
- [ ] Стабильные 55–60 FPS на мобильных устройствах среднего уровня (Snapdragon 778G / Helio G99) в ландшафтном режиме
- [ ] Время первой загрузки WebGL сцены <= 3.0 секунды при холодном старте на 3G/4G соединении
- [ ] Пиковое потребление памяти вкладки браузера <= 180 МБ

## 3. Target Browser Matrix
- Google Chrome (Desktop & Android Mobile)
- Yandex Browser (Desktop & Android Mobile)
- Safari (iOS 16+ WebGL2)
