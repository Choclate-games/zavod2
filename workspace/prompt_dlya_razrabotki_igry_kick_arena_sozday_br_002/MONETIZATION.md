# Monetization Specification: Вышибала: Сброс за борт

## 1. Strategy Summary
Ненавязчивая гибридная монетизация: Rewarded Video за мгновенный возврат на арену при случайном ринг-ауте (1 раз за забег) и удвоение фишек за чистую зачистку; Interstitial в меню между завершенными контрактами с кулдауном 120 с; IAP на покупку премиальных неоновых обликов экипировки и отключение межстраничной рекламы.

## 2. Rewarded Video Ad Placements
### Спасение при падении за борт (`revive_ringout`)
- **Benefit**: Возврат игрока в центр арены с полным здоровьем и 2 секундами неуязвимости
- **Trigger**: Экран падения за борт или гибели игрока
- **Limit**: 1 раз за забег

### Удвоение золотых фишек (`double_chips_victory`)
- **Benefit**: Умножение всех заработанных за контракт фишек на x2
- **Trigger**: Экран победы контракта
- **Limit**: После каждого успешного контракта

### Элитное кинетическое оружие (`mystery_weapon_crate`)
- **Benefit**: Получение мощного 'Титанового молота с турбонаддувом' на финальную 4-ю волну с боссом
- **Trigger**: Перед стартом 4-й волны босса
- **Limit**: 1 раз за волну босса


## 3. Interstitial Ads Rules
- Minimum **90 seconds** interval between consecutive interstitials.
- Zero interstitials during active combat gameplay.
- Shown only on run game over or returning to Main Menu.

## 4. Optional In-App Purchases (IAP)
- **VIP Вышибала (Без рекламы)** (`no_ads_vip_pack`): Полное отключение межстраничных баннеров + Золотой неоновый скин титановых ботинок + 2,000 фишек (Tier 2 (~199 RUB / 150 YAN))
- **Мешок золотых фишек (5000)** (`chips_sack_5000`): Пакет валюты казино для мгновенной разблокировки всего арсенала оружия (Tier 1 (~99 RUB / 75 YAN))
