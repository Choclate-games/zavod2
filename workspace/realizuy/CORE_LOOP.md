# Core Loop Design: Kick Arena: Кинетический Рикошет

## 1. Чем эта петля отличается
- **Фирменный момент**: В кульминации 4-го натиска 240-килограммовый босс-джаггернаут идет на таран через всю арену. Игрок за 0.25 с заряжает спартанский фронт-кик и вбивает армейский берц в грудь набегающего 80-кг хулигана. Тело хулигана с импульсом 520 Н*с летит со скоростью 16.5 м/с, пробивает дощатый штабель поддонов с разлетом щепок, сбивает с ног двоих бандитов с битами, рикошетит точно в уязвимый затылок босса и опрокидывает бочку с горючим. В момент удара о бочку срабатывает хитстоп на 0.08 с, камера дает яростный импульсный зум с голландским углом 8°, бочка детонирует с радиусом ударной волны 4.5 м, поджигая и разбрасывая врагов по металлической сетке октагона, а из развороченной баррикады фонтаном вылетают 140 хрустящих купюр под рев экстатической толпы.
- **Отличие от жанрового шаблона**: Враги здесь — не просто мишени или препятствия, а твой главный дальнобойный боеприпас и инструмент контроля толпы. Прямой удар ногой наносит минимальный урон (20 ед.), но запуск врага-снаряда в группу противников генерирует квадратичный кинетический урон (до 250 ед.) и активирует каскадный кегельбан с экспоненциальным спавном купюр. Игрок побеждает не закликиванием кнопок, а геометрическим расчетом траекторий: 'игрок -> легкий враг -> плотная группа -> взрывоопасная бочка / хрупкая стена'.
- **Сознательно НЕ берём**: Отказ от классической Beat 'em up системы длинных кнопочных комбо-цепочек (Dial-a-Combo), губчатых полосок здоровья врагов (HP Sponges) и жестких анимационных блокировок игрока (Animation Lock). В традиционных браулерах враги выступают статичными мешками для заученных серий ударов (Light-Light-Heavy). В нашей игре каждый противник — это полноценное физическое тело с массой 75–240 кг в физическом мире Rapier3D. Главный урон наносится не микроударами кулаков, а кинетической энергией столкновения тел с окружением, геометрией рикошетов и цепными разрушениями, превращая арену в адреналиновый физический бильярд живыми телами.

## 2. Схема петли
```text
+---------------------------------------------------------------------------------------------------------+
|                                     KICK ARENA: КИНЕТИЧЕСКИЙ РИКОШЕТ                                    |
+---------------------------------------------------------------------------------------------------------+
|                                                                                                         |
|  [МАКРО-ПЕТЛЯ МАТЧА (3-5 мин)]                                                                          |
|  Вход в октагон ---> Натиски 1-3 (Эскалация) ---> Натиск 4: Босс-Джаггернаут ---> Зал Славы (Мета)     |
|        ^                                                                                 |              |
|        +------------------------- Новые типы оружия и перки кубков <--------------------+              |
|                                                                                                         |
|  [МЕЗО-ПЕТЛЯ РАУНДА-НАТИСКА (45-60 с)]                                                                  |
|  +---------------------------------------------------------------------------------------------------+  |
|  | Оценка спавна толпы ---> Кинетический контроль арены ---> Гонг победы ---> Верстак и закупка кэшем |  |
|  |        ^                                                                          |               |  |
|  |        +------------------- Следующий натиск с прокачанным билдом <---------------+               |  |
|  +---------------------------------------------------------------------------------------------------+  |
|                                                                                                         |
|  [МИКРО-ПЕТЛЯ УДАРА И КАСКАДА (1.5-3.0 с)]                                                              |
|  +---------------------------------------------------------------------------------------------------+  |
|  |  (1) ПОЗИЦИОНИРОВАНИЕ  ---> (2) СПАРТАНСКИЙ КИК  ---> (3) КИНЕТИЧЕСКИЙ  ---> (4) СБОР КЭША И      |  |
|  |      Выбор угла и линии         Удар берцем (480 Н*с)      КЕГЕЛЬБАН             ПОДБОР ОРУЖИЯ    |  |
|  |      огня по хулигану           Хитстоп 0.08 с             Сбивание толпы,       Рост комбо х4.0, |  |
|  |                                                            взрыв бочек, стены    подхват трубы    |  |
|  |            ^                                                                            |         |  |
|  |            +------------------ Смена позиции с новым оружием в руках <------------------+         |  |
|  +---------------------------------------------------------------------------------------------------+  |
+---------------------------------------------------------------------------------------------------------+
```

## 6. Кривая напряжения
Пилообразная кривая с экспоненциальным нарастанием стресса внутри каждого натиска и глубокими тактическими спадами у верстака:
- Натиск 1 (0–45 с): Низкое напряжение (20–35%). Ознакомление с физикой: 5 слабых хулиганов, свободное пространство для экспериментов с пинками.
- Пауза 1 (45–60 с): Релаксация (10%). Безопасная зона у верстака, выбор первого апгрейда импульса (+15%).
- Натиск 2 (60–110 с): Среднее напряжение (35–60%). Спавн быстрых фланкеров и вооруженных битами головорезов. Требуется активный подбор предметов.
- Пауза 2 (110–130 с): Релаксация (15%). Покупка оружия ближнего боя и бронежилета.
- Натиск 3 (130–185 с): Высокое напряжение (60–85%). Смешанная плотная толпа с тяжело бронированными громилами и метателями огня. Арена завалена опасными обломками.
- Пауза 3 (185–205 с): Релаксация (20%). Финальная закупка перед боссом: максимальный импульс пинка, арматурный молот, восстановление здоровья.
- Натиск 4 / Кульминация (205–270 с): Пиковое напряжение (85–100%). Босс-джаггернаут с непробиваемой лобовой броней. Опасность мгновенного нокаута. Победа достигается только ювелирным запуском миньонов в уязвимую спину босса.
- Финал / Зал славы (270–300 с): Катарсис (0%). Замедление времени, победный салют уличных купюр, триумфальный шопинг постоянных наград.

## 7. Формулы ядра
- `Импульс запуска тела: J_launch = J_base * (1.0 + 0.15 * Lvl_Kick) * Charge_Mult, где J_base = 350 Н*с, Lvl_Kick [0..5] (уровень прокачки на верстаке), Charge_Mult = 1.0 (быстрый тычок) или 1.45 (зарядка 0.25 с). Диапазон импульса: 350.0–648.4 Н*с.`
- `Начальная скорость полета рэгдолла: V_0 = J_launch / M_victim, где M_victim = 75 кг (легкий хулиган) -> V_0 = 4.67–8.65 м/с; M_victim = 140 кг (тяжеловес) -> V_0 = 2.50–4.63 м/с.`
- `Кинетический урон первичного удара о препятствие/врага: Dmg_impact = Dmg_base + K_kinetic * 0.5 * M_flying * (V_impact)^2, где Dmg_base = 20 ед., K_kinetic = 0.035 Дж^-1. При скорости V_impact = 12.0 м/с и массе 80 кг: Dmg_impact = 20 + 0.035 * 0.5 * 80 * 144 = 20 + 201.6 = 221.6 ед.`
- `Каскадный урон по цепи рикошетов: Dmg_chain(i) = Dmg_impact * (Decay_Factor ^ i), где Decay_Factor = 0.65 (базовый) или 0.85 (при прокачке кегельбана), i — порядковый индекс сбитого врага (i=0: 100%, i=1: 65%, i=2: 42.25%).`
- `Дроп уличных наличных за комбо-уничтожение: Cash_drop = Base_Bounty * (1.0 + Combo_Tier * 0.3) * (1 + Destroyed_Props_Count * 0.5), где Base_Bounty = $25 за рядового бандита, Combo_Tier [1..5], Destroyed_Props_Count — количество разбитых объектов окружения в рамках одного кинетического импульса.`
- `Порог разрушения конструкций и генерации осколков: F_impact = (M_flying * Delta_V) / Delta_t. При F_impact >= 1200 Н деревянный штабель поддонов разрушается, поглощая 30% импульса снаряда и разбрасывая 4 поражающих деревянных бруса с уроном по 18 ед. и импульсом 90 Н*с.`
