# QA & Testing Plan: Kick Arena: Кинетический Рикошет

## 1. Functional Test Matrix
- [ ] Проверка корректной передачи кинетического импульса от пинка игрока телу врага (скорость отлета не менее 25 м/с при базовой силе)
- [ ] Проверка срабатывания цепных столкновений: летящий рэгдолл наносит урон и сбивает с ног других мобов на своем пути
- [ ] Проверка процедурного разрушения ящиков и столов при контакте с телом или оружием с достаточным импульсом
- [ ] Проверка работы верстака: списание наличных, корректное увеличение характеристик (сила пинка, HP, урон)
- [ ] Проверка переключения управления между клавиатурой/мышью на десктопе и тач-управлением на смартфонах
- [ ] Проверка возрождения за Rewarded Video: корректный сброс кулдауна, восстановление HP и отталкивающая волна

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS на ПК в Chrome/Edge/Firefox при 25 одновременно активных мобах и 10 разрушаемых пропсах
- [ ] Не менее 55-60 FPS на мобильных устройствах среднего уровня (Snapdragon 778G / Helio G99 / iPhone 11) в WebGL
- [ ] Время инициализации и полной загрузки 3D сцены не превышает 2.5 секунд на 4G соединении
- [ ] Размер исходного JS/WASM бандла с Three.js и Rapier3D не превышает 4.5 МБ

## 3. Target Browser Matrix
- Desktop Chrome / Edge (Windows, macOS, Linux)
- Desktop Firefox / Safari (macOS)
- Mobile Safari (iOS 15+)
- Mobile Chrome / Yandex Browser (Android 10+)
