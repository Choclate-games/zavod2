# UI/UX Specification: Kick Arena: Кинетический Рикошет

## 1. Материал интерфейса
Интерфейс живёт в том же мире, что и сцена. Проверка: если закрыть игровое поле,
меню обязано выдавать именно эту игру, а не любую другую.

- **Тема от арт-директора**: Кибер-Гранж: темные полупрозрачные плашки с неоновой окантовкой, агрессивный скошенный шрифт и динамические плавающие индикаторы урона и комбо
- **Визуальный язык**: Индустриально-неоновый киберпанк: скошенные плашки под углом 45 градусов, неоновые обводки толщиной 2px, светящиеся шрифты, динамические шейки плашек урона.
- **Типографика**: Заголовки: 'Russo One' / 'Teko' (рубленый, агрессивный, 700 weight); Интерфейс и цифры: 'Roboto Mono' / 'Montserrat' (высокая читаемость при динамике).

## 2. Акценты: один цвет — один смысл
Разный цвет у каждой кнопки «чтобы отличались» — главная ошибка игрового
интерфейса. На одном экране одновременно видно не больше двух акцентов.

| Токен | Единственный смысл |
|---|---|
| `action_primary` | #ff6b00 (Неоново-оранжевый: кнопки атаки, пинки, индикаторы взрыва) |
| `currency_gold` | #ffd700 (Золотистый: выбитые наличные, множители комбо, кубки) |
| `danger_critical` | #ff2a44 (Ярко-красный: здоровье босса, тяжелые атаки врагов, низкое HP) |
| `system_success` | #00f0ff (Неоново-бирюзовый: подбираемое оружие, верстак, победные экраны) |

Все значения — токенами в `src/ui/theme.css`: цвета, гарнитуры, шкала отступов,
радиусы, длительности, порядок слоёв `--z-*`. Литерал цвета внутри экрана — баг.

## 3. Композиция экрана
Меню и экраны между сессиями лежат ПОВЕРХ живой игровой сцены — той же, что в
игре, только с медленной камерой. Непрозрачная заливка на весь экран запрещена:
подложка только под текстом и кнопками.

- **Сцена за меню**: Камера плавно облетает бойца, разминающего кулаки в центре освещенного октагона; на заднем плане искрят провода и виден силуэт финального босса за решеткой

Экран — не колонка кнопок по центру. Три зоны, и каждый элемент лежит ровно в одной:

1. **Идентичность** — что это за экран: заголовок, режим, состояние игрока.
2. **Главное действие** — ровно одно на экран, самое крупное и единственное с
   основным акцентом.
3. **Второстепенный ряд** — всё остальное, одним рядом или сеткой, одним весом.

Зоны нажатия: основная ≥ 96 px, остальные ≥ 64 px, зазор ≥ 12 px, отступы через
`env(safe-area-inset-*)` плюс измеренная высота липкого баннера. Ни один экран не
скроллит страницу: длинный список скроллится во внутреннем контейнере.

## 4. Набор компонентов (закрытый)
Всё на экране — один из этих компонентов. Одноразовый `<div>` с инлайновыми
стилями — это то, из-за чего второй экран перестаёт совпадать с первым.

- KickButton
- JoystickZone
- HealthBar
- CashCounter
- WorkbenchCard
- ComboBanner

Каждый интерактивный компонент несёт пять состояний: покой, наведение, нажатие,
недоступность, `:focus-visible`; асинхронное действие — ещё и `loading`.

## 5. HUD
Не больше пяти постоянных элементов на телефоне. Пять якорей, посередине экрана
не висит ничего, кроме временной обратной связи.

| Якорь | Что там |
|---|---|
| `bottom_left` | Virtual Dynamic Touch Stick |
| `bottom_right` | Combat Action Buttons (Kick, Strike, Throw, Dash) |
| `center_top` | Combo Streak Multiplier & Kinetic Alerts |
| `top_left` | HP Bar, Player Avatar, Armor Segments |
| `top_right` | Cash Earned, Wave Counter (Round X/4) |

Элементы:
- Индикатор здоровья бойца (динамическая полоска в левом верхнем углу с сегментами брони)
- Счетчик наличных текущего раунда ($)
- Индикатор комбо-рикошетов (множитель х2, х3, KINETIC STRIKE!)
- Счетчик оставшихся противников в натиске (х/20)
- Иконка текущего оружия в руках и полоска его прочности
- Плавающий виртуальный джойстик перемещения (на мобильных устройствах слева)
- Контекстная боевая кнопка (атака/пинок/бросок) справа

Меняющиеся числа — `tabular-nums` в слоте фиксированной ширины, полосы —
`transform: scaleX()`, а не `width`. Текст поверх геймплея всегда с подложкой или
обводкой: белое число исчезает на светлой сцене.

## 6. Состояние, показанное миром, а не оверлеем
- Искрящий распределительный щиток на стене арены, служащий ловушкой под напряжением при ударе об него врагом
- Оружейный верстак, физически открывающийся в центре арены между натисками
- Ржавые подвешенные бочки, раскачивающиеся от ударов и падающие на арену

## 7. Каталог экранов
### Экран: Main Menu
- **Что на экране**: Экран старта с кнопкой 'В ОКТАГОН', выбором скинов и таблицей лидеров
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: HUD Overlay
- **Что на экране**: Минималистичный игровой интерфейс поверх 3D сцены во время боя
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: Workbench Screen
- **Что на экране**: Интерфейс верстака между раундами: 4 ветки апгрейдов и покупка оружия за наличные
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: Pause Modal
- **Что на экране**: Окно паузы с настройками звука, управлением и кнопкой выхода
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: Victory / Defeat Screen
- **Что на экране**: Финальный экран матча: заработанные кубки, статистика рикошетов, кнопка удвоения награды и реванша
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

**Переходы**: Splash/Loading -> Main Menu -> Match Start -> Wave Combat -> Round Clear -> Workbench Upgrade -> Next Wave (x4) -> Boss Battle -> Victory/Defeat -> Main Menu

## 9. Отклик и движение
- При успешном пинке: звук глухого сокрушительного удара 'БАМ', хитстоп 0.08с, вспышка оранжевого кольца, отлет врага с дымным шлейфом
- При столкновении тел: звук костяного хруста и треска дерева, каскад искр, появление текста 'RICOCHET x2!'
- При покупке на верстаке: звук звона наковальни и снопа искр, мгновенное визуальное изменение ботинок/перчаток бойца

Переход один на всю игру и укладывается в 300 мс; анимируются только `transform`
и `opacity`; `prefers-reduced-motion: reduce` убирает трансформации.

## 11. Чек-лист приёмки интерфейса
- [ ] Ни одного литерала цвета, шрифта, радиуса или длительности вне `theme.css`.
- [ ] Слои над канвасом не перехватывают игровой ввод: контейнеры `pointer-events: none`.
- [ ] Каждый экран помещается в измеренный вьюпорт, страница не скроллится.
- [ ] Одно главное действие на экран, не больше двух акцентов одновременно.
- [ ] Меняющиеся числа не дёргают строку HUD.
- [ ] У каждого экрана описаны загрузка, пустота и ошибка.
- [ ] Возможность, которой нет на площадке, не нарисована вовсе.
- [ ] Ни `alert`/`confirm`, ни эмодзи вместо иконок, ни `z-index` мимо токенов.
- [ ] Самая длинная переведённая строка помещается в кнопку.
- [ ] За меню видна живая сцена игры, а не заливка цветом.
- [ ] Ни одного эмодзи в подписи кнопки: иконка — инлайновый SVG с `currentColor`.
- [ ] У каждого экрана расписаны три зоны, а не «карточка по центру».
- [ ] С закрытым игровым полем меню всё ещё узнаётся как «Kick Arena: Кинетический Рикошет».
