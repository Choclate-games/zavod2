# Skill: Процедурное Разрушение и Пул Обломков

## Purpose
Эффективное разрушение ящиков, бочек и мебели на 3D арене без падения производительности.

## When to Use
При создании интерактивного разрушаемого окружения в браузерных 3D играх.

## Core Rules & Constraints
- Не более 6 обломков на 1 разрушаемый объект
- Все обломки управляются через централизованный Object Pool с нулевым GC (Garbage Collection)

## System Architecture
Разбиение меша объекта на 4-6 заранее запеченных осколков в пуле, активируемых с приданием импульса при превышении предела прочности.

## Implementation Guidance
Хранить в пуле готовые группы мешей обломков. При ударе скрывать целый меш ящика, активировать группу осколков на его месте и прикладывать радиальный импульс от точки удара.

## Common Mistakes to Avoid
- ❌ **Mistake**: Динамическое триангулирование и нарезка геометрии в рантайме (вызывает микрофризы в WebGL)
- ❌ **Mistake**: Оставление сотен активных физических осколков на сцене, просаживающих FPS

## Validation Checklist
- [ ] Обломки спавнятся из пула без аллокаций памяти во время боя
- [ ] Коллайдеры осколков используют упрощенные Convex Hull или Box геометрии
- [ ] Включено авто-скрытие осколков через 3 секунды с плавным погружением под пол
