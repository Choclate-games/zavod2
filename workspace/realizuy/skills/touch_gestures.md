# Skill: Жестовый Боевой Ввод для Мобильного WebGL

## Purpose
Обеспечение идеальной эргономики управления и мгновенного распознавания пинков/ударов на сенсорных экранах.

## When to Use
При адаптации 3D экшенов и браулеров под мобильные браузеры и платформу Яндекс Игр.

## Core Rules & Constraints
- Плавающий джойстик спавнится в точке первого касания в левой зоне экрана
- Свайп вперед по кнопке атаки инициирует спартанский пинок, одиночный тап — комбо ударов

## System Architecture
Слушатель touchstart/touchmove/touchend с анализом вектора дельты и времени касания для дифференциации тапа, холда и резкого свайпа.

## Implementation Guidance
Свайп детектируется при скорости перемещения пальца более 800 px/s на дистанцию более 40 px за время менее 150 мс.

## Common Mistakes to Avoid
- ❌ **Mistake**: Использование мышиных событий вместо Pointer/Touch Events
- ❌ **Mistake**: Отсутствие компенсации безопасных зон (Safe Area Insets) на экранах с вырезами

## Validation Checklist
- [ ] Использован touch.identifier для предотвращения сброса ввода при касании вторым пальцем
- [ ] Установлен CSS touch-action: none на игровом canvas
- [ ] Радиус мертвого пространства (deadzone) стика настроен на 12–15 пикселей
