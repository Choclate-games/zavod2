# QA & Testing Plan: Рикошет Снайпер 3D: Замедленный Выстрел

## 1. Functional Test Matrix
- [ ] Проверка корректности отражения лазера от плоских и наклонных поверхностей (угол падения строго равен углу отражения)
- [ ] Проверка непрерывности детекции столкновений (CCD): скоростная пуля ни при каких условиях не должна пролетать сквозь тонкие стены
- [ ] Проверка телепортации пули через порталы с сохранением скорости и правильным углом выхода
- [ ] Проверка работы мгновенного рестарта [R]: состояние уровня, физика и счетчик патронов сбрасываются мгновенно без утечек памяти
- [ ] Проверка корректности начисления звезд (1-3) в зависимости от числа выстрелов на всех 20 уровнях

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS на средних смартфонах (уровня Mali-G52 / Adreno 610)
- [ ] Количество Draw Calls в сцене не превышает 50 на самых насыщенных уровнях
- [ ] Время загрузки ассетов первого уровня не превышает 1.5 секунды на 4G-соединении
- [ ] Потребление оперативной памяти вкладки браузера не более 120 МБ

## 3. Target Browser Matrix
- Chrome Desktop & Mobile (Android)
- Safari Desktop & Mobile (iOS 15+)
- Yandex Browser (Desktop & Mobile)
- VK App In-App WebView (Android/iOS)
