# Skill: Математика векторных рикошетов и порталов

## Purpose
Обеспечение математической точности расчета векторов отражения и преобразования координат при прохождении сквозь порталы.

## When to Use
При реализации лазерного предикшна и физического отражения пули в Three.js.

## Core Rules & Constraints
- Формула отражения: R = V - 2.0 * dot(V, N) * N, где N — нормализованный вектор нормали поверхности
- Смещение точки старта следующего луча на EPSILON = 0.001 вдоль нормали для исключения самоколлизий
- Матричное преобразование направления при выходе из портала: V_out = RotationMatrix_Portal * V_in

## System Architecture
Статический чистый математический модуль без сторонних зависимостей для максимальной скорости выполнения.

## Implementation Guidance
Использовать переиспользуемые экземпляры THREE.Vector3 для предотвращения сборки мусора (GC) в цикле анимации.

## Common Mistakes to Avoid
- ❌ **Mistake**: Забывание нормализации вектора нормали N
- ❌ **Mistake**: Отсутствие эпсилон-смещения, приводящее к застреванию луча в точке контакта

## Validation Checklist
- [ ] Проверен угол отражения от наклонных поверхностей под 45 градусов
- [ ] Проверена работа порталов под произвольными углами входа
- [ ] Отсутствуют аллокации new Vector3 в update-цикле
