# QA & Testing Plan: Лесной Рейс: Доставка на Лесопилку 3D

## 1. Functional Test Matrix
- [ ] Проверка корректности начисления монет при разном проценте доставленного груза (0%, 50%, 100%)
- [ ] Тестирование коллизий: брёвна не должны проваливаться сквозь дно или стенки кузова при резком ускорении
- [ ] Проверка работы Rewarded видео на удвоение монет и возврат груза через мок-адаптер Playgama
- [ ] Проверка сохранения прогресса и купленных улучшений при перезагрузке страницы

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS на ПК в разрешении Full HD
- [ ] Не менее 50-60 FPS на мобильных устройствах среднего уровня (уровня Snapdragon 680 / Apple A12)
- [ ] Время первичной загрузки страницы не более 2.5 секунд при 4G соединении

## 3. Target Browser Matrix
- Google Chrome (Desktop & Android)
- Safari (iOS 15+ / macOS)
- Yandex Browser (Desktop & Mobile)
- Mozilla Firefox & Microsoft Edge
