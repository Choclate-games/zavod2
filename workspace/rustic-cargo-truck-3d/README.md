# Лесной Рейс: Доставка на Лесопилку 3D

> **Заведи старый добрый грузовик и доставь брёвна, топливные бочки, стройматериалы, сено и спецгрузы сквозь бездорожье, топи и броды! Покупай новые грузовики (ЗиЛ-130, ГАЗ-66, КрАЗ-255, Урал-4320), прокачивай мотор, шины, подвеску и борта кузова в Гараже и выдержи 50 сложнейших маршрутов.**

---

## Обзор
- **Жанр**: физический 3D-симулятор доставки по бездорожью с прокачкой и автопарком.
- **Автопарк**: 4 грузовика (4х2, 4х4, 6х6 тягачи) с уникальными характеристиками и тюнингом.
- **Грузы**: 7 видов физических грузов (брёвна, бочки ГСМ, бетонные блоки, трубы, тюки сена, спецконтейнеры, ящики).
- **Стек**: TypeScript, Vite, Three.js и Rapier3D.
- **Платформа**: Web, мобильные браузеры (iOS / Android) и Playgama Bridge с офлайн-fallback.
- **Ориентация экрана**: **2 режима** — альбомный (Landscape) и портретный (Portrait) с адаптивным рендером и UI.

---

## Запуск
```bash
npm install
npm run dev
```

Для production-проверки:
```bash
npm run build
npm run preview
```

Открой адрес Vite в браузере. Для проверки мобильной раскладки мышью на ПК добавь `?touch=1`; `?touch=0` принудительно отключает её.

## Управление

### 💻 Клавиатура (Десктоп)
- `W` / `↑` — Газ / Движение вперёд
- `S` / `↓` — Тормоз / Реверс (задний ход)
- `A` / `←` и `D` / `→` — Руль (влево / вправо)
- `Space` — Ручной тормоз
- `R` — Быстрый сброс / переворот машины на колёса
- `P` / `Esc` — Пауза

### 📱 Мобильный экран (Тачскрин — Портрет и Альбом)
- **Управление одним виртуальным джойстиком**:
  - Касание в любой точке экрана активирует стильный светящийся джойстик под пальцем.
  - **Свайп вверх (▲)** — Газ / Тяга вперёд.
  - **Свайп вниз (▼)** — Тормоз / Задний ход.
  - **Свайп влево (◀) / вправо (▶)** — Поворот руля.
  - Мягкая мёртвая зона (6%) и плавная кривая для точного объезда препятствий.
- **Управление звуком**: кнопка `🔊`/`🔇` доступна прямо в верхнем углу HUD, в меню и в паузе.
- **Чистый экран**: все громоздкие кнопки и педали убраны, освобождая максимум обзора дороги.
- **Safe Area**: интерфейс автоматически адаптируется под вырезы камер и системные панели.

## Структура каталогов
```text
workspace/rustic-cargo-truck-3d/
├── index.html                       # HTML-точка входа
├── src/main.ts                      # Boot guards, Bridge и запуск Game
├── src/core/                        # Game, fixed-step loop, EventBus и типы
├── src/world/                       # 50 уровней, процедурная трасса, деревня и лесопилка
├── src/rendering/                   # Three.js сцена, адаптивная камера (портрет/альбом), свет и материалы
├── src/physics/                     # Rapier3D world, Vehicle Controller и коллайдеры
├── src/vehicle/                     # TruckController, автопарк, тюнинг и CargoManager
├── src/input/                       # Keyboard + Pointer Events TouchControls (джойстик + педали)
├── src/ui/                          # Адаптивный UIManager (HUD, Меню, Гараж, Уровни, Пауза, Итоги)
├── src/audio/                       # Web Audio мотор, звуки ударов, финиша и переключатель звука
├── src/platform/                    # Playgama Bridge и сохранение
├── src/styles.css                   # Адаптивные стили для портретного и альбомного режимов
├── skills/                          # Обязательные инструкции домена проекта
├── DEVLOG.md                        # Журнал рабочих сессий
└── CHANGELOG.md                     # Изменения глазами игрока
```

---

## Разработка
1. Изменения игровой логики находятся в `src/`, а документация спецификации остаётся в корне.
2. После изменения исходников запускай `npm run build`.
3. Каждая рабочая сессия фиксируется в `DEVLOG.md` и `CHANGELOG.md`.
