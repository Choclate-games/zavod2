# Skill: Procedural Bumpy Road Spline Generator

## Purpose
Генерация сглаженной 3D-дороги с естественными ухабами, кочками и придорожными декорациями.

## When to Use
При создании бесконечных или сегментных трасс для гонок и симуляторов вождения на Three.js.

## Core Rules & Constraints
- Формировать сплайн через CatmullRomCurve3 с равномерным шагом точек
- Модулировать высоту через 2D Simplex Noise с контролем максимальной амплитуды
- Переиспользовать буферы геометрии для предотвращения сборок мусора (GC spikes)

## System Architecture
Модуль RoadGenerator создает сплайн, вычисляет нормали/бинормали (Frenet frames) и генерирует BufferGeometry дороги и коллидера.

## Implementation Guidance
Для физики дороги создавать Rapier Trimesh коллидер на основе вершин сгенерированной BufferGeometry.

## Common Mistakes to Avoid
- ❌ **Mistake**: Слишком высокая плотность вершин меша, снижающая производительность
- ❌ **Mistake**: Резкие перепады высоты, приводящие к подбрасыванию машины в космос

## Validation Checklist
- [ ] Сплайн генерируется без самопересечений
- [ ] Коллидер дороги совпадает с визуальной поверхностью
- [ ] Деревья и декорации не спавнятся прямо посреди проезжей части
