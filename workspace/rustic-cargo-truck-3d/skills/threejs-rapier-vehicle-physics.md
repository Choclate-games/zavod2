# Skill: Three.js & Rapier3D Vehicle and Cargo Controller

## Purpose
Обеспечить стабильную симуляцию физики грузовика с динамической подвеской и коллизиями груза в веб-среде.

## When to Use
При реализации физического контроллера автомобиля, взаимодействия колес с неровным грунтом и симуляции предметов в кузове.

## Core Rules & Constraints
- Всегда использовать фиксированный шаг физики (fixed timestep 1/60s)
- Применять CCD для быстро движущихся физических тел груза
- Не изменять позицию Three.js мешей напрямую, синхронизировать их строго с RigidBody.translation() и rotation()

## System Architecture
TruckController связывает ввод пользователя с Rapier Raycast/RigidBody колес, передавая смещения в визуальную иерархию Three.js.

## Implementation Guidance
Использовать составной составной коллидер (Compound Collider) для кузова грузовика с достаточной толщиной бортов, чтобы исключить проскальзывание бревен.

## Common Mistakes to Avoid
- ❌ **Mistake**: Использование стандартного Trimesh для динамического кузова (Trimesh в Rapier должен быть только статическим)
- ❌ **Mistake**: Отсутствие деактивации выпавших за пределы экрана брёвен

## Validation Checklist
- [ ] Проверен отклик педалей газа и тормоза
- [ ] Подвеска амортизирует кочки без бесконечной раскачки
- [ ] Груз стабильно лежит в кузове при спокойной езде
