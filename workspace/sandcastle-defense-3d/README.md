# Песочный Бастион 3D: Защита Пляжа 🏖️🏰

> **Постройте несокрушимый песчаный лабиринт на солнечном берегу! Расставляйте ракушечные пушки, поливайте наглых крабов из водяных брызгалок и не дайте чайкам и морским звездам разрушить ваш песчаный замок в трехмерном Tower Defense с умным поиском пути!**

---

## 🌟 Об игре
- **Жанр**: 3D Tower Defense / Real-Time Strategy (Лабиринтное строительство / Mazing)
- **Технологический стек**: TypeScript (strict mode), Three.js (WebGL), Vite
- **Платформа**: Playgama Bridge 2.x (Яндекс Игры, VK, Web & Mobile)
- **Ориентация**: Landscape (Альбомная)
- **Целевой FPS**: 60 FPS на ПК и мобильных браузерах

---

## 🎮 Управление

### На компьютере (Клавиатура и мышь):
- **1, 2, 3** — Выбрать башню для постройки:
  - `1` — Ракушечная Пушка (🐚 100)
  - `2` — Водная Поливалка (💦 150)
  - `3` — Песчаная Стена (🧱 20)
- **ЛКМ** — Поставить башню на выбранную клетку пляжа / Выбрать существующую башню
- **Space (Пробел)** — Запустить волну / Пауза
- **R** — Переключение скорости игры (`1x` / `2x`)
- **W, A, S, D** или **Стрелки** / **Зажатая ЛКМ** — Панорамирование камеры по пляжу
- **Колёсико мыши** — Плавный зум камеры (приближение/отдаление)
- **Esc** — Снять выделение / Закрыть меню

### На смартфоне / планшете (Тач-управление):
- **Один палец (тап)** — Выбор типа башни в нижней панели / Постройка на клетке / Просмотр радиуса и меню башни
- **Один палец (свайп)** — Плавное панорамирование камеры по пляжу
- **Два пальца (щипок / pinch)** — Плавный зум камеры
- **Радиальное меню башни** — Улучшение, продажа и просмотр характеристик прямо над выбранной постройкой

## 🏗️ Структура проекта

```text
sandcastle-defense-3d/
├── package.json               # Зависимости (three, @playgama/bridge, vite, typescript)
├── tsconfig.json              # Конфигурация TypeScript (Strict ES2022)
├── vite.config.ts             # Конфигурация Vite и чанков бандла
├── index.html                 # Разметка UI HUD, стили, модальные окна и Canvas
├── src/
│   ├── main.ts                # Инициализация, Bootstrap Playgama, запуск игры
│   ├── core/
│   │   ├── EventBus.ts        # Типизированный диспетчер событий
│   │   ├── GameLoop.ts        # 60Hz фиксированный цикл с компенсацией дельты
│   │   └── Game.ts            # Главный координатор игры и стейт-машина
│   ├── platform/
│   │   ├── BridgeService.ts   # Интеграция @playgama/bridge (Реклама, Сохранения, Аналитика)
│   │   ├── SaveService.ts     # Облачные и локальные сохранения с дебаунсом
│   │   └── Localization.ts    # Полная локализация (RU / EN)
│   ├── audio/
│   │   └── AudioManager.ts    # Процедурный Web Audio API синтезатор SFX и BGM
│   ├── game/
│   │   ├── grid/
│   │   │   └── GridManager.ts # Сетка пляжа 24x16, валидация постройки
│   │   ├── ai/
│   │   │   └── FlowFieldSolver.ts # Высокоскоростной BFS/Dijkstra поиск путей
│   │   ├── entities/
│   │   │   ├── Tower.ts       # Башни: Ракушечная пушка, Поливалка, Стена
│   │   │   ├── Enemy.ts       # Враги: Крабы, Отшельники, Звёзды, Чайки, Боссы
│   │   │   ├── Projectile.ts  # Баллистические снаряды с параболической дугой
│   │   │   └── VFXManager.ts  # Частицы песка, брызг, искр, волна Цунами
│   │   └── systems/
│   │       ├── LevelsData.ts  # Уровни кампании и конфигурация волн
│   │       ├── WaveManager.ts # Контроллер волн и спавна
│   │       ├── CombatSystem.ts# Наведение, урон, замедление, Цунами
│   │       └── UpgradeManager.ts # Древо талантов за Жемчуг
│   ├── rendering/
│   │   ├── SceneManager.ts    # Three.js сцена, изометрическая камера, солнце, океан
│   │   ├── ModelBuilder.ts    # Процедурные 3D-модели (Замок, Башни, Крабы, Чайки)
│   │   ├── GridRenderer.ts    # Отрисовка сетки, подсветка ячеек и стрелок течения
│   │   └── AdaptiveQuality.ts # Динамический оптимизатор 60 FPS под устройство
│   └── ui/
│       ├── UIManager.ts       # Управление экранами, HUD, контекстными меню
│       └── TouchControls.ts   # Подсистема жестов и тач-управления на Pointer Events
```

## 🚀 Запуск и Сборка

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки (Vite)
npm run dev

# Продакшн сборка (TypeScript + Vite)
npm run build

# Предпросмотр продакшн сборки
npm run preview
```
