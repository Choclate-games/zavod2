# UI/UX Specification: Песочный Бастион 3D: Защита Пляжа

## 1. HUD Overlay Elements
- Счетчик Ракушек (ресурс стройки) с анимацией сбора
- Счетчик Жемчуга (мета-валюта)
- Индикатор Прочности Замка (HP Bar)
- Индикатор Волны (Текущая / Всего) и полоса спавна
- Кнопка 'Старт Волны / Ускорение x2'
- Нижняя Панель Башен: Ракушечная Пушка (100), Поливалка (150), Стена (20), Продажа/Улучшение
- Кнопка Паузы и Настроек (Звук/Музыка)
