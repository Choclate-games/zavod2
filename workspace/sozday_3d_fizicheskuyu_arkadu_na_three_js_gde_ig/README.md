# Метро-Балансир: Час Пик 🚇📦

> **Удержи трехметровую стопку из пузатого телевизора, золотой рыбки в аквариуме и коробок с пиццей в несущемся вагоне метро! Компенсируй центробежные силы на виражах и толчки торможения на стрелках одним пальцем, довези груз в целости и стань легендой подземной курьерской службы.**

---

## 🚀 Запуск и сборка

1. Установка зависимостей:
   ```bash
   npm install
   ```
2. Запуск локального сервера разработки:
   ```bash
   npm run dev
   ```
3. Сборка для публикации (production build):
   ```bash
   npm run build
   ```
4. Статическая проверка спецификации:
   ```bash
   npm run check:spec
   ```
5. Дымовой тест в браузере:
   ```bash
   npm run smoke
   ```

## 🎮 Управление в игре

### На компьютере (Клавиатура и мышь):
- **Смещение опоры курьера влево / вправо**: Клавиши `A` / `D` или стрелки `←` / `→` (либо горизонтальное перемещение мыши).
- **Амортизирующий присед**: Клавиша `S` или стрелка `↓`.
- **Продольный контр-наклон корпуса**: Клавиши `W` / `S` или стрелки `↑` / `↓`.
- **Аварийный захват рукой за поручень**: Клавиша `Space` (Пробел).

### На смартфоне / планшете (Touch):
- **Смещение опоры курьера**: Горизонтальный свайп / drag пальцем в нижней половине экрана.
- **Амортизирующий присед**: Свайп вниз и удержание.
- **Продольный наклон**: Вертикальный drag в верхней половине экрана.
- **Аварийный захват**: Тап по круглой неоновой кнопке «ХВАТ» в правом нижнем углу.

## 📁 Структура исходного кода (`src/`)

```text
src/
├── main.ts                    # Инициализация платформы, запуск игры, game_ready
├── config/
│   └── BalanceConfig.ts       # Все числа и параметры из balance.yaml
├── core/
│   ├── Game.ts                # Главный координатор и машина состояний (State Machine)
│   ├── GameLoop.ts            # Фиксированный 60Гц цикл обновления
│   └── EventBus.ts            # Типизированная шина событий
├── platform/
│   ├── PlaygamaService.ts     # Интеграция с @playgama/bridge v2 (Ads, Lifecycle)
│   └── StorageService.ts      # Сохранения player_coins (Cloud + Local mirror)
├── physics/
│   ├── PhysicsWorld.ts        # Физика Rapier3D (составной обратный маятник, CCD)
│   └── MetroKinematics.ts     # Кинематика поезда (4 фазы перегона, центробежные силы)
├── entities/
│   ├── CourierEntity.ts       # Процедурный 3D персонаж курьера (позы, присед)
│   ├── CargoStackEntity.ts    # 3D стопка разнородного груза
│   └── EntityManager.ts       # Менеджер сущностей
├── systems/
│   ├── PhysicsMetroTrainSimulationSystem.ts # Координатор перегрузок поезда
│   ├── CompoundStackRagdollSolverSystem.ts  # Расчет устойчивости маятника и крена
│   ├── CargoOrderGenerationSystem.ts        # Процедурная генерация заказов
│   └── SessionLifecycleAndScoringSystem.ts  # Таймер перегона, чаевые, победа/поражение
├── rendering/
│   ├── SceneManager.ts        # Сцена Three.js, камера FOV 58°, свет 2700K/6500K, шейк
│   ├── ProceduralModels.ts    # Низкополигональные 3D модели ретро-вагона и грузов
│   ├── TunnelVisuals.ts       # Движущиеся туннельные огни и светофоры
│   └── ParticleSystem.ts      # InstancedMesh пул неоновых искр (#00F0FF)
├── ui/
│   ├── theme.css              # Токены дизайн-системы, z-index, @media брейкпоинты
│   ├── icons.ts               # Инлайновые SVG иконки с currentColor (без эмодзи)
│   ├── UiRoot.ts              # Монтирование интерфейса в DOM
│   ├── ScreenRouter.ts        # Роутер 4 экранов (MainMenu, GameplayHUD, Win, Lose)
│   ├── Hud.ts                 # HUD с 5 якорными зонами
│   ├── TouchControls.ts       # Сенсорный контроллер
│   ├── components/            # Кнопки, инклинометр, спидометр, прогресс-бар
│   └── screens/               # Экраны игры
└── audio/
    └── AudioManager.ts        # Процедурный синтезатор Web Audio
```
