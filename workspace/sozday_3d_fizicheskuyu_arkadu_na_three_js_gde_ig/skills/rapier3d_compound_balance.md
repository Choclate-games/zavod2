# Skill: Симуляция составного обратного маятника в Rapier3D

## Purpose
Настройка стабильной физики стопки разнородных тел с непрерывным пересчетом крутящего момента и точек контакта.

## When to Use
При инициализации физического мира и добавлении новых предметов в стопку.

## Core Rules & Constraints
- Всегда задавать CCD (Continuous Collision Detection) для легких и тонких предметов
- Использовать относительные кинематические координаты вагона для оптимизации расчетов
- Ограничивать максимальную силу компенсации опоры во избежание катапультирования тел

## System Architecture
PhysicsManager -> RapierWorld -> KinematicCarriagePlatform -> RigidBodyStack

## Implementation Guidance
Применять импульсы компенсации к точке опоры персонажа с коэффициентом линейной интерполяции (lerp) 0.25 для устранения высокочастотных шумов мыши/тача.

## Common Mistakes to Avoid
- ❌ **Mistake**: Прямое изменение transform.position мешей вместо физических импульсов
- ❌ **Mistake**: Слишком низкий damping, приводящий к бесконечному раскачиванию

## Validation Checklist
- [ ] Substepping настроен на 2-4 шага
- [ ] Коэффициенты трения и упругости настроены для каждого материала
- [ ] Тест на резкое торможение пройден без проваливания сквозь пол
