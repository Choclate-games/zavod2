# Skill: Оптимизация ретро-сцены вагона метро в Three.js

## Purpose
Создание выразительного ретро-окружения с янтарным светом и неоновыми искрами в пределах 35 Draw Calls.

## When to Use
При рендеринге интерьера поезда, оконных отражений и туннельного окружения.

## Core Rules & Constraints
- Весь салон вагона объединять в единый статичный BufferGeometry меш с текстурным атласом
- Туннель за окнами процедурно сдвигать через UV-офсет в шейдере вместо перемещения геометрии
- Искры рельсов реализовывать через единый Points/InstancedMesh

## System Architecture
SceneRenderer -> MetroCarriageStaticMesh -> DynamicWindowTunnelShader -> ParticleSparkSystem

## Implementation Guidance
Использовать кастомный шейдер материала для окон вагона, смешивающий легкое отражение интерьера и проносящиеся текстурные полосы туннеля.

## Common Mistakes to Avoid
- ❌ **Mistake**: Создание сотен отдельных мешей для каждого поручня и плафона
- ❌ **Mistake**: Использование реальных точечных теней от всех ламп

## Validation Checklist
- [ ] Draw calls <= 35
- [ ] Геометрия вагона уложена в 1 меш
- [ ] Адаптивный pixelRatio (1.0 - 1.5)
