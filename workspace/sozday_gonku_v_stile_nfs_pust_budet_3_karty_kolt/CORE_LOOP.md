# Core Loop Design: Ночной Синдикат: Дуэли и Контракты

## 1. Чем эта петля отличается
- **Фирменный момент**: Ночной спринт по хайвею: на скорости 195 км/ч на мокром асфальте игрок закладывает спорткар в поворот под 48 градусов в 0.3 метра от бетонного отбойника, искры от касания дисков осыпают асфальт, множитель риска подскакивает до x4.0, мгновенно заполнив 3-й баллон бирюзового нитро; игрок сбрасывает ручник, вдавливает кнопку форсажа — камера рывком отдаляется с расширением FOV с 60° до 85°, радиальный блюр смазывает неоновые небоскребы, и болид с ревом перегруженной турбины на 240 км/ч протискивается в 50-сантиметровый зазор между лидирующим маслкаром соперника и фурой трафика, пересекая финишную черту за 0.12 секунды до соперника под взрыв неона и фанфары репутации Синдиката!
- **Отличие от жанрового шаблона**: В отличие от стандартных аркад, где нитро восстанавливается по пассивному таймеру или подбором пикапов с трассы, в «Ночном Синдикате» нитро — это конвертируемая валюта риска и мастерства. Заряд генерируется только через два сопряженных действия: удержание предельного угла заноса (угол 35°–60° на скорости выше 90 км/ч) и экстремальное сближение с отбойниками и трафиком («Лезвие бритвы», <1.2 м). Риск катастрофичен: малейшее касание сбрасывает комбо-множитель и прерывает закись азота, но идеальный тайминг выхода из заноса с прострелом нитро катапультирует спорткар из апекса поворота быстрее любого ИИ.
- **Сознательно НЕ берём**: Отвергнут шаблон «бесцельного открытого мира с рутинными переездами между маркерами» (NFS Underground 2 / Forza Horizon) и шаблон «стерильного кольцевого симулятора с замедлением на газоне» (Gran Turismo). Причина отказа: для 3D WebGL-сессии (Playgama / Яндекс Игры) открытый мир размывает фокус, перегружает оперативную память браузера фоновыми ассетами и создает простои до 70% времени без адреналина. Вместо этого выбрана концентрированная аркадная структура сессий по 60–90 секунд на 3 характерных трассах (Downtown Loop, Neon Highway, Port Docks), где 100% времени игрок находится в состоянии плотной дуэли, непрерывного управляемого дрифта и рискованного накопления нитро без холостой езды.

## 2. Схема петли
```text
+-----------------------------------------------------------------------+
  |                   ПОДЗЕМНЫЙ ГАРАЖ СИНДИКАТА                           |
  |  [Выбор Контракта] ---> [Тюнинг: Турбина / Шины / Неон] ---> [Старт]  |
  +-----------------------------------+-----------------------------------+
                                      |
                                      v
  +=======================================================================+
  |              ГОНОЧНЫЙ ЗАЕЗД (ДЛИТЕЛЬНОСТЬ: 60-90 СЕК)                 |
  |                                                                       |
  |   +-----------------> [ ПРЯМАЯ: РАЗГОН ] <------------------------+   |
  |   |                   |  - Вход в слипстрим за ИИ                 |   |
  |   |                   |  - Достижение 180+ км/ч                   |   |
  |   |                   v                                           |   |
  |   |          [ ТОРМОЖЕНИЕ / РУЧНИК ]                              |   |
  |   |          - Срыв задней оси (Скандинавский щелчок)             |   |
  |   |          - Контрруление + балансировка газом                  |   |
  |   |                   v                                           |   |
  |   |       [ ДРИФТ В ПОВОРОТЕ: 35°-60° ]                           |   |
  |   |       +-- Близость к отбойнику (<1.0м) = Множитель x2..x4     |   |
  |   |       +-- Накопление баллонов Нитро (0 -> 100%)               |   |
  |   |                   v                                           |   |
  |   |       [ ВЫХОД ИЗ АПЕКСА + ПРОЖИГ НИТРО ]                      |   |
  |   |       - Рывок форсажа (+45 км/ч, FOV 60°->85°)                |   |
  |   |       - Контактный обгон соперника по кромке                  |   |
  |   |                   |                                           |   |
  |   +-------------------+                                           |   |
  |                                                                   |   |
  |   [ ФИНИШНАЯ ЧЕРТА (Чекпоинт 0.00 с / Топ-3 / 15 000 Drift Pts) ]  |
  +===================================+===================================+
                                      |
                                      v
  +-----------------------------------------------------------------------+
  |                    ЭКРАН НАГРАД И ПРОГРЕССИИ                          |
  |  [Кредиты Синдиката] + [Очки Репутации (Rep Tiers 1-5)]               |
  |  --> Разблокировка новых запчастей, трасс и Дуэлей с Боссами          |
  +-----------------------------------------------------------------------+
```

## 6. Кривая напряжения
Пилообразная синусоида высокой частоты с кульминацией на финише: 1. Секунды 0–10 (Старт): Резкий стартовый всплеск адреналина (80%) — борьба в узком горлышке первого поворота, риск завала; 2. Секунды 10–35 (Хайвей/Кольцо): Циклы напряжения (40% на прямых во время набора слипстрима -> 90% в апексах поворотов при удержании дрифта в 30 см от стены на множителе x4); 3. Секунды 35–65 (Средняя фаза): Плато высокой концентрации (75%) — адаптивный ИИ прессингует бампер в бампер, любая ошибка срывает комбо; 4. Секунды 65–85 (Техничная шпилька): Пик напряжения (95%) — череда двойных перекладок ручником, дефицит времени на секундомере чекпоинта; 5. Секунды 85–90 (Финишный створ): Взрывная разрядка (100% -> катарсис) — тройной прожиг нитро, финиш нос к носу с лидером, замедление времени и победный фанфарный аккорд.

## 7. Формулы ядра
- `Формула скорости накопления нитро в дрифте: dNitro/dt = BaseChargeRate * (DriftAngle / IdealAngle) * (CurrentSpeed / MaxSpeed) * RiskMultiplier, где BaseChargeRate = 25.0% в сек, IdealAngle = 45.0°, RiskMultiplier = [1.0..4.0] в зависимости от дистанции до отбойника.`
- `Формула множителя риска «Лезвие бритвы» (Razor Edge Proximity): RiskMultiplier = 1.0 + clamp((WallProximityThreshold - DistanceToObstacle) / WallProximityThreshold, 0.0, 1.0) * 3.0, где WallProximityThreshold = 1.20 м. При дистанции <= 0.35 м множитель равен ровно 4.0x.`
- `Формула начисления дрифт-очков стиля: DriftScoreTick = (CurrentSpeed_kmh * 0.50) * sin(DriftAngle_rad) * RiskMultiplier * DeltaTime_sec * (ComboStreak + 1).`
- `Формула адаптивной тяги соперников (Rubberband AI): AiTorqueModifier = 1.0 + clamp((DistanceToPlayer_m - DesiredGap_m) * 0.035, -0.25, 0.40), где DesiredGap = 15.0 м. Если бот отстает на 30 м, его крутящий момент растет на +40%, если опережает на 30 м — падает на 25%.`
- `Формула динамического латерального сцепления шин (Rapier Lateral Grip): LateralGrip = BaseGrip * (1.0 - HandbrakeInput * 0.65) * (1.0 / (1.0 + (SlipAngle / DriftTransitionAngle)^2)), где DriftTransitionAngle = 18.5°.`
- `Формула динамического ускорения при форсаже Нитро: BoostAcceleration = (EngineTorque * 1.60 / VehicleMass_kg) + (NitroThrust_N / VehicleMass_kg) * NitroTierMult, где NitroThrust = 4500 Н, NitroTierMult = [1.0..1.5].`
