# QA & Testing Plan: Ночной Синдикат: Дуэли и Контракты

## 1. Functional Test Matrix
- [ ] Тест инициализации и переключения всех 3 трасс (Downtown Loop, Neon Highway, Port Docks)
- [ ] Тест физического контроллера автомобиля: разгон, торможение, срыв в занос ручником, стабилизация
- [ ] Тест механики нитро: прирост скорости, расширение FOV камеры, списание баллона, перезарядка в дрифте
- [ ] Тест адаптивного ИИ: следование по вейпоинтам, слипстрим, коррекция раббербендинга, отсутствие застреваний
- [ ] Тест интеграции Playgama Bridge: сохранение кредитов в Cloud Storage, показ рекламы и отправка рекордов в лидерборды

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS на десктопных браузерах с разрешением 1920x1080
- [ ] Не менее 55-60 FPS на мобильных устройствах среднего уровня (Snapdragon 7xx / Apple A13)
- [ ] Количество Draw Calls в кадре не более 75 на всех 3 трассах
- [ ] Суммарный объем используемой оперативной памяти JS Heap < 180 МБ
- [ ] Время первой загрузки ассетов и старта сцены < 3.0 секунд

## 3. Target Browser Matrix
- Google Chrome (Windows, macOS, Android) - Основной целевой браузер (WebGL 2.0)
- Yandex Browser (Windows, Android) - Приоритет платформы Yandex Games
- Safari (iOS 15+, iPadOS) - Тестирование Web Audio API и Touch-событий
- Mozilla Firefox (Windows, Linux) - Проверка производительности WASM Rapier3D
