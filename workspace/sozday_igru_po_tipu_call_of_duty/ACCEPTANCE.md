# Приёмка: AC-130: Ночной Тепловизор

Готовность игры определяется этим файлом, а не ощущением. Каждый пункт — либо
команда с ожидаемым результатом, либо факт, который видно на экране. Пока хотя
бы один пункт раздела **A–C** красный, игра не готова: это не качество, это
работоспособность.

Автоматическая часть запускается одной командой:

```bash
node scripts/check-spec.mjs        # или npm run check:spec
```

Скрипт лежит в проекте и проверяет то, что проверяется статически. Остальное —
руками, по этому же списку. Результат прогона записывается в `DEVLOG.md`.

## C. Платформа Playgama

Без этого раздела игра не запускается на площадке — не «работает хуже», а не
стартует и снимается с модерации.

- [ ] **C1** · `game_ready` отправляется РОВНО ОДИН РАЗ и только после загрузки, когда меню уже интерактивно.
- [ ] **C2** · `bridge.initialize()` обёрнут таймаутом (~10 с), сторожевой таймер (~15 с) отправляет `game_ready` в любом случае.
- [ ] **C3** · Прогресс загрузки идёт от реальных вех, заставка доходит до 100% до `game_ready`.
- [ ] **C4** · Ни один шаг загрузки не ждёт решения игрока: `authorize()` в загрузке отсутствует.
- [ ] **C5** · Сохранение — один ключ (`player_credits`), один JSON, нормализация при чтении; битый сейв поднимается на умолчаниях.
- [ ] **C6** · Награда за rewarded выдаётся только по `state === 'rewarded'` (Экстренная Реанимация Спецназа), слушатель снимается через `off()`, повторный клик не платит дважды.
- [ ] **C7** · Interstitial не показывается при старте, в середине геймплея и сразу после покупки; пауза между показами соблюдена.
- [ ] **C8** · Пауза и звук приходят из событий моста (`PAUSE_STATE_CHANGED` / `AUDIO_STATE_CHANGED`), дельта времени сбрасывается при возврате.
- [ ] **C9** · Возможность, которой на площадке нет, не нарисована вовсе — не серой кнопкой и не ошибкой по нажатию. Проверяется подменой флага (leaderboard_high_score_global).
- [ ] **C10** · Покупки: `getPurchases()` при каждом запуске, сначала выдача, потом `consumePurchase(productId)`.
- [ ] **C11** · Игра проверена в фрейме площадки и гостем, и авторизованным.

## D. Геймплей

Это игра, а не движок: пункты ниже проверяются игрой руками.

- [ ] **D1** · Баллистическое жонглирование тройным калибром (Triple-Caliber Orbital Ballistics): Клавиатура: Клавиши 1, 2, 3 — мгновенный выбор калибра; Пробел / ЛКМ — стрельба; Колесо мыши — оптический зум 2x/4x/8x. Мобильный тач: Крупные боковые плашки выбора калибров '25mm', '40mm', '105mm' под правый палец; тап/удержание правой зоны экрана — ведение огня; свайп левой зоны — наведение турели.\n- [ ] **D2** · Протокол Danger Close и ИК-стробоскопы Bravo-6 (Danger Close & IR Beacon Protocol): Визуальное позиционирование прицела вдали от пульсирующего маркера союзников. Двойной клик/быстрый тап по кнопке '25mm' для мгновенного безопасного переключения при входе врагов в зону Danger Close.\n- [ ] **D3** · Физическая цепная детонация и разрушение укрытий (Physics Chain Reactions & Structural Collapse): Наведение прицела на интерактивные объекты окружения (подсвечиваются горячим термоконтуром на FLIR) и выстрел калибром 40мм или 105мм.\n- [ ] **D4** · Термодинамика FLIR и подавление живой силы (FLIR Thermal Contrast & Kinetic Suppression): Удержание кнопки/зоны огня для непрерывной очереди; отпускание гашетки для принудительного охлаждения ствольного блока. Тап по переключателю тепловых палитр 'W-HOT / B-HOT' для смены контраста в дыму.\n- [ ] **D5** · Условие успеха срабатывает: Успешная эвакуация союзного отряда спецназа (минимум 1 выживший боец достиг зоны посадки вертолета на 90-й секунде) и полная ликвидация тяжелой техники противника.\n- [ ] **D6** · Условие проигрыша срабатывает: Гибель всех 4 бойцов союзного отряда от огня противника ИЛИ дружественный огонь (попадание снаряда 105мм/40мм в радиус союзников, уничтожившее отряд) ИЛИ истечение лимита времени (100 секунд) до выхода к эвакуации.

## Как отчитываться

Прогон приёмки записывается в `DEVLOG.md` строкой вида:

```text
2026-01-01 приёмка: A1–A4 ✅, B1–B12 ✅, C1–C11 ✅, D1–D5 ✅, E1–E5 частично (E1 на телефоне 48 FPS), F1–F4 ✅, G1–G10 ✅, H1 ✅ (2 осознанных отказа)
```

Пункт, который не проходит, честнее оставить красным с объяснением, чем
отметить зелёным: следующий, кто откроет проект, будет считать его проверенным.
