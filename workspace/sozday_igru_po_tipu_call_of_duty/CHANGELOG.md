# Changelog — AC-130: Ночной Тепловизор

## [Unreleased]

### Added
- Полная игровая архитектура тактического ганшипа AC-130 на Three.js и Rapier3D.
- Монохромный FLIR-шейдер (White-Hot / Black-Hot) с CRT-сканлайнами, термо-контрастом, шумом матрицы и виньеткой.
- Орбитальная баллистика трех калибров: 25-мм GAU-12 (1800 выстр/мин с термодинамикой), 40-мм Bofors (очереди по 3) и 105-мм M102 (2.2с время подлета, радиус 18м).
- Протокол Danger Close (14.5м) и детекция дружественного огня по спецназу «Браво-6».
- ИИ дружественного отряда «Браво-6» (4 бойца с ИК-стробоскопами на 2.0 Гц, марш к зоне эвакуации).
- Трехфазный директор вражеских волн (пехота в укрытиях, скоростные технички, танки Т-72 и БТР).
- Физическая система разрушений и каскадных цепных реакций цистерн с топливом (радиус 16.5м, урон 3500) и пул осколков.
- Процедурный синтезатор Web Audio API (выстрелы, взрывы, саб-бас 45 Гц, зуммеры, радиодоклады) без MP3.
- Интеграция Playgama Bridge v2 (сохранения по ключу `player_credits`, Rewarded Ads с проверкой `state === 'rewarded'`, Interstitial Ads).
- Дизайн-система интерфейса: токены в `theme.css`, инлайновые SVG-иконки без эмодзи, экраны ScreenMainMenu, ScreenArmory, ScreenBattleHUD, ScreenVictory, ScreenDefeat.
- Поддержка мультитач-управления (Pointer Events) и клавиатуры/мыши с возможностью включения через `?touch=1`.
