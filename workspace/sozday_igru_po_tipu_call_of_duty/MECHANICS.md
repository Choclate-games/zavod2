## Механика: Баллистическое жонглирование тройным калибром (Triple-Caliber Orbital Ballistics) (CORE)
- **Категория**: Двигатель боевого темпа и основной инструмент решения огневых задач
- **Описание**: В отличие от большинства мобильных тиров с мгновенным уроном, здесь реализована честная физическая задержка орбитальной баллистики (2.2 с для 105мм), требующая мышления на 2 секунды вперед и дарящая эйфорический выброс дофамина при точном попадании.
- **Взаимодействие игрока**: Клавиатура: Клавиши 1, 2, 3 — мгновенный выбор калибра; Пробел / ЛКМ — стрельба; Колесо мыши — оптический зум 2x/4x/8x. Мобильный тач: Крупные боковые плашки выбора калибров '25mm', '40mm', '105mm' под правый палец; тап/удержание правой зоны экрана — ведение огня; свайп левой зоны — наведение турели.
- **Отклик**: Визуал/VFX: Для 25мм — сплошная трассирующая белая нить в тепловизоре с россыпью микро-вспышек на бетоне; для 40мм — пульсирующие яркие вспышки разрывов диаметром 4м; для 105мм — гигантская ослепительно белая термическая вспышка с эффектом FLIR-засветки сенсора (bloom 2.2x), огненный шар диаметром 22м и столб раскаленной пыли.; Звук (Web Audio): Приглушенный тяжелый грохот выстрела внутри фюзеляжа ганшипа с пространственной реверберацией, глухой свист рассекаемого воздуха, через 2.2 с — низкочастотный басовый удар (45 Гц sub-bass) детонации на земле и радиодоклад штурмана: 'Kaboom! Direct hit!'.; Камера (импульс/зум): Для 105мм — резкий вертикальный угловой толчок виртуальной камеры (шейк 0.35° с затуханием 0.4 с) в момент выстрела и вторичный легкий микро-шейк при детонации на земле.; UI/Тактильность: Для мобильных устройств — мощный короткий виброотклик (45 мс) при выстреле 105мм и пульсирующая вибрация (12 мс) при стрельбе из 25мм; динамическая смена прицельной сетки с отображением термошкалы нагрева ствола и таймера заряжания.
- **Техническая сложность**: Medium
- **Сильные стороны**: Высокая вовлеченность, Глубокая кривая мастерства
- **На что смотреть**: Требует точной калибровки таймингов

### Глубина механики
- **Роль в петле**: Двигатель боевого темпа и основной инструмент решения огневых задач
- **Решение игрока**: Какой калибр применить по текущему типу угрозы: мгновенно подавить пехоту 25-мм пулеметом, выдать серию 40-мм снарядов по быстрому пикапу или выпустить 105-мм гаубичный снаряд по танку/зданию с учетом 2.2-секундного упреждения и 4.5-секундного кулдауна.
- **Управление**: Клавиатура: Клавиши 1, 2, 3 — мгновенный выбор калибра; Пробел / ЛКМ — стрельба; Колесо мыши — оптический зум 2x/4x/8x. Мобильный тач: Крупные боковые плашки выбора калибров '25mm', '40mm', '105mm' под правый палец; тап/удержание правой зоны экрана — ведение огня; свайп левой зоны — наведение турели.
- **Состояния**: `CALIBER_READY: выбранный калибр заряжен, прицельная марка активна, орудие готово к открытию огня.`, `FIRING_BURST: ведется стрельба (25мм — непрерывная очередь до отпускания гашетки; 40мм — полуавтоматическая отсечка по 1-3 выстрела; 105мм — одиночный залп).`, `RELOADING_COOLDOWN: орудие на перезарядке (105мм — 4.5 с, 40мм — 1.8 с на кассету); доступно мгновенное переключение на другие калибры.`, `OVERHEAT_JAM: ствольный блок 25мм нагрелся до 100°C; принудительная блокировка огня на 3.5 с с воспроизведением аварийного зуммера.`
- **Параметры и настройка**:
  - **Скорость полета 105-мм снаряда (V_105)**: `455 м/с (время подлета с 1000м: 2.20 с)` — Если увеличить скорость выше 700 м/с, пропадет магия предвкушения попадания и расчет упреждения; если уменьшить ниже 350 м/с, попадать по движущейся технике станет невозможно без чистого везения.
  - **Радиус сплошного поражения 105-мм ОФС**: `18.0 м (Base Damage 2500 ед)` — Если сделать больше 25 м, гаубица будет зачищать весь экран в один клик и постоянно взрывать спецназ; если меньше 12 м, попадание покажется слабым и не оправдает 4.5-секундную перезарядку.
  - **Скорострельность 25-мм пулемета GAU-12**: `1800 выстр/мин (30 выстр/с, 85 ед урона/пуля)` — При занижении ниже 1200 выстр/мин пулемет теряет тактильный кайф лазерной 'пилы'; при завышении выше 2500 выстр/мин перегрев наступает мгновенно за 0.8 с.
  - **Время перезарядки 105-мм гаубицы**: `4.50 с` — Если снизить до 2.0 с, игрок перестанет использовать 40мм и 25мм; если поднять выше 6.5 с, темп игры в 90-секундной сессии провисает в мучительное ожидание.
- **Слои отклика**:
  - Визуал/VFX: Для 25мм — сплошная трассирующая белая нить в тепловизоре с россыпью микро-вспышек на бетоне; для 40мм — пульсирующие яркие вспышки разрывов диаметром 4м; для 105мм — гигантская ослепительно белая термическая вспышка с эффектом FLIR-засветки сенсора (bloom 2.2x), огненный шар диаметром 22м и столб раскаленной пыли.
  - Звук (Web Audio): Приглушенный тяжелый грохот выстрела внутри фюзеляжа ганшипа с пространственной реверберацией, глухой свист рассекаемого воздуха, через 2.2 с — низкочастотный басовый удар (45 Гц sub-bass) детонации на земле и радиодоклад штурмана: 'Kaboom! Direct hit!'.
  - Камера (импульс/зум): Для 105мм — резкий вертикальный угловой толчок виртуальной камеры (шейк 0.35° с затуханием 0.4 с) в момент выстрела и вторичный легкий микро-шейк при детонации на земле.
  - UI/Тактильность: Для мобильных устройств — мощный короткий виброотклик (45 мс) при выстреле 105мм и пульсирующая вибрация (12 мс) при стрельбе из 25мм; динамическая смена прицельной сетки с отображением термошкалы нагрева ствола и таймера заряжания.
- **Режим отказа**: Игрок стреляет 105-мм снарядом в быструю технику без упреждения — снаряд падает в пустоту позади машины, орудие уходит на 4.5-секундную перезарядку, а техничка безнаказанно подъезжает к спецназу и открывает огонь. Сигнал: радиодоклад 'Splash, no hit! Lead the target!' и маркер падения в 20 метрах за целью.
- **Кривая мастерства**: Новичок на 30-й секунде судорожно палит из 105мм по одиночным пехотинцам, перегревает 25мм пулемет и оказывается безоружным перед танком. Эксперт на 10-м забеге непрерывно жонглирует оружием: удерживает пехоту короткими отсечками 25мм (3–5 пуль), 40мм кассетами срезает пикапы на виражах с упреждением в 1.8 с, а 105мм оставляет строго для тяжелой брони и узловых зданий.
- **Сопротивление игры**: Противник выпускает скоростные пикапы 'Тойота' (скорость до 22 м/с), которые резко меняют траекторию движения на перекрестках при звуках близких разрывов, сбивая прицельное упреждение.
- **Синергии**:
  - Связь с Механикой 2 (Danger Close): выбор калибра жестко лимитируется дистанцией до отряда Bravo-6 (вблизи своих разрешен только точечный 25-мм пулемет).
  - Связь с Механикой 3 (Физическая детонация): 105-мм снаряд подрывает цистерны с топливом, создавая вторичные волны поражения без расхода боеприпасов.
- **Почему это не жанровый шаблон**: В отличие от большинства мобильных тиров с мгновенным уроном, здесь реализована честная физическая задержка орбитальной баллистики (2.2 с для 105мм), требующая мышления на 2 секунды вперед и дарящая эйфорический выброс дофамина при точном попадании.
- **Псевдокод тика**:
```text
function tickWeapons(dt, input) {
  if (input.switchCaliber) currentCaliber = input.selectedCaliber;
  if (currentCaliber.isOverheated) {
    currentCaliber.heatTimer -= dt;
    if (currentCaliber.heatTimer <= 0) currentCaliber.isOverheated = false;
    return;
  }
  if (input.firePressed && currentCaliber.cooldown <= 0) {
    currentCaliber.cooldown = currentCaliber.baseCooldown;
    currentCaliber.heat += currentCaliber.heatPerShot;
    spawnBallisticProjectile(camera.getAimRay(), currentCaliber.speed, currentCaliber.splashRadius);
    triggerRecoilCameraShake(currentCaliber.shakeIntensity);
    playWebAudioShot(currentCaliber.soundId);
  }
  currentCaliber.cooldown = Math.max(0, currentCaliber.cooldown - dt);
  currentCaliber.heat = Math.max(0, currentCaliber.heat - currentCaliber.coolingRate * dt);
}
```

## Механика: Протокол Danger Close и ИК-стробоскопы Bravo-6 (Danger Close & IR Beacon Protocol) (SECONDARY)
- **Категория**: Главный источник тактического риска, напряжения и регулятор точности стрельбы
- **Описание**: Friendly Fire в игре — это не банальный штраф по очкам, а фундаментальное пространственное ограничение физического сплеша оружия с отложенным баллистическим таймингом, создающее киношную драму 'на волоске от гибели'.
- **Взаимодействие игрока**: Визуальное позиционирование прицела вдали от пульсирующего маркера союзников. Двойной клик/быстрый тап по кнопке '25mm' для мгновенного безопасного переключения при входе врагов в зону Danger Close.
- **Отклик**: Визуал/VFX: Нашлемные стробоскопы 4 бойцов спецназа вспыхивают ярко-белым тепловым импульсом с мягким ореолом; при наведении 105мм в опасную зону на земле проецируется пульсирующий пунктирный круг Danger Close с перечеркнутым черепом.; Звук (Web Audio): Предупреждающий прерывистый сигнал зуммера (частота 880 Гц / 440 Гц 'бип-бип'), тревожные доклады в радиоэфире командира спецназа: 'Bravo-6 to Spectre, you are Danger Close, watch your splash!'.; Камера (импульс/зум): Автоматическое легкое натяжение виньетки с красным хроматическим смещением по краям экрана при попадании прицела в зону Danger Close.; UI/Тактильность: Мерцающая надпись 'DANGER CLOSE: 12.4m' в центре HUD рядом с перекрестьем прицела; частая тактильная микро-вибрация смартфона (по 20 мс каждые 150 мс) как тактильный сигнал опасности.
- **Техническая сложность**: Medium
- **Сильные стороны**: Высокая вовлеченность, Глубокая кривая мастерства
- **На что смотреть**: Требует точной калибровки таймингов

### Глубина механики
- **Роль в петле**: Главный источник тактического риска, напряжения и регулятор точности стрельбы
- **Решение игрока**: Стрелять ли тяжелым 105-мм/40-мм калибром по врагам, подошедшим вплотную к союзному спецназу, рискуя мгновенно уничтожить отряд дружественным огнем, или ювелирно вырезать врагов точечным 25-мм пулеметом за счет драгоценного времени.

- **Параметры и настройка**:
  - **Радиус запрета огня 105-мм гаубицы (Danger Radius)**: `14.5 м от ИК-маяка Bravo-6` — Если уменьшить радиус ниже 8 м, опасность дружественного огня перестает ощущаться и игрок начинает бездумно спамить 105мм по своим; если увеличить свыше 22 м, стрелять в 3-й фазе становится некуда.

  - **Здоровье одного бойца спецназа**: `150 HP (выдерживает до 4 попаданий из АК-47)` — Если дать больше 300 HP, игрок перестает защищать союзников; если дать меньше 75 HP, спецназ погибает от случайной шальной пули за 0.5 с.
  - **Скорость движения отряда Bravo-6 на марше**: `4.2 м/с (при спринте: 6.5 м/с)` — Если замедлить ниже 2.5 м/с, миссия становится затянутой и скучной; если ускорить выше 8.0 м/с, баллистические снаряды 105мм отстают от темпа группы.
- **Слои отклика**:
  - Визуал/VFX: Нашлемные стробоскопы 4 бойцов спецназа вспыхивают ярко-белым тепловым импульсом с мягким ореолом; при наведении 105мм в опасную зону на земле проецируется пульсирующий пунктирный круг Danger Close с перечеркнутым черепом.
  - Звук (Web Audio): Предупреждающий прерывистый сигнал зуммера (частота 880 Гц / 440 Гц 'бип-бип'), тревожные доклады в радиоэфире командира спецназа: 'Bravo-6 to Spectre, you are Danger Close, watch your splash!'.
  - Камера (импульс/зум): Автоматическое легкое натяжение виньетки с красным хроматическим смещением по краям экрана при попадании прицела в зону Danger Close.
  - UI/Тактильность: Мерцающая надпись 'DANGER CLOSE: 12.4m' в центре HUD рядом с перекрестьем прицела; частая тактильная микро-вибрация смартфона (по 20 мс каждые 150 мс) как тактильный сигнал опасности.
- **Режим отказа**: Игрок выпускает 105-мм снаряд в группу врагов, но спецназ успевает добежать до зоны поражения до момента приземления снаряда через 2.2 с. Сигнал: ослепительный взрыв накрывает стробоскопы, радиоканал заполняется белым шумом, экран покрывается статическими помехами с надписью 'MISSION FAILED: FRIENDLY FIRE CASUALTY'.
- **Кривая мастерства**: Новичок на 30-й секунде либо взрывает собственный отряд фугасом, либо боится стрелять тяжелым калибром и смотрит, как спецназ расстреливают враги. Мастер на 10-м забеге кладет 105-мм снаряд ровно в 15.5 метрах от головы бегущей колонны спецназа с идеальным расчетом упреждения, расчищая путь секунда-в-секунду без единой царапины союзникам.
- **Сопротивление игры**: Вражеские камикадзе-штурмовики и бронированные багги целенаправленно таранят позиции спецназа, сокращая дистанцию до 5–8 метров и вынуждая игрока отказываться от артиллерии.
- **Синергии**:

  - Связь с Механикой 1 (Калибры): мгновенное тактическое переключение на 25-мм пулемет как единственное безопасное хирургическое оружие в радиусе 10 метров.

- **Псевдокод тика**:
```text
function checkDangerClose(impactPoint, alliesList) {
  for (let ally of alliesList) {
    let dist = impactPoint.distanceTo(ally.position);
    if (dist < currentCaliber.dangerRadius) {
      hud.setWarningState(true, dist);
      audio.playDangerWarningBeep();
      if (projectileExploded) {
        ally.applyDamage(calculateSplashDamage(dist));
        if (ally.health <= 0) triggerGameOver('FRIENDLY_FIRE');
      }
      return true;
    }
  }
  hud.setWarningState(false, 0);
  return false;
}
```

## Механика: Физическая цепная детонация и разрушение укрытий (Physics Chain Reactions & Structural Collapse) (SECONDARY)
- **Категория**: Главный источник взрывного удовлетворения (награды), мультипликатор боевого счета и инструмент контроля толпы

function onExplosionImpact(epicenter, blastPower, blastRadius) {
  let nearbyPhysicsBodies = physicsWorld.querySphere(epicenter, blastRadius);
  for (let body of nearbyPhysicsBodies) {
    let dir = body.position.clone().sub(epicenter);
    let dist = dir.length();
    let forceMagnitude = blastPower / Math.max(1.0, dist * dist);
    body.applyImpulse(dir.normalize().multiplyScalar(forceMagnitude));
    if (body.isExplosive && !body.isDetonated) {
      scheduleDelayedDetonation(body, 0.25);
    }
    if (body.isDestructible) {
      body.takeStructuralDamage(blastPower * 0.8);
    }
  }
  vfx.spawnThermalShockwave(epicenter, blastRadius);
}
```

## Механика: Термодинамика FLIR и подавление живой силы (FLIR Thermal Contrast & Kinetic Suppression) (SECONDARY)

### Глубина механики
- **Роль в петле**: Тормоз/регулятор темпа стрельбы и механика тактического сдерживания противника
- **Решение игрока**: Поливать ли сектор непрерывным огнем 25-мм пулемета для 100% подавления вражеских гранатометчиков (не давая им прицелиться в спецназ), рискуя словить заклинивание от перегрева ствола (Jam Lockout), или стрелять короткими расчетными отсечками.
- **Управление**: Удержание кнопки/зоны огня для непрерывной очереди; отпускание гашетки для принудительного охлаждения ствольного блока. Тап по переключателю тепловых палитр 'W-HOT / B-HOT' для смены контраста в дыму.
- **Состояния**: `COOL_NOMINAL: температура стволов 20–60°C; максимальная кучность стрельбы (разброс 0.15°), стандартный термоконтраст FLIR.`, `HIGH_HEAT_WARNING: температура 61–99°C; стволы раскалены докрасна, разброс увеличивается до 0.45°, звучит предупредительный сигнал температурного датчика.`, `OVERHEAT_JAM: температура достигла 100°C; орудие блокируется на 3.5 с; оператор вынужден ждать сброса тепла или переключаться на другие калибры.`, `ENEMY_SUPPRESSED: вражеский отряд пехоты под воздействием близких разрывов 25мм (дистанция < 4м) падает ничком, меткость снижается на 90% на 3.0 секунды.`
- **Параметры и настройка**:
  - **Прирост температуры за 1 выстрел 25мм**: `1.85°C за выстрел (перегрев за 43 непрерывных выстрела ~ 1.4 с огня)` — Если сделать более 3.0°C, пулемет перегревается моментально и раздражает игрока; если сделать менее 0.8°C, механика перегрева теряет смысл и превращается в зажатую гашетку.
  - **Скорость охлаждения ствольного блока GAU-12**: `18.0°C / сек в покое` — При занижении ниже 10°C/с игрок слишком долго скучает без пулемета; при завышении выше 40°C/с перегрев сбрасывается мгновенно.
  - **Радиус зоны подавления пули 25мм**: `3.8 м от точки попадания пули` — Позволяет эффективно прижимать к земле группы пехоты даже без прямого попадания в силуэт.
  - **Длительность эффекта подавления пехоты (Suppression duration)**: `2.8 с после прекращения обстрела` — Дает союзному отряду Bravo ровно столько времени, чтобы безопасно пробежать простреливаемый перекресток.
- **Слои отклика**:
  - Визуал/VFX: По мере нагрева 25-мм блока пушка на HUD раскаляется от белого к ярко-оранжевому свечению; при стрельбе трассеры выбивают фонтаны термопыли; подавленная пехота падает на живот и закрывает голову руками (анимация 'hit_the_deck').
  - Звук (Web Audio): Непрерывный низкий гул вращения блока стволов Гатлинга (звук 'BRRRRT'), при критическом нагреве — нарастающий высокочастотный вой перегретого ротора и щелчок защитного соленоида при заклинивании.
  - Камера (импульс/зум): Высокочастотный мелкий дрожащий зуд камеры (шейк амплитудой 0.08° на частоте 30 Гц) при зажатой гашетке пулемета.
  - UI/Тактильность: Вертикальный секторный датчик HEAT GAU-12 с градиентным заполнением; непрерывная нарастающая по частоте виброотдача на мобильном устройстве (от 10 Гц до 50 Гц по мере приближения к 100°C).
- **Режим отказа**: Игрок зажимает гашетку пулемета, ловит перегрев стволов на 100°C, в этот момент из-за угла выбегает гранатометчик РПГ-7 и стреляет по спецназу, пока игрок беспомощно ждет 3.5 секунды охлаждения. Сигнал: звуковой сигнал тревоги 'GUN OVERHEAT, LOCKOUT ACTIVE'.

- **Синергии**:

- **Почему это не жанровый шаблон**: Подавление огнем превращает пулемет из примитивного инструмента нанесения урона в тактический щит для союзного отряда, моделируя реальную тактику непосредственной авиационной поддержки CAS (Close Air Support).

function updateGatlingSuppression(dt, isFiring, hitPoint) {
  if (isFiring && !gatling.isJammed) {
    gatling.heat += gatling.heatPerShot * (dt * 30);
    if (gatling.heat >= 100.0) {
      gatling.isJammed = true;
      audio.playJamAlarm();
    }
    suppressEnemiesInRadius(hitPoint, 3.8, 2.8);
  } else {
    gatling.heat = Math.max(0, gatling.heat - gatling.coolingRate * dt);
    if (gatling.isJammed && gatling.heat <= 30.0) {
      gatling.isJammed = false;
    }
  }
  hud.updateHeatGauge(gatling.heat, gatling.isJammed);
}
```
