# QA & Testing Plan: AC-130: Ночной Тепловизор

## 1. Functional Test Matrix
- [ ] Проверка переключения калибров (25мм/40мм/105мм) и соответствия их времени подлета и радиусов сплеша
- [ ] Тест системы Friendly Fire: гарантированное поражение миссии при попадании 105мм снаряда по союзному спецназу
- [ ] Тест продвижения союзного отряда спецназа по 3 фазам контрольных точек и победа при эвакуации
- [ ] Тест цепной детонации: взрыв бензовоза должен наносить урон соседним машинам и разрушать стены
- [ ] Тест монетизации Playgama Bridge: корректный вызов и вознаграждение за Rewarded Video (ревайв/удвоение)

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS на ПК (Chrome/Firefox/Edge/Safari)
- [ ] Стабильные 55-60 FPS на смартфонах среднего сегмента (Snapdragon 778G / Helio G99 / iPhone 11+)
- [ ] Время начальной загрузки игры в браузере не более 3.0 секунд
- [ ] Потребление оперативной памяти WebGL контекстом не более 250 МБ

## 3. Target Browser Matrix
- Google Chrome (Desktop & Android)
- Safari (macOS & iOS 15+)
- Yandex Browser (Desktop & Mobile)
- Mozilla Firefox (Desktop)
