# Skill: FLIR Thermal Post-Processing Shader

## Purpose
Создание монохромного шейдера тепловизора White-Hot с термо-эмиссией, CRT-сканлайнами и шумом матрицы для Three.js.

## When to Use
При настройке рендерера и постобработки боевой сцены AC-130.

## Core Rules & Constraints
- Использовать однопроходный ShaderPass в EffectComposer
- Рендерить горячие объекты с Emissive > 1.0 для последующего теплового свечения
- Оптимизировать шум матрицы через UV псевдорандом без ресурсоемких математических функций

## System Architecture
Three.js EffectComposer -> Custom ThermalShaderMaterial (Uniforms: tDiffuse, uTime, uNoiseIntensity, uZoom) -> Output to Canvas.

## Implementation Guidance
Скомпилировать GLSL фрагментный шейдер, рассчитывающий градиент яркости от температуры материала и накладывающий динамическую зернистость.

## Common Mistakes to Avoid
- ❌ **Mistake**: Использование тяжелых многослойных шумов Перлина, просаживающих FPS на мобильных устройствах
- ❌ **Mistake**: Отсутствие маскирования интерфейса HUD (HUD должен оставаться четким и не зашумляться шейдером сцены)

## Validation Checklist
- [ ] Шейдер выдает стабильные 60 FPS на мобильном Safari
- [ ] Горячие двигатели и взрывы имеют ослепительно белый цвет
- [ ] Союзные стробоскопы отчетливо мерцают с частотой 2 Гц
