# Core Loop Design: Гангейм: Контейнерный Прорыв

## 1. Чем эта петля отличается
- **Фирменный момент**: Скользя на мокром асфальте в низком подкате между двумя ржавыми контейнерами, вы разносите врага в упор из дробовика; оружие в руках со звонким щелчком мгновенно трансформируется в снайперскую винтовку — вы не прерывая скольжения выпрыгиваете на крышу ящика, без прицела в воздухе снимаете второго врага, зарабатываете 3-й фраг в серии, и небо озаряется сигналом БПЛА, подсвечивающим оставшихся соперников сквозь стальные стены.
- **Отличие от жанрового шаблона**: В отличие от классических Gun Game с задержкой смены оружия в 0.6–1.2 с и мобильных шутеров с автострельбой, здесь реализована бесшовная нулевая задержка смены ствола (0.08 с), инерционная физика подкатов со стрельбой от бедра и тактический 3D-рентген БПЛА за серию убийств, превращающий лабиринт из контейнеров в прозрачную арену для непрерывного скоростного спидрана.
- **Сознательно НЕ берём**: Шаблон классического FPS с ручной перезарядкой обоймы (кнопка R), покупкой оружия в бай-меню и кемперским отсиживанием в укрытиях для регенерации здоровья.
ПОЧЕМУ ОТВЕРГНУТ: В сессионном веб/мобильном шутере длительностью 90 секунд любая 3-секундная пауза на перезарядку или пассивное стояние за ящиком разрушает темп адреналинового флоу. Здесь перезарядка полностью заменена мгновенной трансформацией оружия за совершение фрага, что превращает матч в непрерывный скоростной танец смерти без единой секунды простоя.

## 2. Схема петли
```text
+-------------------------------------------------------------------------------+
|                       ГАНГЕЙМ: КОНТЕЙНЕРНЫЙ ПРОРЫВ                           |
+-------------------------------------------------------------------------------+
                                       |
                               [СПАВН НА ТЕРМИНАЛЕ] (t = 0.0с)
                                       |
                                       v
    +-------------------> [СПРИНТ И МАНЕВРИРОВАНИЕ] <--------------------+
    |                                 |                                  |
    |                      (Обнаружен противник)                         |
    |                                 v                                  |
    |                    [БОЕВОЙ ПОДКАТ / ПЕРЕЛАЗ]                       |
    |                    (Скорость +35%, Хитбокс -50%)                   |
    |                                 |                                  |
    |                     (Огневой контакт CQB)                          |
    |                                 v                                  |
    |                [ПРИЦЕЛИВАНИЕ В УЯЗВИМУЮ ЗОНУ]                      |
    |              (Голова: 2.0x урон | Корпус: 1.0x)                    |
    |                                 |                                  |
    |                         (Фраг подтвержден)                         |
    |                                 v                                  |
    |                   [МГНОВЕННАЯ ТРАНСФОРМАЦИЯ]                       |
    |                 (Ствол N -> N+1 за 0.08с, 100% патронов)           |
    |                                 |                                  |
    |               +-----------------+-----------------+                |
    |               |                                   |                |
    |    [СЕРИЯ = 3 ФРАГА]                     [СЕРИЯ < 3 ФРАГА]         |
    |               |                                   |                |
    |               v                                   |                |
    |    [АКТИВАЦИЯ БПЛА «ОВЕРЛОРД»]                    |                |
    |   (Подсветка сквозь стены на 8.0с)                |                |
    |               |                                   |                |
    |               +-----------------> + <-------------+                |
    |                                   |                                |
    |                            (Ранг < 12)                             |
    +-----------------------------------+                                |
                                        |                                |
                                    (Ранг == 12)                         |
                                        v                                |
                           [ФИНАЛЬНЫЙ ФРАГ ИЗ ЗОЛОТОГО РПГ]              |
                                        |                                |
                                        v                                |
                             [ТРИУМФ И ПОБЕДА В МАТЧЕ]                   |
                               (Награды, Звезды, Скины)                  |
```

## 3. Микро-петля (посекундно)
| Шаг | Действие игрока | Ответ игры | Решение игрока | Длительность |
| :--- | :--- | :--- | :--- | :--- |
| 1. Сканирование коридора и позиционирование | Спринт по узкому проходу между контейнерами с контролем углов поворотом камеры | Отображение теней врагов на асфальте, звуки шагов за углом, маркеры на миникарте | Атаковать в лоб через агрессивный боевой подкат или залезть на контейнер для атаки сверху | 1.0–2.0 с |
| 2. Инициация контакта и боевой подкат | Вход в боевой подкат под линию прицела врага со смещением корпуса | Снижение высоты камеры до 0.75 м, искры из-под подошв об асфальт, разгон скорости на +35% | Стрелять от бедра в скольжении или выждать момент для точной наводки в голову | 0.5–0.9 с |
| 3. Огневой контакт и ликвидация цели | Точный выстрел в верхнюю зону хитбокса противника с компенсацией отдачи | Золотой хитмаркер, Web Audio FM-клик попадания, рэгдолл врага, регистрация фрага | Продолжить движение вперед по инерции или резко развернуть камеру на 180° для проверки спины | 0.2–0.5 с |
| 4. Мгновенная трансформация оружия | Мгновенная адаптация хвата и прицела под новый тип оружия лестницы без паузы на перезарядку | Голографическая вспышка декомпиляции за 0.08 с, новый ствол в руках со 100% патронов, +1 к рангу лестницы | Сокращать дистанцию под дробовик/ПП или занять длинный прострел под снайперку/марксманку | 0.08–0.3 с |

## 4. Мезо-петля (этап за этапом)
| Шаг | Действие игрока | Ответ игры | Решение игрока | Длительность |
| :--- | :--- | :--- | :--- | :--- |
| 1. Стартовый прорыв ближнего боя (Ранги 1–4: Пистолеты и Дробовики) | Сверхскоростные подкаты и дуэли в упор в центральном узле контейнеров из пистолетов и дробовиков | Высокая плотность спавна врагов в центре, быстрый набор первых 3–4 фрагов, переход на автоматическое оружие | Агрессивно фармить первые фраги в узком центре арены или обойти по внешнему периметру терминала | 15–20 с |
| 2. Тактическая серия и активация БПЛА (Ранги 5–8: ПП и Штурмовые Винтовки) | Контроль отдачи на средних дистанциях (MP5, P90, M4, AK), набор серии из 3 фрагов и вызов БПЛА «Оверлорд» | Звук сонара, подсветка силуэтов врагов сквозь контейнеры на 8.0 с, рост плотности ответного огня ботов | Использовать подсветку БПЛА для штурма плотной группы врагов или занять контейнер для отстрела сверху | 25–35 с |
| 3. Финальная дуэль на точность и триумфальный залп (Ранги 9–12: DMR, AWP, РПГ-7) | Выцеливание уязвимых зон из DMR и снайперки AWP, уклонение от перекрестного огня и финальный выстрел из Золотого РПГ-7 | Таймер матча тикает (<20 с), звуковые сирены финала, боты стягиваются к позиции лидера гонки | Рискнуть выстрелом ноу-скопом в прыжке с подката или занять выжидательную позицию на контейнере под таймер матча | 20–30 с |

## 6. Кривая напряжения
Кривая напряжения представляет собой агрессивную пилообразную синусоиду с экспоненциальным взлетом в финале: 0–15 с (Ранги 1–3) — быстрый старт на 60% напряжения, разгоняющий ритм; 15–45 с (Ранги 4–8) — пик флоу на 75–80% с активацией БПЛА и доминированием на арене; 45–75 с (Ранги 9–11) — зона максимального тактического стресса на 90% напряжения (снайперки повышают цену промаха); 75–90 с (Ранг 12, РПГ-7) — финальный катарсис на 100% напряжения, когда все боты атакуют лидера, а единственный точный залп приносит мгновенную триумфальную победу.

## 7. Формулы ядра
- `Урон с учетом зон попадания: Damage_Final = Base_Weapon_Damage * Zone_Multiplier (где Head = 2.0, Torso = 1.0, Legs = 0.7)`
- `Скорость перемещения: V_Current = V_Base * Slide_Factor * Stagger_Penalty (где V_Base = 8.0 м/с, Slide_Factor = 1.35 в окне скольжения 0.90 с, Stagger_Penalty = 0.70 на 0.35 с при получении урона)`
- `Таймер мгновенной трансформации ствола: T_Morph = 0.08 с (мгновенный swap 3D-модели в руках и пополнение обоймы до 100% Capacity_Max без паузы на перезарядку)`
- `Эффективность БПЛА «Оверлорд»: UAV_Duration = 8.0 с, Pulse_Freq = 1.5 с, Stencil_Outline_Radius = 1.8 м вокруг меша врага с альфа-прозрачностью 0.85`
- `Итоговый боевой счет матча: Match_Score = (Frags * 100) + (Headshot_Count * 50) + (Killstreaks * 150) + max(0, (90 - Elapsed_Time) * 10)`
- `Адаптивный радиус спавна ботов: Spawn_Distance = clamp(12.0 + (Rank * 0.8), 12.0, 22.0) метров от игрока вне прямого конуса видимости камеры (FOV 80°)`
