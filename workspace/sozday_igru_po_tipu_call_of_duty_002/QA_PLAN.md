# QA & Testing Plan: Гангейм: Контейнерный Прорыв

## 1. Functional Test Matrix
- [ ] Проверка корректной смены оружия строго после каждого фрага в соответствии с лестницей 1..12
- [ ] Проверка физики подката: срабатывание только в движении, сохранение инерции 0.85 сек, снижение высоты коллайдера на 50%
- [ ] Проверка вызова БПЛА при достижении серии в 3 фрага и подсветки ботов сквозь контейнеры на 8 секунд
- [ ] Проверка условия победы при совершении 12-го фрага и корректного завершения раунда
- [ ] Проверка мгновенного респауна игрока и ботов за 1.0 секунды на безопасных точках спавна

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS на средних смартфонах (Mali-G57 / Adreno 610)
- [ ] Время первой загрузки WebGL сцены менее 2.5 секунд
- [ ] Количество Draw Calls не более 65 в любой точке арены
- [ ] Потребление оперативной памяти не более 180 МБ

## 3. Target Browser Matrix
- Chrome Mobile / Desktop (Windows, Android)
- Safari Mobile / Desktop (iOS 15+, macOS)
- Yandex Browser Mobile / Desktop
- VK In-App Browser (Android / iOS)
