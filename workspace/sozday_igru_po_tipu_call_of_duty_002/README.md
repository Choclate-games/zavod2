# Гангейм: Контейнерный Прорыв 🎮

> **Контейнерный Прорыв — это сверхдинамичный 3D FPS в стиле Shipment, где бойцы сходятся в 90-секундной гонке вооружений: каждый фраг мгновенно меняет ваш ствол (от пистолета до РПГ), скольжение в подкатах спасает от пуль, а серия из 3 фрагов вызывает БПЛА с подсветкой врагов сквозь контейнеры.**

---

## 🌟 Обзор проекта
- **Жанр**: 3D Экшен-Шутер от первого лица (Аркадный Гангейм / Fast-Paced FPS)
- **Движок и стек**: Three.js + TypeScript + Vite + Web Audio API
- **Платформа**: Playgama Bridge (Яндекс Игры, VK Play, Web & Mobile)
- **Ориентация**: Landscape (горизонтальная)

---

## 🕹️ Управление

### Десктоп (Клавиатура + Мышь)
- **WASD** / **Стрелки**: Передвижение (вперед, назад, стрейф)
- **Мышь (Pointer Lock)**: Обзор и прицеливание
- **ЛКМ**: Стрельба (одиночные / зажим)
- **ПКМ**: Прицеливание (ADS зум 68° FOV)
- **Shift**: Тактический спринт
- **C** / **Ctrl**: Боевой подкат (во время спринта) / присед
- **Пробел**: Прыжок / Залезание на контейнеры (2.60 м)
- **E** / **4**: Активация БПЛА «Оверлорд» (при серии из 3 фрагов)
- **P** / **Esc**: Пауза

### Мобильные устройства (Touch Controls)
- **Левая зона**: Плавающий виртуальный джойстик (с 8% мертвой зоной)
- **Правая зона**: Вращение камеры / прицеливание
- **Свайп вниз на правой зоне**: Боевой подкат
- **Кнопка Огня**: Стрельба
- **Кнопка Прицела**: Переключение ADS прицеливания
- **Кнопка Прыжка**: Прыжок и перелаз
- **Кнопка БПЛА**: Вызов разведки (появляется при серии 3 фрагов)
- **Режим принудительного тача на ПК**: добавить `?touch=1` к URL

## 🚀 Запуск и сборка

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера с горячей перезагрузкой
npm run dev

# Проверка статической спецификации и приёмки
npm run check:spec

# Сборка production-бандла
npm run build

# Предпросмотр production-сборки
npm run preview
```

## 📁 Структура проекта

```text
src/
├── config/
│   └── balance.ts                    # Параметры баланса и конфигурации 12 видов оружия
├── core/
│   ├── EventBus.ts                   # Строго типизированная шина событий
│   ├── GameLoop.ts                   # 60 Гц игровой цикл с фиксированным шагом
│   └── Game.ts                       # Главный координатор игры и стейт-машина
├── platform/
│   ├── PlaygamaService.ts            # Интеграция с SDK Playgama Bridge
│   └── StorageService.ts             # Локальное и облачное хранилище
├── physics/
│   └── PhysicsWorld.ts               # AABB коллизии, рэйкасты, проверка пола и уступов
├── entities/
│   ├── Player.ts                     # Сущность игрока (передвижение, стрельба, подкаты)
│   ├── Enemy.ts                      # Сущность бота-соперника (FSM, реакция, хитбоксы)
│   └── EntityManager.ts              # Менеджер и спавнер сущностей на арене
├── systems/
│   ├── WeaponLadderProgressionSystem.ts # Лестница оружия и мгновенный морфинг (0.08с)
│   ├── SlideFpsMovementPhysicsSystem.ts # Кинематика подката (10.8 м/с) и снижение хитбокса
│   ├── KillstreakDroneRadarSystem.ts    # БПЛА «Оверлорд» и миникарта
│   ├── AggressiveCqbCombatAiSystem.ts   # Тактика штурма и укрытий ботов
│   └── MatchFlowVictoryResolutionSystem.ts # Таймер 90с и условия победы (12 фрагов)
├── rendering/
│   ├── SceneManager.ts               # Three.js сцена, камера, свет, тени и фон меню
│   ├── MapBuilder.ts                 # Процедурная арена Shipment с контейнерами

├── input/
│   └── InputManager.ts               # Единый агрегатор ввода с клавиатуры, мыши и тача
├── ui/
│   ├── theme.css                     # Дизайн-система и токены оформления
│   ├── icons.ts                      # Векторные SVG иконки
│   ├── TouchControls.ts              # Двухзонное тач-управление на Pointer Events
│   ├── Hud.ts                        # Тактический HUD (таймер, ранг, патроны, сонар)
│   ├── ScreenRouter.ts               # Роутер переключения экранов
│   ├── UiRoot.ts                     # Контейнер UI слоев
│   ├── components/                   # Базовые UI компоненты (Button, Panel, Modal)
│   └── screens/                      # Экраны (MainMenu, Pause, VictoryDefeat)
└── main.ts                           # Точка входа приложения
```
