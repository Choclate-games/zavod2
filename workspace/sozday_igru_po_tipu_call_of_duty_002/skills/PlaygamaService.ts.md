# Skill: Playgama SDK Integration

## Purpose
Интеграция облачных сохранений, рекламы и лидербордов на платформе Яндекс Игры и VK Play

## When to Use
При запуске игры, завершении матча и сохранении прогресса игрока

## Core Rules & Constraints
- Никакой рекламы во время 90-секундного боя
- Кулдаун межстраничной рекламы строго не менее 90 секунд

## System Architecture
Модульный сервис-обертка вокруг @playgama/bridge 2.x с реактивным хранилищем состояния

## Implementation Guidance
Используйте методы bridge.storage для сохранения прогрессии и bridge.advertisement.showRewardedVideo для удвоения очков после раунда.

## Common Mistakes to Avoid
- ❌ **Mistake**: Показ рекламы прямо во время активного огневого боя
- ❌ **Mistake**: Блокировка ввода без проверки наличия фокуса окна

## Validation Checklist
- [ ] Инициализирован bridge.initialize() до старта геймплея
- [ ] Настроена пауза аудио и таймеров при открытии оверлея рекламы
- [ ] Сохраняются ключи ранга, золота и разблокированных камуфляжей
