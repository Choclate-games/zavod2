# Core Loop Design: Снайпер: Призрачный Контракт

## 1. Чем эта петля отличается
- **Фирменный момент**: Выстрел с дистанции 420 метров в стальной трос подвесного прожектора на 30-метровой мачте: пуля 7.62x54mm перебивает крепление в момент прохода командира гарнизона. В замедленном времени (Time Dilation 50%) полутонный прожектор срывается вниз, обрывает силовой кабель с фонтаном ослепительных электрических искр и насмерть погребает цель под обломками. Вся база погружается в аварийную тьму, а часовые в радиоэфире кричат о коротком замыкании из-за метели, не поднимая боевой тревоги.
- **Отличие от жанрового шаблона**: В отличие от классических снайперских игр, где игрок просто методично отстреливает головы статичным часовым, здесь каждый выстрел — это физический триггер для цепной аварии (Kinetic Environmental Sabotage) или синхронизированный с громом/дизелем скрытный трюк (Acoustic Masking). Ликвидация через падение прожектора, разрыв паропровода или утечку азота не считается убийством для ИИ: враги воспринимают это как производственную аварию в условиях сурового Заполярья, что позволяет зачистить охраняемый военный объект без единого выстрела в человека.
- **Сознательно НЕ берём**: Отвергнут шаблон «Аркадный тир с волнами бегущих врагов и автоприцеливанием» (а-ля мобильные клоны Sniper 3D / аркадные рельсовые шутеры) и шаблон «Случайные карты перков после убийства». В нашей игре нет открытого штурмового боя с автоматом в руках и нет абстрактных бонусов вроде «+10% к урону от магии». Вместо этого реализован чистый тактический стелс-пазл от первого лица: цена каждого патрона предельно высока, стрельба подчиняется физической баллистике и полярному ветру, а любая ошибка карается 5-секундным таймером общей тревоги и провалом контракта.

## 2. Схема петли
```text
+-----------------------------------------------------------------------------------+
|                            МАКРО-ПЕТЛЯ (ШТАБ / ПРОГРЕССИЯ)                        |
|  [Выбор полярного контракта] -> [Кастомизация винтовки и оптики] -> [Эвакуация /  |
|  Награда ГРУ] -> [Покупка спецпатронов, сошек, тепловизоров]                      |
+-----------------------------------------------------------------------------------+
                                          |  Старт контракта (60-90 с)
                                          v
+-----------------------------------------------------------------------------------+
|                            МЕЗО-ПЕТЛЯ (СЕКТОР / VIP-ЦЕЛИ)                         |
|  [Сканирование базы] -> [Выбор порядка целей] -> [Изоляция снайперов] ->          |
|  [Провокация цепных аварий] -> [Устранение свидетелей] -> [Контроль сирены 5.0с]   |
+-----------------------------------------------------------------------------------+
                                          |  Каждый отдельный выстрел
                                          v
+-----------------------------------------------------------------------------------+
|                         МИКРО-ПЕТЛЯ (ПОСЕКУНДНАЯ СТРЕЛЬБА)                        |
|                                                                                   |
|  +-----------------------------------------------------------------------------+  |
|  | 1. НАВЕДЕНИЕ: Считывание ветра (0-14 м/с) и дистанции (300-600 м)           |  |
|  |                                      |                                      |  |
|  |                                      v                                      |  |
|  | 2. ФОКУС: Задержка дыхания (Time Dilation 50%, sway -> 0, легкие 4.0 с)      |  |
|  |                                      |                                      |  |
|  |                                      v                                      |  |
|  | 3. СИНХРОНИЗАЦИЯ: Ожидание акустического окна (гром / дизель базы)          |  |
|  |                                      |                                      |  |
|  |                                      v                                      |  |
|  | 4. ВЫСТРЕЛ: Спуск бойка, поправка Mil-Dot, полет пули (0.35-0.70 с)         |  |
|  |                                      |                                      |  |
|  |                                      v                                      |  |
|  | 5. ИМПАКТ: Разрыв троса/хедшот -> Accident Kill / Паника ИИ 1.8 с           |  |
|  +-----------------------------------------------------------------------------+  |
+-----------------------------------------------------------------------------------+
```

| Спуск курка и полет пули | Игрок нажимает кнопку выстрела по уязвимому узлу (трос подвеса / вентиль пара / шея офицера). | Сухой щелчок бойка, глухой хлопок выстрела, отдача подбрасывает прицел на 1.8 градуса вверх, камера сопровождает пулю в кинематографичном ракурсе Bullet-Cam. | Немедленно отпустить задержку дыхания для предотвращения гипервентиляции и перевести взгляд на соседних часовых. | 0.35–0.7 с |
| Кинетический импакт и оценка реакции гарнизона | Игрок наблюдает за падением конструкции или цели, контролируя конусы зрения ближайших солдат. | Цель нейтрализована без шума (Accident Kill / Silent Headshot), над соседним часовым загорается желтый маркер подозрения (0–40%), затем сбрасывается из-за списания на аварию. | Остаться на текущей прицельной позиции или сместить оптику на вторую цель маршрута. | 1.0–2.0 с |

## 6. Кривая напряжения
Кривая напряжения строится по волновой тактической схеме: 0–15 с (Холодный расчет, напряжение 20%) — спокойное изучение базы, чтение ветра, маркировка целей и поиск уязвимых тросов; 15–40 с (Нарастание давления, напряжение 55%) — первая ликвидация часового на вышке, тело падает на грани зоны обзора патруля, запуск первого тайминга акустической маскировки; 40–70 с (Пиковая кульминация, напряжение 95%) — выстрел в подвесной прожектор над офицером, лампа обрушивается, перерубленный провод искрит, соседний часовой входит в фазу подозрения (желтый маркер 80%), игрок за 1.8 секунды в режиме задержки дыхания обязан снять бегущего к сирене свидетеля; 70–85 с (Катарсис и триумф, напряжение 15%) — все 4 цели ликвидированы без тревоги, в эфире тишина, вертолет эвакуации забирает снайпера с заснеженного гребня; 85–90 с — спокойное распределение наград в оружейной.

## 7. Формулы ядра
- `Формула вертикального падения пули (Bullet Drop): y_drop = 0.5 * g * (distance / v_muzzle)^2, где g = 9.81 м/с^2, v_muzzle = 850.0 м/с (для 7.62x54mmR). Вертикальная поправка по сетке Mil-Dot: mil_elevation = (y_drop / distance) * 1000 [милы]. На дистанции 450 м падение составляет 1.37 м (поправка 3.05 мила вниз).`
- `Формула горизонтального ветрового сноса (Wind Deflection): x_drift = 0.5 * a_wind * (distance / v_muzzle)^1.45, где a_wind = wind_speed_mps * sin(wind_angle_rad). При боковом ветре метели 10.0 м/с под углом 90° на дистанции 450 м снос пули составляет 1.82 м (поправка 4.04 мила по горизонту).`
- `Формула накопления тревоги гарнизона (AI Awareness Accumulation): awareness_delta = (base_alert_rate * (1.0 - distance / max_vision_range) * posture_mod * weather_mod) * dt. При значении awareness >= 100% за 1.80 с часовой переходит в режим 'Паника' и начинает 5.00-секундный забег к сирене со скоростью 5.20 м/с.`
- `Формула акустической заметности выстрела (Audible Footprint): audible_radius = base_gun_noise * suppressor_mod * (1.0 - env_noise_mask_factor). При выстреле во время раската грома (env_noise_mask_factor = 1.0) эффективный радиус шума падает со 120.0 м до 0.0 м даже для крупнокалиберной винтовки без глушителя.`
- `Формула финальной награды за контракт (Contract Bounty Multiplier): total_credits = base_contract_reward * (1.0 + 0.5 * is_ghost_stealth) * (1.0 + 0.25 * accident_kills_count) * (headshot_accuracy_percent / 100.0) * difficulty_tier_mult.`
