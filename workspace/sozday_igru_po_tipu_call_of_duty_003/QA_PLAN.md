# QA & Testing Plan: Снайпер: Призрачный Контракт

## 1. Functional Test Matrix
- [ ] Проверка точности попадания Raycast по хитбоксам головы, туловища и конечностей на дистанциях 200–600 м.
- [ ] Проверка корректности работы 5-секундного таймера тревоги при обнаружении тела патрульным.
- [ ] Проверка физического отрыва подвесного прожектора и нанесения урона целям в радиусе 3.5 м.
- [ ] Проверка расхода и восстановления шкалы задержки дыхания со слоу-мо 0.5x.
- [ ] Проверка сохранения прогресса и кредитов в Playgama Cloud Storage.

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS на iPhone 11 / Samsung Galaxy A52 в ландшафтном режиме.
- [ ] Количество Draw Calls не превышает 75 во всех ракурсах оптического прицела.
- [ ] Общее число полигонов на сцене не превышает 45 000 треугольников.
- [ ] Время начальной загрузки страницы до интерактивного кадра — менее 2.5 секунд.

## 3. Target Browser Matrix
- Chrome 120+ (Desktop & Android)
- Safari 16+ (iOS 16+ & macOS)
- Firefox 120+ (Desktop)
- Yandex Browser (Desktop & Mobile)
