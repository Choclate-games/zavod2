# Снайпер: Призрачный Контракт 🎮⚡

> **«Снайпер: Призрачный Контракт» — тактический 3D-снайперский стелс-экшен от первого лица. Ликвидируйте офицеров и часовых на заполярной военной базе за 60–90 секунд: задерживайте дыхание для замедления времени, перебивайте силовые кабели, взрывайте щитки и обрушивайте прожекторы, выполняя контракты без единой сирены.**

---

## 🌟 Обзор проекта
- **Жанр**: Тактический 3D Снайперский Экшен (Снайперский стелс-симулятор / Тактическая головоломка от первого лица)
- **Рендерер**: Three.js (^0.160.0) + Rapier3D (@dimforge/rapier3d-compat ^0.14.0)
- **Платформа**: Playgama Bridge v2 (Yandex Games / VK / Web)
- **Ориентация**: Landscape (Альбомная)
- **Целевая аудитория**: Фанаты серии Call of Duty (миссия «All Ghillied Up»), Sniper Elite и Hitman.

---

## 🚀 Запуск и сборка

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки (Vite)
npm run dev

# Проверка статической приёмки ACCEPTANCE.md
npm run check:spec

# Сборка продакшен-бандла
npm run build

# Предпросмотр сборки
npm run preview
```

## 🎮 Управление в игре

### Десктоп (Клавиатура и мышь)
- **Прицеливание**: Движение мыши (с плавным расчетом инерции).
- **Выстрел**: `Левая кнопка мыши (ЛКМ)` / `Enter`.
- **Задержка дыхания (Фокус 0.5x)**: Зажатие `Shift` или `Пробел`.
- **Смена кратности оптики**: `Q` (4X / уменьшение), `E` (16X / увеличение).
- **Тактическая пауза**: `Escape` / `P`.

### Мобильные устройства (Тачскрин)
- **Прицеливание**: Свайп пальцем по центральной зоне экрана.
- **Выстрел**: Кнопка **«ВЫСТРЕЛ»** в правом нижнем углу.
- **Задержка дыхания**: Удержание кнопки **«ФОКУС»** в левом нижнем углу.
- **Зум**: Кнопки **«4X»**, **«8X»**, **«16X»** в верхнем левом углу.
- **Пауза**: Кнопка паузы в верхнем правом углу.

## 📁 Структура исходного кода (`src/`)

```text
src/
├── main.ts                    # Bootstrap приложения, защита вьюпорта, интеграция Playgama
├── core/
│   ├── Constants.ts           # Балансные числа из balance.yaml
│   ├── EventBus.ts            # Типизированная шина событий и состояний
│   └── GameEngine.ts          # Главный игровой цикл 60Гц с фиксированным шагом
├── platform/
│   ├── BridgeService.ts       # Обертка Playgama Bridge SDK v2 (реклама, game_ready, баннеры)
│   └── SaveService.ts         # Нормализация сохранений, облако и зеркало LocalStorage
├── physics/
│   └── PhysicsWorld.ts        # Обертка Rapier3D физики и лучей
├── rendering/
│   └── SceneManager.ts        # Three.js сцена полярной базы, освещение и метель
├── game/
│   ├── SniperController.ts    # Задержка дыхания, покачивание, гипервентиляция, отдача
│   ├── BallisticsSystem.ts    # Баллистика падения, боковой ветер, акустическая маскировка
│   ├── StealthSystem.ts       # ИИ патрулей, конусы зрения, тревога, спринт к кнопке
│   ├── HazardSystem.ts        # Интерактивные тросы, падающие прожекторы, бочки
│   └── ContractManager.ts     # Контракты, учет целей, боекомплект, расчет наград
├── input/
│   ├── InputManager.ts        # Обработка мыши, клавиатуры и захвата указателя
│   └── TouchControls.ts       # Мобильный тач-слой в DOM
└── ui/
    ├── theme.css              # Токены дизайн-системы, z-index, адаптивная вёрстка
    ├── i18n.ts                # Двуязычная локализация (RU / EN)
    ├── ScreenRouter.ts        # Маршрутизатор экранов и пауза
    └── screens/
        ├── BriefingScreen.ts  # Экран брифинга и выбора контрактов
        ├── GameplayHUD.ts     # Игровой HUD с сеткой Mil-Dot и шкалой шума
        ├── DebriefingScreen.ts# Экран итогов контракта и удвоения награды
        └── ArsenalScreen.ts   # Экран арсенала и покупки винтовок
```
