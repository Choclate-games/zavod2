# UI/UX Specification: Снайпер: Призрачный Контракт

## 1. Материал интерфейса
Интерфейс живёт в том же мире, что и сцена. Проверка: если закрыть игровое поле,
меню обязано выдавать именно эту игру, а не любую другую.

- **Тема от арт-директора**: Армейский тактический интерфейс в стиле Modern Warfare: моноширинные шрифты, матовые полупрозрачные темные плашки, неоново-зеленые и янтарные акценты.
- **Визуальный язык**: Холодный высокотехнологичный милитари-интерфейс: темное стекло, приглушенный сине-стальной фон, контрастный зеленый тритиевый свет и аварийный оранжево-красный сигнал тревоги.
- **Типографика**: Chakra Petch / Rajdhani — четкие военные рубленые шрифты с отличной читаемостью цифр.

## 2. Акценты: один цвет — один смысл
Разный цвет у каждой кнопки «чтобы отличались» — главная ошибка игрового
интерфейса. На одном экране одновременно видно не больше двух акцентов.

| Токен | Единственный смысл |
|---|---|
| `alert_danger` | #e63946 |
| `hud_neutral` | #d8e2dc |
| `interactive_hazard` | #ffb703 |
| `positive_stealth` | #38b000 |

Все значения — токенами в `src/ui/theme.css`: цвета, гарнитуры, шкала отступов,
радиусы, длительности, порядок слоёв `--z-*`. Литерал цвета внутри экрана — баг.

## 3. Композиция экрана
Меню и экраны между сессиями лежат ПОВЕРХ живой игровой сцены — той же, что в
игре, только с медленной камерой. Непрозрачная заливка на весь экран запрещена:
подложка только под текстом и кнопками.

- **Сцена за меню**: Главное меню: снайперская винтовка крупным планом на заснеженном ящике с боеприпасами в лучах контрового света под звуки ветра.

Экран — не колонка кнопок по центру. Три зоны, и каждый элемент лежит ровно в одной:

1. **Идентичность** — что это за экран: заголовок, режим, состояние игрока.
2. **Главное действие** — ровно одно на экран, самое крупное и единственное с
   основным акцентом.
3. **Второстепенный ряд** — всё остальное, одним рядом или сеткой, одним весом.

Зоны нажатия: основная ≥ 96 px, остальные ≥ 64 px, зазор ≥ 12 px, отступы через
`env(safe-area-inset-*)` плюс измеренная высота липкого баннера. Ни один экран не
скроллит страницу: длинный список скроллится во внутреннем контейнере.

## 4. Набор компонентов (закрытый)
Всё на экране — один из этих компонентов. Одноразовый `<div>` с инлайновыми
стилями — это то, из-за чего второй экран перестаёт совпадать с первым.

- ScopeVignetteOverlay
- BreathHoldBar
- TargetStatusCard
- WindDirectionWidget
- AlertCountdownBanner

Каждый интерактивный компонент несёт пять состояний: покой, наведение, нажатие,
недоступность, `:focus-visible`; асинхронное действие — ещё и `loading`.

## 5. HUD
Не больше пяти постоянных элементов на телефоне. Пять якорей, посередине экрана
не висит ничего, кроме временной обратной связи.

| Якорь | Что там |
|---|---|
| `bottom_left` | BreathHoldTouchZone |
| `bottom_right` | FireButtonAndAmmoCounter |
| `center` | ScopeCrosshairAndVignette |
| `top_left` | TargetObjectivesList |
| `top_right` | WindAndTimerWidget |

Элементы:
- Круглая маска оптического прицела с затемнением периферии и шкалой Mil-Dot
- Сегментированная дуговая шкала запаса воздуха (Breath Meter)
- Индикатор текущей кратности зума (4x / 8x / 16x)
- Мини-индикатор бокового ветра (скорость в м/с и стрелка направления)
- Список целей контракта в правом верхнем углу (аватар, имя, статус: ЖИВ / УСТРАНЕН)
- Таймер обратного отсчета до тревоги (появляется только при обнаружении)

Меняющиеся числа — `tabular-nums` в слоте фиксированной ширины, полосы —
`transform: scaleX()`, а не `width`. Текст поверх геймплея всегда с подложкой или
обводкой: белое число исчезает на светлой сцене.

## 6. Состояние, показанное миром, а не оверлеем
- Физическая сетка Mil-Dot, выгравированная на стекле оптической линзы
- Запотевание и капли конденсата по контуру окуляра при тяжелом дыхании
- Флажки и дым из труб на зданиях базы, показывающие реальное направление ветра

## 7. Каталог экранов
### Экран: briefing screen
- **Что на экране**: Тактическая карта базы, досье на цели, выбор оружия и кнопка «НАЧАТЬ ОПЕРАЦИЮ».; name: Экран Брифинга Контракта
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: gameplay hud
- **Что на экране**: Минималистичный интерфейс стрельбы с фокусом на перекрестии и индикаторах дыхания.; name: Игровой HUD Прицела
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: debriefing win
- **Что на экране**: Детализация выплат за скрытность, кнопка удвоения за рекламу и переход в оружейную.; name: Экран Завершения Контракта
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: arsenal screen
- **Что на экране**: 3D-просмотр винтовок, установка оптических прицелов, глушителей и покупка патронов.; name: Оружейная Мастерская
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

**Переходы**: Загрузка -> Главное меню -> Брифинг контракта -> Геймплей (Выцеливание/Слоу-мо/Выстрел) -> Kill-Cam финальной цели -> Дебрифинг контракта -> Оружейная -> Следующий контракт.

## 8. Состояния экрана
- Состояние идеального стелса (чистый зеленый HUD, спокойная музыка ветра)
- Состояние подозрения (желтые маркеры над ботами, затухание эмбиента)
- Состояние критической тревоги (красный мигающий баннер обратного отсчета)
- Состояние паузы (затемнение с тактической картой и настройками чувствительности)

## 9. Отклик и движение
- Прикосновение к кнопке дыхания -> мгновенный глухой звук пульса и визуальное размытие краев экрана
- Нажатие на спуск -> яркая вспышка, сотрясение прицела вверх, выброс гильзы со звоном
- Попадание в цель -> хруст попадания, кинематический отлет тела и появление маркера 'ХИТ'
- Срабатывание тревоги -> пульсирующий красный свет по краям экрана и нарастающий вой сирены

Переход один на всю игру и укладывается в 300 мс; анимируются только `transform`
и `opacity`; `prefers-reduced-motion: reduce` убирает трансформации.

## 11. Чек-лист приёмки интерфейса
- [ ] Ни одного литерала цвета, шрифта, радиуса или длительности вне `theme.css`.
- [ ] Слои над канвасом не перехватывают игровой ввод: контейнеры `pointer-events: none`.
- [ ] Каждый экран помещается в измеренный вьюпорт, страница не скроллится.
- [ ] Одно главное действие на экран, не больше двух акцентов одновременно.
- [ ] Меняющиеся числа не дёргают строку HUD.
- [ ] У каждого экрана описаны загрузка, пустота и ошибка.
- [ ] Возможность, которой нет на площадке, не нарисована вовсе.
- [ ] Ни `alert`/`confirm`, ни эмодзи вместо иконок, ни `z-index` мимо токенов.
- [ ] Самая длинная переведённая строка помещается в кнопку.
- [ ] За меню видна живая сцена игры, а не заливка цветом.
- [ ] Ни одного эмодзи в подписи кнопки: иконка — инлайновый SVG с `currentColor`.
- [ ] У каждого экрана расписаны три зоны, а не «карточка по центру».
- [ ] С закрытым игровым полем меню всё ещё узнаётся как «Снайпер: Призрачный Контракт».
