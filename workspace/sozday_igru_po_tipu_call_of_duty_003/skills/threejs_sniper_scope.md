# Skill: Three.js Sniper Scope & Optics Shader Skill

## Purpose
Создание кинематографичного шейдера оптического прицела с виньетированием, искажением линзы и сеткой Mil-Dot.

## When to Use
При разработке системы камеры от первого лица и эффектов задержки дыхания.

## Core Rules & Constraints
- Использовать единый полноэкранный проход шейдера для минимизации оверхенда GPU.
- Сетка Mil-Dot должна масштабироваться процедурно в шейдере без потери резкости.

## System Architecture
PostProcessingPass -> ScopeShaderMaterial -> Vignette & Reticle Uniforms.

## Implementation Guidance
Передавать фактор задержки дыхания в униформу шейдера для плавного изменения хроматической аберрации.

## Common Mistakes to Avoid
- ❌ **Mistake**: Использование тяжелых текстурных масок вместо математических шейдерных функций

## Validation Checklist
- [ ] 60 FPS на мобильных устройствах
- [ ] Отсутствие артефактов на экранах с разным соотношением сторон
