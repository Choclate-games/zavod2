# Core Loop Design: Ван-Тап: Дуэли на Крыше

## 1. Чем эта петля отличается
- **Фирменный момент**: Момент на 7-й секунде раунда: ты на микро-стрейфе выскальзываешь из-за стального двутавра, мгновенно прожимаешь противоположный вектор, фиксируя скорость в абсолютный 0.0 м/с за 80 мс; перекрестие Desert Eagle сжимается в точку, ты производишь один выверенный клик в голову выходящего из-за вентшахты соперника — его тактическая каска с ослепительным снопом золотых искр и звонким 'ДЗЫНЬ!' улетает в закатную бездну мегаполиса с высоты 70-го этажа в режиме 0.3-секундного Slow-mo.
- **Отличие от жанрового шаблона**: В отличие от стандартных мобильных/браузерных шутеров с автострельбой или аркадным бегом без штрафа на точность, здесь физика инерции и баллистический разброс жестко завязаны на состояние контр-стрейфа: малейшее движение (скорость > 0.5 м/с) дает 100% промах в сторону, а идеальная остановка клавишей противохода за 80 мс дарит лазерную точность. Компактная дуэльная арена на недостроенной крыше превращает каждый 15-секундный раунд в напряженную дуэль майндгеймсов и таймингов пика.
- **Сознательно НЕ берём**: Отвергнут шаблон «Спрей-контроль длинных очередей и позиционный холд (CS/Valorant full-buy round)»: В игре полностью отсутствуют хаотичные длинные зажимы на 30 патронов, заучивание паттернов отдачи, 2-минутные раунды с кемпингом за углами и сложная экономика гранат. Вместо этого — бескомпромиссная культура ван-тапов (1 выстрел — 1 труп или срыв каски), жесткий таймер на 15 секунд с обоюдным поражением за пассивность и мгновенная проверка микро-тайминга контр-стрейфа.

## 2. Схема петли
```text
+-----------------------------------------------------------------------------------+
|                           MACRO LOOP: РЕЙТИНГ И АРСЕНАЛ                           |
|  [Поиск дуэли] -> [Серия Best of 5 (60-90с)] -> [Награды / Скины] -> [Ранг 'Крыша'] |
+------------------------------------------+----------------------------------------+
                                           |
+------------------------------------------v----------------------------------------+
|                      MESO LOOP: СЕРИЯ РАУНДОВ BEST OF 5 (до 3 побед)              |
|  +-----------------------------------------------------------------------------+  |
|  | [Выбор ствола: Deagle/AK/AWP] -> [Спавн на крыше] -> [Дуэль 15с] -> [Счет]   |  |
|  +---------------------------------------+-------------------------------------+  |
+------------------------------------------|----------------------------------------+
                                           |
+------------------------------------------v----------------------------------------+
|                     MICRO LOOP: 15-СЕКУНДНЫЙ ОГНЕВОЙ КОНТАКТ                      |
|                                                                                   |
|    [1. Пре-эим из укрытия]                                                        |
|             |                                                                     |
|             v                                                                     |
|    [2. Стрейф-выход (A/D: 6.2 м/с)] ---> [Промах тайминга -> Разброс 12° -> Смерть]|
|             |                                                                     |
|             v                                                                     |
|    [3. Контр-стрейф (активный тормоз: V=0.0 м/с за 80 мс, прицел в точку)]        |
|             |                                                                     |
|             v                                                                     |
|    [4. Ван-Тап в голову (Raycast 120 мс, срыв каски, 'ДЗЫНЬ!', Slow-mo 0.3с)]     |
|             |                                                                     |
|             v                                                                     |
|    [5. Победа в раунде / Смена позиции укрытия]                                   |
+-----------------------------------------------------------------------------------+
```

## 6. Кривая напряжения
0–3 сек: Фаза саспенса и позиционирования — тишина на высоте 70-го этажа, слышен лишь свист ветра и эхо шагов соперника, пульс игрока умеренный (напряжение 20%); 3–7 сек: Фаза сближения и пре-пика — игроки подходят к углам укрытий, напряжение резко взлетает до 85%, перекрестие наведено на миллиметровую щель между балками; 7–8 сек: Взрывной пик контакта — стрейф, контр-стрейф, щелчок выстрела за 120 мс (пик напряжения 100%); 8–8.5 сек: Катарсис и разрядка — Slow-mo, звонкий срыв каски, золото искр, напряжение спадает до 10%; 9–15 сек (в случае затяжки): Паническая клаустрофобия — пульсирующий красный экран и тиканье таймера, вынуждающее идти ва-банк под угрозой Draw-Loss (напряжение 95%).

## 7. Формулы ядра
- `Формула скорости контр-стрейфа: V(t) = max(0, V_current - (a_base + a_counter * input_opposed) * dt), где a_base = 18.0 м/с², a_counter = 54.0 м/с², время полной остановки при контр-нажатии t_stop = 0.08 с (против 0.34 с при пассивном накате).`
- `Формула разброса при стрельбе: Spread_deg = Base_Spread + (V_player / V_max)^1.8 * Max_Move_Spread + Recoil_Penalty * (1 - e^(-t_since_last_shot / t_recovery)), где для Desert Eagle: Base_Spread = 0.05°, Max_Move_Spread = 14.5°, t_recovery = 0.42 с.`
- `Формула модификатора урона по зонам: Damage_Final = Base_Damage * Hitbox_Multiplier * Armor_Penetration, где для головы Multiplier = 4.0 (ван-тап 140 HP с гарантированным срывом каски), корпус Multiplier = 1.0 (35 HP), конечности Multiplier = 0.75 (26 HP).`
- `Формула времени реакции адаптивного ИИ: T_bot_reaction = clamp(T_base * (1.0 - WinStreak * 0.08) + random(-0.03, +0.03), 0.18, 0.55) секунд, где на ранге 'Новичок' T_bot = 0.50 с, на ранге 'Властелин Крыш' T_bot = 0.19 с.`
- `Формула очков дуэли: Score_Round = 1000 * (Headshot ? 1.5 : 1.0) * max(0.2, (15.0 - Round_Time) / 15.0) + (CounterStrafe_Quality > 0.95 ? 300 : 0).`
