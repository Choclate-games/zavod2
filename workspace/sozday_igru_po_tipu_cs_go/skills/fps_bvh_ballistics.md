# Skill: Three.js BVH Fast Raycasting & Micro-Hitbox System

## Purpose
Обеспечение прецизионного расчета лучей стрельбы и попаданий в миллиметровые хитбоксы каски без лагов рендера на 60 FPS.

## When to Use
При реализации стрельбы от первого лица, проверки зон попадания (голова/тело/конечности) и расчете декалей пуль.

## Core Rules & Constraints
- Никогда не создавать новые Raycaster объекты внутри игрового цикла (использовать синглтон)
- Хитбоксы персонажа должны быть слинкованы с костями анимации скелета через BVH-дерево
- При выстреле проверять пересечение только с активными BVH-нодами

## System Architecture
Модуль BallisticsEngine держит ссылку на BVH-меши персонажей и сцены, выполняет raycastFirst, определяет материал поверхности и генерирует событие DamageEvent.

## Implementation Guidance
Использовать библиотеку three-mesh-bvh, обновлять матрицу трансформации хитбокса головы в LateUpdate после обновления анимации скелета.

## Common Mistakes to Avoid
- ❌ **Mistake**: Вызов mesh.raycast на чистой геометрии Three.js без предварительного построения BVH-индекса
- ❌ **Mistake**: Игнорирование смещения камеры при отдаче ствола

## Validation Checklist
- [ ] BVH-дерево построено для всех статичных укрытий и динамических хитбоксов
- [ ] Raycaster переиспользуется
- [ ] Звуковой отклик попадания вызывается синхронно с детекцией луча
