# Skill: Mobile FPS Dual-Zone Touch & Counter-Strafe Handler

## Purpose
Реализация эргономичного сенсорного управления для соревновательного FPS без перегрузки виртуальными джойстиками.

## When to Use
При адаптации десктопного соревновательного шутера под мобильные экраны и браузеры.

## Core Rules & Constraints
- Левая зона обрабатывает только горизонтальное движение со стабилизацией по оси Y
- Правая зона доводки не должна сбрасывать вектор при случайном выходе пальца за край
- Тап по кнопке спуска не должен вносить рывок в координаты прицела

## System Architecture
TouchInputManager разделяет экран на две области по центру, отслеживает touchstart/touchmove/touchend с passive: false и передает нормализованные дельты в MovementController.

## Implementation Guidance
Применять экспоненциальный фильтр сглаживания (EMA) для устранения дрожания сенсора дешевых мобильных экранов.

## Common Mistakes to Avoid
- ❌ **Mistake**: Использование стандартного плавающего джойстика, требующего постоянного удержания пальца в определенном радиусе
- ❌ **Mistake**: Отсутствие компенсации безопасной зоны Safe Area

## Validation Checklist
- [ ] Касания не вызывают скролл страницы браузера (touch-action: none)
- [ ] Контр-стрейф срабатывает сразу при отпускании пальца
- [ ] Размер кнопки огня не менее 64x64px
