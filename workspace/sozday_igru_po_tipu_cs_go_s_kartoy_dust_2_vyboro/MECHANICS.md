# Mechanics Catalog: Dust 2: Ретейк и Дуэли

> Каждая механика описана до уровня, на котором её можно реализовать без
> додумывания: решение игрока, числа, состояния, режим отказа и сопротивление игры.

## Механика: Контр-стрейф и фиксация ствола (Counter-Strafing & Velocity Zeroing) (CORE)
- **Категория**: Фундаментальный двигатель боевой точности и тайминга дуэли.
- **Описание**: Честная физическая эмуляция механики Counter-Strike Source/GO с физикой трения и сбросом разброса без авто-наводки и искусственного занижения мобильной динамики.
- **Взаимодействие игрока**: ПК: Нажатие клавиши 'D' при беге влево ('A') или отпускание 'A' с тапом 'D'. Мобильные: Резкий свайп стика движения в противоположную сторону с отпусканием в центр.
- **Отклик**: Визуал/VFX: Динамические риски перекрестия прицела резко сжимаются в компактную точку при достижении порога остановки; на бегу прицел расширяется в 4 раза.; Звук (Web Audio): Мгновенный тихий глухой шуршащий звук трения подошвы о песок/плитку ('scuff step') в момент идеального торможения.; Камера: Мгновенное гашение покачивания камеры (head bobbing) с легким микро-толчком вперед на 0.05 единиц по оси Z.; UI/Тактильность: Короткий тактильный микро-отклик вибрации (10 мс) на мобильных устройствах в момент входа в зону нулевого разброса.
- **Техническая сложность**: Medium
- **Сильные стороны**: Высокая вовлеченность, Глубокая кривая мастерства
- **На что смотреть**: Требует точной калибровки таймингов

### Глубина механики
- **Роль в петле**: Фундаментальный двигатель боевой точности и тайминга дуэли.
- **Решение игрока**: В какой микро-момент прекратить движение и нажать противоположный стрейф, чтобы обнулить разброс строго перед нажатием на спуск.
- **Управление**: ПК: Нажатие клавиши 'D' при беге влево ('A') или отпускание 'A' с тапом 'D'. Мобильные: Резкий свайп стика движения в противоположную сторону с отпусканием в центр.
- **Состояния**: `moving_full_speed (250 u/s, разброс max)`, `counter_strafing (активное торможение противоходом)`, `zero_velocity_locked (<34 u/s, разброс 0 MOA)`, `firing_spread_cooldown (восстановление стабильности)`
- **Параметры и настройка**:
  - **Тайминг идеального контр-стрейфа**: `0.08 с` — Если увеличить до 0.25 с — стрельба станет вязкой и 'мыльной'; если уменьшить до 0.02 с — исчезнет механический скилл остановки, игра превратится в аркадный run-and-gun.
  - **Порог скорости нулевой неточности**: `34.0 units/s (0.85 м/с)` — Если поднять до 100 units/s — игроки смогут стрелять на бегу без наказания; если опустить до 5 units/s — любое микро-касание стика будет портить выстрел.
  - **Максимальная скорость бега с AK-47**: `215.0 units/s (5.38 м/с)` — Если увеличить — пики из-за угла станут нечеловечески быстрыми (peeker's advantage); если уменьшить — персонаж покажется неповоротливым.
  - **Штраф неточности на бегу**: `85.0 MOA` — Если уменьшить — пули будут случайно залетать в голову на бегу; если увеличить — при стрельбе на бегу пули будут улетать строго в пол/небо.
- **Слои отклика**:
  - Визуал/VFX: Динамические риски перекрестия прицела резко сжимаются в компактную точку при достижении порога остановки; на бегу прицел расширяется в 4 раза.
  - Звук (Web Audio): Мгновенный тихий глухой шуршащий звук трения подошвы о песок/плитку ('scuff step') в момент идеального торможения.
  - Камера: Мгновенное гашение покачивания камеры (head bobbing) с легким микро-толчком вперед на 0.05 единиц по оси Z.
  - UI/Тактильность: Короткий тактильный микро-отклик вибрации (10 мс) на мобильных устройствах в момент входа в зону нулевого разброса.
- **Режим отказа**: Игрок нажимает огонь до полной остановки (на скорости >34 u/s) — первая же пуля летит мимо цели на 1.5 метра в сторону, перекрестие прицела широко распахнуто, выдавая визуальный маркер ошибки тайминга.
- **Кривая мастерства**: Новичок на 30-й секунде стреляет во время бега и недоумевает, почему пули летят в молоко. Эксперт на 10-м матче делает jiggle-peek из-за угла с точностью до 2 кадров (33 мс), моментально выстреливая ровно одну пулю в пиксель головы врага и сразу уходя обратно в укрытие.
- **Сопротивление игры**: Боты высокой сложности считывают предсказуемые тайминги контр-стрейфа игрока и ставят прицел с пре-аимом на угол выхода, наказывая за повторный выход в той же позиции.
- **Синергии**:
  - Компенсация спрей-паттерна и темповые отсечки
  - Баллистический прострел укрытий и физика материалов
  - Обезвреживание C4, звуковой блеф и клатч-тайминги
- **Почему это не жанровый шаблон**: Честная физическая эмуляция механики Counter-Strike Source/GO с физикой трения и сбросом разброса без авто-наводки и искусственного занижения мобильной динамики.
- **Псевдокод тика**:
```text
function updateCounterStrafe(player, dt) {
  const vel = player.body.velocity.length();
  const isOppositePressed = (player.input.x * player.prevVelocity.x < 0);
  if (isOppositePressed) player.body.velocity.multiplyScalar(0.2);
  player.isInaccuracyZero = (vel < 34.0);
  player.crosshairSpread = player.isInaccuracyZero ? 0 : (vel / 250.0) * 85.0;
  if (player.isInaccuracyZero && !player.wasStable) playScuffSound();
  player.wasStable = player.isInaccuracyZero;
}
```

## Механика: Компенсация спрей-паттерна и темповые отсечки (Recoil Spray Pattern & Burst Fire) (SECONDARY)
- **Категория**: Источник риска при затяжной стрельбе и главный инструмент нанесения взрывного урона на средней дистанции.
- **Описание**: Детерминированный математический спрей-паттерн (фиксированная траектория смещения пуль), идентичный соревновательным ПК-шутерам, а не случайный конус разброса (Cone of Fire).
- **Взаимодействие игрока**: ПК: Зажатие ЛКМ с плавным смещением мыши вниз (пули 1-6), затем влево (пули 7-15) и вправо (пули 16-30). Мобильные: Удержание правой кнопки огня с одновременным свайпом правого пальца по контуру отдачи.
- **Отклик**: Визуал/VFX: Яркие конические вспышки дульного пламени с динамическим светом на стенах, трассеры пуль Three.js, вылетающие дымящиеся латунные гильзы 7.62 мм.; Звук (Web Audio): Сочный басовитый выстрел AK-47 с эхом в закрытых зонах (B-Tunnels) и сухим щелчком затвора при окончании патронов.; Камера: Процедурный толчок камеры вверх с последующим затухающим покачиванием по оси Pitch/Yaw (Spring Physics Euler).; UI/Тактильность: Динамическое смещение перекрестия прицела вверх вслед за спреем и нарастающая пульсирующая виброотдача каждого выстрела.
- **Техническая сложность**: Medium
- **Сильные стороны**: Высокая вовлеченность, Глубокая кривая мастерства
- **На что смотреть**: Требует точной калибровки таймингов

### Глубина механики
- **Роль в петле**: Источник риска при затяжной стрельбе и главный инструмент нанесения взрывного урона на средней дистанции.
- **Решение игрока**: Сделать ван-тап в голову, выпустить точную отсечку из 3 пуль или начать зажимать полный спрей с контролем формы 'семерки' при встрече с двумя врагами.
- **Управление**: ПК: Зажатие ЛКМ с плавным смещением мыши вниз (пули 1-6), затем влево (пули 7-15) и вправо (пули 16-30). Мобильные: Удержание правой кнопки огня с одновременным свайпом правого пальца по контуру отдачи.
- **Состояния**: `idle_weapon`, `tapping_single (1-я пуля, 100% точность)`, `burst_firing (2-4 пули, линейный подъем)`, `full_spray_control (5-30 пуль, горизонтальные колебания)`, `recoil_recovery (восстановление исходного угла ствола)`
- **Параметры и настройка**:
  - **Вертикальный подъем ствола AK-47**: `2.4 градуса/выстрел` — Если увеличить до 4.5° — экран будет мгновенно задираться в небо, делая зажим невозможным; если уменьшить до 0.8° — пропадет необходимость вести мышь вниз.
  - **Время восстановления отдачи (Recoil Decay)**: `0.32 с` — Если увеличить — стрельба одиночными станет слишком медленной; если уменьшить — зажим превратится в спам ван-тапами без пауз.
  - **Темп стрельбы AK-47**: `600 выстр/мин (10 выстр/с)` — Если ускорить — враги будут умирать за 100 мс без шанса на реакцию; если замедлить — оружие потеряет соревновательную хватку.
  - **Горизонтальный размах спрея**: `1.8 градуса` — Если убрать — отдача станет одномерной и примитивной; если сделать хаотичной — исчезнет механический навык заучивания паттерна.
- **Слои отклика**:
  - Визуал/VFX: Яркие конические вспышки дульного пламени с динамическим светом на стенах, трассеры пуль Three.js, вылетающие дымящиеся латунные гильзы 7.62 мм.
  - Звук (Web Audio): Сочный басовитый выстрел AK-47 с эхом в закрытых зонах (B-Tunnels) и сухим щелчком затвора при окончании патронов.
  - Камера: Процедурный толчок камеры вверх с последующим затухающим покачиванием по оси Pitch/Yaw (Spring Physics Euler).
  - UI/Тактильность: Динамическое смещение перекрестия прицела вверх вслед за спреем и нарастающая пульсирующая виброотдача каждого выстрела.
- **Режим отказа**: Игрок не уводит прицел вниз при зажиме — пули с 4-й по 30-ю улетают на 2 метра выше головы врага, оставляя следы декалей на стене за спиной соперника.
- **Кривая мастерства**: Новичок панически зажимает всю обойму в тело и попадает только первой пулей. Эксперт за доли секунды компенсирует отдачу первых 5 пуль строго в грудь и голову, оформляя фраги за 300 мс.
- **Сопротивление игры**: Враги используют укрытия и стрейфят между вашими очередями, вынуждая сбрасывать зажим и тратить 0.32 с на восстановление точности.
- **Синергии**:
  - Контр-стрейф и фиксация ствола
  - Баллистический прострел укрытий и физика материалов
  - Тактическое зонирование дымовой завесой
- **Почему это не жанровый шаблон**: Детерминированный математический спрей-паттерн (фиксированная траектория смещения пуль), идентичный соревновательным ПК-шутерам, а не случайный конус разброса (Cone of Fire).
- **Псевдокод тика**:
```text
function processRecoil(weapon, isShooting, dt) {
  if (isShooting && weapon.ammo > 0) {
    weapon.shotIndex++;
    const patternOffset = getRecoilPattern(weapon.id, weapon.shotIndex);
    camera.pitch += patternOffset.pitch * dt;
    camera.yaw += patternOffset.yaw * dt;
    spawnBulletRaycast(camera.direction.add(patternOffset));
  } else {
    weapon.shotIndex = Math.max(0, weapon.shotIndex - dt * 15);
    camera.pitch = lerp(camera.pitch, 0, dt * 12.0);
  }
}
```

## Механика: Обезвреживание C4, звуковой блеф и клатч-тайминги (C4 Defusal & Audio Bluff Clutch) (SECONDARY)
- **Категория**: Главный источник финального напряжения, риска и эмоциональной кульминации раунда.
- **Описание**: Глубокая психологическая игра на слух (Mind Games): звук начала дефьюза слышен на весь плент и является главным катализатором дуэли 1v1.
- **Взаимодействие игрока**: ПК: Зажатие и удержание клавиши 'E' (или F) при наведении на C4. Мобильные: Удержание большой круглой кнопки 'DEFUSE' по центру экрана.
- **Отклик**: Визуал/VFX: Голографический круговой прогресс-бар дефьюза на экране, синие искры разрезаемых проводов C4, мигающий красным диод бомбы с нарастающей частотой.; Звук (Web Audio): Громкий характерный металлический щелчок открытия кейса C4 (слышен на 20 метров всем игрокам), ускоряющийся писк зуммера (1 Гц -> 2 Гц -> 4 Гц -> 8 Гц).; Камера: Ограничение угла поворота камеры до 70 градусов во время удержания дефьюза, фокусировка взгляда на объективе бомбы.; UI/Тактильность: Нарастающая частая пульсирующая вибрация смартфона в последние 5 секунд до взрыва, крупный таймер обратного отсчета.
- **Техническая сложность**: Medium
- **Сильные стороны**: Высокая вовлеченность, Глубокая кривая мастерства
- **На что смотреть**: Требует точной калибровки таймингов

### Глубина механики
- **Роль в петле**: Главный источник финального напряжения, риска и эмоциональной кульминации раунда.
- **Решение игрока**: Зажать дефьюз до конца, надеясь на укрытие в дыму, или сделать фейк-дефьюз на 0.15 с, спровоцировать врага на пик и встретить его префаером.
- **Управление**: ПК: Зажатие и удержание клавиши 'E' (или F) при наведении на C4. Мобильные: Удержание большой круглой кнопки 'DEFUSE' по центру экрана.
- **Состояния**: `bomb_ticking (свободный таймер 35.0 с)`, `defusing_active (игрок прикован к радиусу бомбы)`, `fake_defuse_cancelled (мгновенная отмена для стрельбы)`, `bomb_defused_victory`, `bomb_detonated_loss`
- **Параметры и настройка**:
  - **Базовое время разминирования C4**: `10.0 с` — Если уменьшить до 5.0 с — спецназу не понадобятся саперные наборы; если увеличить до 15.0 с — шансы на ретейк упадут до нуля.
  - **Время разминирования с набором сапёра (Kit)**: `5.0 с` — Если уменьшить до 3.0 с — террористы не успеют среагировать на звук; если увеличить до 7.0 с — ценность набора сапёра нивелируется.
  - **Таймер детонатора C4**: `35.0 с` — Если сделать 45 с — раунд станет слишком затянутым для браузера; если сделать 20 с — спецназ не успеет зайти на точку.
  - **Радиус взаимодействия с C4**: `2.2 метра` — Если увеличить — можно будет дефьюзить из-за глухих углов; если уменьшить — придется стоять вплотную на открытом месте.
- **Слои отклика**:
  - Визуал/VFX: Голографический круговой прогресс-бар дефьюза на экране, синие искры разрезаемых проводов C4, мигающий красным диод бомбы с нарастающей частотой.
  - Звук (Web Audio): Громкий характерный металлический щелчок открытия кейса C4 (слышен на 20 метров всем игрокам), ускоряющийся писк зуммера (1 Гц -> 2 Гц -> 4 Гц -> 8 Гц).
  - Камера: Ограничение угла поворота камеры до 70 градусов во время удержания дефьюза, фокусировка взгляда на объективе бомбы.
  - UI/Тактильность: Нарастающая частая пульсирующая вибрация смартфона в последние 5 секунд до взрыва, крупный таймер обратного отсчета.
- **Режим отказа**: Игрок начинает дефьюз без набора сапёра на 7-й секунде до взрыва (требуется 10 с) — бомба детонирует прямо в руках на 50% прогресса, сотрясая экран вспышкой взрыва.
- **Кривая мастерства**: Новичок боится подойти к бомбе или сидит на дефьюзе 'намертво', погибая от первой пули. Эксперт по звуку шагов определяет позицию террориста, дает фейк-клик дефьюза (0.1 с), разворачивается и мгновенно убивает выбежавшего врага.
- **Сопротивление игры**: Террористы не выходят на первый звук щелчка C4, выжидая 2.5 секунды, или простреливают дым по позиции установки бомбы.
- **Синергии**:
  - Тактическое зонирование дымовой завесой
  - Баллистический прострел укрытий и физика материалов
  - Контр-стрейф и фиксация ствола
- **Почему это не жанровый шаблон**: Глубокая психологическая игра на слух (Mind Games): звук начала дефьюза слышен на весь плент и является главным катализатором дуэли 1v1.
- **Псевдокод тика**:
```text
function updateDefusal(c4, player, dt) {
  if (player.isHoldingDefuseKey && distance(player, c4) <= 2.2) {
    if (!c4.isDefusing) { c4.isDefusing = true; broadcast3DSound('defuse_start', c4.pos); }
    const rate = player.hasKit ? (dt / 5.0) : (dt / 10.0);
    c4.defuseProgress += rate;
    if (c4.defuseProgress >= 1.0) triggerRoundWin('CT', 'bomb_defused');
  } else {
    if (c4.isDefusing) { c4.isDefusing = false; broadcast3DSound('defuse_abort', c4.pos); }
  }
}
```

## Механика: Тактическое зонирование дымовой завесой (Smoke Screen Tactical Denial) (SECONDARY)
- **Категория**: Инструмент временной блокады углов обзора и безопасного пересечения простреливаемых зон (Long/Cross).
- **Описание**: Плотная физическая геометрия видимости Raycast: внутри дыма дистанция обзора падает до 0.8 метра, превращая дуэль в контактный бой в упор.
- **Взаимодействие игрока**: ПК: Выбор клавишей '4' (или колесом мыши) -> бросок на ЛКМ (дальний навес) или ПКМ (короткий подброс под ноги). Мобильные: Тап по иконке гранаты -> кнопка броска.

```text
function checkWallbangRay(origin, dir, maxDist) {
  const hit = raycastFirst(origin, dir, maxDist);
  if (!hit) return null;
  if (hit.material.penetrable) {
    const exitHit = raycastReverse(hit.point.add(dir.clone().multiplyScalar(hit.material.maxDepth)), dir.negate());
    const thickness = hit.point.distanceTo(exitHit.point);
    if (thickness <= hit.material.maxDepth) {
      const remainingDmg = baseDamage * hit.material.dmgModifier * (1.0 - thickness / hit.material.maxDepth);
      return applyDamageBehindWall(exitHit.point, dir, remainingDmg);
    }
  }
  spawnSparkDecal(hit.point, hit.normal);
}
```
