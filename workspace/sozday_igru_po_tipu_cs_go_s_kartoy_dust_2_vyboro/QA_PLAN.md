# QA & Testing Plan: Dust 2: Ретейк и Дуэли

## 1. Functional Test Matrix
- [ ] Проверка мгновенного сброса разброса пуль при выполнении контр-стрейфа
- [ ] Проверка корректной регистрации попаданий в хитбоксы головы, тела и ног
- [ ] Проверка таймера C4 (ровно 35 секунд до взрыва) и времени дефьюза (5с с китом, 10с без кита)
- [ ] Проверка завершения матча при достижении одной из команд 3 побед в раундах

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS на средних смартфонах (Mali G52 / Adreno 610)
- [ ] Время загрузки 3D-сцены и текстур менее 3.0 секунд на соединении 4G
- [ ] Потребление оперативной памяти вкладки браузера не более 250 МБ
- [ ] Количество Draw Calls в кадре не превышает 75

## 3. Target Browser Matrix
- Chrome Desktop / Mobile (WebGL 2.0)
- Safari iOS (Mobile WebKit, WebAudio touch unlock)
- Yandex Browser Desktop / Mobile
- Firefox Desktop
