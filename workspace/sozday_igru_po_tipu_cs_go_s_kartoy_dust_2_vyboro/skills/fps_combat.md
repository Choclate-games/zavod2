# Skill: FPS Controller and Ballistics

## Purpose
Обеспечение аутентичной физики стрельбы, контр-стрейфа и спрея оружия

## When to Use
При разработке механики передвижения и стрельбы от первого лица

## Core Rules & Constraints
- Кучность стрельбы строго зависит от текущей скорости перемещения
- Спрей имеет детерминированный паттерн отдачи для каждого типа оружия

## System Architecture
Модульный WeaponManager и PlayerMotor с интеграцией Three.js и Rapier3D

## Implementation Guidance
Использование Continuous Collision Detection для лучей пуль и таблиц смещения спрея

## Common Mistakes to Avoid
- ❌ **Mistake**: Стрельба без учета контр-стрейфа превращает игру в казуальную аркаду

## Validation Checklist
- [ ] Проверен мгновенный сброс разброса при остановке персонажа
- [ ] Настроены точные хитбоксы головы, тела и ног с множителем урона
