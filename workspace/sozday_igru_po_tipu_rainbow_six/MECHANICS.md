# Mechanics Catalog: Тактика Прорыва: CQB Штурм

> Каждая механика описана до уровня, на котором её можно реализовать без
> додумывания: решение игрока, числа, состояния, режим отказа и сопротивление игры.

## Механика: Взрывной Бричинг Укреплений (Breach Dynamics) (CORE)
- **Категория**: combat
- **Описание**: Установка направленного бричинг-заряда C4 или термической ленты на слабую зону стены/двери с последующим дистанционным подрывом, физическим разломом преграды и оглушением противников за ней.
- **Взаимодействие игрока**: ПКМ / Тап по подсвеченной зоне стены — прикрепить заряд C4; Пробел / Кнопка кликера детонатора — дистанционный подрыв; Свайп двумя пальцами вниз — отмена и снятие заряда.
- **Отклик**: Визуал/VFX: Вспышка взрыва с объемным дымовым грибом, разлет 32 трехмерных фрагментов штукатурки и арматуры с расчетом коллизий Rapier3D, оседающая белая взвесь строительной пыли.; Звук (Web Audio): Низкочастотный саб-басовый взрыв (45 Гц sine-drop) с последующим высокочастотным свистом в ушах (Tinnitus notch-filter на 4.2 кГц) и грохотом падающих обломков.; Камера: Травматический импульсный шейк (амплитуда 0.35 м, затухание 0.4 с), динамический зум FOV с 75 градусов до 62 градусов в момент вспышки и плавный возврат.; UI/Тактильность: Короткая двойная вибрация (Haptic feedback 80 мс / 120 мс) на мобильных устройствах, красный индикатор радиуса ударной волны на полу, маркер BREACH SUCCESS.
- **Техническая сложность**: Medium
- **Сильные стороны**: Невероятная зрелищность и кинематографичность первого контакта, Тактическая свобода выбора вектора атаки
- **На что смотреть**: Требует строгого контроля пула физических мешей для удержания 60 FPS

### Глубина механики
- **Роль в петле**: Двигатель штурма и трансформатор геометрии арены
- **Решение игрока**: Куда и какой заряд установить: пробить деревянную дверь по центру или наложить C4 на слабую гипсокартонную стену сбоку, чтобы зайти во фланг террористам и поразить их разлетающимися обломками.
- **Управление**: ПКМ / Тап по подсвеченной зоне стены — прикрепить заряд C4; Пробел / Кнопка кликера детонатора — дистанционный подрыв; Свайп двумя пальцами вниз — отмена и снятие заряда.
- **Состояния**: `READY_TO_DEPLOY (оперативник держит заряд, зоны стен подсвечены желтым/зеленым)`, `ATTACHED_ARMED (заряд на стене, диод мигает зеленым с частотой 2 Гц, активна кнопка подрыва)`, `DETONATION_IMPACT (триггер подрыва, спавн взрывной волны, фрагментация полигональной сетки на 32 твердых тела Rapier3D)`, `BREACH_SMOKE_CLEARING (рассеивание пылевого облака в течение 3.5 с, образование постоянного проема)`
- **Параметры и настройка**:
  - **charge_placement_time**: `0.65 с` — Если уменьшить до 0.2 с — теряется вес и уязвимость установки; если увеличить до 1.5 с — ломается динамика мобильной сессии.
  - **blast_radius_lethal**: `2.2 м` — Если увеличить до 4.0 м — взрыв убивает всех врагов за стеной без участия игрока; если уменьшить до 1.0 м — осколки не задевают прилегающие укрытия.
  - **wall_fragment_count**: `32 шт` — Если сделать 8 шт — разрушение выглядит дешево и плоско; если сделать больше 60 шт — просаживается FPS в браузере Three.js на мобильных устройствах.
  - **safe_standoff_distance**: `2.5 м` — Если игрок стоит ближе 2.5 м к стене без щита — получает 45 ед. урона и контузию на 1.8 с; если дистанция 0 м — исчезает необходимость тактического отхода.
- **Слои отклика**:
  - Визуал/VFX: Вспышка взрыва с объемным дымовым грибом, разлет 32 трехмерных фрагментов штукатурки и арматуры с расчетом коллизий Rapier3D, оседающая белая взвесь строительной пыли.
  - Звук (Web Audio): Низкочастотный саб-басовый взрыв (45 Гц sine-drop) с последующим высокочастотным свистом в ушах (Tinnitus notch-filter на 4.2 кГц) и грохотом падающих обломков.
  - Камера: Травматический импульсный шейк (амплитуда 0.35 м, затухание 0.4 с), динамический зум FOV с 75 градусов до 62 градусов в момент вспышки и плавный возврат.
  - UI/Тактильность: Короткая двойная вибрация (Haptic feedback 80 мс / 120 мс) на мобильных устройствах, красный индикатор радиуса ударной волны на полу, маркер BREACH SUCCESS.
- **Режим отказа**: Игрок подрывает стену, находясь слишком близко без поднятого щита (получает контузию и потерю 45 HP), либо устанавливает C4 на армированную сталь без термоленты (заряд детонирует вхолостую). Сигнал: красный крест на детонаторе и металлический звон.
- **Кривая мастерства**: Новичок на 30-й секунде взрывает только центральные двери и попадает под встречный огонь. Эксперт на 10-м забеге использует накладной заряд для кинетического рикошета обломков стены, убивая зазевавшегося наемника физикой летящего куска бетона без единого выстрела.
- **Сопротивление игры**: Враги укрепляют стены титановыми кевларовыми щитами (требуют термического прожига 4.0 с) и устанавливают сейсмические датчики движения, открывая огонь насквозь через стену при шуме установки C4.
- **Синергии**:
  - Штурмовой Slow-Mo Фокус: детонация стены автоматически триггерит окно замедления времени 0.2x.
  - Эндоскопическая Разведка: эндоскоп подсвечивает точные стыки арматуры для максимального радиуса разлета обломков.
  - Баллистический Щит: щит полностью поглощает фронтальную взрывную волну при близком подрыве.
- **Почему это не жанровый шаблон**: В отличие от скриптовых взрывов в обычных шутерах, здесь разрушение является честным физическим процессом на Rapier3D: выбитая дверь превращается в тяжелый физический снаряд, сбивающий врагов с ног.
- **Псевдокод тика**:
```text
function onBreachDetonate(charge: C4Charge, wall: DestructibleWall): void {
  if (wall.isReinforced && !charge.hasThermite) { playDudSparks(charge.pos); return; }
  const fragments = RapierPhysics.fractureMesh(wall.mesh, 32);
  fragments.forEach(f => f.applyImpulse(calcBlastVector(charge.pos, f.pos, 450)));
  const enemiesInRadius = SpatialGrid.queryRadius(charge.pos, 3.5);
  enemiesInRadius.forEach(e => e.applyStun(calcStunDuration(e.distance, 2.5)));
  TimeDilationSystem.triggerSlowMo(2.0, 0.2);
  AudioEngine.playSpatialSubBoom(charge.pos, 1.0);
}
```

## Механика: Штурмовой Slow-Mo Фокус (Breach-Focus Time) (CORE)
- **Категория**: combat
- **Описание**: В момент детонации время замедляется до 20% на 1.5–3.0 секунды. Ослепленные террористы медленно роняют оружие или пытаются вскинуть стволы, пока игрок методично распределяет прицельные выстрелы.
- **Взаимодействие игрока**: Активируется автоматически при детонации пролома; Повторный клик Shift / Тап по индикатору пульса — досрочный выход из Slow-Mo для сохранения энергии фокуса.
- **Отклик**: Визуал/VFX: Эффект радиального размытия по краям экрана (Radial Blur), яркие замедленные трассеры выстрелов с дымовым следом, зависшие в воздухе гильзы и крупицы штукатурки.; Звук (Web Audio): Приглушение всех высоких частот через Low-Pass Filter (срез 400 Гц), ритмичный тяжелый стук сердца (Heartbeat 55 BPM), выстрелы звучат как раскатистые басовые удары.; Камера: Плавный кинематографичный наезд камеры вперед (Dolly Zoom +0.3 м), динамическая стабилизация прицельной марки.; UI/Тактильность: Пульсирующая полоса адреналина в центре экрана, замедленное тиканье таймера штурма, легкая непрерывная микровибрация устройства.
- **Техническая сложность**: Medium
- **Сильные стороны**: Идеальная точность прицеливания на мобильных устройствах без виртуальных стиков, Устраняет хаотичный спам выстрелов, превращая бой в тактическую головоломку
- **На что смотреть**: Требует точной калибровки таймера замедления для сохранения челленджа

### Глубина механики
- **Роль в петле**: Двигатель точности и источник тактического превосходства (высокая награда за мастерство)
- **Решение игрока**: Как распределить 2.0 секунды замедления: сделать 3 быстрых хедшота по открытым целям или потратить время на поиск и отстрел капсюля лазерной мины-растяжки.
- **Управление**: Активируется автоматически при детонации пролома; Повторный клик Shift / Тап по индикатору пульса — досрочный выход из Slow-Mo для сохранения энергии фокуса.
- **Состояния**: `REALTIME_ACTIVE (время течет 1.0x, прицел стандартного размера)`, `SLOWMO_ENTER (плавная интерполяция таймскейла от 1.0x до 0.2x за 0.12 с, включение хроматической аберрации)`, `SLOWMO_RUNNING (посекундный расход шкалы адреналина, подсветка трассеров пуль и уязвимых зон врагов)`, `SLOWMO_EXIT (щелчок затвора, возврат таймскейла в 1.0x за 0.18 с, восстановление звукового спектра)`
- **Параметры и настройка**:
  - **time_dilation_scale**: `0.20x` — Если сделать 0.05x (Superhot) — бой превращается в пошаговую головоломку без адреналина; если сделать 0.5x — мобильные игроки не успевают навестись пальцем.
  - **base_focus_duration**: `2.0 с` — Если уменьшить до 0.8 с — игрок успевает сделать лишь 1 выстрел; если увеличить до 4.5 с — пропадает напряжение и цена промаха.
  - **headshot_time_refund**: `0.35 с` — Если убрать — нет стимула стрелять точно в голову; если сделать 1.0 с — опытный игрок находится в бесконечном Slow-Mo.
  - **player_turn_speed_multiplier**: `1.8x` — Враги замедлены в 5 раз, но прицел игрока сохраняет высокую чувствительность (1.8x) для удобной микро-доводки на тачскрине.
- **Слои отклика**:
  - Визуал/VFX: Эффект радиального размытия по краям экрана (Radial Blur), яркие замедленные трассеры выстрелов с дымовым следом, зависшие в воздухе гильзы и крупицы штукатурки.
  - Звук (Web Audio): Приглушение всех высоких частот через Low-Pass Filter (срез 400 Гц), ритмичный тяжелый стук сердца (Heartbeat 55 BPM), выстрелы звучат как раскатистые басовые удары.
  - Камера: Плавный кинематографичный наезд камеры вперед (Dolly Zoom +0.3 м), динамическая стабилизация прицельной марки.
  - UI/Тактильность: Пульсирующая полоса адреналина в центре экрана, замедленное тиканье таймера штурма, легкая непрерывная микровибрация устройства.
- **Режим отказа**: Игрок паникует, делает хаотичные выстрелы в корпус, не убивает ключевых врагов за отведенные 2.0 секунды и оказывается в реальном времени под перекрестным огнем с пустым магазином. Сигнал: резкий срыв звукового фильтра в 1.0x, визг врагов и красный экран попаданий.
- **Кривая мастерства**: Новичок за время замедления убивает 1 врага и тратит весь магазин. Эксперт за 1.8 с делает 3 выверенных хедшота с компенсацией отдачи и выбивает мину, продлевая Slow-Mo бонусами точности.
- **Сопротивление игры**: Элитные наемники в Комнате 3 экипированы тактическими шлемами со стимуляторами адреналина — их время реакции замедляется лишь до 0.6x (они открывают ответный огонь прямо в Slow-Mo).
- **Синергии**:
  - Взрывной Бричинг: качественный подрыв в центр стены дает +25% к длительности Slow-Mo.
  - Баллистический Щит: возможность безопасно оценить траектории пуль противников во время замедления.
  - Эндоскопическая Разведка: заранее размеченные цели подсвечиваются яркими силуэтами в Slow-Mo.
- **Почему это не жанровый шаблон**: Slow-Mo здесь не бесконечное и не включается кнопкой когда угодно — это строго регламентированное тактическое окно кинематографичной зачистки, открываемое только успешным бричингом.
- **Псевдокод тика**:
```text
function updateSlowMoTick(dt: number, focusState: FocusData): void {
  if (!focusState.isActive) return;
  focusState.remainingTime -= dt;
  AudioEngine.setLowPassCutoff(THREE.MathUtils.lerp(400, 20000, 1.0 - focusState.remainingTime / 2.0));
  if (PlayerWeapon.onEnemyHit(HitZone.HEAD)) {
    focusState.remainingTime = Math.min(focusState.remainingTime + 0.35, 3.0);
    VFXEngine.spawnHeadshotSpark(PlayerWeapon.targetPos);
  }
  if (focusState.remainingTime <= 0) {
    TimeDilationSystem.setTimeScale(1.0);
    focusState.isActive = false;
  }
}
```

## Механика: Баллистический Щит и Тактические Наклоны (Tactical Shield & Lean) (CORE)
- **Категория**: defense
- **Описание**: Использование ростового бронещита со смотровым окном. Защищает от фронтального огня, позволяя выглядывать влево/вправо (Lean Q/E) для ведения беглого прицельного огня.
- **Взаимодействие игрока**: Клавиши Q / E (или кнопки-стрелки по краям экрана на мобильных) — наклон влево/вправо; Зажатие ПКМ — поднятие щита в глухую оборону; ЛКМ — выстрел из пистолета с упора.
- **Отклик**: Визуал/VFX: Искры и вмятины на бронеплите щита при попаданиях, нарастающая паутина трещин на баллистическом стекле, дым от пороховых газов при выстреле с упора.; Звук (Web Audio): Звонкий металлический лязг рикошетов пуль о сталь (Bell-metallic ping), глухой стук попаданий в титан, механический скрежет фиксаторов щита при наклоне.; Камера: Смещение оси камеры на 0.45 м вбок с креном 14 градусов, легкий толчок назад (0.05 м) при поглощении тяжелых пуль щитом.; UI/Тактильность: Индикатор целостности щита (Shield Durability bar) и смотрового окна, сильная прерывистая виброотдача при пулеметном обстреле щита.
- **Техническая сложность**: Medium
- **Сильные стороны**: Глубокий позиционный геймплей с контролем углов обзора, Дает игроку инструмент защиты от мгновенного ваншота
- **На что смотреть**: Сужает угол периферийного зрения, делая игрока уязвимым с флангов

### Глубина механики
- **Роль в петле**: Защитный стабилизатор и регулятор риска (баланс между неуязвимостью и открытием для стрельбы)
- **Решение игрока**: Оставаться в глухой фронтальной защите, принимая пули на бронесталь, или выглянуть вправо (Lean E) на 0.4 секунды для прицельного выстрела, подставив открытое плечо.
- **Управление**: Клавиши Q / E (или кнопки-стрелки по краям экрана на мобильных) — наклон влево/вправо; Зажатие ПКМ — поднятие щита в глухую оборону; ЛКМ — выстрел из пистолета с упора.
- **Состояния**: `FULL_GUARD (щит закрывает 80% экрана, скорость движения -40%, 100% защита от пуль спереди)`, `LEAN_PEEKING (камера и ствол вынесены в сторону на 0.45 м, открыта уязвимая зона руки/плеча)`, `GLASS_CRACKED (смотровое стекло получило критический урон, обзор затруднен паутиной трещин)`, `SHIELD_STAGGER (попадание тяжелой пули/гранаты выбивает щит в сторону на 0.65 с)`
- **Параметры и настройка**:
  - **shield_hp_max**: `350 ед` — Если сделать 100 ед — щит разбивается за 2 выстрела и теряет смысл; если сделать 1000 ед — игрок становится бессмертным танком.
  - **lean_angle_deg**: `14 градусов` — Если уменьшить до 5 градусов — наклон не дает угла обзора за угол; если увеличить до 30 градусов — моделька неестественно падает вбок.
  - **lean_transition_time**: `0.18 с` — Если уменьшить до 0.05 с — нет ощущения массы титанового щита; если увеличить до 0.5 с — игрок не успевает стрелять между очередями врагов.
  - **glass_durability_shots**: `12 пуль` — После 12 попаданий в триплекс стекло покрывается плотной сеткой трещин, вынуждая выглядывать из-за щита вслепую.
- **Слои отклика**:
  - Визуал/VFX: Искры и вмятины на бронеплите щита при попаданиях, нарастающая паутина трещин на баллистическом стекле, дым от пороховых газов при выстреле с упора.
  - Звук (Web Audio): Звонкий металлический лязг рикошетов пуль о сталь (Bell-metallic ping), глухой стук попаданий в титан, механический скрежет фиксаторов щита при наклоне.
  - Камера: Смещение оси камеры на 0.45 м вбок с креном 14 градусов, легкий толчок назад (0.05 м) при поглощении тяжелых пуль щитом.
  - UI/Тактильность: Индикатор целостности щита (Shield Durability bar) и смотрового окна, сильная прерывистая виброотдача при пулеметном обстреле щита.
- **Режим отказа**: Игрок жадничает, задерживает наклон (Lean) дольше 0.5 с во время очереди пулеметчика и ловит летальные пули в открытое плечо. Сигнал: кровавый всплеск на экране и стон ранения бойца.
- **Кривая мастерства**: Новичок сидит в глухой обороне, пока враги не разобьют стекло щита. Эксперт ритмично использует Quick-Lean Peek за 0.18 с в паузах между выстрелами террористов, не получая урона в тело.
- **Сопротивление игры**: Враги бросают гранаты под ноги за щит и заходят с двух флангов одновременно, перегружая фронтальный сектор блокирования.
- **Синергии**:
  - Штурмовой Slow-Mo: в замедлении наклоны позволяют филигранно уворачиваться от летящих трассеров.
  - Взрывной Бричинг: щит полностью блокирует осколки собственной взрывчатки при близком подрыве.
  - Обезвреживание СВУ: возможность одной рукой держать щит в сторону врага во время разрезания проводов.
- **Почему это не жанровый шаблон**: Щит — это не пассивная прибавка к броне, а физический трехмерный объект в пространстве: игрок вручную позиционирует его плоскость относительно вражеских дул.
- **Псевдокод тика**:
```text
function processShieldBlock(incomingBullet: Bullet, shield: BallisticShield, isLeaning: boolean): HitResult {
  if (isLeaning && isHitExposedArm(incomingBullet.ray)) {
    return PlayerHealth.applyDirectDamage(incomingBullet.damage);
  }
  if (shield.bounds.intersectsRay(incomingBullet.ray)) {
    shield.durability -= incomingBullet.caliberPower;
    VFXEngine.spawnSparks(incomingBullet.impactPoint, shield.normal);
    AudioEngine.playMetalRicochet(incomingBullet.caliber);
    if (shield.isGlassHit(incomingBullet.impactPoint)) shield.addGlassCrack();
    return HitResult.BLOCKED;
  }
  return PlayerHealth.applyDirectDamage(incomingBullet.damage);
}
```

## Механика: Эндоскопическая Разведка (Optic-Wand Recon) (SUPPORTING)
- **Категория**: tactics
- **Описание**: Просовывание гибкого кабеля с камерой под дверную щель или в технологическое отверстие перед штурмом для обнаружения позиций террористов и растяжек с взрывчаткой.
- **Взаимодействие игрока**: Удержание клавиши 'F' / Кнопка 'Камера' на экране — опустить кабель эндоскопа под дверь; Перемещение мыши / Джойстик — вращение микрокамеры на 120 градусов; Клик ЛКМ — расстановка тактических меток.
- **Отклик**: Визуал/VFX: Зернистый монохромный зеленый интерфейс микрокамеры (Night-Vision CRT-noise), красные тепловые силуэты наемников сквозь дым, желтые контуры растяжек C4.; Звук (Web Audio): Высокочастотный электронный писк включения ночного видения (12 кГц beep), приглушенные радиопереговоры террористов за дверью, звук жужжания микромотора кабеля.; Камера: Переключение на широкоугольный объектив типа 'рыбий глаз' (Fisheye distorsion 0.35) с легким виньетированием.; UI/Тактильность: Наложение тактической сетки с дальномером, появление постоянных 3D-маркеров врагов над дверным полотном после выхода из режима.
- **Техническая сложность**: Low
- **Сильные стороны**: Награждает вдумчивое планирование и устраняет элемент случайной гибели, Усиливает атмосферу спецоперации спецназа
- **На что смотреть**: Расходует драгоценные секунды общего таймера операции

### Глубина механики
- **Роль в петле**: Информационный двигатель и тактический предвестник штурма (снижение неопределенности)
- **Решение игрока**: Потратить 3 секунды на детальный осмотр комнаты через щель, чтобы выявить растяжки и расстановку наемников, или пойти на быстрый слепой штурм ради сохранения таймера миссии.
- **Управление**: Удержание клавиши 'F' / Кнопка 'Камера' на экране — опустить кабель эндоскопа под дверь; Перемещение мыши / Джойстик — вращение микрокамеры на 120 градусов; Клик ЛКМ — расстановка тактических меток.
- **Состояния**: `RECON_INACTIVE (вид от первого лица перед запертой дверью)`, `CABLE_DEPLOYING (анимация просовывания гибкого зонда под дверное полотно 0.8 с)`, `OPTIC_SCANNING (монохромный интерфейс ночного видения/тепловизора, маркировка угроз)`, `RECON_RETRACTING (быстрый возврат камеры в штурмовую позицию 0.4 с)`
- **Параметры и настройка**:
  - **scan_field_of_view**: `120 градусов` — Если уменьшить до 45 градусов — игрок не видит засады по углам комнат; если сделать 360 градусов — теряется необходимость крутить камеру зонда.
  - **recon_time_cost**: `3.5 с` — Время штурмового таймера продолжает тикать во время разведки, создавая баланс между безопасностью и спешкой.
  - **max_threat_tags**: `4 метки` — Ограничение на количество подсвечиваемых сквозь стену целей (приоритезация самых опасных врагов).
  - **recon_noise_level**: `15 дБ` — Если держать камеру под дверью дольше 6 секунд, патрульный боевик может заметить зонд и прострелить дверь сверху.
- **Слои отклика**:
  - Визуал/VFX: Зернистый монохромный зеленый интерфейс микрокамеры (Night-Vision CRT-noise), красные тепловые силуэты наемников сквозь дым, желтые контуры растяжек C4.
  - Звук (Web Audio): Высокочастотный электронный писк включения ночного видения (12 кГц beep), приглушенные радиопереговоры террористов за дверью, звук жужжания микромотора кабеля.
  - Камера: Переключение на широкоугольный объектив типа 'рыбий глаз' (Fisheye distorsion 0.35) с легким виньетированием.
  - UI/Тактильность: Наложение тактической сетки с дальномером, появление постоянных 3D-маркеров врагов над дверным полотном после выхода из режима.
- **Режим отказа**: Игрок задерживается в режиме эндоскопа слишком долго, террорист замечает объектив под дверью, кричит Контакт! и стреляет очередью сквозь дверь в лицо оперативнику. Сигнал: резкий треск помех на экране сканера и падение HP.
- **Кривая мастерства**: Новичок осматривает только середину комнаты и пропускает растяжку у порога. Эксперт за 1.5 секунды сканирует углы, ставит метку на пулеметчика и сразу переходит к установке C4 точно напротив головы командира.
- **Сопротивление игры**: Боевики устанавливают глушилки радиосигнала (создающие артефакты на экране эндоскопа) и прячут растяжки за мебелью вне прямого сектора обзора щели.
- **Синергии**:
  - Взрывной Бричинг: метки эндоскопа позволяют разместить заряд C4 с идеальным поражением врагов за стеной.
  - Штурмовой Slow-Mo: заранее размеченные цели подсвечиваются в замедлении, экономя доли секунды на прицеливание.
  - Обезвреживание СВУ: разведка серверной заранее показывает световую схему верного провода детонатора.
- **Почему это не жанровый шаблон**: Разведка эндоскопом дает осязаемое преимущество, перенося тактическую информацию в основную фазу боя в виде сквозных AR-маркеров (Augmented Reality) на Three.js.
- **Псевдокод тика**:
```text
function updateOpticRecon(opticCable: OpticWand, dt: number): void {
  if (!opticCable.isDeployed) return;
  opticCable.exposureTimer += dt;
  const visibleThreats = FrustumCuller.getObjectsInCone(opticCable.headPos, opticCable.lookDir, 120);
  visibleThreats.forEach(threat => {
    if (threat.isSpottedByPlayerRay()) threat.addPersistentARMarker();
  });
  if (opticCable.exposureTimer > 6.0 && Math.random() < 0.25) {
    EnemyAI.triggerDoorWallbangAlert(opticCable.doorRef);
    opticCable.forceRetract();
  }
}
```

## Механика: Обезвреживание СВУ под Огнем и Разрезание Проводов (Defusal Tension QTE) (SECONDARY)
- **Категория**: Финальный тормоз и кульминационный источник напряжения миссии
- **Описание**: Обезвреживание бомбы — это не скучное стояние с зажатой кнопкой на 5 секунд (как в Counter-Strike), а микро-тактическая головоломка в реальном времени под звуки боя.
- **Взаимодействие игрока**: Удержание 'E' / Тап по корпусу бомбы — открыть панель взрывателя; ЛКМ / Свайп кусачками по нужному проводу (Красный/Синий/Желтый); ПКМ — удерживать щит свободной рукой.
- **Отклик**: Визуал/VFX: Крупный план цифрового дисплея СВУ с быстро меняющимися красными цифрами, искры от кусачек при перерезании медной жилы, зеленый залп светодиодов успеха.; Звук (Web Audio): Ускоряющийся частый писк зуммера бомбы (от 1 Гц до 8 Гц на последних секундах), металлический щелчок инструмента, облегченный выдох бойца.; Камера: Жесткий динамический фокус на электронный блок бомбы с размытием заднего плана (Depth of Field), тревожное покачивание при близких выстрелах.; UI/Тактильность: Пульсирующий красный оверлей тревоги, частые короткие виброимпульсы в такт таймеру бомбы, кнопка CUT WIRE.
- **Техническая сложность**: Medium
- **Сильные стороны**: Высокая вовлеченность, Глубокая кривая мастерства
- **На что смотреть**: Требует точной калибровки таймингов

### Глубина механики
- **Роль в петле**: Финальный тормоз и кульминационный источник напряжения миссии
- **Решение игрока**: Приступить к обезвреживанию бомбы прямо сейчас, прикрываясь щитом от выжившего стрелка, или сначала добить врага, рискуя опоздать по таймеру детонатора.
- **Управление**: Удержание 'E' / Тап по корпусу бомбы — открыть панель взрывателя; ЛКМ / Свайп кусачками по нужному проводу (Красный/Синий/Желтый); ПКМ — удерживать щит свободной рукой.
- **Состояния**: `BOMB_ARMED_COUNTDOWN (таймер бомбы пищит с нарастающей частотой, до взрыва 15-25 с)`, `DEFUSAL_PANEL_OPEN (открытие электронной схемы с 3 цветными проводами и микрочипом)`, `WIRE_SNIP_VERIFICATION (анализ логической схемы: провод питания, заземление, триггер детонации)`, `BOMB_DEFUSED_SUCCESS (отключение звука таймера, зеленый светодиод, победа в операции)`
- **Параметры и настройка**:
  - **bomb_timer_limit**: `25.0 с` — Если сделать 10 с — игрок физически не успевает зачистить комнату; если сделать 60 с — таймер перестает создавать нерв и спешку.
  - **wire_cut_reaction_window**: `1.2 с` — Время на выбор верного провода по подсказке из эндоскопа (соответствие цвета маркировке на стене).
  - **one_handed_shield_coverage**: `55%` — Во время обезвреживания бомбы щит прикрывает только торс сбоку, оставляя спину и ноги уязвимыми.
  - **wrong_wire_penalty**: `-8.0 с от таймера` — Ошибка при срезе провода мгновенно сжигает 8 секунд на таймере детонатора, вводя игрока в критический стресс.
- **Слои отклика**:
  - Визуал/VFX: Крупный план цифрового дисплея СВУ с быстро меняющимися красными цифрами, искры от кусачек при перерезании медной жилы, зеленый залп светодиодов успеха.
  - Звук (Web Audio): Ускоряющийся частый писк зуммера бомбы (от 1 Гц до 8 Гц на последних секундах), металлический щелчок инструмента, облегченный выдох бойца.
  - Камера: Жесткий динамический фокус на электронный блок бомбы с размытием заднего плана (Depth of Field), тревожное покачивание при близких выстрелах.
  - UI/Тактильность: Пульсирующий красный оверлей тревоги, частые короткие виброимпульсы в такт таймеру бомбы, кнопка CUT WIRE.
- **Режим отказа**: Игрок в спешке перерезает провод-ловушку (Trigger wire) вместо провода питания или не успевает обезвредить заряд до истечения таймера. Сигнал: непрерывный гудок зуммера, белый экран взрыва и провал миссии.
- **Кривая мастерства**: Новичок пытается сначала полностью убить всех врагов, теряет время и взрывается на последних секундах. Эксперт блокирует огонь щитом в угол, за 2.5 секунды считывает схему и обезвреживает бомбу прямо под градом пуль.
- **Сопротивление игры**: Последний бронированный наемник в серверной бросает дымовую шашку перед бомбой, ослепляя оперативника и мешая разглядеть цветовую маркировку проводов.
- **Синергии**:
  - Эндоскопическая Разведка: разведка серверной заранее показывает световую схему верного провода на мониторе схем.
  - Баллистический Щит: возможность одной рукой держать щит в сторону врага, пока вторая орудует кусачками.
- **Почему это не жанровый шаблон**: Обезвреживание бомбы — это не скучное стояние с зажатой кнопкой на 5 секунд (как в Counter-Strike), а микро-тактическая головоломка в реальном времени под звуки боя.

```text
function onCutWire(bomb: C4BombLogic, wireColor: WireColor): DefusalResult {
  if (wireColor === bomb.disarmTargetWire) {
    bomb.isArmed = false;
    AudioEngine.playDisarmSuccessJingle();
    GameState.triggerMissionVictory();
    return DefusalResult.SUCCESS;
  } else {
    bomb.remainingTimeSec = Math.max(0, bomb.remainingTimeSec - 8.0);
    AudioEngine.playWarningBuzzer();
    VFXEngine.spawnShortCircuitSparks(bomb.panelPos);
    if (bomb.remainingTimeSec <= 0) GameState.triggerBombExplosionDefeat();
    return DefusalResult.TIME_PENALTY;
  }
}
```
