# QA & Testing Plan: Тактика Прорыва: CQB Штурм

## 1. Functional Test Matrix
- [ ] Тест детонации C4: стена корректно разрушается, спавнятся физические осколки, генерируется проход
- [ ] Тест замедления времени: Time.scale плавно переходит в 0.2 и возвращается в 1.0 по истечении таймера
- [ ] Тест баллистики: попадание в голову мгновенно уничтожает врага, попадание в тело снимает броню
- [ ] Тест баллистического щита: щит блокирует 100% фронтального урона при активной стойке
- [ ] Тест переходов между 3 комнатами штурма без утечек памяти Three.js

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS на iPhone 11 / Redmi Note 9 и выше в разрешении 1080p
- [ ] Не более 65 Draw Calls в момент взрыва стены с 24 физическими осколками
- [ ] Время полной загрузки ассетов первого уровня менее 2.5 секунд на 4G-соединении
- [ ] Потребление оперативной памяти вкладки браузера не более 180 МБ

## 3. Target Browser Matrix
- Google Chrome (Windows, macOS, Android) - WebGL 2.0 / Web Audio
- Safari (iOS 15+, iPadOS, macOS) - WebGL / Touch Events
- Yandex Browser (Desktop / Mobile) - Интеграция Playgama SDK
- Mozilla Firefox (Desktop) - WebGL 2.0
