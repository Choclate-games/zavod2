# Тактика Прорыва: CQB Штурм 🎮

> **Тактический 3D-шутер от первого лица в духе Rainbow Six: пробивайте стены зарядами C4, прикрывайтесь баллистическим щитом и зачищайте захваченное посольство в замедленном времени!**

---

## 🌟 Обзор Проекта
- **Жанр**: Тактический 3D CQB-Шутер (Бричинг, щитовой штурм, зачистка комнат)
- **Технологический стек**:
  - **Three.js** (`^0.185.1`): 3D-рендеринг, процедурные модели, эффекты частиц и материалов.
  - **Rapier3D** (`@dimforge/rapier3d-compat ^0.20.0`): детерминированная физика разрушения стен и обломков.
  - **Playgama Bridge** (`@playgama/bridge ^2.1.0`): интеграция с платформой (облачные сохранения, реклама, лидерборды).
  - **TypeScript** (`^5.7.3`) + **Vite** (`^6.1.0`): строгая типизация и быстрая сборка.
  - **Web Audio API**: процедурный синтезатор звуков выстрелов, взрывов C4, рикошетов и контузии.
- **Ориентация**: Landscape (ПК, планшеты, смартфоны).

## 🎮 Управление в Игре

### Управление на ПК (Клавиатура + Мышь)
- **W, A, S, D** — Перемещение оперативника
- **Мышь** — Прицеливание / поворот камеры (PointerLock по клику)
- **ЛКМ (Левая кнопка мыши)** — Выстрел из основного оружия
- **ПКМ (Правая кнопка мыши)** — Полное укрытие за баллистическим щитом
- **Q / E** — Тактический наклон влево / вправо (угол 14°, смещение 0.45м)
- **Пробел / F** — Детонация установленного заряда C4 / Thermite-X
- **R** — Перезарядка магазина
- **T** — Включение тактического зонда-эндоскопа (Optic Wand)
- **E** — Взаимодействие с терминалом бомбы (в радиусе 2.5м)
- **Esc / P** — Тактическая пауза

### Управление на смартфонах и планшетах (Touch)
- **Левая половина экрана** — Плавающий виртуальный джойстик для перемещения
- **Правая половина экрана** — Проведение пальцем для прицеливания и наведения
- **Кнопка «🛡️ ЩИТ»** — Удержание для глухой обороны щитом
- **Кнопки «◀ LEAN / LEAN ▶»** — Выглядывание из-за укрытия
- **Кнопка «🎯 ОГОНЬ»** — Стрельба
- **Кнопка «💥 C4 ПОДРЫВ»** — Подрыв пробивного заряда
- **Кнопка «🔄 РЕЛОАД»** — Перезарядка оружия
- **Кнопка «📷 ЗОНД»** — Активация эндоскопа
- *(Для симуляции тач-управления на ПК откройте URL с параметром `?touch=1`)*

## 📁 Структура Проекта
```text
src/
├── core/
│   ├── Types.ts                   # Доменные типы, характеристики оружия, щита, комнат
│   ├── EventBus.ts                # Типизированная шина событий
│   ├── TimeManager.ts             # Система тактического slow-mo (0.2x) и рефанда времени
│   ├── GameLoop.ts                # 60 FPS физический аккумулятор (Rapier substeps)
│   └── Game.ts                    # Главный координатор систем и состояний
├── physics/
│   ├── CollisionGroups.ts         # Битовые маски физических групп коллизий
│   └── PhysicsWorld.ts            # Rapier3D мир, тела обломков, рейкастинг
├── renderer/
│   ├── Renderer.ts                # Three.js WebGLRenderer, настройки теней и скейлинга
│   ├── SceneManager.ts            # Окружение, свет, туман, интерьеры 3 секторов
│   ├── CameraController.ts        # Камера 1-го лица, наклоны Q/E, отдача, bobbing, FOV
│   ├── ProceduralMeshFactory.ts   # Модели щита, оружия, разрушаемых стен, врагов, СВУ
│   └── VFXPool.ts                 # Пул частиц взрывов C4, трассеров, искр и вспышек
├── audio/
│   ├── ProceduralSoundSynthesizer.ts # Процедурный синтез выстрелов, взрывов, хедшотов
│   └── AudioManager.ts            # Фильтр контузии (low-pass), мастер-громкость
├── gameplay/
│   ├── ShieldController.ts        # Логика блока щитом, уязвимость плеча, трещины стекла
│   ├── WeaponSystem.ts            # Стрельба, разброс, отдача, перезарядка, 1-shot headshot
│   ├── BreachManager.ts           # Установка C4/Thermite, физический пролом стены
│   ├── CombatAIController.ts      # ИИ врагов (Guarding -> Stunned -> Alerted -> Shooting)
│   ├── ReconSystem.ts             # Эндоскоп Optic Wand под дверь с ночным видением
│   ├── BombDefusalSystem.ts       # Обезвреживание бомбы (25 сек, 3 цветных провода)
│   ├── LevelManager.ts            # 3 сектора (Периметр -> Офис -> Серверная)
│   └── ScoringSystem.ts           # Подсчет очков, звезд (1-3) и рангов (S/A/B/C/D)
├── platform/
│   └── PlaygamaBridgeService.ts   # Playgama Bridge SDK v2 (сохранения, реклама, лидерборд)
├── input/
│   ├── DesktopControls.ts         # Клавиатура, мышь, PointerLock
│   ├── TouchControls.ts           # Pointer Events тач-слой для мобильных устройств
│   └── InputManager.ts            # Единый агрегатор ввода
├── ui/
│   ├── theme.css                  # Дизайн-токены Mil-Spec HUD
│   ├── HUD.ts                     # Игровой HUD (щит, фокус, патроны, прицел, хедшот)
│   ├── UiRoot.ts                  # Роутер экранов и модальных окон
│   └── screens/
│       ├── MainMenuScreen.ts      # Главное меню, выбор миссии, статистика
│       ├── ArmoryScreen.ts        # Арсенал (покупка и выбор оружия, прокачка щита)
│       ├── BreachPlanningScreen.ts# Брифинг и выбор точки прорыва (дверь / стена)
│       ├── DefusalModal.ts        # Окно обезвреживания бомбы с перекусыванием проводов
│       ├── AfterActionReportScreen.ts # Итоги штурма, ранг, статистика, удвоение награды
│       ├── GameOverModal.ts       # Экран поражения с кнопкой тактического медпакета
│       └── PauseModal.ts          # Меню паузы
└── main.ts                        # Точка входа приложения
```

## 🚀 Запуск и сборка

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Откройте браузер по адресу `http://localhost:3000`.

### 3. Сборка для публикации
```bash
npm run build
```
Скомпилированный проект будет находиться в папке `dist/` и готов к размещению на игровых платформах (Яндекс Игры, VK Play, Web).
