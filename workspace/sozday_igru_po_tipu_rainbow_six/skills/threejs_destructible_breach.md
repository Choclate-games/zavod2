# Skill: Three.js & Rapier3D Разрушаемые Преграды

## Purpose
Создание процедурно разрушаемых стен и дверей с генерацией динамических физических осколков

## When to Use
При реализации механики бричинга C4 и разрушения дверных баррикад

## Core Rules & Constraints
- Заменять цельный меш стены на составной разбитый каркас в момент детонации
- Использовать InstancedMesh для обломков с общим материалом для экономии Draw Calls
- Удалять или отключать физику мелких осколков через 1.5 секунды после взрыва

## System Architecture
Модуль BreachPhysicsManager подписывается на событие ON_BREACH_DETONATED, деактивирует статический коллайдер стены и активирует пул динамических Rigidbody Rapier3D с радиальным импульсом.

## Implementation Guidance
Применять предварительно разбитые фрагменты геометрии (Voronoi fracture) вместо вычислений CSG в реальном времени в браузере.

## Common Mistakes to Avoid
- ❌ **Mistake**: Использование сложной физической сетки для каждого мелкого осколка
- ❌ **Mistake**: Неосвобожденная память геометрий при частых перезапусках уровня

## Validation Checklist
- [ ] Меш стены разделен на фрагменты
- [ ] Коллайдер прохода открывается мгновенно
- [ ] FPS стабилен в момент подрыва
