# QA & Testing Plan: Бастион 13: Сапёр Периметра

## 1. Functional Test Matrix
- [ ] Проверка монтажа всех 4 типов турелей на свободные слоты периметра.
- [ ] Проверка физики перегрева: авто-клин при 100% тепла и сброс температуры крио-спреем.
- [ ] Проверка логистики батарей: взятие с генератора, снижение скорости бега, активация Overcharge на 25 сек.
- [ ] Проверка условий победы при отражении 3 волн и условий поражения при разрушении реактора.
- [ ] Проверка сохранения прогресса чертежей в Playgama Cloud Save.

## 2. Performance Benchmarks
- [ ] Десктоп: 60 FPS при 120 одновременных зомби и 4 активных турелях на экране
- [ ] Мобильные (средний сегмент): стабильные 45-60 FPS при dpr 1.0-1.25
- [ ] Потребление оперативной памяти: не более 180 МБ в пике сражения
- [ ] Количество Draw Calls: не более 65 в самом насыщенном кадре с метелью и партиклами
