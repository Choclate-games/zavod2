# UI/UX Specification: Бастион 13: Сапёр Периметра

## 1. Материал интерфейса
Интерфейс живёт в том же мире, что и сцена. Проверка: если закрыть игровое поле,
меню обязано выдавать именно эту игру, а не любую другую.

- **Тема от арт-директора**: Индустриальный дизельпанк: темный клепаный металл, стрелочные манометры, трафаретные моноширинные шрифты, янтарная и бирюзовая подсветка индикаторов
- **Визуальный язык**: Индустриальная читаемость: тяжелые металлические рамки, диегетические приборы со стрелками, контрастные неоновые индикаторы состояний (синий — норма, оранжевый — нагрев, красный — клин, бирюзовый — оверчардж).
- **Типографика**: Заголовки, цифровые таймеры, показатели манометров и статус волны: Russo One (тяжелый индустриальный рубленый шрифт с трафаретным дизельпанк-характером; числа набраны с font-variant-numeric: tabular-nums в слотах фиксированной ширины). Интерфейсный текст, подписи турелей, описания модулей и контекстные подсказки: Share Tech Mono (технический моноширинный терминальный гротеск, имитирующий штампованные таблички армейских инструкций и полевых формуляров Бастиона).

## 2. Акценты: один цвет — один смысл
Разный цвет у каждой кнопки «чтобы отличались» — главная ошибка игрового
интерфейса. На одном экране одновременно видно не больше двух акцентов.

| Токен | Единственный смысл |
|---|---|
| `cooling_ready` | #3498DB |
| `danger_overheat` | #E74C3C |
| `power_charged` | #F1C40F |
| `reactor_health` | #2ECC71 |
| `scrap_resource` | #E67E22 |

Все значения — токенами в `src/ui/theme.css`: цвета, гарнитуры, шкала отступов,
радиусы, длительности, порядок слоёв `--z-*`. Литерал цвета внутри экрана — баг.

## 3. Композиция экрана
Меню и экраны между сессиями лежат ПОВЕРХ живой игровой сцены — той же, что в
игре, только с медленной камерой. Непрозрачная заливка на весь экран запрещена:
подложка только под текстом и кнопками.

- **Сцена за меню**: Интерьер командного бункера: верстак с чертежами и разобранным пулеметом на переднем плане; за бронеокном виден заснеженный ночной периметр и огни дотов

Экран — не колонка кнопок по центру. Три зоны, и каждый элемент лежит ровно в одной:

1. **Идентичность** — что это за экран: заголовок, режим, состояние игрока.
2. **Главное действие** — ровно одно на экран, самое крупное и единственное с
   основным акцентом.
3. **Второстепенный ряд** — всё остальное, одним рядом или сеткой, одним весом.

Зоны нажатия: основная ≥ 96 px, остальные ≥ 64 px, зазор ≥ 12 px, отступы через
`env(safe-area-inset-*)` плюс измеренная высота липкого баннера. Ни один экран не
скроллит страницу: длинный список скроллится во внутреннем контейнере.

## 4. Набор компонентов (закрытый)
Всё на экране — один из этих компонентов. Одноразовый `<div>` с инлайновыми
стилями — это то, из-за чего второй экран перестаёт совпадать с первым.

- Radial Turret Selector (круговой диск монтажа)
- Overheat Arc Gauge (дуговой индикатор тепла над орудием)
- Cryo-Tank Pressure Capsule (манометр давления крио-ранца)
- Context Action Pill (динамическая кнопка действия с иконкой)
- Perimeter Threat Radar (секторальный радар угроз)

Каждый интерактивный компонент несёт пять состояний: покой, наведение, нажатие,
недоступность, `:focus-visible`; асинхронное действие — ещё и `loading`.

## 5. HUD
Не больше пяти постоянных элементов на телефоне. Пять якорей, посередине экрана
не висит ничего, кроме временной обратной связи.

| Якорь | Что там |
|---|---|
| `bottom_left` | Scrap Counter & Active Cryo-Tank Level |
| `bottom_right` | Dynamic Context Action Button (Cool / Charge / Repair) |
| `center` | Crosshair with Heat Arc & Interaction Distance Prompt |
| `top_center` | Reactor Core Integrity Bar & Wave Progress Timer |
| `top_left` | Perimeter Threat Radar & Sector Breach Alerts |

Элементы:
- Индикатор целостности реактора Бастиона (верх по центру)
- Шкала наступающей волны и счетчик оставшихся зомби (верх по центру)
- Мини-радар секторов периметра с индикацией перегрева орудий (верх слева)
- Счетчик собранного металлолома (Scrap) (низ слева)
- Манометр давления крио-ранца инженера (низ слева)
- Диегетическая круговая шкала перегрева нацеленной турели (по центру у прицела)
- Контекстная плавающая кнопка действия «Охладить / Зарядить / Ремонт» (низ справа)

Меняющиеся числа — `tabular-nums` в слоте фиксированной ширины, полосы —
`transform: scaleX()`, а не `width`. Текст поверх геймплея всегда с подложкой или
обводкой: белое число исчезает на светлой сцене.

## 6. Состояние, показанное миром, а не оверлеем
- Аналоговые стрелочные манометры на корпусах турелей
- Цветовая градация раскаления металла стволов от темно-серого до оранжевого свечения
- Светодиодные полосы заряда на корпусах переносных энергоячеек
- Манометр остатка крио-агента на рукаве инженера

## 9. Отклик и движение
- Оглушительный свист пара и морозный иней на краях экрана при успешном охлаждении турели
- Красная пульсация и предупреждающий зуммер при критическом перегреве орудия (90%+)
- Звук тяжелого механического затвора и бирюзовый импульс при установке энергоячейки
- Мигание аварийного красного прожектора и сирена при падении HP реактора ниже 30%

Переход один на всю игру и укладывается в 300 мс; анимируются только `transform`
и `opacity`; `prefers-reduced-motion: reduce` убирает трансформации.

## 11. Чек-лист приёмки интерфейса
- [ ] Ни одного литерала цвета, шрифта, радиуса или длительности вне `theme.css`.
- [ ] Слои над канвасом не перехватывают игровой ввод: контейнеры `pointer-events: none`.
- [ ] Каждый экран помещается в измеренный вьюпорт, страница не скроллится.
- [ ] Одно главное действие на экран, не больше двух акцентов одновременно.
- [ ] Меняющиеся числа не дёргают строку HUD.
- [ ] У каждого экрана описаны загрузка, пустота и ошибка.
- [ ] Возможность, которой нет на площадке, не нарисована вовсе.
- [ ] Ни `alert`/`confirm`, ни эмодзи вместо иконок, ни `z-index` мимо токенов.
- [ ] Самая длинная переведённая строка помещается в кнопку.
- [ ] За меню видна живая сцена игры, а не заливка цветом.
- [ ] Ни одного эмодзи в подписи кнопки: иконка — инлайновый SVG с `currentColor`.
- [ ] У каждого экрана расписаны три зоны, а не «карточка по центру».
- [ ] С закрытым игровым полем меню всё ещё узнаётся как «Бастион 13: Сапёр Периметра».
