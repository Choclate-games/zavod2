# Skill: Mobile Touch Dual-Zone FPS Controller

## Purpose
Идеальная эргономика управления от первого лица на смартфонах без физической клавиатуры.

## When to Use
Для всех 3D экшенов и шутеров от первого лица на мобильных браузерах.

## Core Rules & Constraints
- Никаких микроскопических кнопок: размер зоны действия не менее 80x80dp
- Плавная интерполяция кватерниона камеры для устранения рывков

## System Architecture
Event-driven Touch Controller с раздельной обработкой виртуального стика и зоны свайпа камеры.

## Implementation Guidance
Реализуйте плавающий стик, центрирующийся в точке первого касания пальца в левой половине экрана.

## Common Mistakes to Avoid
- ❌ **Mistake**: Фиксированный джойстик вместо динамического плавающего в левой зоне
- ❌ **Mistake**: Отсутствие сглаживания вращения камеры при резких тачах

## Validation Checklist
- [ ] Проверка touch.identifier для предотвращения конфликта пальцев
- [ ] Deadzone 8px для исключения микро-дрожания стика
- [ ] Контекстная кнопка действия реагирует на расстояние до турели < 2.5 м
