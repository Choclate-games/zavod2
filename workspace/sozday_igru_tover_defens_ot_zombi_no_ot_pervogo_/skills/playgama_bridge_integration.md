# Skill: Playgama Bridge SDK Integration & Lifecycle

## Purpose
Бесшовная интеграция платформенных фичей (реклама, сейвы, лидерборды) для Yandex Games и VK.

## When to Use
При подготовке релизной сборки WebGL игры для платформ Playgama/Yandex/VK.

## Core Rules & Constraints
- Строго соблюдать кулдаун межстраничной рекламы (120 сек)
- Никогда не блокировать загрузку игры ожиданием ответа рекламного SDK

## System Architecture
Обертка над @playgama/bridge с поддержкой промисов, авто-восстановлением звука и безопасным сохранением.

## Implementation Guidance
Интегрируйте Bridge в отдельный синглтон-сервис с подпиской на жизненный цикл игры.

## Common Mistakes to Avoid
- ❌ **Mistake**: Вызов рекламы посреди активного сражения волны
- ❌ **Mistake**: Отсутствие глушения Howler.js звуков при показе оверлейного ролика

## Validation Checklist
- [ ] Обработка ошибки отсутствия рекламы без зависания интерфейса
- [ ] Сохранение прогресса каждые 60 секунд и при завершении смены
- [ ] Корректная пауза игрового таймера во время показа рекламы
