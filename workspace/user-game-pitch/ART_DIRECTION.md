# Art Direction Specification: User game pitch: тестовый 2d п

## 1. Visual Identity & Aesthetic
- **Style Name**: Стилизованный High-Contrast Action
- **Camera Perspective**: Top-Down Изометрическая 3D камера с динамическим зумом (FOV: 50°, Pitch: 45°)
- **Environment Mood**: Постапокалиптическая арена с динамическим освещением
- **Character Proportions**: Бронированная техника с гипертрофированными модулями

## 2. Color Palette & Lighting
- **Primary**: `#00f0ff`
- **Secondary**: `#ff3366`
- **Accent Gold**: `#ffb800`
- **Background Dark**: `#0a0e17`
- **Surface Panel**: `#131c2e`

**Lighting Setup**: Направленный солнечный свет с мягкими тенями + неоновые акцентные источники

## 3. Visual Effects (VFX)
- Клубы дыма и следы шин на поверхности
- Искры при таране металлических препятствий
- Вспышки лазеров и выстрелов турелей
- Радиальные взрывы при гибели элитных противников
