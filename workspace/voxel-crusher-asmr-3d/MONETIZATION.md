# Monetization Specification: Воксельный Измельчитель ASMR 3D

## 1. Strategy Summary
Мягкая гибридная модель: вознаграждающие видео (Rewarded Video) для ускорения прогресса и умножения наград + редкие межстраничные объявления (Interstitial) между успешными завершениями коллекций + внутриигровые покупки (IAP) для отключения рекламы и покупки премиальных скинов.

## 2. Rewarded Video Ad Placements
### Удвоение монет за предмет (`x2_stage_reward`)
- **Benefit**: Умножает все заработанные с текущего объекта монеты на 2
- **Trigger**: Экран успешного уничтожения модели (Victory Popup)
- **Limit**: После каждого завершенного предмета

### Мега-Турбо Дробилка (30 сек) (`mega_turbo_boost`)
- **Benefit**: Включает авто-кликер на максимальной скорости x5 и золотые валы на 30 секунд
- **Trigger**: Плавающая кнопка-бонус на основном игровом экране
- **Limit**: Кулдаун 3 минуты

### Бесплатный уровень прокачки (`free_instant_upgrade`)
- **Benefit**: Мгновенно дает +1 уровень самому дорогому текущему улучшению без траты монет
- **Trigger**: Иконка подарка рядом с карточкой апгрейда
- **Limit**: 2 раза за игровую сессию


## 3. Interstitial Ads Rules
- Minimum **90 seconds** interval between consecutive interstitials.
- Zero interstitials during active combat gameplay.
- Shown only on run game over or returning to Main Menu.

## 4. Optional In-App Purchases (IAP)
- **Отключение рекламы (No Ads)** (`no_ads_permanent`): Навсегда убирает межстраничные баннеры и дает пассивный бонус +20% к доходу (Tier 2 ($1.99 / 149 YAN))
- **Набор 'Золотой Измельчитель'** (`golden_crusher_pack`): Эксклюзивный скин валов из чистого золота + утроенный стартовый капитал (Tier 3 ($2.99 / 249 YAN))
- **Сундук Воксельного Золота** (`huge_coin_chest`): Огромный запас монет для мгновенной прокачки всех характеристик (Tier 1 ($0.99 / 79 YAN))
