# QA & Testing Plan: Воксельный Измельчитель ASMR 3D

## 1. Functional Test Matrix
- [ ] Проверка корректности повоксельного уничтожения модели до 0 оставшихся вокселей
- [ ] Проверка удвоения скорости при быстрых тапах и корректного возврата к базовой скорости
- [ ] Проверка начисления монет и списания средств при покупке каждого типа апгрейда
- [ ] Проверка сохранения и загрузки прогресса из Playgama Storage при перезагрузке страницы
- [ ] Проверка корректного вызова и награждения за Rewarded Video

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS при 1500 одновременно активных частицах вокселей на экране
- [ ] Потребление оперативной памяти (RAM) не более 120 МБ во время непрерывной 15-минутной игры
- [ ] Время начальной загрузки и старта рендера менее 2.5 секунд на 4G соединении

## 3. Target Browser Matrix
- Chrome Mobile (Android 10+)
- Safari iOS (iOS 14+ / iPhone X - 15 Pro)
- Яндекс.Браузер (Десктоп и Мобайл)
- Desktop Chrome, Edge, Firefox, Opera
