# Воксельный Измельчитель ASMR 3D 🎮⚡

> **Наблюдайте, как мощные стальные валы по вокселю перемалывают сладости, игрушки, гаджеты и сокровища! Кликайте для бешеного ускорения, собирайте золотые крошки и прокачивайте свою дробилку до максимума.**

---

## 🌟 Обзор проекта
- **Жанр**: Казуальный симулятор / Кликер (ASMR Дробилка / Физический Idle-разрушитель)
- **Стек**: TypeScript (Strict Mode), Three.js, Web Audio API, Vite
- **Платформа**: Playgama Bridge (Яндекс Игры / VK / Web / Android / iOS)
- **Ориентация**: Portrait (вертикальная)
- **Целевая аудитория**: Любители расслабляющих ASMR-видео с гидравлическим прессом/дробилками и поклонники медитативного кликер-геймплея.
- **FPS**: Стабильные 60 FPS на ПК и смартфонах.

---

## 🚀 Запуск и сборка

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки (Vite)
npm run dev

# Проверка TypeScript и сборка продакшн-бандла
npm run build

# Предпросмотр собранного билда
npm run preview
```

## 🎮 Управление

### На смартфонах и планшетах (Touch):
- **Тап в любом месте экрана**: Яростное турбо-ускорение вращения валов (Combo Multiplier x2 - x3) и спавн тактильных микро-частиц.
- **Нижняя панель**: Удобные кнопки прокачки под большой палец (Ширина, Острота, Ценность, Подача).
- **Кнопка бонуса**: Активация «Мега-Турбо» (30 секунд авто-клика на скорости x5).
- **Галерея и Магазин**: Выбор любых открытых воксельных коллекций и покупка золотого скина валов.

### На компьютере (Клавиатура и мышь):
- **ЛКМ / `Space` / `J`**: Турбо-ускорение вращения валов
- **`1`**: Прокачать «Ширину валов»
- **`2`**: Прокачать «Остроту зубьев»
- **`3`**: Прокачать «Ценность вокселей»
- **`4`**: Прокачать «Авто-подачу»
- **`M`**: Включить / выключить звук

## 📁 Структура проекта (`src/`)

```text
src/
├── main.ts                     # Bootstrap платформы Playgama Bridge и запуск игры
├── style.css                   # Адаптивные стили HUD, модалок и safe-area
├── core/
│   ├── EventBus.ts             # Типизированная шина событий с нулевыми аллокациями
│   ├── Game.ts                 # Главный координатор и менеджер состояний
│   ├── GameLoop.ts             # Фиксированный 60 Гц цикл с защитой от скачков delta time
│   └── Types.ts                # TypeScript интерфейсы и структуры данных
├── data/
│   ├── ModelsData.ts           # 16 детализированных воксельных 3D моделей в 4 коллекциях
│   ├── UpgradeConfig.ts        # Математические формулы и баланс улучшений
│   └── Localization.ts         # Локализация на русском и английском языках
├── platform/
│   ├── PlaygamaService.ts      # Интеграция SDK Playgama Bridge (Реклама, Облако, Лидерборды)
│   └── StorageService.ts       # Автосохранение с дебаунсом 1.5 сек и зеркалом в LocalStorage
├── audio/
│   └── AudioManager.ts         # Процедурный ASMR синтезатор звуков хруста, мотора и монет
├── rendering/
│   ├── SceneManager.ts         # Студийное освещение Three.js, мягкие тени и камера (42° FOV)
│   ├── RollerMechanism.ts      # Двойные зубчатые валы со встречным вращением и скинами
│   ├── VoxelModelObject.ts     # Послойный срез вокселей через Three.InstancedMesh
│   ├── ParticleStream.ts       # Пул физических частиц (1500 кубиков) с гравитацией
│   └── SparkVFX.ts             # Искры и динамическое свечение в точке контакта
├── systems/
│   ├── ShredderSystem.ts       # Физика затягивания модели и скола вокселей
│   ├── EconomySystem.ts        # Расчет наград за воксели и форматирование чисел (1.2K, 3.4M)
│   ├── UpgradeSystem.ts        # 4 ветки прокачки дробилки
│   └── ComboSystem.ts          # Комбо-шкала скорости и режим Мега-Турбо
└── ui/
    ├── TouchControls.ts        # Мультитач на Pointer Events с защитой от жестов браузера
    └── UIManager.ts            # Оверлей интерфейса, карточки улучшений, окно победы и галерея
```
