# UI/UX Specification: Воксельный Измельчитель ASMR 3D

## 1. HUD Overlay Elements
- Верхний бар: Баланс монет с иконкой золота, Название текущей модели, Прогресс уничтожения (0% - 100%)
- Центральная зона: 3D вьюпорт с работающими валами и падающим предметом (интерактивная зона тапа)
- Индикатор Турбо: Шкала комбо-скорости x2 с таймером удержания
- Нижняя панель прокачки: 4 крупные карточки улучшений (Ширина, Острота, Ценность, Авто-подача) с ценами и уровнями
- Кнопка меню коллекций и переключатели звука/вибрации
