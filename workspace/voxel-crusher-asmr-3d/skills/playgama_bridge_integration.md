# Skill: Паттерны интеграции Playgama Bridge SDK

## Purpose
Стабильная работа облачных сохранений, рекламы и управления звуком на игровых порталах.

## When to Use
При подключении монетизации, сохранений и управления фокусом окна игры.

## Core Rules & Constraints
- Всегда глушить звук игры перед вызовом showRewardedVideo / showInterstitial.
- Сохранять прогресс в Cloud Storage не чаще раза в 30 секунд и при закрытии страницы.
- Корректно обрабатывать отказ или отсутствие рекламы без блокировки интерфейса игрока.

## System Architecture
BridgeAdapter -> StateStore -> AutoSave Throttler -> Ad Callback Handlers

## Implementation Guidance
Использовать обертку Promise вокруг событий показа рекламы с обязательным таймаутом на случай зависания стороннего рекламного скрипта.

## Common Mistakes to Avoid
- ❌ **Mistake**: Попытка синхронного вызова рекламы до окончания инициализации SDK
- ❌ **Mistake**: Потеря монет игрока при внезапном закрытии вкладки без автосохранения

## Validation Checklist
- [ ] Звук восстанавливается после закрытия рекламы
- [ ] Игра ставится на паузу во время показа оверлея платформы
- [ ] Cloud Save корректно синхронизирует монеты и уровни улучшений
