# Core Loop Design: Огненный Каньон: Водный Сброс

## 1. Чем эта петля отличается
- **Фирменный момент**: Момент, когда на 42-й секунде вылета перегруженный 4.5 тоннами воды гидроплан со скрежетом и воем моторов проносится в 1.5 метрах над огненной стеной реликтового леса, вы прожимаете рычаг залпового сброса: гигантская белая стена воды мгновенно гасит бушующий ад, экран заливает густой пар, а облегченный самолет от отдачи и восходящего термика пушечным ядром выстреливает вертикально вверх в чистое лазурное небо над гребнем каньона с утроением комбо-очков!
- **Отличие от жанрового шаблона**: В отличие от классических авиасимуляторов (со сложными приборами и долгим заходом на цель) и казуальных раннеров (без инерции и физики массы), здесь ядро построено на циклической пульсации массы и баллистической отдачи: 'забор воды утяжеляет штурвал и прижимает к земле -> слалом требует раннего упреждения траектории -> сброс воды даёт мощный вертикальный импульс отдачи'. Игрок использует огонь не только как цель для тушения, но и как тактический лифт: раскаленный воздух над пожаром создает восходящий термик, компенсирующий возросшую массу самолета перед сбросом.
- **Сознательно НЕ берём**: Отвергнут стандартный аркадный шаблон «рельсового 3D-раннера с неизменной физикой и абстрактными монетами/бустерами». В обычных раннерах вес и физическая модель транспорта статичны, а манёвры сводятся к выбору одной из трёх полос. Мы полностью отвергаем дискретные полосы и статичную массу: гидроплан подчиняется непрерывной гидроаэродинамике, где масса непрерывно меняется от 4500 кг (пустой) до 9000 кг (полный бак), радикально изменяя радиус разворота, скорость сваливания и просадку по высоте. Забор воды — это не мгновенный подбор сферы-бонуса, а рискованное физическое глиссирование по реке с гидросопротивлением и риском зарывания поплавков в пороги.

## 2. Схема петли
```text
+-----------------------------------------------------------------------------------+
|                             МЕТА-ПЕТЛЯ (АВИАБАЗА)                                 |
|  [Выбор гидроплана] -> [Прокачка баков/ковшей] -> [Контракт: Огненный Каньон]     |
+----------------------------------------+------------------------------------------+
                                         | Старт вылета (60 сек)
                                         v
+-----------------------------------------------------------------------------------+
|                           МЕЗО-ПЕТЛЯ (СЕКТОР / ОЧАГ 1..3)                         |
|  +-----------------------------------------------------------------------------+  |
|  |                       МИКРО-ПЕТЛЯ (ПОСЕКУНДНО: 1-3 сек)                     |  |
|  |                                                                             |  |
|  |   [1. Бреющий полет] --------> [2. Глиссирование по реке]                   |  |
|  |     (h < 1.8м над водой)         (Забор воды: 1800 л/с, штурвал тяжелеет)   |  |
|  |             ^                                   |                           |  |
|  |             |                                   v                           |  |
|  |   [4. Реактивный взмыв] <------ [3. Баллистический сброс на очаг]           |  |
|  |     (Облегчение -4.5т,            (Ликвидация пламени, +Комбо x3,           |  |
|  |      подхват термиком +15м)        шлейф густого пара)                      |  |
|  +-----------------------------------------------------------------------------+  |
|                                        | Очаг ликвидирован (+5 сек бонус)          |
|                                        v                                           |
|         [Слалом в узкую теснину к следующему очагу пожара]                         |
+----------------------------------------+------------------------------------------+
                                         | Все 3 очага потушены / Выход из каньона
                                         v
+-----------------------------------------------------------------------------------+
|                             ЭКРАН ПОБЕДЫ И НАГРАДЫ                                |
|     [Ранг S: Ас-Ликвидатор] -> [Кредиты спасения] -> [Новые гидропланы/перки]     |
+-----------------------------------------------------------------------------------+
```

## 3. Микро-петля (посекундно)
| Шаг | Действие игрока | Ответ игры | Решение игрока | Длительность |
| :--- | :--- | :--- | :--- | :--- |

| Глиссирование и скоростной водозабор | Удержание высоты глиссирования (1.5 м) и корректировка крена рулями направления (A/D / мышь) | Включение ковшевых водозаборников, заполнение баков (1800 л/с), замедление самолета со 190 до 140 км/ч от гидросопротивления, потяжеление штурвала | Забрать полный бак (4500 л) с риском не успеть набрать высоту до скального мыса или оборвать забор на 3000 л для легкого виража | 1.5–2.5 с |

| Залповый водосброс и реактивный взмыв | Нажатие кнопки залпового сброса (Пробел / Левый клик / Кнопка сброса) строго в створе огненного сектора | Распах створок бомболюка, сброс лавины воды 4.5 т, генерация облака пара, мгновенная ликвидация очага, резкий реактивный толчок гидроплана вверх на +14.5 м | Сбросить весь объем залпом для 100% тушения главного очага и максимального комбо или разделить сброс на два очага | 0.5–1.0 с |

## 6. Кривая напряжения
Волнообразная пилообразная кривая с 3 нарастающими пиками напряжения внутри 60-секундного спринта: Секунды 0–5 (Низкое): Старт вылета, пикирование в каньон, прицеливание на речную гладь; Секунды 5–15 (Пик 1): Первый забор воды на бреющем полете (напряжение удержания высоты 1.5 м) -> тяжелый вираж -> первый залповый сброс и эйфорический взмыв облегченного самолета; Секунды 15–35 (Пик 2): Вход во второй S-образный сектор ущелья с дымовыми смерчами; баки быстро тяжелеют в порожистом русле, сброс на второй очаг на грани столкновения со скалой; Секунды 35–55 (Пик 3 — Кульминация): Финальная узкая теснина, таймер мигает красным (<15 с), третий гигантский очаг требует 100% заполнения бака; самолет предельно инертен, игрок на бреющем полете проносится под падающей горящей сосной, ловит восходящий термик прямо перед пламенем и сбрасывает лавину воды на последней секунде; Секунды 55–60 (Катарсис): Финальный взмыв сквозь пар над гребнем каньона в лучи заката, подсчет спасенного леса и начисление комбо-ранга.

## 7. Формулы ядра
- `Масса гидроплана: M_total = M_empty (4500 кг) + V_water (литры) * 1.0 кг/л (максимум 9000 кг при полном баке 4500 л).`
- `Гидродинамическое торможение при заборе: F_drag_water = 0.42 * V_plane^2 * min(1.0, depth / 0.8м), замедляет самолет с 190 км/ч до предела глиссирования 130 км/ч за 2.5 секунды.`
- `Инерция тангажа и крена: Angular_Accel = Base_Torque / (1.0 + (M_total - M_empty) / M_empty * 1.25), снижает угловую приемистость штурвала на 55% при полной загрузке баков.`
- `Эффективность тушения очага: Extinguish_Power = (V_dropped / Target_Required_Water) * Overlap_Factor * (1.0 + Current_Speed / 200), где идеальный сброс (Overlap > 0.85) наносит 100% урон очагу и начисляет комбо-ранг 'ИДЕАЛЬНО'.`
- `Реактивный вертикальный импульс сброса (Recoil Lift): Delta_V_y = (M_dropped / M_empty) * 9.81 * 1.35 + Thermal_Boost (8.0 м/с при наличии термика), мгновенно подбрасывает самолет вверх на 12–18 метров за 0.6 секунды.`
- `Формула комбо-очков: Score_Drop = Base_Points (1000) * Combo_Multiplier (1.0..3.0) * Speed_Factor (V / 150) * Altitude_Bonus (1.0 + max(0, (25м - Alt) / 20)).`
- `Перегрев двигателя в дыму: Temp_Engine = Temp_Base (75°C) + Smoke_Density * 35°C/с * dt - Air_Cooling (15°C/с * (V_plane / 180)), при Temp > 115°C падает тяга на 40%.`
