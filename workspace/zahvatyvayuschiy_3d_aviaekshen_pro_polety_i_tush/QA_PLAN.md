# QA & Testing Plan: Огненный Каньон: Водный Сброс

## 1. Functional Test Matrix
- [ ] Проверка набора воды: при высоте поплавков <1.8м над рекой бак заполняется со скоростью 1800 л/с, а масса возрастает
- [ ] Проверка физики веса: радиус разворота гидроплана с полными баками увеличивается минимум на 80%
- [ ] Проверка водосброса: нажатие кнопки сброса обнуляет бак за 0.6с, наносит урон очагу и облегчает борт
- [ ] Проверка Playgama Bridge: успешная загрузка сохранений и воспроизведение Rewarded Video при аварии

## 2. Performance Benchmarks
- [ ] Стабильные 60 FPS на iPhone 11 / Redmi Note 10 при активных частицах огня и воды
- [ ] Время полной загрузки игры до меню < 2.5 секунд на 4G соединении
- [ ] Общий вес исходного бандла сборки < 4.2 МБ (включая 3D-модели и текстуры)
- [ ] Пиковое потребление оперативной памяти WebGL < 220 МБ
