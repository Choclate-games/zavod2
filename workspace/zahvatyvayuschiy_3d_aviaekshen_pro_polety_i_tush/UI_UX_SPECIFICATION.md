# UI/UX Specification: Огненный Каньон: Водный Сброс

## 1. Материал интерфейса
Интерфейс живёт в том же мире, что и сцена. Проверка: если закрыть игровое поле,
меню обязано выдавать именно эту игру, а не любую другую.

- **Тема от арт-директора**: Минималистичный авиационный HUD: авиагоризонт, изогнутые индикаторы уровня воды и высоты, контрастные полупрозрачные темные подложки с неоново-бирюзовыми и оранжевыми акцентами
- **Визуальный язык**: Четкие полупрозрачные авиационные приборные дуги, высококонтрастные неоново-бирюзовые маркеры воды, янтарно-оранжевые маркеры пожаров, жирный гротескный шрифт
- **Типографика**: Chakra Petch / Rajdhani для цифровых приборов и счетчиков; Montserrat Bold для кнопок и рангов

## 2. Акценты: один цвет — один смысл
Разный цвет у каждой кнопки «чтобы отличались» — главная ошибка игрового
интерфейса. На одном экране одновременно видно не больше двух акцентов.

| Токен | Единственный смысл |
|---|---|
| `fire_threat` | #FF5400 |
| `speed_boost` | #7000FF |
| `ui_neutral` | #FFFFFF |
| `water_interactive` | #00F5D4 |

Все значения — токенами в `src/ui/theme.css`: цвета, гарнитуры, шкала отступов,
радиусы, длительности, порядок слоёв `--z-*`. Литерал цвета внутри экрана — баг.

## 3. Композиция экрана
Меню и экраны между сессиями лежат ПОВЕРХ живой игровой сцены — той же, что в
игре, только с медленной камерой. Непрозрачная заливка на весь экран запрещена:
подложка только под текстом и кнопками.

- **Сцена за меню**: Гидроплан покачивается на воде в тихой речной заводи каньона в лучах утреннего солнца; винт медленно вращается, механики на понтоне готовят борт к вылету, на горизонте поднимается первый дым

Экран — не колонка кнопок по центру. Три зоны, и каждый элемент лежит ровно в одной:

1. **Идентичность** — что это за экран: заголовок, режим, состояние игрока.
2. **Главное действие** — ровно одно на экран, самое крупное и единственное с
   основным акцентом.
3. **Второстепенный ряд** — всё остальное, одним рядом или сеткой, одним весом.

Зоны нажатия: основная ≥ 96 px, остальные ≥ 64 px, зазор ≥ 12 px, отступы через
`env(safe-area-inset-*)` плюс измеренная высота липкого баннера. Ни один экран не
скроллит страницу: длинный список скроллится во внутреннем контейнере.

## 4. Набор компонентов (закрытый)
Всё на экране — один из этих компонентов. Одноразовый `<div>` с инлайновыми
стилями — это то, из-за чего второй экран перестаёт совпадать с первым.

- Индикатор бака HydroGauge
- Высотомер AltimeterArc
- Маркер очага FireTargetPin
- Кнопка WaterSalvoButton
- Плашка DebriefCard

Каждый интерактивный компонент несёт пять состояний: покой, наведение, нажатие,
недоступность, `:focus-visible`; асинхронное действие — ещё и `loading`.

## 5. HUD
Не больше пяти постоянных элементов на телефоне. Пять якорей, посередине экрана
не висит ничего, кроме временной обратной связи.

| Якорь | Что там |
|---|---|
| `bottom_left` | Кнопка форсажа, скорость и высотомер |
| `bottom_right` | Кнопка сброса воды, шкала заполнения баков |
| `center` | Авиагоризонт и динамический баллистический прицел сброса |
| `top_center` | Таймер вылета, прогресс очагов (3/3) |
| `top_right` | Пауза, текущий счет и комбо-множитель |

Элементы:
- Изогнутая круговая шкала емкости водяного бака (0–100%) по правому борту прицела
- Авиационный вариометр / индикатор высоты над водой (Radar Altimeter) слева
- Центральная динамическая марка упреждения водосброса (Bomb/Drop Reticle)
- Индикатор оставшихся очагов возгорания (3/3 Очагов) по центру сверху
- Таймер спринта вылета (обратный отсчет 60.0 с)
- Счетчик комбо-множителя (x1 / x2 / x3) с полосой удержания
- Крупная сенсорная кнопка «ВОДОСБРОС» (для мобайла) в правой нижней четверти
- Кнопка «ФОРСАЖ» в левой нижней четверти (или двойной тап)

Меняющиеся числа — `tabular-nums` в слоте фиксированной ширины, полосы —
`transform: scaleX()`, а не `width`. Текст поверх геймплея всегда с подложкой или
обводкой: белое число исчезает на светлой сцене.

## 6. Состояние, показанное миром, а не оверлеем
- Стрелочный указатель на крыле гидроплана
- Дымовой след за фюзеляжем при форсаже
- Водяные струи из переливных отверстий поплавков при 100% заполнении баков

## 7. Каталог экранов
### Экран: screen main menu
- **Что на экране**: 3D-ангар в заводи реки, гидроплан на понтоне, кнопки «В ВЫЛЕТ», ангар модернизации, таблица рекордов, настройки
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: screen gameplay hud
- **Что на экране**: Легкий авиационный HUD, баллистический прицел, индикаторы бака и высоты, маркеры пожаров, комбо-счетчик
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: screen pause
- **Что на экране**: Затемненное меню: продолжить вылет, перезапуск, чувствительность штурвала, выход в ангар
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: screen mission debrief
- **Что на экране**: Ранг вылета (S/A/B), ликвидировано очагов, точность сброса, заработанный престиж, кнопка «Удвоить награду (Реклама)», следующий каньон
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

### Экран: screen crash revive
- **Что на экране**: Таймер 5 секунд на второй шанс: «Вызов пены / Экспресс-ремонт за просмотр рекламы»
- **Композиция**: Три зоны: чем экран себя называет, единственное главное действие, второстепенный ряд одним весом. Меню лежит поверх живой сцены.

**Переходы**: Загрузка -> Главное меню / Ангар -> Выбор вылета -> Геймплей (45-60с) -> (Авария -> Revive Dialog ->) Экран итогов Debrief -> Ангар / Следующий уровень

## 8. Состояния экрана
- Меню ангара
- Загрузка ассетов
- Полет / Глиссирование
- Залповый сброс
- Пауза
- Крушение
- Итоги вылета (Debrief)

## 9. Отклик и движение
- Касание реки (всплеск пены + тактильная вибрация)
- Заполнение 100% (механический звонкий гонг + бирюзовое сияние шкалы)
- Водосброс (взмыв фюзеляжа вверх + громоподобный хлопок + Hit-Stop 0.2с)
- Ликвидация очага (взрыв белого пара + мажорные фанфары комбо)

Переход один на всю игру и укладывается в 300 мс; анимируются только `transform`
и `opacity`; `prefers-reduced-motion: reduce` убирает трансформации.

## 11. Чек-лист приёмки интерфейса
- [ ] Ни одного литерала цвета, шрифта, радиуса или длительности вне `theme.css`.
- [ ] Слои над канвасом не перехватывают игровой ввод: контейнеры `pointer-events: none`.
- [ ] Каждый экран помещается в измеренный вьюпорт, страница не скроллится.
- [ ] Одно главное действие на экран, не больше двух акцентов одновременно.
- [ ] Меняющиеся числа не дёргают строку HUD.
- [ ] У каждого экрана описаны загрузка, пустота и ошибка.
- [ ] Возможность, которой нет на площадке, не нарисована вовсе.
- [ ] Ни `alert`/`confirm`, ни эмодзи вместо иконок, ни `z-index` мимо токенов.
- [ ] Самая длинная переведённая строка помещается в кнопку.
- [ ] За меню видна живая сцена игры, а не заливка цветом.
- [ ] Ни одного эмодзи в подписи кнопки: иконка — инлайновый SVG с `currentColor`.
- [ ] У каждого экрана расписаны три зоны, а не «карточка по центру».
- [ ] С закрытым игровым полем меню всё ещё узнаётся как «Огненный Каньон: Водный Сброс».
