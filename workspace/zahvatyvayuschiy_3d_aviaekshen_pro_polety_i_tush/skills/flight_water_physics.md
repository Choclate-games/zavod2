# Skill: Гидроаэродинамическая летная модель WebGL

## Purpose
Реализация физики полета гидроплана, глиссирования по воде и динамической трансформации массы фюзеляжа

## When to Use
При разработке авиасимуляторов с переменной массой груза и контактом с водной поверхностью

## Core Rules & Constraints
- Масса должна влиять на все 6 степеней свободы самолета
- Сброс воды обязан сопровождаться ощутимым вертикальным рывком разгрузки

## System Architecture
Модуль HydroAeroController рассчитывает силы Lift, Drag, HydroLift и добавляет массу воды к Rigidbody фюзеляжа

## Implementation Guidance
Использовать кватернионы для стабильного вращения штурвала и пружинную интерполяцию для камеры Spring Arm

## Common Mistakes to Avoid
- ❌ **Mistake**: Использование ступенчатой смены физики вместо плавной интерполяции массы
- ❌ **Mistake**: Слишком сильное гидродинамическое торможение, приводящее к мертвому штопору

## Validation Checklist
- [ ] Проверить непрерывность забора воды при касании реки
- [ ] Убедиться в изменении радиуса виража при 100% баках
- [ ] Протестировать импульс облегчения фюзеляжа при сбросе
