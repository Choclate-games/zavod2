# Skill: Стилизованные шейдеры и эффекты огня/воды в Three.js

## Purpose
Создание производительных визуальных эффектов стилизованной реки, огня, дыма и взрывов пара

## When to Use
При создании шейдеров стихий (огонь, вода, пар) в браузерных 3D-играх

## Core Rules & Constraints
- Частицы должны рендериться через единый InstancedBufferGeometry
- Капли на камере должны исчезать за 1.5 секунды через альфа-затухание

## System Architecture
ParticlePool с инстансингом мешей и кастомный GLSL шейдер горящих углей и пара

## Implementation Guidance
Применять вертексное смещение (Vertex Displacement) по шуму Перлина для создания динамических волн реки

## Common Mistakes to Avoid
- ❌ **Mistake**: Создание новых объектов частиц в runtime вместо пулинга
- ❌ **Mistake**: Чрезмерный оверхед от прозрачности (overdraw) на мобильных экранах

## Validation Checklist
- [ ] Не более 60 draw calls на всю сцену каньона
- [ ] Использование атласов текстур для частиц дыма и огня
