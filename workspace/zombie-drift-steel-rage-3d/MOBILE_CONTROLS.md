# MOBILE_CONTROLS.md — обязательный контракт тач-управления

Игра «Зомби Дрифт: Стальная Ярость 3D» имеет полноценное, высокоточное мобильное
управление. Этот файл — единственный источник правды о раскладке, поведении
и требованиях к тач-вводу. Любое изменение в `src/ui/TouchControls.ts` или
`src/core/InputManager.ts` должно ему соответствовать.

## 1. Платформа и события

- Ввод только на **Pointer Events** (`pointerdown` / `pointermove` / `pointerup` /
  `pointercancel` / `lostpointercapture`). Это даёт мультитач и работу мышью
  для отладки на десктопе без эмулятора.
- Мультитач обязателен: стик направления + НИТРО + ДРИФТ держатся одновременно разными
  пальцами. Различение пальцев — по `pointerId`, не по координатам.
- `setPointerCapture` на каждом элементе, чтобы жест не терялся, если палец
  ушёл за пределы кнопки/зоны.

## 2. Раскладка (Ландшафт и Портрет)

```
┌───────────────────────────────┬───────────────────────────────┐
│  ЛЕВАЯ ПОЛОВИНА               │  ПРАВАЯ ПОЛОВИНА               │
│                               │                                │
│  НАПРАВЛЕННЫЙ ДЖОЙСТИК        │   [НИТРО]                      │
│  (машина плавно поворачивает   │   [ДРИФТ]                      │
│   и едет в сторону жеста)     │                                │
│  (появляется под пальцем      │   [ II ] <- пауза (сверху)     │
│   в любой точке зоны)         │                                │
└───────────────────────────────┴───────────────────────────────┘
```

- **Стик направления (левая зона, 50% ширины):** плавающий джойстик прямого направления движения.
  База возникает в точке касания, стик не привязан к фиксированному месту — удобно под любой палец.
  - В какую сторону игрок тянет стик (вверх, вниз, вправо, влево, по диагонали) — в ту сторону машина плавно поворачивает и ускоряется!
  - Динамический расчёт угла между курсом машины и вектором тяги пальца обеспечивает гладкое выравнивание и эффектный занос на крутых виражах.
  - Мёртвая зона (6px) гасит микроколебания при неподвижном касании.
- **НИТРО:** `nitro` (удержание) — мгновенный форсаж с пламенем из выхлопных труб.
- **ДРИФТ:** `handbrake` (удержание) — блокировка задней оси для затяжного силового скольжения и набора очков дрифт-ярости.
- **ПАУЗА:** кнопка `II` в правом верхнем углу слоя управления (всегда поверх зон, `pointer-events: auto`, `z-index: 26`).

## 3. Отмена браузерных жестов

- `touch-action: none` на `#game-container`, его `<canvas>` и слое `#touch-controls`.
- `contextmenu` — `preventDefault()` на `#game-container`.
- `touchmove` — `preventDefault({ passive: false })` на `#game-container` (нет скролла, pull-to-refresh, rubber-band).
- `dragstart` — `preventDefault()` на `#game-container`.
- Дублирующие гварды на слое `#touch-controls` (изоляция от меню/модалок).

## 4. Safe-area и Адаптивность

- Все отступы кнопок/стик-зоны используют `env(safe-area-inset-*)`
  (left/right/bottom/top), чтобы управление не упиралось в чёлку/домашнюю полосу
  iPhone и системные жесты Android.
- В портретной ориентации и на компактных экранах размеры кнопок адаптируются, чтобы не перекрывать поле боя.

## 5. Видимость

- Управление показывается **только во время заезда** (`UIManager.showHud()`).
- В меню, гараже, выборе уровней, паузе, экране выбора улучшения и Game Over слой скрыт
  (`display: none`), чтобы кнопки не перехватывали тапы по интерфейсу.
- При скрытии вызывается `releaseAll()`: все виртуальные кнопки и стик
  сбрасываются в 0, иначе машина уедет с зажатым газом.
- При `blur` окна и `visibilitychange` (сворачивание вкладки) — `releaseAll()`.

## 6. Включение / отладка

- Авто-включение: сенсорное устройство, `(pointer: coarse)` или ширина < 960px.
- Принудительное включение для проверки мышью на ПК: `?touch=1`.
- Принудительное отключение: `?touch=0`.

## 7. Производительность

- Путь ввода **не аллоцирует** в цикле 60 FPS: `InputManager.update()` отдаёт
  переиспользуемый объект `controls`, `TouchControls` пишет скаляры напрямую.
- Ввод событийно-ориентированный (только на `pointermove`), не опрашивается
  каждый кадр — задержка реакции минимальна, управление максимально отзывчиво.
