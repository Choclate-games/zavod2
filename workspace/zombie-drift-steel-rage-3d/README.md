# Зомби Дрифт: Стальная Ярость 3D

3D изометрический постапокалиптический экшен-дерби шутер на выживание. Управляй боевыми бронемашинами, крути управляемые дрифты на 360°, тарань орды зомби и круши боссов с помощью арсенала автопушек, огнеметов, пил и ракетниц!

---

## 🚀 Запуск и сборка

```bash
# Установка зависимостей
npm install

# Запуск локального dev-сервера с горячей перезагрузкой
npm run dev

# Проверка типов TypeScript
npx tsc --noEmit

# Сборка проекта для продакшена
npm run build

# Предпросмотр собранной версии
npm run preview
```

## 🎮 Игровые режимы

1. **🏆 Кампания (100 Уровней в 10 Главах)**:
   - Масштабная 100-уровневая кампания, охватывающая 10 тематических глав и биомов (Окраины, Ангары, Токсичный могильник, Нефтебаза, Ночной неон, Песчаная буря, Кровавый кратер, Ядерный полигон, Пекло титанов, Апокалипсис).
   - Уникальные условия волн, прогрессивная плотность орды, ускоренные мутанты и 20 именованных боссов-титанов.
   - Система навигации по главам, оценка зачистки на 1–3 звезды (всего до 300 ⭐) и награды в виде шестеренок (⚙️) за победу.

2. **☠️ Режим Выживания**:
   - Бесконечный штурм орды с непрерывным масштабированием сложности каждой волны (+HP, +скорость, +плотность).
   - Битвы с титанами каждые 5 волн.
   - Фиксация рекордов по волнам, времени выживания и общему счету.

3. **🏎️ Полноценный Гараж и Тюнинг**:
   - 3D-демонстрация активного автомобиля в реальном времени с круговым обзором.
   - Выбор и покупка машин: «Железный Клык» (масл-кар), «Жнец Дюн» (багги) и «Титан Войны» (6-колесный джаггернаут).
   - 6 направлений прокачки: Броня кузова, Форсирование двигателя, Контроль заноса, Шипастый таран, Нитро-баллоны и Магнит ресурсов.

## 🕹️ Управление

### Клавиатура (ПК):
- **W / Стрелка вверх**: Движение вперед (газ)
- **S / Стрелка вниз**: Тормоз / Реверс (задний ход)
- **A / Стрелка влево**: Поворот руля влево
- **D / Стрелка вправо**: Поворот руля вправо
- **Пробел (Space) / E**: Нитро-форсаж
- **Левый Shift / F**: Ручной тормоз / Дрифт
- **Esc / P**: Пауза

### Сенсорное управление (Мобильные устройства):
- **Левая зона (Направленный стик)**: Плавающий джойстик прямого направления. Тяните палец в любую сторону (вверх, вниз, влево, вправо, по диагонали) — машина плавно поворачивает и едет в указанную сторону!
- **Правая зона**:
  - **НИТРО**: Турбо-ускорение с шлейфом пламени.
  - **ДРИФТ**: Фиксация заноса для набора нитро-ярости и умножения урона тарана до 2.5x.
  - **Кнопка паузы (II)**: В верхнем правом углу.
- *Примечание:* Для проверки мобильного интерфейса на ПК добавьте `?touch=1` в адресную строку (например, `http://localhost:5173/?touch=1`).

## 🗺️ Карта города-арены и 3D здания

Арена 160х160 метров с чистым бесшовным плиточным полом из бетонных плит и асфальта, застроенная монолитными 3D зданиями и сооружениями:
1. **Многоэтажные городские комплексы**: 2-3-этажные кирпичные и бетонные здания с окнами, карнизами, водонапорными башнями и крышными кондиционерами HVAC.
2. **Промышленные логистические склады**: Крупные ангары с воротами, двускатной кровлей и вытяжными трубами.
3. **Автозаправочная станция**: Магазинчик-будка, навес на массивных опорах и заправочные колонки.
4. **Уличные заграждения и остовы авто**: Бетонные блоки K-Rail и ржавые каркасы машин, создающие интересные повороты для дрифта.

### Интерактивные разрушаемые объекты:
- **Красные взрывоопасные бочки**: Взрываются от тарана (>4 м/с) или выстрелов, нанося 180 ед. AoE-урона зомби в радиусе 8.5 м. Авто-респавн через 25 с.
- **Деревянные ящики снабжения**: Раскалываются при ударе на щепки, выбрасывая 15-30 шестеренок или ремонтные аптечки (+20 HP). Авто-респавн через 35 с.
