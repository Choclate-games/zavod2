# Зомби Дрифт: Стальная Ярость 3D

3D изометрический постапокалиптический экшен-дерби шутер на выживание. Управляй бронированными машинами, крути управляемые дрифты на 360°, тарань орды зомби и круши боссов с помощью арсенала автопушек, огнеметов, пил и ракетниц!

---

## 🚀 Запуск и сборка

```bash
# Установка зависимостей
npm install

# Запуск локального dev-сервера с горячей перезагрузкой

npx tsc --noEmit

npm run build

# Предпросмотр собранной версии
npm run preview
```

## 🎮 Управление

### Клавиатура (ПК):
- **W / Стрелка вверх**: Газ (движение вперед)
- **S / Стрелка вниз**: Тормоз / Задний ход
- **A / Стрелка влево**: Поворот руля влево
- **D / Стрелка вправо**: Поворот руля вправо
- **Пробел (Space)**: Ручной тормоз / Дрифт
- **Левый Shift / E**: Нитро-ускорение
- **Esc / P**: Пауза

### Сенсорное управление (Мобильные устройства):
- **Левая половина экрана**: Плавающий виртуальный джойстик рулевого управления (отслеживает пальцы в динамической позиции касания). Резкий свайп вниз активирует экстренный тормоз.
- **Правая половина экрана**: Кнопки действий:
  - **ГАЗ (Зеленая)**: Тяга вперед
  - **НАЗАД (Оранжевая)**: Реверс / Торможение
  - **НИТРО (Голубая)**: Турбо-ускорение
  - **ДРИФТ (Желтая)**: Ручной тормоз для контролируемого заноса
- *Примечание:* Для тестирования мобильного тач-интерфейса в браузере ПК добавьте `?touch=1` в адресную строку (например, `http://localhost:5173/?touch=1`).

## 🗺️ Карта города-арены и 3D здания

Арена 160х160 метров с чистым бесшовным плиточным полом из бетонных плит и асфальта, застроенная монолитными 3D зданиями и сооружениями:
1. **Многоэтажные городские комплексы**: 2-3-этажные кирпичные и бетонные здания с окнами, карнизами, водонапорными башнями и крышными кондиционерами HVAC.
2. **Промышленные логистические склады**: Крупные ангары с воротами, двускатной кровлей и вытяжными трубами.
3. **Автозаправочная станция**: Магазинчик-будка, навес на массивных опорах и заправочные колонки.
4. **Уличные заграждения и остовы авто**: Бетонные блоки K-Rail и ржавые каркасы машин, создающие интересные повороты для дрифта.

### Интерактивные разрушаемые объекты:
- **Красные взрывоопасные бочки**: Взрываются от тарана (>4 м/с) или выстрелов, нанося 180 ед. AoE-урона зомби в радиусе 8.5 м. Авто-респавн через 25 с.
- **Деревянные ящики снабжения**: Раскалываются при ударе на щепки, выбрасывая 15-30 шестеренок или ремонтные аптечки (+20 HP). Авто-респавн через 35 с.

## 💡 Система освещения и графики

- **ACES Filmic Tone Mapping** и сбалансированная экспозиция.
- **Двухкомпонентный Hemisphere Ambient Light**: теплый песчаный свет апокалиптического неба сверху и землисто-коричневый отсвет снизу.
- **Golden Sun Directional Light** с мягкими тенями (`PCFSoftShadowMap`), оптимизированными `normalBias` и `bias` для устранения артефактов.
- **Прожекторные стадионные вышки (Floodlight Towers)** по периметру арены с направленными спотлайтами и объемными конусами света.
- **Динамические фары автомобилей**: реальные конусы света (`SpotLight`) и объемные лучи пыли, освещающие зомби и дорогу.
- **Интерактивные задние фонари**: яркая вспышка стоп-сигналов и красная подсветка при торможении и дрифте.
- **Динамический свет нитро**: бирюзовое свечение под днищем и за выхлопными трубами во время ускорения.
- **Система динамических вспышек (DynamicLightManager)**: пул точечных источников света без аллокаций в цикле 60 FPS для выстрелов минигана, огнемета, взрывов ракет, ударов босса и сбора ресурсов.
